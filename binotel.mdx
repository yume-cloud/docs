**Об интеграции**

Интеграция с Binotel переносит телефонию компании внутрь Yume: звонки сотрудников попадают в систему сами, сопоставляются с клиентами по номеру телефона и собираются в дашборд, историю и записи разговоров. Менеджер видит, кто и когда звонил, что из этого пропущено и как звучал разговор, — не выходя из карточки клиента.

**Как работает интеграция**

1. **Звонки приходят сами.** Раз в пять минут Yume забирает у Binotel новые входящие и исходящие звонки. При подключении подтягивается история за последние девяносто дней.
2. **Мгновенная доставка по вебхуку.** Если передать в поддержку Binotel адрес вебхука со страницы интеграции, завершённые звонки будут появляться в Yume сразу, не дожидаясь очередной синхронизации.
3. **Сопоставление с клиентами.** Номер звонка сверяется с телефонами клиентов компании — целиком или по последним девяти цифрам. Совпавший звонок получает карточку клиента со ссылкой, а у клиента появляется вкладка **«Звонки»**.
4. **Записи по запросу.** Запись разговора проигрывается прямо в строке истории. Ссылку на файл Yume запрашивает у Binotel в момент нажатия — она действует пятнадцать минут и поэтому не хранится.

**Что вы получаете**

- **Дашборд** за выбранный период: всего звонков, входящие и исходящие, отвечено (с долей) и пропущено, среднее ожидание, средний и суммарный разговор, уникальные номера; график звонков по дням; последние пропущенные; таблица по сотрудникам с переходом в их звонки.
- **История звонков** с фильтрами по периоду, направлению, статусу и сотруднику, поиском по номеру, имени клиента или сотрудника и настраиваемыми столбцами; на телефоне список бесконечный.
- **Вкладку «Звонки» в карточке клиента** — все его разговоры с записями и ссылкой «Все звонки» в общую историю.
- **Раздел Binotel в мобильном меню** — дашборд и история доступны с телефона.

<Note>
Кнопка **«Позвонить»** в карточке клиента работает через ту же интеграцию: Yume просит Binotel соединить внутренний номер сотрудника с номером клиента.
</Note>

**Инструкция по подключению**

<Steps>
  <Step title="Получите ключ и секрет REST API в Binotel">
    Напишите в поддержку Binotel и запросите доступ к REST API для вашей компании: вам выдадут **ключ** (key) и **секрет** (secret).
  </Step>
  <Step title="Подключите интеграцию в Yume">
    Откройте **Интеграции → Binotel** и нажмите **«Подключить интеграцию»**. Введите ключ и секрет. Yume сразу проверит их у Binotel: неверная пара, отключённая на стороне Binotel компания или недоступное API отклоняются в этот же момент, а не при первой синхронизации.
  </Step>
  <Step title="Передайте адрес вебхука в Binotel">
    После подключения на странице интеграции появится блок **«Адрес вебхука»** с кнопкой копирования. Передайте этот адрес в поддержку Binotel для метода **API CALL COMPLETED** — тогда завершённые звонки будут приходить в Yume мгновенно. Адрес персональный для вашей компании: не публикуйте его.
  </Step>
  <Step title="Дождитесь загрузки истории">
    Сразу после подключения Yume подгружает список сотрудников Binotel и импортирует историю звонков за девяносто дней — порциями по неделе, с паузами под ограничения Binotel. Пока идёт импорт, дашборд заполняется постепенно.
  </Step>
</Steps>

**Обновление данных**

| Как | Когда |
| --- | --- |
| Периодическая синхронизация | Каждые 5 минут, все подключённые компании |
| Вебхук Binotel | Мгновенно после завершения звонка — если адрес передан в Binotel |
| Кнопка **«Обновить»** на странице интеграции | По требованию, не чаще одного раза в минуту |
| Список сотрудников | Ежедневно ночью и сразу при подключении |

**Статусы звонков**

| Статус в Yume | Что означает |
| --- | --- |
| Отвечен, Переведён, Голосовое сообщение | Разговор состоялся — такие звонки считаются **отвеченными**, по ним доступна запись |
| В разговоре | Звонок ещё идёт; окончательный статус придёт позже |
| Занято, Нет ответа, Отменён, Сбой сети, Канал недоступен, Голосовая почта | Входящий звонок с таким статусом считается **пропущенным** |
| SMS отправляется / доставлено / не доставлено, Факс принят / не принят | Не разговоры: входят в общее число звонков, но не считаются ни отвеченными, ни пропущенными |

**Если что-то пошло не так**

- **Binotel отклонил ключ или секрет.** На странице интеграции появится плашка сбоя с предложением обновить данные подключения; синхронизация остановится, пока подключение не будет отредактировано.
- **Компания отключена на стороне Binotel.** Плашка сообщит об отключении — обратитесь в Binotel.
- **API Binotel временно недоступен.** Синхронизация повторится сама; если сбой затянулся, появится плашка «не удалось синхронизировать звонки».
- **«Запись недоступна».** Binotel хранит записи только для состоявшихся разговоров и не бесконечно; у звонка без записи вместо кнопки воспроизведения стоит прочерк.
