## Что это за раздел?

Раздел **«Документы»** позволяет хранить, отслеживать и автоматически генерировать документы по арендам и клиентам.

Здесь вы можете:

- видеть все созданные договоры и акты
- отслеживать статус подписания
- создавать документы из шаблонов с автозаполнением данных

Раздел состоит из двух вкладок: **Быстрый поиск** и **Генерация документов**.

## Как открыть раздел

В левом меню нажмите:

→ **«Документы»**

## Вкладка: Быстрый поиск

Здесь отображаются все документы, созданные в системе — с их статусами и привязками.

### Фильтры

В верхней части экрана расположены три фильтра:

**Поиск** — поиск по названию документа.

**Период** — фильтрация по дате подписания. Укажите начало и конец периода.

**Способ подписания** — фильтрация по типу подписи:

- Ручное подписание
- SMS подписание
- EGOV подписание

### Статусы документов

Над таблицей находятся три вкладки:

**Все** — показывает все документы без фильтрации.

**Подписано** — только документы, которые подписаны обеими сторонами.

**Ожидает подписание** — документы, ожидающие подписи компании или подписанта.

### Таблица документов

Основная часть экрана — это таблица.

В каждой строке отображается:

- **Документ** — название и ссылка на документ
- **Статус** — текущий статус (например, «Ожидает подписание»)
- **Дата подписания** — дата и время создания/подписания документа
- **Способ подписания** — как именно подписывается документ (ручное, SMS, EGOV)
- **Статус подписания** — отдельно показывает статус для Компании и Подписанта (кружок красный — не подписано, зелёный — подписано)
- **Пользователь** — менеджер, создавший документ
- **Клиент** — клиент, к которому привязан документ
- **Аренда** — ссылка на аренду, к которой относится документ

## Вкладка: Генерация документов

Здесь находятся два инструмента: управление шаблонами и созданными документами.

### Подвкладка: Шаблоны

Шаблоны — это заготовки документов (договор аренды, акт приема-передачи и другие), из которых система автоматически формирует документы.

В таблице отображается:

- **Название** — имя шаблона
- **Пункт проката** — к какому пункту привязан шаблон (если применимо)
- **Создано** — дата и время создания
- **Обновлено** — дата последнего редактирования
- **Статус** — «Обязательный» означает, что шаблон используется при каждой аренде автоматически

Чтобы добавить новый шаблон, нажмите:

→ **«\+ Добавить»** (в правом верхнем углу)

Чтобы отредактировать существующий шаблон, нажмите на иконку карандаша в строке нужного шаблона.

### Подвкладка: Созданные Документы

Здесь хранятся все документы, сгенерированные вручную (не через аренду).

В таблице отображается:

- **Название** — имя документа
- **Кем создан** — пользователь, который создал документ
- **Дата добавления** — когда документ был создан

Для поиска документа используйте строку поиска в верхней части.

Чтобы создать новый документ вручную, нажмите:

→ **«\+ Создать»**

## Редактор документа

При открытии шаблона или создании нового документа открывается встроенный редактор.

### Панель инструментов

Вверху — полноценный текстовый редактор с поддержкой:

- форматирования текста (жирный, курсив, зачёркнутый, подчёркнутый)
- списков, таблиц, изображений
- HTML-редактора (для прямого редактирования кода)
- выбора стиля и размера шрифта

### Правая панель: Переменные для шаблона

Это ключевая функция раздела.

Переменные — это автоматически подставляемые данные из системы. Вместо того чтобы вручную вписывать имя клиента, номер договора или дату — вы один раз вставляете переменную, и система подставляет актуальное значение при каждой генерации.

**Привязать к** — выберите, к чему привязан документ: к **Аренде** или **Клиенту**. От этого зависит набор доступных переменных.

Доступные переменные разделены на группы:

**Общее:**

- ID — номер записи
- Имя менеджера
- Дата, День, Месяц, Год, Время, Дата со временем

**Аренда** — данные по конкретной аренде (номер, даты, суммы и т.д.)

**Клиент** — имя, телефон, документы клиента

**Пункт проката** — название и реквизиты точки

**Инвентарь** — список оборудования в аренде

Чтобы вставить переменную в документ — нажмите **«\+»** рядом с ней. Она появится в тексте в виде выделенного поля.

### Импорт документа

Если у вас уже есть готовый договор в другом формате, нажмите:

→ **«Импорт документа»** (верхний правый угол)

Это позволяет загрузить существующий документ и использовать его как основу для шаблона.

### Сохранение

После редактирования нажмите:

→ **«Сохранить»**

## Как используется в работе

Типичный сценарий:

1. Вы создаёте шаблон договора аренды один раз — вставляете переменные в нужные места.
2. При каждой новой аренде система автоматически генерирует документ с данными конкретного клиента и операции.
3. Документ отправляется клиенту на подписание выбранным способом (ручное, SMS, EGOV).
4. В разделе «Быстрый поиск» вы видите статус подписания по каждому документу.

## Важно понять

Раздел **«Документы»** — это не просто хранилище файлов. Это инструмент автоматизации: один шаблон заменяет ручное заполнение сотен договоров.

Если статус документа показывает «Ожидает подписание» — значит одна из сторон ещё не подписала. Отслеживайте это через фильтр, чтобы не упускать незакрытые договоры.

## Если коротко

1. Создайте шаблон с переменными в разделе «Генерация документов» → «Шаблоны»
2. Привяжите шаблон к арендам
3. Система сама формирует документы при каждой операции
4. Отслеживайте статус подписания через «Быстрый поиск»
