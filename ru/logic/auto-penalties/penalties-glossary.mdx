## Модели и поля

### Автомобиль сервиса автоштрафов

*Автомобиль, известный сервису автоштрафов, по которому подтягиваются штрафы. Идентифицируется уникальным ID во внешнем сервисе.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| ID в сервисе автоштрафов | число | Уникальный идентификатор авто во внешнем сервисе автоштрафов |
| Номер автомобиля | текст | Госномер автомобиля |
| Номер техпаспорта | текст | Номер технического паспорта авто |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата активации | дата/время | Когда авто было активировано для синхронизации |
| Активен | флаг | Включена ли синхронизация штрафов по этому авто |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент появления записи в системе. |
| Дата обновления | дата/время | Момент последнего изменения записи. |

| Поле | Тип | Описание |
| --- | --- | --- |

| Цвет | текст | Цвет статуса в HEX (по умолчанию #ffffff) |

### Сверка с ЕРАП

*По БИН компании-нарушителя и дате его регистрации запрашивается публичный реестр, статусы оплаты проставляются у известных системе штрафов. По одной подзадаче на компанию, с ограничением частоты. Запускается компанией со страницы штрафов или администратором платформы.*

**Запуск со страницы штрафов**

| Поле / ответ | Описание |
| --- | --- |
| Подстановка формы (чтение) | БИН, дата регистрации и название компании-нарушителя, на которую записано больше всего штрафов по машинам компании; пусто, если таких штрафов нет. |
| БИН (запись) | Обязателен, ровно 12 цифр. Неизвестный БИН заводит новую компанию-нарушителя. |
| Дата регистрации БИН (запись) | Обязательна, не в будущем; перезаписывает сохранённую у компании-нарушителя. |
| Начало / конец периода (запись) | Необязательны; пустые строки из фильтров страницы игнорируются; начало позже конца отклоняется. |
| Ответ «запущена» | Идентификатор и БИН компании-нарушителя, время запуска. Ставит окно повторного запуска на 6 часов. |
| Ответ «уже выполняется» | Незавершённая задача сверки этой компании создана меньше часа назад. |
| Ответ «ограничение частоты» | С прошлого запуска прошло меньше 6 часов; в ответе время прошлого запуска. |

**Параметры запроса в реестр**

| Параметр | Описание |
| --- | --- |
| БИН | Из формы на странице штрафов либо из карточки компании-нарушителя при запуске администратором. |
| Дата регистрации БИН | Из формы (сохраняется в карточку) либо из карточки компании-нарушителя. |
| Начало периода | Начало окна сверки; по умолчанию — дата регистрации БИН. |
| Конец периода | Конец окна сверки, сдвинутый на день вперёд: в реестре граница исключающая. |
| Номер страницы и размер | Постраничная выгрузка: 500 записей на страницу, не более 200 страниц. |

**Результат по одной компании**

| Поле | Описание |
| --- | --- |
| Статус | Успешно, ошибка обращения к реестру или пропуск (компания не найдена, БИН или дата не заполнены). |
| Дел получено | Сколько уникальных номеров дел с известным статусом пришло из реестра. |
| Штрафов обновлено | У скольких штрафов изменились признак оплаты, компания или привязка к водителю. |
| Не найдено в системе | Сколько номеров дел из реестра не сопоставились ни с одним штрафом. |
| Уведомлено | Сколько штрафов на машинах запустившей компании попало в уведомление о смене признака оплаты; при запуске администратором — ноль. |

**Уведомление о сверке**

| Поле | Описание |
| --- | --- |
| Тема | «Сверка штрафов с ЕРАП»; каналы — веб, push, Telegram; отключается в настройках уведомлений сотрудника. |
| Текст | «Сверка с ЕРАП по „компания“: оплачено N, снят признак оплаты у M» — только по штрафам, у которых признак оплаты изменился и которые стоят на автомобилях компании. |
| Группировка | По компании: повторные сверки увеличивают счётчик и добавляют строку в общее уведомление «Сверка с ЕРАП обновила штрафы». |
| Доп. данные | Идентификатор, название и БИН компании-нарушителя; число ставших оплаченными и число со снятым признаком. |
| Предупреждение | Отдельное уведомление типа «предупреждение» той же темы: БИН или дата регистрации не заполнены, реестр недоступен. |
| Когда не приходит | Запуск администратором платформы; ни у одного штрафа признак не изменился; реестр вернул пустой ответ. |

**Запись в журнале синхронизации**

| Поле | Описание |
| --- | --- |
| Тип синхронизации | «Сверка с ЕРАП» — отдельный тип рядом с выгрузкой, вебхуком и аутентификацией. |
| Обработано записей | Число компаний, по которым разосланы подзадачи. |
| Сообщение | Окно сверки, число компаний без БИН или даты, число пропущенных дублей БИН. |

### Уведомление о штрафе

*Запись об отправленном клиенту WhatsApp-уведомлении о штрафе. Уникальна по телефону и штрафу; создание ставит фоновую задачу отправки WhatsApp (до трёх повторов с интервалом 5 минут) и системное уведомление сотрудникам.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Телефон | текст | Номер телефона получателя уведомления |
| ID клиента | число | Идентификатор клиента-получателя |
| Компания | связь | Компания, отправившая уведомление |
| Штраф | связь | Штраф, о котором уведомляют |
| Доп. данные | JSON | Дополнительные данные (имя клиента, название компании и т.п.) |

### Задача: рассылка уведомлений о штрафах

*Фоновая задача, которая по свежим штрафам находит подключение авто к компании, покрывающую аренду на момент нарушения и создаёт запись уведомления клиенту. Запускается из синхронизации PDF; окно нарушений — 14 дней от момента запуска, штрафы фильтруются по моменту создания.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Момент запуска синхронизации | дата/время | Точка отсчёта: берутся штрафы, созданные не раньше этого момента; дата нарушения — не старше 14 дней до него |
| Нижняя граница даты нарушения | дата | Момент запуска минус 14 дней; отсекает старые нарушения |
| Отобранные штрафы | список | Штрафы с автомобилем, созданные после момента запуска, с нарушением не старше 14 дней |
| Подключение авто к компании | связь | Подключение по автомобилю штрафа; без него штраф пропускается |
| Компания-арендодатель | связь | Компания, которой принадлежит авто |
| Название компании для сообщения | текст | Из настройки названия компании, иначе имя компании; пустой плейсхолдер игнорируется |
| Единица автопарка компании | связь | Автомобиль в автопарке компании по госномеру авто штрафа |
| Дата и время нарушения | дата/время | Склейка даты и времени нарушения штрафа для поиска покрывающей аренды |
| Покрывающая аренда | связь | Позиция заявки аренды в статусе «в аренде», «превышение», «завершена» или «должник», чей период включает момент нарушения |
| Клиент-арендатор | связь | Клиент из заявки аренды — получатель уведомления |

## Статусы и справочники

### Тип штрафа

Тип штрафа для фильтрации определяется по наличию фото нарушения (в модели не хранится):

- Дорожное нарушение (с фото)
- Прочее (без фото)

### Статус штрафа в ответе реестра ЕРАП

- Оплачен — признак оплаты ставится в «да»
- Не оплачен — признак оплаты ставится в «нет»
- Любое другое значение — пропускается с предупреждением в журнале

### Причины пропуска компании при сверке

- Компания не найдена
- БИН или дата его регистрации не заполнены
- Такой БИН уже сверяется другой записью компании

## Настройки окружения сверки с ЕРАП

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| Адрес реестра | База адресов ЕРАП | `https://erap-public.kgp.kz` |
| Часовой пояс параметров | Смещение, с которым даты уходят в запрос | `+05:00` |
| Подпись клиента | Как система представляется реестру | Имя продукта с контактным адресом |
| Ограничение частоты | Сколько подзадач сверки в минуту выполняет воркер | 20 в минуту |

Окно повторного запуска сверки и ручного обновления штрафов одной компанией — 6 часов; это константа, не настройка окружения.
