Полный перечень полей — в [глоссарии](/ru/logic/auto-penalties/penalties-glossary).

## Что даёт раздел

Компания отмечает свои автомобили, и система начинает собирать по ним штрафы ПДД: реквизиты нарушения, суммы, документы и данные для оплаты. Каждый штраф сопоставляется с арендой и клиентом, у которого машина была в этот момент, а клиент получает сообщение о нарушении.

Видно только своё: список штрафов всегда ограничен машинами вашей компании.

## Подключение автомобилей

Компания выбирает автомобили из своего автопарка — по ним включается слежение за штрафами. Подключённую машину можно отключить в любой момент.

При подключении проверяется, что данные автомобиля пригодны для внешнего сервиса:

| Что проверяется | Требование |
| --- | --- |
| Госномер | Либо 3 цифры + 2–3 буквы + 2 цифры, либо 1 буква + 6 цифр |
| Номер техпаспорта | 2 буквы + 8 цифр |

<Note>
Проверка выполняется только для заполненных полей: если у автомобиля не указан номер или техпаспорт, соответствующая проверка пропускается. Но штрафы приходят с госномером, поэтому машина без номера штрафы получать не будет.
</Note>

<Warning>
Один и тот же автомобиль нельзя подключить дважды. Если подключение не удалось, чаще всего дело в формате номера или техпаспорта либо во временной недоступности внешнего сервиса — попробуйте ещё раз.
</Warning>

## Откуда берутся штрафы

Штрафы приезжают двумя путями:

- **Сами** — внешний сервис присылает новые штрафы по подключённым машинам.
- **По кнопке «Обновить»** — принудительная подгрузка штрафов по всем машинам компании.

<Warning>
Ручное обновление доступно **не чаще одного раза в 3 часа** на компанию. Если окно ещё не прошло, в ответ приходит время последнего запуска. Неудачная попытка тоже закрывает окно на 3 часа.
</Warning>

## Что собирается по каждому штрафу

| Группа данных | Что в неё входит |
| --- | --- |
| Нарушение | Номер протокола, описание, адрес, дата и время нарушения |
| Наказание | Основная мера наказания, орган, выявивший нарушение, сумма штрафа |
| Оплата | Признак «оплачен», дата оплаты, до какого момента действует скидка |
| Реквизиты для оплаты | Код налогового органа, КБК, КНП, название получателя, его IBAN и БИН |
| Документы | PDF протокола и фотографии нарушения |
| Участники | Автомобиль (госномер, техпаспорт), водитель по данным сервиса, компания-владелец |
| Ваши данные | Единица инвентаря, аренда и клиент, к которым отнесён штраф |
| Пометки компании | «Просмотрен» и свой статус штрафа |

<Note>
Всё, что приходит из внешнего сервиса, доступно только для чтения. Изменить в штрафе можно две вещи: отметку «просмотрен» и свой статус.
</Note>

### Как штраф связывается с арендой и клиентом

По моменту нарушения система ищет аренду этой машины, срок которой его покрывает, и подставляет в карточку штрафа номер и статус аренды, а также клиента — имя и телефон.

<Note>
Если ни одна аренда не покрывает момент нарушения (машина стояла свободной, была на обслуживании или нарушение произошло вне аренды), поля аренды и клиента остаются пустыми. Это нормально, а не ошибка.
</Note>

## Список, фильтры и сводка

Список показывает штрафы только по машинам компании; по умолчанию сверху свежие.

| Фильтр | По чему отбирает |
| --- | --- |
| Единица инвентаря | Штрафы по конкретной машине |
| Точка проката | Штрафы по всем машинам точки |
| Аренда, Клиент | Штрафы, попавшие в срок соответствующих аренд |
| Тип штрафа | Дорожное нарушение (с фото) или прочее (без фото) |
| С водителем | Есть ли в штрафе водитель |
| Дата нарушения, Сумма | Диапазоны «от» и «до» |
| Оплачен, Просмотрен | Отметки |
| Свой статус | Конкретный статус, несколько статусов или «без статуса» |

Поиск работает по номеру протокола, описанию и адресу нарушения, госномеру и техпаспорту автомобиля. Сортировать список можно по дате нарушения, сумме, дате появления и номеру протокола.

Над списком — сводка по тому, что попало под фильтры: сколько штрафов всего, сколько оплачено и не оплачено, и те же три величины в деньгах.

## Свои статусы штрафов

Компания может завести собственные статусы (название и цвет) и помечать ими штрафы — например «Передан клиенту», «Оспаривается», «Закрыт».

В выборе доступны и **общие** статусы платформы, и статусы **вашей компании**. Общий статус можно присвоить своему штрафу, но переименовать, перекрасить или удалить его нельзя — он принадлежит платформе, а не компании.

## Сверка оплаты с государственным реестром

Признак «оплачен» приходит из внешнего сервиса и может отставать от действительности. Поэтому оплату можно сверить с публичным государственным реестром ЕРАП — по БИН компании-владельца автомобилей.

| | |
| --- | --- |
| Что нужно | Заполненные БИН компании-владельца и дата его регистрации; без них сверка не выполняется |
| За какой период | По умолчанию вся история — от даты регистрации БИН до сегодняшнего дня |
| Что даёт | У найденных штрафов проставляется «оплачен» или «не оплачен» по данным реестра |
| Что ещё меняется | Штраф, выписанный на юридическое лицо, закрепляется за компанией, а привязка к водителю с него снимается |

Сверка **не создаёт и не удаляет штрафы**: записи реестра, которых нет в системе, пропускаются, а отсутствие штрафа в ответе реестра не считается доказательством, что штрафа не было. Статусы, которых система не знает, тоже пропускаются — оплата по ним не угадывается.

<Note>
Сверка запускается администратором платформы — по одной компании или сразу по всем, у которых заполнены БИН и дата его регистрации. Пустой результат по компании чаще всего означает неверную дату регистрации БИН, а не отсутствие штрафов.
</Note>

## Уведомления

### Клиенту

Клиент получает сообщение в WhatsApp о каждом новом штрафе по машине, которая была у него в аренде.

| | |
| --- | --- |
| Кому | Клиенту-арендатору из вашей заявки, а **не** водителю из данных внешнего сервиса |
| Когда | Как только штраф попал в систему, если нарушению не больше 14 дней |
| Что в сообщении | Обращение по имени, номер автомобиля, дата нарушения, сумма, орган, выявивший нарушение, и название вашей компании — на казахском и русском |
| Что приложено | PDF протокола штрафа |

Сообщение подписано как отправленное ботом: отвечать в этот чат, присылать чеки и подтверждения оплаты бесполезно — ответы никто не читает.

<Note>
На один штраф — одно сообщение с суммой именно этого штрафа, а не общей суммой всех нарушений клиента. Повторно на тот же номер по тому же штрафу сообщение не уйдёт.
</Note>

<Warning>
Рассылку клиентам можно выключить в настройках компании. Пока настройка не тронута, рассылка считается включённой.
</Warning>

### Сотрудникам

Одновременно в кабинете появляется внутреннее уведомление «получен штраф» с номером машины, датой нарушения и суммой. Оно приходит в веб-интерфейс, в push и в Telegram, а к нему прикладываются данные о штрафе, машине, органе и клиенте — чтобы сотрудник видел, о чём речь, не открывая карточку.

### Когда уведомление клиенту не уходит

- Автомобиль не подключён к слежению за штрафами.
- Госномер в штрафе не совпадает с номером машины в вашем автопарке.
- В момент нарушения машина не была в аренде.
- У аренды не указан клиент.
- Нарушению больше 14 дней — даже если сам штраф пришёл только что.
- Рассылка клиентам выключена в настройках компании.
- PDF протокола ещё не скачан — сообщение уйдёт после того, как документ появится.

## Что важно знать

- Окно в 14 дней для уведомлений фиксировано и в настройках не меняется.
- Тип штрафа (дорожное нарушение или прочее) определяется наличием фотографий и в самом штрафе не хранится.
- Ограничение в 3 часа на ручное обновление действует на всю компанию, а не на отдельного сотрудника.
- Если один и тот же автомобиль подключён сразу к нескольким компаниям, уведомление о штрафе получит только одна из них.
