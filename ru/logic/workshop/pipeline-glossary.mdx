## Понятия

Сквозные механизмы (сигналы), которые поддерживают порядок и денежные итоги в воронке.

| Понятие | Значение |
| --- | --- |
| Переупорядочивание этапов | При сохранении этапа сдвигает порядок остальных этапов, освобождая позицию. |
| Переупорядочивание задач | При сохранении задачи сдвигает порядок остальных задач того же статуса. |
| Пересчёт стоимости задачи | При сохранении задачи пересчитывает стоимость расходников, услуг, оплаченную сумму и итоговую стоимость, затем обновляет метрику прибыли; выходит без изменений, если суммы не поменялись. |
| Автоперевод состояния инвентаря | При сохранении задачи переводит связанный инвентарь в целевое состояние этапа; срабатывает только если у этапа задано целевое состояние и оно отличается от текущего. |

## Модели и поля

### Воронка мастерской

*Именованная воронка, группирующая этапы ремонтных задач. При создании автоматически получает 4 дефолтных этапа.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название воронки. |
| Компания | связь | Владелец записи (изоляция по компании). |
| Создана | дата/время | Момент создания. |
| Обновлена | дата/время | Момент последнего изменения. |

### Этап воронки

*Колонка kanban-воронки, через которую движутся задачи; несёт цвет, порядок и целевое состояние инвентаря. При попадании задачи на этап инвентарь переводится в целевое состояние.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название этапа. |
| Статус | перечисление | Статус задачи, соответствующий этапу. |
| Цвет | текст | Цвет колонки в HEX (#ffffff). |

**Порядок**

| Поле | Тип | Описание |
| --- | --- | --- |
| Порядок | число | Позиция этапа в воронке; при вставке остальные сдвигаются. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Доп. данные | объект | Произвольные данные. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Воронка | связь | Воронка, которой принадлежит этап. |
| Целевое состояние инвентаря | связь | Состояние, в которое переводится инвентарь при попадании задачи на этап. |
| Компания | связь | Владелец записи (изоляция по компании). |

### Ремонтная задача

*Задача мастерской (единица ремонта/сервиса), движущаяся по этапам воронки; агрегирует стоимость, оплаты и прибыль. Стоимости пересчитываются автоматически по расходникам, услугам и платежам.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название задачи (обязательно). |
| Номер | текст | Номер задачи. |
| Тип задачи | перечисление | Внутренняя или внешняя. |

**Статус**

| Поле | Тип | Описание |
| --- | --- | --- |
| Статус | перечисление | Текущий статус задачи. |
| Направление операции | перечисление | Тип проводки; по умолчанию расход. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Этап | связь | Этап воронки, на котором находится задача. |
| Автор | связь | Пользователь, создавший задачу (только чтение). |
| Исполнитель | связь | Пользователь-исполнитель; при первой смене статуса подставляется текущий пользователь. |
| Клиент | связь | Клиент, для которого выполняется задача. |
| Заявка на аренду | связь | Связанная аренда. |
| Позиция заявки | связь | Конкретная позиция инвентаря в аренде. |
| Единица инвентаря | связь | Ремонтируемая единица инвентаря; её состояние меняется по этапу. |
| Точка проката | связь | Точка проката (обязательно). |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Стоимость | число (2 знака) | Итоговая стоимость = расходники + услуги (вычисляется, только чтение). |
| Стоимость услуг | число (2 знака) | Сумма по услугам (вычисляется, только чтение). |
| Стоимость расходников | число (2 знака) | Сумма по расходникам (вычисляется, только чтение). |
| Оплачено | число (2 знака) | Сумма платежей по модулю (вычисляется, только чтение). |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Завершена в | дата/время | Момент завершения; проставляется автоматически при переходе в статус «Завершена». |
| Порядок сортировки | число | Позиция задачи внутри статуса; при вставке остальные сдвигаются. |
| Создана | дата/время | Момент создания (можно переопределить при создании). |
| Обновлена | дата/время | Момент последнего изменения. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Доп. данные | объект | Произвольные данные. |
| Компания | связь | Владелец записи (изоляция по компании). |

### Сводка по задачам

*Сводные агрегаты по отфильтрованному списку задач, отдаваемые вместе с постраничным ответом. Агрегаты считаются по всему отфильтрованному набору, а не по текущей странице.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Активные | число | Кол-во задач в статусах «Новая» и «В работе». |
| Завершённые | число | Кол-во задач в статусе «Завершена». |
| Сумма завершённых | число (2 знака) | Суммарная стоимость завершённых задач. |
| Общая сумма | число (2 знака) | Сумма стоимостей всех задач, кроме архивных. |
| Средняя длительность | интервал | Среднее время от создания до завершения по завершённым задачам. |
| Последняя задача | дата/время | Дата создания самой свежей неархивной задачи. |

### Фильтр задач

*Набор фильтров списка задач, включая статус оплаты, наличие расходника/услуги и стандартные поля.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Статус оплаты | текст | Оплачено / частично / не оплачено / без суммы. |
| Расходник | число | Задачи, содержащие указанный расходник. |
| Услуга | число | Задачи, содержащие указанную услугу. |
