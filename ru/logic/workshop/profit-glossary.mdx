## Модели и поля

### Пересчёт прибыли по задаче мастерской (Celery-задача)

*Фоновая задача, принимает идентификатор задачи мастерской и вызывает метод агрегации прибыли для пересчёта строк прибыли по этой задаче. Тонкая обёртка: тело логики находится в классовом методе агрегации.*

| Поле | Тип | Описание |
| --- | --- | --- |
| ID задачи мастерской | число | Идентификатор задачи мастерской, для которой пересчитывается прибыль. |

### Метод агрегации прибыли задачи

*Классовый метод: строит записи прибыли только для завершённых задач (есть отметка о завершении), по ключу «расходник, услуга, дата» сравнивает существующие строки с нужными и применяет вставку, обновление или удаление групповыми операциями.*

Если задача не найдена или отметка о завершении пуста — метод завершается без изменений. Дата берётся из момента завершения задачи; расходники и услуги задачи дают отдельные строки прибыли, где ожидаемая, прогнозная и заработанная суммы равны цене позиции.

| Поле | Тип | Описание |
| --- | --- | --- |
| ID задачи мастерской | число | Идентификатор задачи мастерской для пересчёта. |
