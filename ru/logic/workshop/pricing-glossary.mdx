## Модели и поля

### Ремонтная задача

*Задача мастерской (единица ремонта или сервиса), движущаяся по этапам воронки; агрегирует стоимость, оплаты и прибыль. Стоимости пересчитываются автоматически по расходникам, услугам и платежам.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название задачи (обязательно). |
| Номер | текст | Номер задачи. |
| Тип задачи | перечисление | Внутренняя или внешняя. |

**Статус**

| Поле | Тип | Описание |
| --- | --- | --- |
| Статус | перечисление | Текущий статус задачи. |
| Направление операции | перечисление | Тип проводки; по умолчанию расход. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Этап | связь | Этап воронки, на котором находится задача. |
| Автор | связь | Пользователь, создавший задачу (только чтение). |
| Исполнитель | связь | Пользователь-исполнитель; при первой смене статуса подставляется текущий пользователь. |
| Клиент | связь | Клиент, для которого выполняется задача. |
| Заявка на аренду | связь | Связанная аренда. |
| Позиция заявки | связь | Конкретная позиция инвентаря в аренде. |
| Единица инвентаря | связь | Ремонтируемая единица инвентаря; её состояние меняется по этапу. |
| Точка проката | связь | Точка проката (обязательно). |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Стоимость | число (2 знака) | Итоговая стоимость = расходники + услуги (вычисляется, только чтение). |
| Стоимость услуг | число (2 знака) | Сумма по услугам (вычисляется, только чтение). |
| Стоимость расходников | число (2 знака) | Сумма по расходникам (вычисляется, только чтение). |
| Оплачено | число (2 знака) | Сумма платежей по модулю (вычисляется, только чтение). |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Завершена в | дата/время | Момент завершения; проставляется автоматически при переходе в статус «Завершена». |
| Порядок сортировки | число | Позиция задачи внутри статуса; при вставке остальные сдвигаются. |
| Создана | дата/время | Момент создания (можно переопределить при создании). |
| Обновлена | дата/время | Момент последнего изменения. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Доп. данные | объект | Произвольные данные. |
| Компания | связь | Владелец записи (изоляция по компании). |

### Ресурс задачи мастерской

*Привязка складского ресурса или инвентаря к конкретной ремонтной задаче с количеством, ценой и статусом подтверждения. Уникальность обеспечивается парой «компания + единица инвентаря + задача» при заполненной единице; списание и возврат остатка завязаны на сохранение и удаление позиции.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Задача | связь | Ремонтная задача, к которой привязан ресурс. |
| Складской ресурс | связь | Списываемый со склада расходник (может отсутствовать). |
| Единица инвентаря | связь | Привязанная единица инвентаря. |
| Группа инвентаря | связь | Привязанная группа инвентаря. |
| Тариф | связь | Тариф инвентаря; обнуляется при удалении тарифа. |

**Количество**

| Поле | Тип | Описание |
| --- | --- | --- |
| Количество | число (2 знака) | Списываемое или возвращаемое количество ресурса. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена | число (2 знака) | Стоимость позиции в задаче. |

**Подтверждение**

| Поле | Тип | Описание |
| --- | --- | --- |
| Подтверждён | флаг | Признак подтверждения позиции. |
| Кем подтверждён | связь | Пользователь, подтвердивший позицию. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Доп. данные | словарь (JSON) | Произвольные дополнительные данные. |
| Создан | дата/время | Момент создания. |
| Обновлён | дата/время | Момент последнего изменения. |
| Компания | связь | Арендатор-владелец записи. |

### Услуга задачи мастерской

*Услуга из справочника, добавленная к ремонтной задаче, со снимком тарифа и итоговой ценой; участвует в расчёте стоимости задачи. При каждом сохранении или удалении стоимость связанной задачи пересчитывается.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Ремонтная задача | связь | Задача мастерской, к которой привязана услуга; при удалении задачи услуга удаляется. Только для чтения в API. |
| Услуга | связь | Услуга из справочника. |
| Тариф услуги | связь | Выбранный тариф услуги; может быть пустым, при удалении тарифа обнуляется. |
| Компания | связь | Компания-владелец записи; проставляется автоматически. |

**Деньги и тариф**

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена по тарифу | число (2 знака) | Снимок цены выбранного тарифа на момент добавления. |
| Длительность по тарифу | длительность | Снимок срока выполнения услуги по тарифу; по умолчанию 1 день. |
| Итоговая цена услуги | число (2 знака) | Фактическая стоимость услуги в задаче; суммируется в общую стоимость задачи. |

**Вложения**

| Поле | Тип | Описание |
| --- | --- | --- |
| Изображения | связь | Прикреплённые изображения (обобщённая связь). |
| Файлы | связь | Прикреплённые файлы (обобщённая связь). |
| Комментарии | связь | Комментарии (обобщённая связь). |
| Ссылки | связь | Прикреплённые ссылки (обобщённая связь). |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дополнительные данные | объект JSON | Произвольные дополнительные поля. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Проставляется автоматически при создании. |
| Дата обновления | дата/время | Обновляется автоматически при каждом сохранении. |

**Оплата (транзакция)** — см. [канонический глоссарий](/ru/logic/finances/payments-glossary#оплата).

**Направление операции** — см. [канонический глоссарий](/ru/logic/metrics/finances-glossary#направление-операции).

### Сводка по задачам

*Сводные агрегаты по отфильтрованному списку задач, отдаваемые вместе с постраничным ответом. Агрегаты считаются по всему отфильтрованному набору, а не по текущей странице.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Активные | число | Количество задач в статусах «Новая» и «В работе». |
| Завершённые | число | Количество задач в статусе «Завершена». |
| Сумма завершённых | число (2 знака) | Суммарная стоимость завершённых задач. |
| Общая сумма | число (2 знака) | Сумма стоимостей всех задач, кроме архивных. |
| Средняя длительность | интервал | Среднее время от создания до завершения по завершённым задачам. |
| Последняя задача | дата/время | Дата создания самой свежей неархивной задачи. |

### Фильтр по статусу оплаты

*Вычисляемый фильтр списка задач по соотношению оплаченной суммы и итоговой стоимости (не хранимое поле).*

| Поле | Тип | Описание |
| --- | --- | --- |
| Оплачено | фильтр | Оплачено не меньше стоимости при стоимости больше нуля. |
| Оплачено частично | фильтр | Стоимость больше нуля и оплачено не равно стоимости. |
| Не оплачено | фильтр | Оплачено равно нулю. |
| Без стоимости | фильтр | Стоимость равна нулю. |

## Статусы и справочники

### Статус ремонтной задачи

Определяет колонку задачи в воронке и её участие в сводных метриках.

- Новая
- В работе
- Завершена
- Архив

### Тип ремонтной задачи

Различает внутренние и внешние ремонтные задачи.

- Внутренняя
- Внешняя
