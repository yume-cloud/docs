Справочник к странице [«Автоматическое отслеживание изменений»](/ru/logic/audit/tracking).

## Понятия

| Понятие | Значение |
| --- | --- |
| Наблюдение за справочником | Подписка журнала на сохранение и удаление записей одного справочника. Даёт события «создана», «обновлена» и «удалена» без участия кода бизнес-процессов. |
| Снимок до сохранения | Текущее состояние записи, прочитанное из базы перед сохранением. Сравнение нового состояния с ним и даёт перечень изменившихся полей. Если записи в базе нет, сохранение считается созданием. |
| Производное поле | Поле, значение которого система вычисляет сама: итоговые суммы, оплаченные суммы, суммы скидок и штрафов, длительность аренды, баланс счёта, поисковый индекс, номер договора, компания и отметки времени. Из наблюдения исключено. |
| Перечень отслеживаемых полей | Сужение наблюдения до нескольких полей вместо всех. Применяется к клиенту, документу и шаблону. |
| Отслеживание без создания | Режим, в котором фиксируются только изменения записи, а её создание — нет. Применяется к настройкам компании. |
| Родительский объект | Владелец записи, к которому автоматически прикрепляется её событие: аренда для своих дочерних записей, платёж для проводки, продажа для своей позиции. |
| Связанный объект | Участник действия, прикрепляемый к событию для фильтрации: клиент, точка проката, единица инвентаря, группа, категория, скидка, счёт, статья, способ оплаты, шаблон, подписант. |
| Фильтрация дополнительных полей клиента | Сравнение только тех дополнительных полей, которые компания показывает на момент записи события. Значения снятых с формы полей в журнал не попадают. |
| Сводная строка массовой операции | Одно событие на всю массовую операцию с количеством затронутых записей вместо построчного сравнения. Нужна потому, что массовая запись в базу не вызывает наблюдения. |

| Раздел | Справочник | Особенности наблюдения |
| --- | --- | --- |
| Аренда | Аренда | Связанные: клиент, точка проката, скидка. Исключены признак активности и блок дополнительных данных |
| Аренда | Позиция аренды | Родитель — аренда. Связанные: единица инвентаря, группа, клиент |
| Аренда | Сервис в аренде | Родитель — аренда |
| Аренда | Залог | Родитель — аренда |
| Аренда | Доставка | Родитель — аренда |
| Аренда | Штраф | Родитель — аренда |
| Аренда | Скидка в аренде | Родитель — аренда |
| Аренда | Приостановка аренды | Родитель — аренда |
| Аренда | Вознаграждение агента | Родитель — аренда |
| Инвентарь | Инвентарь | Связанные: группа, категория, точка проката |
| Инвентарь | Группа инвентаря | Связанные: категория, скидка |
| Инвентарь | Комплект | — |
| Инвентарь | Тариф | Связанные: единица инвентаря, группа |
| Инвентарь | Услуга | — |
| Инвентарь | Деактивация | Связанные: шестнадцать справочников, которые запись может деактивировать |
| Инвентарь | Продажа | Связанные: клиент, точка проката, скидка |
| Инвентарь | Позиция продажи | Родитель — продажа. Связанные: единица инвентаря, группа |
| Клиент | Клиент | Перечень отслеживаемых полей; дополнительные поля фильтруются по настройкам компании. Связанные: скидка, источник привлечения |
| Клиент | Документ физического лица | Номер документа и ИИН маскируются |
| Клиент | Документ юридического лица | БИН и расчётный счёт маскируются |
| Финансы | Платёж | Родители: аренда, продажа, заказ мастерской, обслуживание, залог, штраф. Связанные: счёт, статья, способ оплаты |
| Финансы | Проводка | Родитель — платёж. Связанные: единица инвентаря, контрагент |
| Финансы | Счёт | Баланс исключён как производный |
| Финансы | Способ оплаты | — |
| Финансы | Статья | — |
| Финансы | Скидка | — |
| Сотрудники | Доступ сотрудника | Связанные: пользователь, роль доступа |
| Сотрудники | Роль доступа | Отслеживается только название |
| Документ | Документ | Перечень полей: название, признак подписания, тип, источник, шаблон, подписант |
| Документ | Шаблон | Перечень полей: название, статус, порядок, тип содержимого, точки, формат |
| Настройки | Настройки | Только изменения, без создания |
| Настройки | Дополнительное поле | В журнале отображается как «Кастомное поле» |
| Настройки | Настройка таблицы | — |
| Настройки | Наименование сущности | В журнале отображается как «Метка» |
| Настройки | Компания | Реквизиты и параметры самой компании |
| Интеграция | Подключение интеграции | Связанное: интеграция. Ключи маскируются |
| Интеграция | Аккаунт Wialon | Токен маскируется |
| Подписка | Счёт на оплату | Связанное: карта |
| Подписка | Лимит | Связанное: компания. Текущее значение счётчика исключено |

## Исключённые производные поля

| Группа | Что входит |
| --- | --- |
| Итоговые суммы аренды | Общая сумма, сумма по инвентарю, сумма по услугам, суммы со скидкой, налог, начисленная сумма |
| Оплаченные суммы | Оплачено по аренде и по позиции |
| Суммы скидок | Сумма скидки, произвольная скидка, скидка по услугам |
| Суммы штрафов | Общая сумма штрафов и автоматически начисленная часть |
| Длительность | Расчётная и начальная длительность аренды |
| Баланс | Баланс счёта |
| Служебное | Поисковый индекс, номер договора клиента, компания, дата создания, дата изменения |
