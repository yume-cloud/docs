Справочник к странице [«Просмотр, фильтры и доступ»](/ru/logic/audit/access).

## Понятия

| Понятие | Значение |
| --- | --- |
| Панель истории | Всплывающая панель из бокового меню со лентой событий от новых к старым, фильтрами и подгрузкой по прокрутке порциями по 30 событий. |
| Свёрнутая строка | Одна линия ленты: значок раздела, название действия, подпись объекта, инициатор, время. |
| Раскрытая строка | Развёрнутое событие: инициатор с типом, адрес, плашки объектов, построчное сравнение изменённых полей. |
| Отметка разрушающего действия | Красная полоса слева у действий, которые удаляют, отменяют, отзывают, отключают или завершились отказом. Определяется по названию действия. |
| Область поиска | Подпись объекта и подпись инициатора. Содержимое изменений в поиск не входит. |
| Курсорная выдача | Постраничная выдача по метке продолжения, а не по номеру страницы. Новые события не сдвигают уже показанные. |
| Выборка по объекту | Отбор событий по виду объекта и его номеру, при необходимости с уточнением роли. Так собирается история одной аренды или одной единицы. |
| Выборка по запросу | Отбор всех событий одного обращения к системе по идентификатору запроса. |
| Устранение дублей | Отсечение повторов, возникающих при отборе по объекту, когда событию подходит сразу несколько его объектов. |
| Плашка объекта | Ссылка на карточку затронутого объекта в раскрытой строке. Построена для шести видов объектов; остальные виды не показываются. |
| Право просмотра журнала | Право роли на чтение журнала. Без него кнопка истории не показывается, а запрос получает отказ. |
| Ограничение компанией | Безусловное сужение выборки до текущей компании, независимо от прав пользователя. |
| Справочник значений фильтров | Отдельная выдача трёх наборов для выпадающих списков: действия, разделы и типы инициаторов с человеческими названиями на языке запроса. |
| Служебный экран платформы | Экран журнала в административной панели, доступный только суперпользователям и работающий исключительно на чтение. |

## Фильтры панели

| Фильтр | Тип | Описание |
| --- | --- | --- |
| Поиск | текст | Совпадение по подписи объекта или подписи инициатора |
| Все разделы | выбор из списка | Один из одиннадцати разделов журнала |
| Тип инициатора | выбор из списка | Один из шести типов инициатора |
| Все действия | выбор из списка | Одно или несколько действий из каталога; список ищется по названию |
| Сотрудник | выбор из списка | Конкретный инициатор из сотрудников компании |
| Период | диапазон дат | Начало и конец периода по моменту события |

## Дополнительные условия отбора

| Условие | Описание |
| --- | --- |
| Вид объекта | Ограничение событиями, затронувшими объекты одного вида |
| Номер объекта | Ограничение событиями конкретной записи |
| Роль объекта | Уточнение: основной, родительский или связанный |
| Идентификатор запроса | Все события одного обращения к системе |

## Права

| Условие | Требование |
| --- | --- |
| Авторизация | Запрос должен быть авторизован |
| Принадлежность к компании | Пользователь должен быть сотрудником компании, в которой выполняется запрос |
| Право просмотра | У роли должно быть право чтения журнала |
| Изменение и удаление | Не предусмотрено ни для одной роли |
| Служебный экран платформы | Только суперпользователь; все операции записи отключены |
