Справочник к странице [«Подписи в журнале»](/ru/logic/audit/labels).

## Понятия

| Понятие | Значение |
| --- | --- |
| Подпись на момент события | Название, сохранённое в самом событии и больше не меняющееся: подпись инициатора, подпись объекта, подписи значений с фиксированным набором, названия связанных объектов. |
| Подпись при чтении | Название, подбираемое каждый раз при выдаче события: название действия, название поля, название вида объекта, значения статуса аренды. Следует настройкам компании и языку запроса. |
| Готовая формулировка действия | Заданная в системе фраза события. Переименованиям компании не подчиняется, потому что согласована по роду. |
| Складное название действия | Название из имени справочника и слова «запись создана», «запись обновлена» или «запись удалена». Имя справочника подчиняется переименованиям компании. |
| Название поля | Человеческое название, заданное для поля вручную. Учитывается только заданное вручную значение — производное от имени колонки названием не считается. |
| Переименование сущности | Собственное название системной сущности, заданное компанией. Перекрывает системное название в метке объекта, складном названии действия, названии поля-ссылки и значениях статуса аренды. |
| Правило выбора наименования | Строка компании перекрывает общую строку для её типа бизнеса; дополнительно отбирается строка нужного языка. |
| Поле, сохраняющее своё название | Поле-ссылка, чей смысл уже сущности, на которую оно ссылается: точка возврата в аренде, заказ мастерской в платеже. Переименование к нему не применяется. |
| Проверка совпадения названий | Контроль того, что после подстановки переименований у двух полей одного справочника не получилось одинаковых названий. |
| Подстановка на стороне интерфейса | Восстановление названия связанного объекта из справочников, загруженных интерфейсом, для старых событий, записанных до сохранения таких названий в самой строке. |

## Переименуемые сущности

| Сущность | Пример собственного названия |
| --- | --- |
| Инвентарь | Автомобиль, самокат |
| Группа инвентаря | Модель, товар |
| Комплект | Набор |
| Услуга | Опция |
| Точка проката | Филиал, станция |
| Клиент | Водитель, гость |
| Залог | Депозит |
| Мастерская | СТО, заказ-наряд |

## Переименуемые статусы аренды

| Статус | Смысл |
| --- | --- |
| Запрос | Заявка ещё не подтверждена |
| Забронировано | Аренда забронирована |
| В прокате | Инвентарь выдан |
| Отменено | Аренда отменена |
| Завершено | Аренда закрыта |
| Должник | По аренде есть непогашенный долг |
| Просрочено | Срок возврата прошёл |

## Что переименования не затрагивают

| Подпись | Почему |
| --- | --- |
| Готовые формулировки действий | Законченные фразы, согласованные по роду; подстановка существительного нарушила бы согласование |
| Названия разделов журнала | Раздел — область системы, а не переименуемая сущность |
| Подписи, сохранённые в момент события | Уже зафиксированы и не пересчитываются |
