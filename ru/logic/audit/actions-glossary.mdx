Справочник к странице [«Каталог событий»](/ru/logic/audit/actions).

## Понятия

| Понятие | Значение |
| --- | --- |
| Заранее заданная формулировка | Готовая фраза события: «Аренда выдана», «Залог возвращён», «Неудачный вход». Задана в системе, переводится вместе с интерфейсом и образует список значений фильтра «Все действия». Всего таких формулировок 134. |
| Складная формулировка | Название, собранное из имени справочника и слова «запись создана», «запись обновлена» или «запись удалена»: «Позиция аренды: запись обновлена». Используется, когда готовой фразы для события нет. |
| Состав фильтра действий | Список значений выпадающего фильтра. Состоит только из заранее заданных формулировок, складные в него не попадают. |
| Смысловое событие | Событие, записанное кодом бизнес-процесса под собственным именем. Может поглотить автоматическое сравнение полей того же объекта. |
| Дополнительные данные события | Свободный набор значений, специфичный для конкретного действия: количество затронутых записей, сумма, код, причина отказа, статус до и после перехода. |
| Формулировка без события | Заранее заданная формулировка, которую не записывает ни один сценарий. Присутствует в фильтре, но никогда не встречается в журнале. Таких шесть. |

## Дополнительные данные по типам событий

| Тип события | Что попадает в дополнительные данные |
| --- | --- |
| Переход статуса аренды | Статус до перехода и статус после |
| Массовая операция | Количество затронутых записей и параметры вызова |
| Списание инвентаря | Способ списания, комментарий и количества по единицам, группам, услугам и комплектам |
| Неудачный вход | Переданный логин и класс причины отказа |
| Вход от имени пользователя | Разовый токен входа и компания |
| Проводка перенесена | Вид операции, сумма и счёт |
| Оплата по публичной ссылке | Код ссылки и сумма |
| Удаление записи | Отметка о том, что запись удалена |
| Чёрный список | Отметка о совпадении, признак общего списка и перечень компаний, которые его видят |

## Распределение действий по разделам

| Раздел | Число событий в каталоге |
| --- | --- |
| Аренда | 31 (включая доставку) |
| Инвентарь | 13 |
| Клиент | 8 |
| Финансы | 17 |
| Доступ | 12 |
| Сотрудники | 9 |
| Настройки | 4 |
| Интеграция | 3 |
| Документ | 8 |
| Подписка | 8 |
| Витрина | 15 |

Всего в каталоге 128 событий. Ещё шесть формулировок заданы в системе, попадают в фильтр, но не возникают ни при
каком действии и в таблице выше не учтены.

<Note>
Раздел события задаётся местом, откуда оно записано, а не префиксом его имени. Поэтому списание бонусов клиентом
относится к разделу «Витрина», хотя описывает ту же операцию, что и «Бонусы в аренде применены» из раздела «Аренда», а
добавление клиента в чёрный список относится к разделу «Клиент», хотя выполняется автоматически.
</Note>
