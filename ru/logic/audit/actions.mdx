Полный перечень понятий — в [глоссарии каталога событий](/ru/logic/audit/actions-glossary).

У журнала два способа назвать строку. **Заранее заданная формулировка** — готовая фраза вида «Аренда выдана» или
«Залог возвращён»; такие названия перечислены на этой странице и одновременно образуют список значений фильтра
«Все действия». **Складная формулировка** используется, когда готовой фразы нет: журнал соединяет название справочника
со словом «запись создана», «запись обновлена» или «запись удалена» и получает «Позиция аренды: запись обновлена».

<Note>
Складные названия в фильтре «Все действия» не показываются — список фильтра составлен только из заранее заданных
формулировок. Такие события в журнале видны, но выбрать их из выпадающего списка нельзя.
</Note>

## Аренда

| Событие | Когда возникает |
| --- | --- |
| Аренда создана | Создание заявки |
| Аренда изменена | Правка полей аренды, за которой не стоит отдельного смыслового события |
| Аренда удалена | Удаление аренды |
| Аренда забронирована | Переход аренды в бронь |
| Аренда собрана | Сборка аренды перед выдачей |
| Аренда выдана | Выдача инвентаря клиенту |
| Аренда принята | Приёмка инвентаря от клиента |
| Аренда отменена | Отмена аренды |
| Аренда архивирована | Архивация аренды — как переходом статуса, так и отдельным действием |
| Действие по аренде отменено | Откат последнего действия в ленте аренды |
| Срок аренды изменён | Изменение даты начала или возврата |
| Аренда приостановлена | Начало простоя |
| Аренда возобновлена | Окончание простоя |
| Скидка в аренде применена | Применение скидки к аренде |
| Скидка в аренде изменена | Изменение уже применённой скидки |
| Скидка в аренде снята | Снятие скидки |
| Бонусы в аренде применены | Списание бонусов клиента в оплату аренды сотрудником |
| Бонусы в аренде отменены | Возврат ранее применённых бонусов |
| Залог принят | Оформление залога по аренде |
| Залог внесён | Приём денег по залогу в кассу (суммой или на весь остаток) |
| Залог зачтён | Зачёт части залога в счёт оплаты аренды |
| Залог возвращён | Возврат залога клиенту |
| Штраф добавлен | Начисление штрафа по аренде |
| Штраф удалён | Снятие штрафа |
| Вознаграждение агенту выплачено | Выплата вознаграждения по приведённой аренде |
| Инвентарь в аренде заменён | Замена единицы инвентаря в позиции аренды |
| Позиции аренды изменены массово | Массовое изменение состава аренды одним запросом |
| График аренды изменён | Правка графика платежей аренды |
| Ссылка на оплату отправлена | Отправка клиенту ссылки на оплату аренды |
| Доставка подтверждена | Подтверждение доставки по коду |
| Доставка забрана | Забор инвентаря курьером |
| Доставка выполнена | Передача инвентаря клиенту |
| Доставка отменена | Отмена доставки |

Переходы статуса аренды записываются вместе с составом: к событию прикрепляются изменённые позиции, задействованные
единицы инвентаря и клиент, а в дополнительных данных остаются статус до и статус после перехода. «Доставка забрана» и
«Доставка выполнена» могут прийти как из ленты действий аренды, так и из отдельного экрана доставки.

## Инвентарь

| Событие | Когда возникает |
| --- | --- |
| Инвентарь продан | Продажа единицы инвентаря, в том числе при закрытии аренды продажей |
| Продажа инвентаря отменена | Откат продажи единицы |
| Инвентарь перемещён | Перемещение единицы между точками или складами |
| Инвентарь импортирован | Загрузка единиц инвентаря из файла |
| Группы инвентаря импортированы | Загрузка групп инвентаря из файла |
| Инвентарь изменён массово | Массовая правка единиц одним запросом |
| Инвентарь списан | Деактивация единиц, групп, комплектов или услуг |
| Инвентарь восстановлен | Возврат деактивированных записей в работу |
| Тариф изменён | Сохранение набора тарифов единицы, группы или комплекта |
| Обслуживание начато | Отправка единицы на обслуживание |
| Обслуживание завершено | Возврат единицы с обслуживания |
| Инвентаризация проведена | Фиксация результата проверки наличия |
| Списание со склада | Расход складских позиций |

## Доступ

| Событие | Когда возникает |
| --- | --- |
| Вход | Успешный вход по логину и паролю |
| Неудачный вход | Ошибка входа; инициатор — анонимно, в дополнительных данных логин и причина отказа |
| Выход | Выход из системы |
| Вход от имени пользователя | Вход администратора платформы под учётной записью пользователя |
| Создана ссылка для входа от имени | Выдача администратору платформы ссылки для такого входа |
| Запрошен сброс пароля | Запрос кода на восстановление; инициатор — анонимно |
| Сброс пароля подтверждён | Успешная проверка кода восстановления |
| Пароль изменён | Установка нового пароля после сброса |
| Код подтверждения отправлен | Выдача одноразового кода |
| Неверный код подтверждения | Ошибка проверки одноразового кода |
| Вход через Google | Вход через учётную запись Google |
| Профиль изменён | Правка собственного профиля пользователем |

<Note>
Часть событий доступа возникает на страницах, которые работают без компании: сброс пароля, коды подтверждения, вход
через Google. Для них компания выводится из единственного места работы пользователя, и если таких мест ноль или больше
одного, событие не записывается — подробно в [«Как события попадают в журнал»](/ru/logic/audit/recording).
</Note>

## Настройки

| Событие | Когда возникает |
| --- | --- |
| Настройки компании изменены | Сохранение настроек компании через её карточку |
| Домен зарегистрирован | Регистрация собственного домена компании фоновой задачей; инициатор — система |
| Запрошено удаление компании | Постановка компании в очередь на удаление |
| Удаление компании отменено | Снятие компании с удаления |

Правки отдельных справочников настроек — дополнительных полей, настроек таблиц, наименований сущностей и реквизитов
компании — фиксируются автоматическим отслеживанием и получают складные формулировки.

## Витрина и личный кабинет

| Событие | Когда возникает |
| --- | --- |
| Заявка с сайта оформлена | Оформление корзины на публичном сайте |
| Запись на событие с сайта | Запись клиента на событие |
| Запись на событие отменена | Отмена такой записи |
| Заявка на грант отправлена | Отправка заявки на грант |
| Клиент зарегистрировался | Самостоятельная регистрация клиента |
| Телефон клиента подтверждён | Подтверждение телефона кодом |
| Клиент изменил пароль | Смена пароля из личного кабинета |
| Клиент сбросил пароль | Восстановление пароля клиентом |
| Клиент изменил профиль | Правка своих данных клиентом |
| Клиент отменил аренду | Отмена аренды из личного кабинета |
| Клиент оставил отзыв | Оценка аренды клиентом |
| Клиент списал бонусы | Оплата бонусами со стороны клиента — тот же обработчик, что и «Бонусы в аренде применены», но вызванный из кабинета |
| Клиент оплатил по ссылке | Оплата аренды по публичной ссылке; инициатор — анонимно, компания берётся из самой ссылки |
| Товар на сайте изменён | Правка или удаление товара публичного каталога |
| Массовая скидка на сайте | Массовое проставление скидки в публичном каталоге |

<Warning>
Шесть формулировок присутствуют в списке фильтра, но не возникают ни при каком действии: «Лимит изменён», «Документы
клиента изменены», «Пользовательское поле изменено», «Функция компании изменена», «Подписи изменены» и «Настройка
таблицы изменена». Соответствующие правки записываются автоматическим отслеживанием под складными названиями, поэтому
фильтр по этим шести значениям всегда возвращает пустой список. Подробно — в
[«Проблемах и логических ошибках»](/ru/logic/audit/issues).
</Warning>
