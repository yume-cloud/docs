## Понятия

| Понятие | Значение |
| --- | --- |
| Изменение поля | Одна запись в списке изменений события: имя поля, вид изменения и данные, зависящие от вида. Поле без изменений записи не даёт. |
| Вид изменения | Способ показать изменение: значение, текст, структура, файл или скрытое. Выбирается по типу поля и размеру значений, первым подошедшим правилом. |
| Подпись значения | Готовое человекочитаемое представление значения, сохранённое рядом с ним: название из фиксированного набора либо название объекта, на который ссылается поле. Записывается в момент события. |
| Порог длинного текста | 200 символов. Значение длиннее порога записывается построчным сравнением, даже если поле не предназначено для длинного текста. |
| Предел сравнения | 8 КБ. Более длинное построчное сравнение обрезается, более длинный список операций сокращается до первых 50. |
| Предел исходного текста | 20 КБ. Если любая из версий больше, сравнение не строится: остаются размеры и контрольные суммы. |
| Контрольная сумма версии | Короткий отпечаток текста, сохраняемый для обеих версий. Позволяет увидеть факт изменения, когда само сравнение не сохранилось. |
| Операция над ключом | Единица сравнения структуры: добавление, удаление или замена значения по конкретному пути внутри структуры. |
| Маскирование | Запись факта изменения без значений для полей и ключей с чувствительными именами. Работает по имени, а не по содержимому. |
| Приведение значения | Перевод значения в вид, пригодный для хранения: суммы — текстом, даты и время — в стандартном виде, ссылки — номерами, остальное — текстовым представлением. |

## Виды изменения

| Вид | Когда выбирается | Что хранится |
| --- | --- | --- |
| Скрытое | Имя поля входит в список чувствительных | Только факт изменения |
| Файл | Поле хранит файл | Прежнее и новое имя файла |
| Структура | Поле хранит структуру | Список операций над ключами с путями и значениями |
| Текст | Поле предназначено для длинного текста либо значение длиннее 200 символов | Построчное сравнение, размеры и контрольные суммы обеих версий |
| Значение | Все остальные поля | Прежнее и новое значение плюс их подписи |

## Ограничения по размеру

| Ограничение | Значение | Поведение при превышении |
| --- | --- | --- |
| Порог длинного текста | 200 символов | Значение записывается как текст, а не как пара значений |
| Предел построчного сравнения | 8 КБ | Сравнение обрезается, ставится отметка об обрезке |
| Предел исходного текста | 20 КБ | Сравнение не строится, остаются размеры и контрольные суммы |
| Предел списка операций | 8 КБ | Сохраняются первые 50 операций, ставится отметка об обрезке |
| Свёртка в интерфейсе | 6 строк | Остальные строки скрыты под кнопкой раскрытия |

## Маскируемые имена

| Группа | Имена |
| --- | --- |
| Пароли и секреты | Пароль, секрет, секрет клиента, приватный ключ |
| Токены | Токен, токен доступа, токен обновления, токен карты, служебные токены платёжных карт |
| Ключи доступа | Ключ интеграции в двух написаниях |
| Документы | Номер, номер паспорта, номер документа, ИИН, БИН |
| Платёжные данные | Номер карты, расчётный счёт |
