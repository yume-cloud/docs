## Понятия

| Понятие | Значение |
| --- | --- |
| Событие журнала | Неизменяемая запись о состоявшемся действии: что произошло, кто это сделал, когда, над какими объектами и что изменилось. Создаётся один раз и после этого не правится. |
| Объект события | Связка события с конкретной записью системы. У события может быть несколько объектов, у каждого своя роль; один объект в одном событии не повторяется. |
| Действие | Внутреннее имя события, по которому на чтении подбирается формулировка. Одна часть имён задана заранее и имеет готовую фразу, остальные складываются из названия справочника и слова «создана», «обновлена» или «удалена». |
| Раздел | Крупная область системы, к которой отнесено действие: аренда, инвентарь, клиент, финансы, доступ, сотрудники, настройки, интеграция, документ, подписка, витрина. |
| Инициатор | Пользователь, выполнивший действие. Хранится ссылкой и текстовой подписью одновременно, чтобы строка читалась и после удаления пользователя. |
| Тип инициатора | Кем выполнено действие: пользователь, клиент, анонимно, система, интеграция, платформа. |
| Роль объекта | Чем объект был в действии: основной, родительский или связанный. |
| Подпись объекта | Текстовое представление основного объекта на момент действия. Единственное, что остаётся читаемым после его удаления. |
| Изменения | Построчное описание изменившихся полей: по одной записи на поле, с видом изменения и парой «было — стало». |
| Дополнительные данные | Свободный набор значений, который смысловое событие записывает о себе само: количества, суммы, коды, причины, статусы до и после. Структуры не имеет. |
| Идентификатор запроса | Общая метка всех событий одного обращения к системе. Приходит во входящем заголовке либо генерируется; возвращается в ответе и попадает в технические логи. |
| Срок хранения | Возраст, после которого событие удаляется ночной уборкой. По умолчанию 365 дней, задаётся на уровне окружения. |

## Модели и поля

### Событие журнала

*Неизменяемая запись о состоявшемся действии. Всегда принадлежит одной компании: без компании событие не создаётся вовсе. Выборка по умолчанию идёт от новых к старым.*

**Что произошло**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ, используется в адресе отдельного события |
| Компания | связь | Владелец журнала. Обязательное поле; удаление компании удаляет её события |
| Действие | текст | Внутреннее имя события, до 64 символов. Формулировка подбирается на чтении, в самом событии не хранится |
| Раздел | выбор из списка | Область системы: аренда, инвентарь, клиент, финансы, доступ, сотрудники, настройки, интеграция, документ, подписка, витрина |
| Дата и время | дата и время | Момент записи события. Проиндексировано, задаётся системой и не редактируется |
| Дата изменения | дата и время | Служебная отметка. У события не меняется: журнал только пополняется |

**Кто сделал**

| Поле | Тип | Описание |
| --- | --- | --- |
| Инициатор | связь | Пользователь, выполнивший действие. Пусто для системных, анонимных и интеграционных событий; при удалении пользователя ссылка обнуляется, а подпись остаётся |
| Тип инициатора | выбор из списка | Пользователь, клиент, анонимно, система, интеграция или платформа. По умолчанию — система |
| Подпись инициатора | текст | Имя инициатора на момент события, до 255 символов. Не пересчитывается позже |

**Над чем и что изменилось**

| Поле | Тип | Описание |
| --- | --- | --- |
| Подпись объекта | текст | Текстовое представление основного объекта на момент действия, до 255 символов |
| Изменения | структура | Построчное сравнение полей: имя поля, вид изменения, значения до и после, готовые подписи значений |
| Дополнительные данные | структура | Свободный набор значений конкретного действия: количества, суммы, коды, причины, статусы до и после |

**Реквизиты запроса**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор запроса | текст | Метка обращения к системе, до 64 символов. Пусто у событий, записанных вне запроса |
| Адрес | адрес | Первый адрес из цепочки прокси, иначе адрес соединения |
| Устройство | текст | Строка браузера или приложения, до 512 символов |

### Объект события

*Связка события с конкретной записью системы. Строк столько, сколько объектов затронуло действие. Пара «тип объекта и объект» внутри одного события уникальна, поэтому повторная привязка того же объекта ничего не добавляет.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Событие | связь | Событие, к которому относится объект; удаление события удаляет его объекты |
| Компания | связь | Владелец записи, дублируется из события ради быстрых выборок по компании |
| Дата и время | дата и время | Время события, скопированное в строку объекта, чтобы историю объекта можно было выбирать без соединения таблиц. Проиндексировано |
| Тип объекта | связь | Вид записи, на которую указывает строка: аренда, клиент, единица инвентаря, документ и так далее |
| Идентификатор объекта | число | Номер записи внутри её вида. Ссылка не проверяется: после физического удаления записи номер остаётся |
| Роль | выбор из списка | Основной, родительский или связанный |

## Разделы журнала

| Раздел | Область |
| --- | --- |
| Аренда | Заявки и аренды со всем их составом |
| Инвентарь | Единицы, группы, комплекты, тарифы, услуги, продажи, обслуживание |
| Клиент | Клиенты, их документы и бонусы |
| Финансы | Платежи, проводки, счета, способы оплаты, статьи, скидки |
| Доступ | Вход, выход, пароли, коды подтверждения, профиль |
| Сотрудники | Сотрудники, роли доступа, смены |
| Настройки | Настройки, дополнительные поля, таблицы, наименования, реквизиты компании |
| Интеграция | Подключения внешних систем и их ключи |
| Документ | Документы, шаблоны и подписание |
| Подписка | Счета за пользование системой, карты, цены, лимиты |
| Витрина | Публичный сайт и личный кабинет клиента |

## Типы инициаторов

| Тип | Кто это |
| --- | --- |
| Пользователь | Сотрудник компании с действующим местом работы в ней |
| Клиент | Авторизованный клиент компании |
| Анонимно | Запрос без авторизации |
| Система | Действие без запроса: фоновая задача, обработка внешнего уведомления, правило |
| Интеграция | Действие от имени внешней системы |
| Платформа | Глобальный администратор платформы, включая вход от имени пользователя |

## Роли объектов

| Роль | Смысл |
| --- | --- |
| Основной | Объект, над которым выполнено действие |
| Родительский | Объект-владелец основного: аренда для своей позиции, платёж для своей проводки |
| Связанный | Объект, задействованный в действии: клиент, точка проката, единица инвентаря, скидка |
