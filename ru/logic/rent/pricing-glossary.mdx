| Понятие | Значение |

## Модели и поля

### Аренда (заявка)

*Центральная сущность аренды: одна заявка клиента со сроками, суммами, скидками, оплатой, штрафами и вычисляемым статусом жизненного цикла. Статус и статус оплаты не задаются напрямую, а пересчитываются в методе сохранения из действий, состояний позиций инвентаря и оплаты.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ аренды. |
| Идентификатор в Plus | число | Ссылка на запись во внешней системе Plus; аренды из Plus нельзя жёстко удалять. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Клиент | связь | Клиент, на которого оформлена аренда; может отсутствовать у черновой заявки. |
| Создатель | связь | Пользователь, оформивший аренду. |
| Точка выдачи | связь | Точка проката, где выдаётся аренда; используется для фильтрации по правам. |
| Точка возврата | связь | Точка проката для приёмки. |
| Корзина | связь | Связанная корзина витрины. |
| Тарифный период по умолчанию | связь | Базовый период тарификации аренды. |

**Статусы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Статус аренды | список | Этап жизненного цикла: заявка, бронь, в аренде, отмена, завершена, должник, просрочка. Вычисляется автоматически. |
| Статус оплаты | список | Ожидает оплаты / оплачено / частично оплачено. Вычисляется из оплаченной суммы и итоговой цены. |
| Активна | флаг | Заявка считается активной, если есть услуги, позиции, клиент, оплата, депозиты или доставки; иначе скрывается из списков. |
| Удалена (в архиве) | флаг | Мягкое удаление/архивирование; переключается при архивации. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Плановое начало аренды | дата/время | Планируемая дата и время начала. |
| Плановый конец аренды | дата/время | Планируемая дата и время окончания; не может быть раньше начала (проверяется ограничением БД). |
| Фактическое начало | дата/время | Момент фактической выдачи (по первому действию выдачи). |
| Фактический конец | дата/время | Момент фактической приёмки/завершения; сбрасывается при возврате позиции в аренду. |
| Автопродление | флаг | Аренда автоматически продлевается посуточно. |
| Автосписание | флаг | Признак автоматического списания. |

**Длительность**

| Поле | Тип | Описание |
| --- | --- | --- |
| Начальная длительность | длительность | Изначальная длительность аренды. |
| Расчётная длительность | длительность | Длительность, используемая при расчёте стоимости. |

**Суммы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Стоимость без скидки | число (2 знака) | Полная сумма до применения скидок. |
| Итоговая стоимость | число (2 знака) | Сумма к оплате со скидкой; сравнивается с оплаченной суммой для статуса оплаты. |
| Начисленная стоимость | число (2 знака) | Часть итоговой стоимости, приходящаяся на дни, которые уже наступили: итоговая стоимость × доля дней журнала прибыли до сегодня. У аренды в терминальном статусе равна итоговой стоимости. Поддерживается всегда; используется вместо итоговой стоимости при расчёте долга, когда включён признак «Долг до сегодня». |
| Стоимость инвентаря | число (2 знака) | Сумма по арендным/продажным позициям без скидки. |
| Стоимость инвентаря со скидкой | число (2 знака) | Сумма по позициям после скидки. |
| Стоимость услуг | число (2 знака) | Сумма по услугам без скидки. |
| Стоимость услуг со скидкой | число (2 знака) | Сумма по услугам после скидки. |
| Стоимость доставки | число (2 знака) | Сумма за доставку. |

| Сумма налога | число (2 знака) | Рассчитанная сумма налога. |

**Скидки**

### Позиция инвентаря в аренде

*Одна строка заявки: конкретная единица инвентаря или услуга, добавленная в аренду, со своим тарифом, сроками, ценой и штрафами. Ключевая модель под-области; каждая замена (обмен) — это новая строка, связанная один-к-одному с заменённой. Штраф позиции переносится в пер-позиционные авто-штрафы отдельной задачей.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Замена (следующая позиция) | связь 1:1 (на себя) | Ссылка на новую позицию, пришедшую на замену этой; обратная связь называется «предыдущая». У заменённой строки заполнена, у активной — пустая. |
| Аренда (заявка) | связь | Заявка, к которой относится позиция; удаление заявки удаляет позиции (каскад). |
| Клиент | связь | Клиент позиции; если пуст, берётся клиент заявки. |
| Группа инвентаря | связь | Товарная группа, из которой взята единица (для позиций без привязки к конкретной единице). |
| Единица инвентаря | связь | Конкретная арендуемая/продаваемая единица; может быть пустой (групповая позиция). |
| Склад | связь | Склад, к которому привязана позиция. |
| Контрагент | связь | Контрагент (поставщик/субарендодатель) позиции. |

**Тип и комплекты**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип позиции | перечисление | Аренда или продажа; по умолчанию аренда. |
| Комплект | связь | Комплект, в рамках которого добавлена позиция. |
| Элемент комплекта | связь | Позиция шаблона комплекта, которой соответствует эта строка. |
| Ключ экземпляра комплекта | текст | Случайный ключ, объединяющий строки одного собранного экземпляра комплекта. |

**Тариф**

**Скидки**

| --- | --- | --- |

**Суммы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма позиции | число (2 знака) | Итоговая начисленная сумма за позицию. |
| Сумма со скидкой | число (2 знака) | Сумма позиции после применения скидки. |

**Штрафы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Итоговый штраф | число (2 знака) | Общая сумма штрафа по позиции; источник для авто-штрафа пер-позиции. |

**Сроки**

| Поле | Тип | Описание |

| Фактическая выдача | дата/время | Момент фактической выдачи единицы клиенту; заполнение означает, что позиция выдана. |
| Фактическая приёмка | дата/время | Момент фактического возврата единицы; заполнение означает, что позиция принята. |

### Пересчёт позиций и сумм аренды

*Главная функция движка пересчёта: выражениями заново считает цены, скидки, штрафы и налоги по всем позициям инвентаря и услугам и складывает итоги в саму аренду. Выполняется в транзакции с блокировкой строк; до 15 повторов ради автопродления; в конце ставит задачу пересчёта прибыли по завершении транзакции.*

**Параметры**

| Поле | Тип | Описание |
| --- | --- | --- |
| Пересчитывать инвентарь | флаг | Обновлять ли цены/штрафы позиций инвентаря. |
| Пересчитывать услуги | флаг | Обновлять ли цены услуг. |

**Расчётные аннотации**

| Поле | Тип | Описание |
| --- | --- | --- |
| Базовая цена позиции | число (2 знака) | Тариф × число периодов (для аренды) либо тариф (для продажи/разового). |
| Цена со скидкой | число (2 знака) | Базовая цена минус применённые скидки, не ниже нуля. |
| Цена после инвентарной скидки | число (2 знака) | Промежуточная величина в устаревшей (не совмещённой) ветке расчёта скидок. |
| Скидка уровня аренды | число (2 знака) | Промежуточная величина в устаревшей ветке. |

### Раскладка скидок по позициям

*Помощник в движке: выражениями вычисляет сумму каждой скидки по её типу (процент/сумма/график) и записывает результат в суммы строк скидок. Разбивает скидки на три набора — по аренде, по инвентарю и по услугам; ручные позиционные скидки не пересчитывает, только скидки уровня аренды и графика.*

**Параметры**

| Поле | Тип | Описание |
| --- | --- | --- |
| Выходные даты | список | Даты, исключаемые из подсчёта дней (нерабочие дни графика). |

**Расчётные аннотации**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма скидки | число (2 знака) | Итог по строке скидки, ограниченный ценой позиции. |

### Подзапросы скидок по инвентарю

*Строит подзапросы, вычитающие скидки из цены позиции инвентаря; имеет режим объединения скидок и устаревшую раздельную ветку. Учитывает скидки, привязанные к позиции, и скидки уровня аренды с назначением «вся аренда» или «инвентарь».*

### Подзапросы скидок по услугам

*Строит подзапрос, вычитающий из цены услуги скидки, привязанные к услуге, и скидки уровня аренды с назначением «вся аренда» или «услуги».*
