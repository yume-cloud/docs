## Модели и поля

### Штраф аренды

*Штраф по аренде: ручной (создаётся сотрудником) или автоматический (за просрочку); может относиться ко всей заявке или к конкретной позиции инвентаря. Ограничение БД требует заполненности клиента или аренды; авто-штрафы по позициям синхронизируются фоновой задачей, ручные — сигналом пересчитывают ручные штрафы заявки.*

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип штрафа | перечисление | Автоматический — за просрочку, ручной — добавлен сотрудником. |
| Причина | текст | Комментарий/причина штрафа. |
| Пользовательский | флаг | Признак штрафа, заданного вручную/индивидуально. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Клиент | связь | Клиент, к которому привязан штраф. |
| Аренда | связь | Заявка, к которой относится штраф. |
| Позиция инвентаря | связь | Строка инвентаря аренды, если штраф пер-позиционный. |
| Кем создан | связь | Пользователь, создавший штраф (пусто для авто). |
| Штраф сервиса автомобильных штрафов | связь | Связь со штрафом внешнего сервиса автомобильных штрафов (ПДД/камеры). |
| График штрафа | список | Даты и суммы разбивки штрафа (сумма по датам должна совпадать с суммой штрафа). |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма штрафа | число (2 знака) | Начисленная сумма штрафа. |
| Оплачено | число (2 знака) | Оплаченная часть штрафа. |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент создания записи. |

### Залог аренды

*Залог по аренде: либо текстовое описание (например, паспорт), либо денежная сумма; хранит статус получения и возврата. Привязан к аренде; сумма депозита сравнивается с суммой платежей по нему.*

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип залога | перечисление | Текстовый или денежный залог. |
| Статус залога | перечисление | Не получен / получен / возвращён. |
| Описание залога | текст | Текст залога (например, что оставлено в залог). |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Аренда | связь | Заявка, к которой относится залог. |
| Кем создан | связь | Пользователь, оформивший залог. |
| Способ оплаты | связь | Тип оплаты залога (может быть пустым). |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма | число (2 знака) | Сумма залога; для текстового залога обнуляется. |
| Сумма платежей | число (2 знака) | Вычисляемая сумма платежей по залогу (не поле БД). |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата возврата | дата/время | Момент возврата залога (заполняется при возврате). |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент создания записи. |

### Строка просрочки аренды

*Запись в общей (глобальной) таблице, планирующая начисление автоматического штрафа за просрочку либо разовое напоминание о её приближении по конкретной аренде. Хранится в общих таблицах и ссылается на компанию напрямую; генерируется по позициям аренды и по триггерам сообщений, обрабатывается ежеминутной фоновой задачей. Уникальность задана двумя условными ограничениями: просрочка — по компании, аренде и индексу; напоминание — по компании, аренде и триггеру.*

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Вид | перечисление | Просрочка (начисление штрафа) или напоминание до просрочки. |
| Индекс | число | Порядковый номер строки в рамках аренды (по разным датам окончания позиций); значим только у просрочек. |
| Момент срабатывания | дата/время | У просрочки — дата окончания позиции; у напоминания — плановый конец аренды минус задержка триггера. |
| Последний запуск | дата/время | Когда строка отрабатывала в последний раз. |
| Шаг начисления | интервал | Периодичность повторного начисления; у напоминания не задан, что и делает его разовым. |
| Активно | флаг | Включена ли строка (аренда в статусе «В аренде»/«Просрочка» и не удалена; иначе строки удаляются). |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания, которой принадлежит аренда. |
| ID аренды | число | Идентификатор заявки (без прямой связи). |
| ID триггера | число | Триггер сообщения, по которому отправляется напоминание (без прямой связи); заполнен только у напоминаний. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата старта начислений | дата/время | Момент, с которого начинают начисляться штрафы (дата окончания позиции). |
| Последний запуск | дата/время | Когда штраф начислялся в последний раз. |
| Шаг начисления | интервал | Периодичность повторного начисления (по умолчанию 1 час). |

### Штрафные поля аренды

*Агрегированные суммы штрафов и настройки авто-штрафов, хранящиеся прямо в заявке аренды. Ручную часть пересчитывает сохранение или удаление ручного штрафа, автоматическую — только пересчёт сумм аренды; это подмножество полей заявки аренды.*

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Общая сумма штрафов | число (2 знака) | Сумма авто-штрафов и ручных штрафов. |
| Авто-штрафы | число (2 знака) | Штраф за просрочку по формуле, суммарно по всем позициям заявки; единственный владелец поля — пересчёт сумм аренды. |
| Ручные штрафы | число (2 знака) | Сумма ручных штрафов заявки. |

**Настройки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Период просрочки | интервал | Длительность просрочки для расчёта штрафа. |
| Шаг начисления штрафа | интервал | Периодичность авто-начисления (по умолчанию 1 час); переносится в строку просрочки. |
| Штрафы отключены | флаг | Признак отключения начисления штрафов по аренде. |

### Штрафные поля позиции инвентаря

*Суммы штрафов, начисленных по отдельной позиции инвентаря в аренде. Сумма штрафа позиции переносится в пер-позиционные авто-штрафы фоновой задачей; это подмножество полей позиции инвентаря аренды.*

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма штрафа позиции | число (2 знака) | Штраф по позиции; источник для авто-штрафа пер-позиции. |
| Авто-штраф позиции | число (2 знака) | Автоматическая часть штрафа позиции. |
| Ручной штраф позиции | число (2 знака) | Ручная часть штрафа позиции. |

## Статусы и справочники

### Тип залога

- Текстовый (описание)
- Денежный (сумма)

### Статус залога

- Не получен
- Получен
- Возвращён

### Тип штрафа

- Автоматический
- Ручной
