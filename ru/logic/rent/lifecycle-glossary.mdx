## Модели и поля

### Аренда (заявка)

*Центральная сущность аренды: одна заявка клиента со сроками, суммами, скидками, оплатой, штрафами и вычисляемым статусом жизненного цикла. Статус и статус оплаты не задаются напрямую, а пересчитываются в методе сохранения из действий, состояний позиций инвентаря и оплаты.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ аренды. |
| Идентификатор в Plus | число | Ссылка на запись во внешней системе Plus; аренды из Plus нельзя жёстко удалять. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Клиент | связь | Клиент, на которого оформлена аренда; может отсутствовать у черновой заявки. |
| Создатель | связь | Пользователь, оформивший аренду. |
| Точка выдачи | связь | Точка проката, где выдаётся аренда; используется для фильтрации по правам. |
| Точка возврата | связь | Точка проката для приёмки. |
| Корзина | связь | Связанная корзина витрины. |
| Тарифный период по умолчанию | связь | Базовый период тарификации аренды. |

**Статусы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Статус аренды | список | Этап жизненного цикла: заявка, бронь, в аренде, отмена, завершена, должник, просрочка. Вычисляется автоматически. |
| Статус оплаты | список | Ожидает оплаты / оплачено / частично оплачено. Вычисляется из оплаченной суммы и итоговой цены. |
| Активна | флаг | Заявка считается активной, если есть услуги, позиции, клиент, оплата, депозиты или доставки; иначе скрывается из списков. |
| Удалена (в архиве) | флаг | Мягкое удаление/архивирование; переключается при архивации. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Плановое начало аренды | дата/время | Планируемая дата и время начала. |
| Плановый конец аренды | дата/время | Планируемая дата и время окончания; не может быть раньше начала (проверяется ограничением БД). |
| Фактическое начало | дата/время | Момент фактической выдачи (по первому действию выдачи). |
| Фактический конец | дата/время | Момент фактической приёмки/завершения; сбрасывается при возврате позиции в аренду. |
| Автопродление | флаг | Аренда автоматически продлевается посуточно. |
| Автосписание | флаг | Признак автоматического списания. |

**Длительность**

| Поле | Тип | Описание |
| --- | --- | --- |
| Начальная длительность | длительность | Изначальная длительность аренды. |
| Расчётная длительность | длительность | Длительность, используемая при расчёте стоимости. |

**Суммы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Стоимость без скидки | число (2 знака) | Полная сумма до применения скидок. |
| Итоговая стоимость | число (2 знака) | Сумма к оплате со скидкой; сравнивается с оплаченной суммой для статуса оплаты. |
| Стоимость инвентаря | число (2 знака) | Сумма по арендным/продажным позициям без скидки. |
| Стоимость инвентаря со скидкой | число (2 знака) | Сумма по позициям после скидки. |
| Стоимость услуг | число (2 знака) | Сумма по услугам без скидки. |
| Стоимость услуг со скидкой | число (2 знака) | Сумма по услугам после скидки. |
| Стоимость доставки | число (2 знака) | Сумма за доставку. |

**Налоги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Ставка налога | число (2 знака) | Процент налога (0–100). |
| Налог включён в цену | флаг | Налог заложен в стоимость, а не добавляется сверху. |
| Сумма налога | число (2 знака) | Рассчитанная сумма налога. |

**Скидки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Скидка | связь | Применённая скидка/промокод. |
| Сумма скидки | число (2 знака) | Общая сумма скидки по аренде. |
| Сумма скидки на инвентарь | число (2 знака) | Скидка, отнесённая на позиции инвентаря. |
| Сумма скидки на услуги | число (2 знака) | Скидка, отнесённая на услуги. |
| Совмещать скидки | флаг | Разрешено ли комбинировать несколько скидок. |
| Дополнительная скидка | число (2 знака) | Ручная добавочная скидка. |

**Оплата**

| Поле | Тип | Описание |
| --- | --- | --- |
| Оплаченная сумма | число (2 знака) | Сколько уже оплачено; определяет статус оплаты (>= итоговой цены — оплачено, >0 — частично). |
| Сумма залога | число (2 знака) | Вычисляемая величина: номиналы денежных залогов аренды на хранении (не поле БД). Режим «деньги на хранении» — признак самого залога, см. [глоссарий залогов](/ru/logic/rent/deposits-penalties-glossary). |
| Внесён залог | число (2 знака) | Вычисляемая величина: сколько денег по залогам на хранении лежит в кассе (не поле БД). |
| Остаток по залогу | число (2 знака) | Вычисляемая величина: по незакрытым залогам на хранении номинал минус внесённое; у закрытых и удалённых аренд — ноль (не поле БД). |

**Штрафы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма штрафа | число (2 знака) | Итоговая сумма штрафа за просрочку (автоматический плюс ручной). |
| Автоматический штраф | число (2 знака) | Часть штрафа за просрочку, посчитанная по формуле по всем позициям; пишется только пересчётом сумм аренды. |
| Ручной штраф | число (2 знака) | Часть штрафа, заданная вручную. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Доп. данные | словарь | Произвольные дополнительные данные, в т.ч. идентификатор в Plus. |
| Дата создания | дата/время | Момент создания записи. |
| Дата изменения | дата/время | Момент последнего изменения. |

### Вознаграждение по аренде

*Процентные ставки вознаграждения сотрудников за этапы работы с одной арендой. Создаётся автоматически при создании аренды из настроек компании; связь 1:1 с арендой.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Аренда | связь | Аренда, к которой относится вознаграждение (1:1). |
| Процент за создание | число (2 знака) | Вознаграждение за оформление заявки. |
| Процент за бронирование | число (2 знака) | Вознаграждение за бронь. |
| Процент за инкассацию | число (2 знака) | Вознаграждение за сбор оплаты. |
| Процент за выдачу | число (2 знака) | Вознаграждение за выдачу инвентаря. |
| Процент за приёмку | число (2 знака) | Вознаграждение за приёмку инвентаря. |

### Счётчики аренд по статусам

*Формат ответа адреса подсчёта аренд по статусам для дашборда/фильтров. Поле «в аренде» может объединять статусы «в аренде» и «просрочка» в зависимости от настройки компании.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Всего | число | Все активные неудалённые аренды. |
| Заявки | число | Количество в статусе «Заявка». |
| Брони | число | Количество в статусе «Бронь». |
| В аренде | число | В аренде (опционально плюс просрочка). |
| Завершённые | число | Количество завершённых аренд. |
| Отменённые | число | Количество отменённых аренд. |
| Должники | число | Должники с неполной оплатой. |
| Просроченные | число | Количество в статусе «Просрочка». |
| Удалённые (архив) | число | Количество архивированных аренд. |

### Отправка ссылки на оплату

*Входные данные для отправки клиенту ссылки на оплату аренды.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Телефон | текст | Номер получателя, проходит валидацию телефона. |
| Канал | список | Канал отправки: sms или wazzup; требует подключённой интеграции. |

## Статусы и справочники

### Статус аренды

*Этапы жизненного цикла аренды; вычисляются автоматически при сохранении из действий, состояний позиций и оплаты. Просрочка, должник и завершена — производные состояния: просрочка при непринятых позициях, должник при завершении с несданным инвентарём или неполной оплатой, завершена при полной сдаче и оплате.*

- Заявка
- Бронь
- В аренде
- Отменена
- Завершена
- Должник
- Просрочка

### Статус оплаты аренды

*Состояние оплаты; вычисляется из оплаченной суммы и итоговой стоимости. Оплачено при оплаченной сумме не меньше итоговой цены, частично при частичной оплате, иначе ожидает оплаты.*

- Ожидает оплаты
- Оплачено
- Частично оплачено

### Тип действия по аренде

*Виды операций над арендой; при пересчёте статуса учитываются выдача и приёмка для определения фактических сроков и статуса. Этапы упорядочены: создание → бронирование → инкассация → выдача → приёмка, и по этому порядку определяется, был ли пройден более поздний этап.*

- Бронирование
- Выдача
- Приёмка
- Отмена
- Архивирование
- Инкассация
- Создание
- Забор при доставке
- Выдача при доставке

### Состояние позиции в аренде

*Состояние отдельной позиции инвентаря внутри аренды. Используется для определения непринятых/несданных позиций при пересчёте статуса аренды.*

- Не выдана
- Выдана
- Принята
- Просрочена

### Тип позиции инвентаря

*Различает арендные и продажные позиции аренды; влияет на пересчёт статуса при сохранении. Аренда завершается по-разному для арендных и продажных позиций.*

- Аренда
- Продажа

### Тип услуги

*Виды услуг аренды; подтипы доставки используются свойством доставки модели аренды. В доставку отбираются доставка, обратная доставка и доставка в обе стороны.*

- Доставка
- Не выбрано
- Обратная доставка
- Доставка в обе стороны
- Мастерская
