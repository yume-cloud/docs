## Модели и поля

### Действие по аренде (событие жизненного цикла)

*Запись в журнале событий аренды: фиксирует этап (создание, бронь, сборка, выдача, приёмка, отмена, архив) и участвовавшие позиции инвентаря. Каждый этап создаётся отдельной записью через методы создания; порядок этапов задаётся заранее, а неудаляемые этапы вынесены в отдельный перечень.*

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип действия | перечисление | Этап жизненного цикла (см. «Тип действия по аренде»). |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Исполнитель | связь | Пользователь, выполнивший действие. |
| Аренда | связь | Аренда, к которой относится действие; при удалении аренды удаляется каскадно. |
| Позиции инвентаря | список связей | Позиции заявки, затронутые этим действием (многие-ко-многим). |
| Доставка | связь | Связанная доставка для действий забора/выдачи по доставке; иначе пусто. |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создано | дата/время | Момент действия; используется для восстановления дат факт-начала/окончания при откате. |
| Обновлено | дата/время | Момент последнего изменения записи. |

### Формат действия по аренде (создание)

*Принимает целевой статус и действие, создаёт соответствующую запись действия и продвигает аренду по жизненному циклу (бронь/сборка/выдача/приёмка/отмена). При выдаче проставляет фактическое начало позициям, при приёмке — фактическое окончание и пересчитывает завершённость; учитывает флаги единой выдачи, единой приёмки и брони.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Позиции инвентаря | список | Идентификаторы позиций заявки, участвующих в действии. |
| Целевой статус | перечисление | Статус аренды, к которому нужно перейти (обязателен). |
| Действие | перечисление | Явный тип действия (бронь/сборка и т.п.); опционально. |
| Дата и время | дата/время | Момент действия; не может быть в будущем, по умолчанию текущий момент. |

### Адреса

**Адрес создания действия** — создаёт действие по аренде (продвижение по жизненному циклу); требует прав на аренду и рент-поинты. См. [«Выдача и приёмка: действия по аренде»](/ru/logic/rent/actions).

**Адрес удаления действия** — удаляет действие с откатом статуса аренды; запрещает удаление ключевых этапов и действий, за которыми уже пройден более поздний этап, удаление доступно автору или админу. См. [«Выдача и приёмка: действия по аренде»](/ru/logic/rent/actions).

## Статусы и справочники

### Статус аренды

Этапы жизненного цикла аренды; вычисляются автоматически из действий, состояний позиций и оплаты. Просрочка, должник и завершена — производные состояния.

- Заявка
- Бронь
- В аренде
- Отменена
- Завершена
- Должник
- Просрочка

### Тип действия по аренде

Виды операций над арендой; выдача и приёмка используются для определения фактических сроков и статуса. Порядок этапов упорядочивает создание → бронирование → инкассацию → выдачу → приёмку.

- Бронирование
- Выдача
- Приёмка
- Отмена
- Архивирование
- Инкассация
- Создание
- Забор при доставке
- Выдача при доставке

### Тип позиции инвентаря

Различает арендные и продажные позиции аренды; влияет на пересчёт статуса. Аренда завершается по-разному для арендных и продажных позиций.

- Аренда
- Продажа
