## Ссылка-вложение

*Внешняя URL-ссылка, прикреплённая к произвольному объекту системы через полиморфную связь. Полиморфная привязка через «тип контента + идентификатор объекта»; каждая ссылка привязана к арендатору.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ записи |
| Арендатор | связь | Компания-владелец ссылки |

**Содержимое**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Необязательная подпись ссылки |
| URL-ссылка | ссылка (URL) | Обязательный внешний адрес |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент создания записи, заполняется автоматически |
| Кем создано | число (идентификатор пользователя) | Идентификатор пользователя, добавившего ссылку |

**Полиморфная привязка**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип объекта | связь | Тип родительского объекта, к которому прикреплена ссылка |
| Идентификатор объекта | число | Идентификатор конкретного родительского объекта |
| Родительский объект | связь (вычисляемая) | Сам объект, к которому прикреплена ссылка; вычисляется по паре «тип + идентификатор», не хранится отдельным полем |
