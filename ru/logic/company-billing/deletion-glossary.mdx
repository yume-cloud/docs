Справочник к странице [«Удаление компании»](/ru/logic/company-billing/deletion).

## Понятия

| Понятие | Значение |
| --- | --- |
| Заявка на удаление | Запись, фиксирующая намерение удалить компанию: снимок компании, срок исполнения, статус и итог чистки. Одна на компанию. |
| Окно отмены | Семь дней между подтверждением удаления и фактической чисткой данных. Доступ компании закрыт всё это время. |
| Надгробие компании | Карточка компании, оставшаяся после чистки: данные удалены, логотип, фон и доп. данные очищены, дата удаления проставлена, счета продолжают на неё ссылаться. |
| План чистки | Порядок удаления моделей «дети раньше родителей», выведенный из живого реестра моделей обходом обратных связей от записи компании. |
| Запечатанная модель | Модель с собственной непустой ссылкой на компанию: отбирается одним прямым путём вместо накопления транзитивных путей. |
| Граница обхода | Модели, за которые план не заходит: аккаунты пользователей, счета компании с позициями и ошибками оплаты, сама заявка на удаление, роли и права Django, типы содержимого, сессии, журнал админки, периодические задачи и результаты фоновых задач. Их необязательные ссылки в данные компании обнуляются, обязательная ссылка останавливает построение плана с ошибкой. |
| Старая компания | Компания с собственным служебным именем (`schema_name`) вместо общего значения по умолчанию. Часть её данных может храниться вне общих таблиц; чистка удаляет их отдельным шагом после строк плана. |
| Срок окончания доступа | Более поздняя из двух дат: самое раннее окончание среди подключённых интеграций с тарифом и датой окончания и самое раннее окончание среди платных лимитов; если одной нет — другая. Считается общей функцией: по нему отбираются компании для автоматической постановки на удаление и для напоминаний об окончании подписки. |

## Модели и поля

### Заявка на удаление компании

*Запись, фиксирующая намерение удалить компанию. Связана с компанией один-к-одному; создаётся при запросе удаления, исполняется фоновой задачей после истечения срока.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь (один-к-одному) | Компания, которую удаляют. |
| Статус | выбор | Текущее состояние заявки. |
| Кем запрошено | связь | Суперпользователь платформы, запросивший удаление. Пусто у автоматической постановки. |
| Снимок | JSON | Слепок компании на момент запроса: идентификатор, название, адрес, служебное имя (`schema_name`), страна, валюта, фирменный цвет, владелец, код типа, домены и идентификаторы всех участников компании. По доменам и участникам из снимка сбрасываются кэши при запросе и отмене, название из снимка служит подписью заявки. |
| Удалено | JSON | Итог чистки: число удалённых строк по каждой модели, только ненулевые. У старой компании сюда же добавляется отметка об удалении её данных вне общих таблиц со значением 1. Роли и периодические задачи, удалённые отдельным шагом, в итог не входят. |
| Ошибка | текст | Трассировка упавшей чистки. |
| Срок исполнения | дата/время | Момент, начиная с которого чистку можно запускать: время запроса плюс семь дней. Обнуляется при отмене. |
| Начато | дата/время | Момент начала чистки. |
| Завершено | дата/время | Момент завершения чистки — успешной или упавшей — либо отмены. |

**Вычисляемые поля**

| Поле | Описание |
| --- | --- |
| Строк удалено | Сумма всех значений в поле «Удалено». |
| Отменяема | Истинно только в статусе «ожидает удаления». |
| Осталось до удаления | Срок исполнения минус текущий момент; пусто, если срок не задан или заявка уже неотменяема. |

### Статусы заявки

| Статус | Значение |
| --- | --- |
| Ожидает удаления | Заявка создана, срок не наступил. Единственный статус, из которого возможна отмена. |
| Удаляется | Чистка запущена. |
| Удалена | Чистка завершена успешно, компания стала надгробием. |
| Ошибка | Чистка упала, трассировка сохранена в заявке. Ежечасная задача такую заявку не подхватывает: чистку повторяют вручную, поставив задачу по идентификатору заявки, или повторным запросом удаления — тогда с новым семидневным сроком. |
| Отменено | Удаление отменено до истечения срока, доступ компании возвращён. |

## Службы

| Служба | Назначение |
| --- | --- |
| Построение плана | Обходит обратные связи от записи компании не глубже десяти уровней, «запечатывает» модели с собственной ссылкой на компанию, останавливается на границах обхода и возвращает порядок удаления вместе со списком связей, которые надо обнулить. Результат кэшируется на время жизни процесса. |
| Удаление строк | Выполняет план в одной транзакции: сначала обнуляет пограничные связи, затем прямыми запросами удаляет строки по каждой модели, в конце переводит ограничения в немедленный режим и обратно в отложенный. Пропускает модели, чьих таблиц нет в базе. |
| Удаление данных вне общих таблиц | Шаг для старой компании: после удаления строк, вне их транзакции, удаляет её данные вне общих таблиц целиком одной командой. Для пустого, общего и системных служебных имён ничего не делает, имя неожиданного формата останавливает чистку с ошибкой. |
| Очистка карточки | Превращает компанию в надгробие: чистит логотип, фон и доп. данные, проставляет дату удаления, если её ещё нет, а у старой компании сбрасывает служебное имя (`schema_name`) на общее значение по умолчанию. |
| Сброс кэшей | Сбрасывает кэши компании по идентификатору и доменам, кэши аккаунтов её участников, их членства и ролей в компании. Вызывается при запросе и отмене — после фиксации транзакции — и по итогам чистки, успешной или упавшей. |
| Запрос удаления | Создаёт заявку или переиспользует заявку в «ошибке» и «отменено», снимает слепок, ставит срок на семь дней вперёд и проставляет компании дату удаления. Заявку в «ожидает удаления», «удаляется» или «удалена» возвращает как есть. |
| Отмена удаления | Снимает дату удаления с компании, обнуляет срок, переводит заявку в «отменено». Работает только для заявки в «ожидает удаления». |
| Отбор неактивных | Возвращает компании без даты удаления, у которых срок окончания доступа определён и раньше заданной границы, — от самого раннего срока, с необязательным ограничением количества. |
| Отбор созревших заявок | Возвращает заявки в статусе «ожидает удаления», у которых срок исполнения наступил. |

## Фоновые задачи

| Задача | Периодичность | Что делает |
| --- | --- | --- |
| Чистка компании | По требованию | Исполняет одну заявку: удаляет строки плана, у старой компании — данные вне общих таблиц, затем периодические задачи и роли компании, чистит карточку, сохраняет итог и сбрасывает кэши. Отказывается работать, если заявки нет, она не в «ожидает удаления»/«ошибка» или её срок ещё не наступил. |
| Исполнение отложенных удалений | Каждый час, в начале часа | Находит заявки в «ожидает удаления» с наступившим сроком и ставит на каждую задачу чистки. Заявки в «ошибке» не подхватывает. |
| Постановка неактивных на удаление | Ежедневно 04:15 | Отбирает компании без доступа дольше срока хранения, заводит на них заявки без автора и, если завела хотя бы одну, отправляет отчёт администраторам в Telegram. |

## Настройки окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| Срок хранения неактивной компании | 365 дней | Насколько давно должен закончиться доступ, чтобы компания попала в автоматическую постановку на удаление. |
| Предел автоматической постановки | 10 | Сколько компаний ставится на удаление за один прогон задачи. |
