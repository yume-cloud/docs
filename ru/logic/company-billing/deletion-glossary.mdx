Справочник к странице [«Удаление компании»](/ru/logic/company-billing/deletion).

## Понятия

| Понятие | Значение |
| --- | --- |
| Заявка на удаление | Запись, фиксирующая намерение удалить компанию: снимок компании, срок исполнения, статус и итог чистки. Одна на компанию. |
| Окно отмены | Семь дней между подтверждением удаления и фактической чисткой данных. Доступ компании закрыт всё это время. |
| Надгробие компании | Карточка компании, оставшаяся после чистки: данные удалены, служебные поля очищены, проставлена дата удаления, счета продолжают на неё ссылаться. |
| План чистки | Порядок удаления моделей «дети раньше родителей», выведенный из живого реестра моделей обходом обратных связей от записи компании. |
| Запечатанная модель | Модель с собственной непустой ссылкой на компанию: отбирается одним прямым путём вместо накопления транзитивных путей. |
| Граница обхода | Модели, за которые план не заходит: аккаунты пользователей, счета, справочники Django, журналы, записи планировщика. |
| Срок окончания доступа | Самая поздняя из двух дат: окончание подключённой подписки с тарифным периодом и окончание платного лимита. По ней отбираются компании для автоматической постановки на удаление. |

## Модели и поля

### Заявка на удаление компании

*Запись, фиксирующая намерение удалить компанию. Связана с компанией один-к-одному; создаётся при запросе удаления, исполняется фоновой задачей после истечения срока.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь (один-к-одному) | Компания, которую удаляют. |
| Статус | выбор | Текущее состояние заявки. |
| Кем запрошено | связь | Суперпользователь платформы, запросивший удаление. Пусто у автоматической постановки. |
| Снимок | JSON | Слепок компании на момент запроса: название, адрес, схема, страна, валюта, цвет, домены, состав администраторов. Нужен, чтобы сбросить кэши и показать заявку после того, как компания стала надгробием. |
| Удалено | JSON | Итог чистки: число удалённых строк по каждой модели. |
| Ошибка | текст | Трассировка упавшей чистки. |
| Срок исполнения | дата/время | Момент, начиная с которого чистку можно запускать: время запроса плюс семь дней. Обнуляется при отмене. |
| Начато | дата/время | Момент начала чистки. |
| Завершено | дата/время | Момент завершения чистки или отмены. |

**Вычисляемые поля**

| Поле | Описание |
| --- | --- |
| Строк удалено | Сумма всех значений в поле «Удалено». |
| Отменяема | Истинно только в статусе «ожидает удаления». |
| Осталось до удаления | Срок исполнения минус текущий момент; пусто, если срок не задан или заявка уже неотменяема. |

### Статусы заявки

| Статус | Значение |
| --- | --- |
| Ожидает удаления | Заявка создана, срок не наступил. Единственный статус, из которого возможна отмена. |
| Удаляется | Чистка запущена. |
| Удалена | Чистка завершена успешно, компания стала надгробием. |
| Ошибка | Чистка упала, трассировка сохранена в заявке. Заявку можно запустить повторно. |
| Отменено | Удаление отменено до истечения срока, доступ компании возвращён. |

## Службы

| Служба | Назначение |
| --- | --- |
| Построение плана | Обходит обратные связи от записи компании, «запечатывает» модели с собственной ссылкой на компанию, останавливается на границах обхода и возвращает порядок удаления вместе со списком связей, которые надо обнулить. Результат кэшируется. |
| Удаление строк | Выполняет план в одной транзакции: сначала обнуляет пограничные связи, затем прямыми запросами удаляет строки по каждой модели, в конце переводит ограничения в немедленный режим и обратно в отложенный. |
| Снос схемы | Удаляет схему компании целиком с проверкой формата имени и запретом служебных схем. Применяется к компаниям, оставшимся с прежней изоляцией по схемам. |
| Очистка карточки | Превращает компанию в надгробие: чистит логотип, фон и служебные данные, проставляет дату удаления, а у компании со снесённой схемой переводит запись на общую схему. |
| Сброс кэшей | Сбрасывает кэши компании по идентификатору, доменам и схеме, кэши аккаунтов и ролей её сотрудников. Вызывается при запросе, отмене и исполнении. |
| Запрос удаления | Создаёт или переиспользует заявку, снимает слепок, ставит срок на семь дней вперёд и проставляет компании дату удаления. |
| Отмена удаления | Снимает дату удаления с компании, обнуляет срок, переводит заявку в «отменено». |
| Отбор неактивных | Возвращает компании, у которых срок окончания доступа определён и раньше заданной границы, с необязательным ограничением количества. |

## Фоновые задачи

| Задача | Периодичность | Что делает |
| --- | --- | --- |
| Чистка компании | По требованию | Исполняет одну заявку: удаляет строки, сносит схему, чистит карточку, сохраняет итог. Отказывается работать, если заявка не в «ожидает удаления»/«ошибка» или её срок ещё не наступил. |
| Исполнение отложенных удалений | Каждый час | Находит заявки с истёкшим сроком и ставит на каждую задачу чистки. |
| Постановка неактивных на удаление | Ежедневно 04:15 | Отбирает компании без доступа дольше срока хранения, заводит на них заявки и отправляет отчёт администраторам в Telegram. |

## Настройки окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| Срок хранения неактивной компании | 365 дней | Насколько давно должен закончиться доступ, чтобы компания попала в автоматическую постановку на удаление. |
| Предел автоматической постановки | 10 | Сколько компаний ставится на удаление за один прогон задачи. |
