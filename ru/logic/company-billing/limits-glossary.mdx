## Модели и поля

### Лимит компании

*Лимит по конкретному типу ресурса для одной компании: сколько разрешено (платно и бесплатно) и сколько фактически используется. Уникальна пара (компания, тип); при сохранении лимит подтягивается минимум до бесплатного лимита; срок действия обязателен; кэш лимитов сбрасывается по сигналу сохранения.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец лимита. |
| Тип ресурса | выбор | Нормируемый ресурс из перечня типов лимита. |
| Текущее количество | число | Фактически используемое количество, пересчитывается задачей пересчёта лимита. |
| Лимит | число | Максимально разрешённое количество; при сохранении не может быть меньше бесплатного лимита. |
| Бесплатный лимит | число | Количество, доступное без оплаты. |
| Конец действия | дата/время (обязательное) | Конец периода действия лимита; при создании без указания — «сейчас + 30 дней». Выравнивается по дате окончания подписки на аренду при сохранении её подключения. Даты начала у лимита нет — купленный период фиксирует позиция счёта. |

### Цена лимита за период

*Цена единицы лимита для типа ресурса и длительности периода; глобальная (без компании) либо персональная для конкретной компании. Уникальна тройка (компания, тип, месяцы); при пустой компании цена глобальная, персональная имеет приоритет; поддерживаемые периоды 1/3/6/12 месяцев.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания для персональной цены; пусто — глобальная цена. |
| Тип ресурса | выбор | Нормируемый ресурс из перечня типов лимита. |
| Длительность периода | число (месяцы) | Период тарификации: 1, 3, 6 или 12 месяцев. |
| Цена | число (2 знака) | Стоимость единицы лимита за указанный период. |

### Менеджер лимитов с ценой

*Менеджер лимитов, который аннотирует каждый лимит полем цены, подбирая её из цен за период с приоритетом персональной цены над глобальной. Цена равна нулю, если тариф не настроен; подзапрос сортирует по компании с пустыми значениями в конце, чтобы персональная строка была первой.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена (аннотация) | число (2 знака) | Вычисляемое поле: подобранная цена лимита; 0 при отсутствии тарифа. |

### Получение цены лимита

*Функция, возвращающая цену лимита для компании, типа и длительности периода с приоритетом персональной цены над глобальной. Бросает ошибку при неподдерживаемом периоде и при отсутствии настроенной цены.*

### Пересчёт лимита (задача)

*Фоновая задача, пересчитывающая фактическое количество ресурсов компании (сотрудники, точки, авто/самокаты/мотоциклы), обновляющая текущее количество и уведомляющая администратора. Работает только внутри контекста компании; при пустом типе пересчитывает все типы подряд; шлёт web-уведомление и уведомление администратора при росте по сотрудникам, точкам аренды и автомобилям.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип лимита | выбор | Какой ресурс пересчитывать; пусто — все типы. |
| Слать уведомление | флаг | Отправлять ли web-уведомление о новом значении текущего количества. |

## Статусы и справочники

### Тип лимита

- Сотрудники
- Точки аренды
- Автомобили
- Самокаты
- Мотоциклы
