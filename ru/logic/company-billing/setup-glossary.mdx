## Понятия

Сквозные процессы и вспомогательные обработчики вокруг компании.

| Понятие | Значение |
| --- | --- |
| Менеджер компаний | Аннотирует каждую компанию вычисляемыми полями «Ссылка (домен)» (основной домен .yume.cloud либо account.yume.cloud) и «Код типа» и сортирует по убыванию идентификатора. |
| Создание компании | Единой операцией создаёт запись компании в общих таблицах, домен *.yume.cloud, членство владельца, лимиты, набор дефолтных справочников и настроек компании и демо-подключения модулей; после фиксации отправляет владельцу письмо «Компания создана». Срока у самой записи нет: пробный доступ — это сроки демо-подключений (длительность демо интеграции, по умолчанию 7 дней). |
| Генерация лимитов плана | Создаёт недостающие лимиты компании (персонал, пункты проката, инвентарь по типам ТС) и сбрасывает кэш лимитов; вызывается при создании компании и при нехватке лимитов. |
| Регистрация кастомного домена | Фоновая задача: проверяет DNS кастомного домена (сверка IP), вызывает внешний API регистрации и при успехе помечает домен верифицированным; при неудаче повторяет с задержкой — до 30 повторов с интервалом 15 минут. |
| Формат аккаунта компании | Чтение и создание компании через API: валидирует поддомен (чёрный список и занятость), отдаёт вычисляемые ссылку-домен, код типа и лимиты, при создании запускает провижининг компании. |
| Проверка занятости поддомена | Проверяет, свободен ли запрошенный поддомен; занятые и зарезервированные (из чёрного списка) считаются существующими. |
| Заявка на демо | Принимает заявку на демо (телефон, ФИО, сфера) и отправляет уведомление в Telegram-канал администраторов. |
| Регистрация компании | Создаёт нового пользователя (телефон, почта, пароль с проверкой уникальности), уведомляет администратора «РЕГИСТРАЦИЯ ПОЛЬЗОВАТЕЛЯ» и после фиксации отправляет пользователю приветственное письмо. Компанию не создаёт — её пользователь заводит сам отдельным запросом; используется вне контекста конкретной компании. |
| Вход компании | Устаревший вход компании, возвращающий токены без идентификатора компании; помечен на удаление после обновления iOS/Android. |

## Модели и поля

### Компания

*Основная запись компании: связывает её данные с владельцем. Данные всех компаний лежат в общих таблицах: каждая строка компании несёт ссылку на неё, а менеджеры моделей ограничивают выборки активной компанией. Отдельного хранилища у компании нет — см. [«Разделение данных компаний»](/ru/logic/infrastructure).*

Менеджер добавляет вычисляемые поля «Ссылка (домен)» и «Код типа».

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ компании. |
| Название | текст | Название компании. |
| Адрес | текст | Адрес компании. |
| Служебное имя (`schema_name`) | текст | Техническое имя компании. У каждой новой компании — общее значение по умолчанию; собственное имя осталось только у старых компаний, и на него опираются старые пути кода (например, чистка при удалении). Собственные имена уникальны. |

Полей срока у компании нет: поля начала и окончания периода удалены 27.07.2026. Сроки живут в подключениях интеграций и в лимитах, общий срок доступа вычисляется — см. [«Срок доступа компании»](/ru/logic/company-billing/invoices#срок-доступа-компании).

**Оформление**

| Поле | Тип | Описание |
| --- | --- | --- |
| Логотип | изображение | Логотип компании. |
| Фон | изображение | Фоновое изображение. |
| Фирменный цвет | текст (HEX) | Цвет бренда, по умолчанию #f25a29. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Владелец | связь | Пользователь-владелец компании (хранится в общих таблицах, удаление запрещено при наличии связей). |
| Тип компании | связь | Категория/сфера деятельности (тип компании). |

**Локализация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Страна | список | Страна из справочника стран, по умолчанию Казахстан. |
| Валюта | список | Валюта из справочника валют, по умолчанию тенге. |
| Часовой пояс | текст | Часовой пояс компании, по умолчанию UTC. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Доп. данные | JSON | Произвольные дополнительные данные; в том числе ИИН и БИН компании (ключи `iin` и `bin`; прежние настройки `company_iin` и `company_bin` перенесены сюда миграцией там, где ключ был пуст) и отметка последнего напоминания об окончании подписки (ключ `subscription_reminder`). |
| Теги | связь (M2M) | Теги компании. |
| Дата удаления | дата/время | Пусто у действующей компании. Проставляется при запросе удаления и снимается при отмене; компания с датой удаления в запросах не резолвится. |
| Дата создания | дата/время | Из базовой модели. |
| Дата обновления | дата/время | Из базовой модели. |

**Вычисляемые**

| Поле | Тип | Описание |
| --- | --- | --- |
| Ссылка (домен) | текст | Вычисляется менеджером: основной домен .yume.cloud либо account.yume.cloud; в самой модели значение отсутствует. |
| Код типа | текст | Вычисляется менеджером на основе типа компании. |

### Домен компании

*Домен, привязанный к компании; хранит признак кастомного домена и статус его верификации.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Домен | текст | Полное доменное имя. |
| Компания | связь | Компания-владелец домена. |
| Основной домен | флаг | Признак основного домена. |
| Кастомный домен | флаг | Домен добавлен клиентом, требует внешней регистрации. |
| Верифицирован | флаг | Домен подтверждён (по умолчанию да). |
| Дата верификации | дата/время | Момент успешной проверки/регистрации. |

### Шаг онбординга компании

*Отметка о пройденном шаге онбординга — общая для компании или личная для менеджера.*

Уникальна тройка (компания, пользователь, шаг), а среди общих отметок (без пользователя) — пара (компания, шаг).

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Компания | связь | Компания. |
| Пользователь | связь | Необязательное. Пусто — отметка общая для компании; заполнено — личная для этого менеджера. |
| Шаг | текст | Код пройденного шага онбординга. |
| Дата прохождения | дата/время | Когда шаг был отмечен. |

### Профиль компании (витрина)

*Публичный профиль/карточка компании в витрине: категория, описание, адрес, оформление и признак приёма оплаты.*

Отдельная сущность от компании; связь с компанией пересекается со списком её витринных профилей.

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Компания | связь | Компания. |
| Пользователь | связь | Пользователь-владелец опубликованного профиля. |
| Категория | связь | Тип компании. |
| ID пункта проката | число | Ссылка на пункт проката в данных компании. |

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Активен | флаг | Виден ли профиль. |
| Название | текст | Название в витрине. |
| Описание | текст | Описание компании. |
| Адрес | текст | Адрес. |
| Ссылка на карте | текст (URL) | Ссылка на карту/2GIS. |

**Оформление**

| Поле | Тип | Описание |
| --- | --- | --- |
| Иконка | файл | Иконка профиля. |
| Фон | изображение | Фон профиля. |
| Доп. данные | JSON | Произвольные данные. |
| Приём оплаты | флаг | Включён ли приём онлайн-оплаты. |
| Дата создания | дата/время | Из базовой модели. |
| Дата обновления | дата/время | Из базовой модели. |

### Режим работы профиля

*График работы публичного профиля компании: дни недели и интервал времени.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Профиль компании | связь | Профиль компании. |
| Дни недели | список чисел | Дни недели 0–6, к которым применяется интервал. |
| Начало | время | Время открытия. |
| Окончание | время | Время закрытия. |
| Активен | флаг | Применяется ли данный интервал. |

### Привязка периодической задачи к компании

*Связывает периодическую задачу (django-celery-beat) с компанией, делая задачу зависимой от неё: прописывает идентификатор компании в заголовки задачи и, при необходимости, часовой пояс компании в расписание.*

Связь один-к-одному с периодической задачей; синхронизация выполняется при сохранении и через сигнал выравнивания.

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Компания | связь | Компания, к которой привязана задача. |
| Периодическая задача | связь (1:1) | Задача django-celery-beat. |
| Использовать часовой пояс компании | флаг | Если включено, расписание пересчитывается в часовой пояс компании, иначе используется UTC. |

## Статусы и справочники

### Тип компании

*Справочник сфер деятельности и категорий компаний (прокат авто, самокатов и т.п.), используемый при регистрации и в витрине; это редактируемый справочник.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Название | текст | Отображаемое название типа. |
| Код | текст | Машинный код типа. |
| Иконка | файл | Иконка типа компании. |
| Опубликован | флаг | Виден ли тип в публичном списке. |
| Активен | флаг | Доступен ли тип для выбора. |
| Порядок | число | Порядок сортировки. |
| Страна | список | Страна, для которой предназначен тип. |

### Страна

Поддерживаемые страны компаний. Коды — по стандарту ISO 3166-1 alpha-2.

- Казахстан (KZ)
- Кыргызстан (KG)
- Узбекистан (UZ)
- Турция (TR)
- Саудовская Аравия (SA)
- ОАЭ (AE)

### Валюта

Поддерживаемые валюты компаний.

- Тенге (KZT)
- Доллар США (USD)
- Рубль (RUB)
- Евро (EUR)
- Узбекский сум (UZS)
- Киргизский сом (KGS)
- Дирхам ОАЭ (AED)
- Саудовский риял (SAR)
