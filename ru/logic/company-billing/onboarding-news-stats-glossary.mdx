## Понятия

| Понятие | Значение |
| --- | --- |
| Задача архивации просроченных заявок | Фоновая задача, задуманная помечать удалёнными забронированные заявки с приближающимся стартом аренды по настройкам автоархивации и буфера. Перебирает только старые компании с собственным служебным именем (`schema_name`) и устанавливает контекст по этому имени, без активной компании; настройки в таком контексте читаются как значения по умолчанию («выключено»), поэтому в текущем коде задача ничего не архивирует. В `CELERY_BEAT_SCHEDULE` её нет. |
| Задача отправки email | Фоновая задача, через которую уходят все транзакционные письма: текстовая часть и опциональная HTML-альтернатива, отправитель `DEFAULT_FROM_EMAIL`, заголовок `Auto-Submitted: auto-generated`, очередь «default». Ошибки не подавляются, автоповтора нет. Подробнее — [«Транзакционные письма»](/ru/logic/notifications/emails). |
| Список новостей (API) | Публичный список новостей, отсортированный от новых к старым, с подгруженными изображениями. |
| Детали новости (API) | Получение одной новости по идентификатору с подгруженными изображениями. |
| Формат новости | Формирует ответ по новости: идентификатор, заголовок, содержимое, изображения, дата создания. Изображения только для чтения. |

## Модели и поля

### Шаг онбординга компании

*Отметка о пройденном шаге онбординга: общая для компании или личная для одного менеджера. Уникальна тройка «компания — пользователь — шаг», а среди общих отметок — пара «компания — шаг».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Компания | связь | Компания. |
| Пользователь | связь | Необязательное. Пусто — отметка общая для компании; заполнено — личная, видна только этому менеджеру; удаляется вместе с пользователем. |
| Шаг | текст | Код пройденного шага онбординга. Шаги `todo_…` всегда личные. |
| Личная отметка | флаг (только запись) | Признак в запросе на отметку шага; по умолчанию выключен. Включённый привязывает отметку к отправившему менеджеру. |
| Дата прохождения | дата/время | Когда шаг был отмечен. |

### Новость

*Системная новость/анонс с форматированным содержимым и вложенными изображениями. Наследует стандартную пару «дата создания / дата обновления».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Заголовок | текст | Заголовок новости. |
| Содержимое | форматированный текст | HTML-контент, редактируется через визуальный редактор. |
| Изображения | связь (список) | Прикреплённые изображения (обобщённая связь с изображениями-вложениями). |
| Дата создания | дата/время | Момент создания (индексируется). |
| Дата обновления | дата/время | Момент последнего изменения. |

**Пользователи**

| Число пользователей | число | Общее количество пользователей. |

**Тариф**

| Период тарифа | число | Длительность периода подписки (в месяцах). |

### Планировщик пени по заявке

*Запись-таймер по конкретной заявке на аренду: периодическое начисление пени за просрочку или разовое напоминание до неё. Просрочка уникальна по тройке «компания — заявка — индекс», напоминание — по тройке «компания — заявка — триггер»; идентификатор заявки — «сырой» ID без связи с таблицей заявок.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания, к которой относится запись; может быть пустой. |
| Вид | выбор | «Просрочка» (по умолчанию) или «Напоминание до просрочки». |
| Индекс | число | У просрочки — порядковый номер группы позиций заявки с общим сроком возврата; у напоминания — 0. |
| ID заявки | число | Идентификатор заявки на аренду; ищется в контексте компании из записи. |
| ID триггера | число | Только у напоминания: триггер сообщения, по которому оно уходит. |
| Время начисления | дата/время | Момент срабатывания: срок возврата группы позиций или окончание аренды минус упреждение триггера. |
| Последний запуск | дата/время | Момент последнего срабатывания. |
| Интервал | интервал | Период повтора: у просрочки — шаг пени из заявки (по умолчанию в модели 1 час), у напоминания пусто — срабатывает один раз. |
| Включено | флаг | Активна ли запись; по умолчанию выключена. |
