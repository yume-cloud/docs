## Модели и поля

### Прибыль (запись начисления)

*Денормализованная построчная запись начисленной и спрогнозированной прибыли за один день по одному источнику дохода (аренда, услуга, доставка, штраф, продажа, работа мастерской).*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата | дата | День, за который начислена сумма. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь | |
| Заявка (аренда) | связь | Аренда, к которой относится начисление. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Прогноз (начислено) | число (2 знака) | Сумма, причитающаяся за день по графику, независимо от факта оплаты. |
| Прибыль (получено) | число (2 знака) | Фактически зачтённая сумма за день с учётом оплаты. |

### Строка дневной сводки

*Одна строка агрегированной дневной сводки: количество и суммы по каждому типу дохода за день плюс итоговые прогноз и прибыль.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата | дата | |

**Счётчики**

| Поле | Тип | Описание |
| --- | --- | --- |
| Количество аренд | число | Число заявок с начислением инвентаря за день. |
| Количество услуг | число | |
| Количество доставок | число | |
| Количество штрафов | число | |
| Количество задач мастерской | число | |
| Количество продаж | число | |

**Суммы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма по аренде | число (2 знака) | Прогнозная сумма начислений по аренде инвентаря за день. |
| Сумма по услугам | число (2 знака) | |
| Сумма по доставкам | число (2 знака) | |
| Сумма по штрафам | число (2 знака) | |
| Сумма по мастерской | число (2 знака) | |
| Сумма по обслуживанию | число (2 знака) | |
| Сумма по продажам | число (2 знака) | |

**Итоги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Итоговый прогноз | число (2 знака) | Сумма прогнозируемого дохода по всем типам за день. |
| Итоговая прибыль | число (2 знака) | Сумма фактически зачтённой прибыли по всем типам за день. |

### Строка детализации дневной сводки

*Одна запись из таблицы «Прибыль» с подтянутыми данными об инвентаре, услуге, клиенте и фактической оплате — построчная детализация сводки за день.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата | дата | |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Прогноз | число (2 знака) | Начисленная за день сумма по этой записи. |
| Прибыль | число (2 знака) | Фактически зачтённая сумма по этой записи. |
| Оплачено клиентом | число (2 знака) | Сумма оплат клиента за этот день, подобранная по заявке/продаже/задаче мастерской. |

**Клиент**

| Поле | Тип | Описание |
| --- | --- | --- |
| Имя клиента | текст | |
| Статус заявки | число (код статуса) | Статус связанной аренды. |

**Клиент**
