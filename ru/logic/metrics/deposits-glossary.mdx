Справочник к странице [«Депозиты»](/ru/logic/metrics/deposits).

## Понятия

| Понятие | Значение |
| --- | --- |
| Залог по аренде | Запись о денежном или предметном залоге, взятом с клиента при оформлении аренды, и его возврате. |

## Модели и поля

### Залог по аренде

| Поле | Тип | Описание |
| --- | --- | --- |
| **Идентификация** | | |
| Тип залога | список (перечисление) | Залог в виде предмета/описания или в виде денежной суммы. |
| Статус залога | список (перечисление) | Ожидает внесения, внесён или возвращён клиенту; у аренд в режиме «деньги на хранении» выводится из фактических денег. |
| **Связи** | | |
| Аренда | связь | |
| **Деньги** | | |
| Сумма залога | число (2 знака) | Номинал: сколько условлено взять. Заполняется для денежного залога. |
| **Сроки** | | |
| Дата возврата | дата/время | |
| Дата создания | дата/время | |

### Вычисляемые показатели отчёта по залогам

*Дополнительные поля, добавляемые отчётом по залогам поверх модели через аннотации запроса; не хранятся в базе.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Точка проката | связь | Точка проката, взятая из связанной аренды. |
| Режим учёта залога | флаг | Взят из аренды: ведётся ли залог как деньги на хранении. |
| Сумма фактических платежей | число (2 знака) | Сумма связанных операций по залогу, включая незавершённые. |
| Внесено | число (2 знака) | Сумма приходных операций залога. |
| Выдано | число (2 знака) | Сумма расходных операций залога — и возвраты, и зачёты. |
| Зачтено | число (2 знака) | Расходные операции с признаком зачёта: ушло в счёт аренды. |
| Возвращено | число (2 знака) | Выдано минус зачтено: отдано клиенту. |
| В кассе | число (2 знака) | Внесено минус выдано. |

### Сводка по залогам

*Итоговые агрегированные показатели по всем залогам, отображаемые в шапке отчёта по залогам; считается через агрегацию по отфильтрованному списку залогов, полям на модели не соответствует напрямую.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Общая сумма залогов | число (2 знака) | |
| Сумма внесённых залогов | число (2 знака) | Сумма залогов со статусом «Внесён». |
| Сумма возвращённых залогов | число (2 знака) | Сумма залогов со статусом «Возвращён». |
| Сумма ожидающих залогов | число (2 знака) | Сумма залогов со статусом «Ожидает внесения». |
| Количество денежных залогов | число | Четыре счётчика: всего, внесено, возвращено, ожидает. |
| Сумма фактических платежей | число (2 знака) | Суммарно по всем операциям залогов из списка. |
| Внесено / Выдано / Зачтено / Возвращено / В кассе | число (2 знака) | Фактические деньги суммарно по всем залогам из списка. |
