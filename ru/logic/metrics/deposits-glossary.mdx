Справочник к странице [«Депозиты»](/ru/logic/metrics/deposits).

## Понятия

| Понятие | Значение |
| --- | --- |
| Залог по аренде | Запись о денежном или предметном залоге, взятом с клиента при оформлении аренды, и его возврате. |

## Модели и поля

### Залог по аренде

| Поле | Тип | Описание |
| --- | --- | --- |
| **Идентификация** | | |
| Тип залога | список (перечисление) | Залог в виде предмета/описания или в виде денежной суммы. |
| Статус залога | список (перечисление) | Не оформлен, получен или возвращён клиенту. |
| **Связи** | | |
| Аренда | связь | |
| **Деньги** | | |
| Сумма залога | число (2 знака) | Заполняется для денежного залога. |
| **Сроки** | | |
| Дата возврата | дата/время | |
| Дата создания | дата/время | |

### Вычисляемые показатели отчёта по залогам

*Дополнительные поля, добавляемые отчётом по залогам поверх модели через аннотации запроса; не хранятся в базе.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Точка проката | связь | Точка проката, взятая из связанной аренды. |
| Сумма фактических платежей | число (2 знака) | Сумма связанных платежей по залогу. |

### Сводка по залогам

*Итоговые агрегированные показатели по всем залогам, отображаемые в шапке отчёта по залогам; считается через агрегацию по отфильтрованному списку залогов, полям на модели не соответствует напрямую.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Общая сумма залогов | число (2 знака) | |
| Сумма полученных залогов | число (2 знака) | Сумма залогов со статусом «Получен». |
| Сумма возвращённых залогов | число (2 знака) | Сумма залогов со статусом «Возвращён». |
| Количество денежных залогов | число | |

## Статусы и справочники

### Тип залога

- Описание/предмет
- Денежная сумма

### Статус залога

- Не оформлен
- Получен
- Возвращён
