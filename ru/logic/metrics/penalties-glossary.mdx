Справочник к странице [«Штрафы»](/ru/logic/metrics/penalties).

## Понятия

| Понятие | Значение |
| --- | --- |
| Штраф аренды | Штраф, начисленный клиенту или по конкретной аренде — автоматически (например за просрочку возврата единицы инвентаря) или вручную сотрудником. Оплата штрафа отслеживается через связанные проводки прибыли; статус оплаты вычисляется в отчёте, а не хранится в модели. |

## Модели и поля

### Штраф аренды

*Оплата штрафа отслеживается через связанные проводки прибыли; статус оплаты вычисляется в отчёте, а не хранится в модели.*

| Поле | Тип | Описание |
| --- | --- | --- |
| **Идентификация** | | |
| Тип штрафа | список (перечисление) | Автоматический (по просрочке/инвентарю) или вручную созданный сотрудником. |
| **Связи** | | |
| Клиент | связь | Клиент, на которого начислен штраф (может быть без привязки к конкретной аренде). |
| Аренда | связь | Аренда, к которой относится штраф (может быть без привязки к клиенту напрямую — заполняется либо клиент, либо аренда). |
| **Деньги** | | |
| Сумма штрафа | число (2 знака) | |
| Оплаченная сумма (на модели) | число (2 знака) | Поле на модели; в отчёте фактическая оплата берётся из суммы связанных проводок прибыли. |
| **Прочее** | | |
| Дата создания | дата/время | |

### Вычисляемые показатели отчёта по штрафам

*Дополнительные поля, которые отчёт по штрафам добавляет поверх модели штрафа через аннотации запроса; не хранятся в базе — считаются в момент построения отчёта.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название единицы инвентаря | текст | |
| Оплаченная сумма | число (2 знака) | Сумма проводок прибыли, привязанных к штрафу. |
| Остаток к оплате | число (2 знака) | Сумма штрафа минус оплаченная сумма. |

- Ручной

- Оплачен
