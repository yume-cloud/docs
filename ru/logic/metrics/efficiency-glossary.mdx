Справочник к странице [«Эффективность инвентаря»](/ru/logic/metrics/efficiency).

## Понятия

| Понятие | Значение |
| --- | --- |
| Эффективность единицы инвентаря | Строка отчёта по одной единице инвентаря (карточка) с показателями простоя, загрузки и упущенной выручки за период; расширяет карточку инвентаря (с данными по авто, если модуль авто включён) метриками эффективности. |
| Эффективность по заявкам инвентаря | Строка отчёта по единице инвентаря, группе инвентаря или комплекту (набору), агрегирующая заявки аренды и доход за период; один и тот же формат ответа используется для трёх разных уровней группировки — единица, группа, комплект. |
| Период отчёта | Параметры `start_at` / `end_at`, общие для всех четырёх отчётов: обе границы включаются и необязательны; недостающую границу подставляют данные (день заведения единицы, сегодняшний день или крайние даты начислений в выборке). |

## Модели и поля

### Эффективность единицы инвентаря

*Расширяет карточку инвентаря (с данными по авто, если модуль авто включён) метриками эффективности.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Дней в аренде | число | Количество дней за период, когда по единице инвентаря была зафиксирована прибыль (фактическая занятость). |
| Дней простоя | число | Разница между всеми днями периода и днями в аренде (не может быть отрицательной). |
| Дней в периоде | число | Длина периода для единицы в днях, включительно: от более поздней из дат «начало периода» и «день заведения единицы» до дня отключения единицы, а если она не отключена — до конца периода (без `end_at` — до сегодняшнего дня). |
| Выручка | число (2 знака) | Сумма прогнозной выручки (prediction) по единице инвентаря за период. |
| Упущенная выручка | число (2 знака) | Сколько выручки недополучено из-за простоя — рассчитывается из выручки и загрузки: выручка × 100 / загрузка − выручка. |
| Загрузка, % | число (2 знака) | Доля дней в аренде от общего числа дней периода (0–100%): дни в аренде × 100, делённые на дни периода нацело, — всегда целое число процентов. |

### Эффективность по заявкам инвентаря

*Один и тот же формат ответа используется для трёх разных уровней группировки — единица, группа, комплект.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор объекта | число | Id единицы инвентаря, группы или комплекта — в зависимости от адреса. |
| Название | текст | Наименование единицы инвентаря, группы или комплекта. |
| Доход | число (2 знака) | Суммарная прибыль (profit) по начислениям выборки за период. По единице выборку ограничивает фильтр учитываемой прибыли (аренды не архивированные, в статусах «в аренде», «просрочена», «завершена», «должник» или отменённые с оплатой, проданные продажи); по группе и комплекту — аренды в любом статусе, у группы ещё и продажи в любом статусе. |
| Всего заявок | число | По единице — количество уникальных аренд в выборке, по комплекту — уникальных вхождений комплекта в аренды, по группе — количество строк начислений, а не аренд. |
| Дней по заявкам | число | Количество уникальных дат начислений объекта в выборке. |
| Успешных заявок | число | То же, что «Всего заявок», но только по арендам в статусах «в аренде», «просрочена», «завершена» или «должник»; у группы и комплекта — включая архивированные. |
| Успешных дней | число | Количество дат начислений, приходящихся на успешные заявки. |
| Сумма по успешным заявкам | число (2 знака) | Суммарная прибыль только по успешным заявкам. |
| Эффективность, % | число (2 знака) | Успешных заявок / всего заявок × 100; деление целочисленное, поэтому сейчас значение всегда 0 или 100 (100 — только когда все заявки строки успешны). |
| Дней в периоде | число | Длина периода в днях, одна на все строки; без границ периода — от первой до последней даты начислений в выборке отчёта. |
