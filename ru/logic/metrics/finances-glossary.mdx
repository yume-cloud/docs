## Понятия

| Понятие | Значение |
| --- | --- |
| Финансовая операция | Запись о поступлении или списании денег (оплата аренды, продажи, мастерской, депозита, штрафа, произвольная операция по счёту), лежит в основе списка операций и всех отчётов. Сумма автоматически становится отрицательной для списания и положительной для поступления. |
| Счёт (касса) | Счёт или касса компании, на котором учитывается баланс денежных операций; используется как фильтр в списке операций. |
| Статья доходов/расходов | Классификатор операций (например, «Аренда», «Зарплата», «Топливо»), используется для группировки в PnL и кэшфлоу по категориям. Поддерживает иерархию через родительскую статью; выключенные статьи исключаются из PnL. |
| Вид оплаты | Справочник способов оплаты (наличные, карта, перевод и т.п.). |
| Ведомость (кассовый ордер) | Дополнительная детализация операции: к какому инвентарю/контрагенту она относится и на какую дату фактически приходится (для отчётов по месяцам). Дата ведомости может отличаться от даты создания операции. |
| Возврат оплаты | Отметка о том, что операция была возвращена клиенту, с причиной. |
| Оплата бонусами | Финансовая операция с заполненной бонусной операцией: аренда, оплаченная бонусными баллами клиента, а не деньгами. Приход без вида оплаты и без счёта; фильтр `bonus__isnull=true` оставляет в отчётах только деньги. |
| Фильтр учитываемой прибыли | Общее правило, какие записи прибыли считаются «настоящей» выручкой в отчётах (например, продажа должна быть в статусе «продано», аренда — не отменена без оплаты). Используется во всех денежных отчётах, не только в PnL. |

## Модели и поля

### Финансовая операция

*Хранится в таблице операций; сумма автоматически становится отрицательной для списания и положительной для поступления.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Направление операции | список (перечисление) | Поступление или списание. |
| Вид оплаты | связь | Ссылка на справочник видов оплаты (наличные, карта и т.п.). |
| Статус операции | список (перечисление) | Ожидает/успешно/ошибка/истёк срок. По умолчанию «успешно»; платёж через Kaspi Pay создаётся «ожидает оплаты». |
| Статья | связь | Статья доходов/расходов для группировки в отчётах. |
| Счёт | связь | Счёт/касса, на которую отнесена операция. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма | число (2 знака) | Положительная для поступления, отрицательная для списания. |

**Сроки**

| --- | --- | --- |
| Дата и время создания | дата/время | Используется как дата операции, если нет даты ведомости. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Продажа | связь | Операция привязана к продаже. |
| Аренда | связь | Операция привязана к заявке на аренду. |
| Задача мастерской | связь | Операция привязана к работе мастерской. |
| Обслуживание | связь | Операция привязана к обслуживанию инвентаря. |
| Депозит | связь | Операция привязана к депозиту по аренде. |
| Штраф | связь | Операция привязана к штрафу по аренде. |
| Возврат | связь | Информация о возврате этой операции. |
| Ведомость (кассовый ордер) | связь | Детализация операции: инвентарь, контрагент, дата ведомости. |

## Статусы и справочники

### Направление операции

Используется в направлении операции, направлении по умолчанию статьи, направлении ведомости, типе ведомости задачи мастерской.

- Поступление (приход)
- Списание (расход)

### Статус операции

Платёж через Kaspi Pay создаётся «Ожидает оплаты» и по ответу Kaspi переходит в «Успешно», «Ошибка» или «Истёк срок»; остальные операции по умолчанию создаются «Успешно».

Список операций, PnL и кэшфлоу учитывают операции в любом статусе; оставить только успешные можно фильтром `status=success`. Начисленную прибыль PnL статус операций не затрагивает. Одни успешные операции считает только сводка `/v1/finances/transactions/general/` — это условие встроено в расчёт. Остаток счёта складывается из успешных операций, дата которых наступила.

- Ожидает оплаты
- Успешно
- Ошибка
- Истёк срок

### Тип источника прибыли

Категория операции, по которой можно отфильтровать дневную сводку и детализацию прибыли.

- Аренда (инвентарь)
- Инвентарь
- Услуга
- Доставка
- Штраф
- Мастерская (работа)
- Обслуживание
- Продажа
