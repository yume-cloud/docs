## Понятия

| Понятие | Значение |
| --- | --- |
| Доставка аренды | Задание на доставку или самовывоз инвентаря по конкретной аренде, назначенное исполнителю; источник данных для отчёта по доставкам, группируется по исполнителю. |
| Задача мастерской | Работа по ремонту/обслуживанию инвентаря, выполняемая сотрудником мастерской; основной источник данных для отчёта по мастерской, группируется по исполнителю. |
| Признак просрочки задачи | Вычисляемый (не хранимый) признак: задача не завершена, а плановая дата завершения уже прошла. |
| Ресурс задачи мастерской | Использованная в задаче единица инвентаря, запчасть или материал (ресурс склада) с ценой; влияет на стоимость ресурсов задачи. |
| Сводка по расходным ресурсам | Агрегированная строка отчёта: сколько потрачено конкретного ресурса и на какую сумму. |
| Этап воронки продаж | Настраиваемый этап (столбец) воронки, через который проходят лиды; используется в отчёте по скорости прохождения этапов. |
| Лид (сделка воронки) | Карточка потенциальной сделки, движущаяся по этапам воронки продаж. |
| История переходов лида | Журнал переходов лида с одного этапа воронки на другой; по нему считается средняя длительность на этапе и скорость менеджера. |
| Сводка по воронке продаж | Итоговый отчёт по воронке: общее число лидов, число за период, самый загруженный этап, средняя скорость по этапам и по сотрудникам. |
| Продажа со склада | Документ продажи товара со склада клиенту; основа отчёта по продажам, прибыль считается как выручка минус себестоимость. |
| Позиция продажи | Строка продажи — конкретный товар или группа товаров, проданные в рамках документа продажи, с ценой и себестоимостью. |
| Сводка по продажам (итоги) | Общие итоги по продажам за период: выручка, количество, себестоимость, прибыль. |
| Сводка по продажам (по товарным группам) | Разбивка продаж по товарным группам с рентабельностью каждой группы. |
| Инвентаризация | Запись о смене состояния конкретной единицы инвентаря (проверка, приёмка, возврат и т.п.); основа отчёта по переходам состояний. |
| Переход состояния инвентаря | Агрегированная строка отчёта: сколько раз конкретный сотрудник перевёл инвентарь из одного состояния в другое. |
| Фильтр периода отчёта | Общий примесь-класс для отчётов, принимающий начало и конец периода в параметрах запроса; по умолчанию период — текущий календарный месяц. |

## Модели и поля

### Доставка аренды

*Источник данных для отчёта по доставкам; группируется по исполнителю.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Аренда (заявка) | связь | Аренда, к которой относится доставка. |
| Исполнитель | связь | Сотрудник-водитель/курьер, выполняющий доставку; по нему строится группировка отчёта. |
| Тип | список (перечисление «Тип доставки») | Доставка или самовывоз. |
| Статус | список (перечисление «Статус доставки») | Текущий статус выполнения. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата и время назначения | дата/время | Запланированная дата доставки/самовывоза; фильтр отчёта по периоду. |
| Дата доставки | дата/время | Фактическое время завершения доставки; используется для расчёта длительности и «последней доставки». |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Стоимость доставки | число (2 знака) | Сумма, начисленная за доставку; основа денежных показателей отчёта. |
| Стоимость со скидкой | число (2 знака) | — |

### Задача мастерской

*Основной источник данных для отчёта по мастерской; группируется по исполнителю.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип задачи | список (перечисление «Тип задачи мастерской») | Внутренняя или внешняя (сторонний сервис). |
| Статус | список (перечисление «Статус задачи мастерской») | Стадия выполнения задачи. |
| Тип проводки | список (перечисление «Тип метода транзакции») | Приход/расход по задаче. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Исполнитель | связь | Сотрудник, выполняющий задачу; по нему строится группировка отчёта. |
| Клиент | связь | — |
| Аренда (заявка) | связь | Связанная аренда, если задача возникла из неё. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Итоговая стоимость | число (2 знака) | Сумма услуг + ресурсов; пересчитывается автоматически при изменении услуг/ресурсов. |
| Стоимость услуг | число (2 знака) | Сумма по связанным услугам задачи. |
| Стоимость ресурсов | число (2 знака) | Сумма по использованным ресурсам/запчастям задачи. |
| Оплачено | число (2 знака) | Сумма фактических платежей по задаче. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата завершения | дата/время | Плановая/фактическая дата окончания; используется для расчёта длительности и признака просрочки. |
| Дата создания | дата/время | Используется для расчёта длительности и фильтра периода. |

### Признак просрочки задачи

*Вычисляемый (не хранимый) признак: задача не завершена, а плановая дата завершения уже прошла.*

Статус вычисляется на лету в отчёте, не хранится в базе; считается для задач в статусах «Новая»/«В процессе», у которых дата завершения меньше текущего момента.

### Ресурс задачи мастерской

*Источник данных для отчёта «ресурсы мастерской»; суммы влияют на поле «Стоимость ресурсов» задачи.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Задача мастерской | связь | Задача, к которой относится ресурс. |
| Инвентарь | связь | Конкретная единица инвентаря, списанная как ресурс. |
| Группа инвентаря | связь | Товарная группа, если списывается не единичный инвентарь. |
| Количество | число (2 знака) | Количество единиц из группы. |
| Стоимость | число (2 знака) | Цена использованного ресурса. |
| Складской ресурс | связь | Запись справочника ресурсов (материал/расходник). |

### Сводка по расходным ресурсам

*Не модель — сериализатор для агрегированного представления.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название ресурса | текст | — |
| Цена ресурса | число (2 знака) | — |
| Списанное количество/сумма | число (2 знака) | — |

### Этап воронки продаж

*Используется в отчёте по скорости прохождения этапов.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | — |
| Воронка | связь | Воронка, которой принадлежит этап. |
| Тип этапа | список (перечисление «Тип этапа воронки») | Обычный, успешный или отменённый. |
| Порядок | число | Позиция этапа в воронке. |

### Лид (сделка воронки)

*По количеству лидов и их истории строится отчёт по воронке.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Клиент | связь | — |
| Текущий этап | связь | Этап воронки, на котором находится лид сейчас. |
| Воронка | связь | Фильтр отчёта по конкретной воронке. |
| Менеджер | связь | Ответственный сотрудник. |
| Сумма сделки | число (2 знака) | — |
| Дата создания | дата/время | Используется для фильтра периода в отчёте. |

### История переходов лида

*По разнице времени между записями считается средняя длительность нахождения на этапе и скорость менеджера.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Лид | связь | — |
| Пользователь | связь | Сотрудник, выполнивший переход; по нему считается «скорость менеджера». |
| Предыдущий этап | связь | Этап, с которого лид ушёл; по нему группируется средняя длительность этапа. |
| Новый этап | связь | Этап, на который лид перешёл. |
| Дата перехода | дата/время | Момент перехода; используется для расчёта длительности между переходами. |

### Сводка по воронке продаж

*Составной отчёт, не модель; вкладывает «Загруженность этапа», «Скорость этапа» и «Скорость сотрудника».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Всего лидов | число | Общее количество лидов (без фильтра по периоду). |
| Лидов за период | число | Количество лидов, созданных в выбранном периоде. |
| Самый загруженный этап | связь | Этап с наибольшим числом лидов, поступивших за период (кроме финальных этапов). |
| Скорость по этапам | список | Средняя длительность нахождения лида на каждом этапе. |
| Скорость по сотрудникам | список | Средняя скорость перевода лида на следующий этап по каждому сотруднику. |

### Продажа со склада

*Основа отчёта по продажам; прибыль считается как выручка минус себестоимость проданных позиций.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Клиент | связь | — |
| Точка проката | связь | — |
| Статус продажи | список (перечисление «Статус продажи») | В отчёт попадают только завершённые (проданные) продажи. |
| Сумма без скидки | число (2 знака) | — |
| Сумма скидки | число (2 знака) | — |
| Сумма со скидкой | число (2 знака) | Итоговая выручка по продаже; основа расчёта прибыли и рентабельности. |
| Оплачено | число (2 знака) | — |
| Дата создания | дата/время | Используется для фильтра периода в отчёте. |

### Позиция продажи

*По позициям строится группировка отчёта по товарным группам и расчёт рентабельности.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Продажа | связь | Документ продажи, к которому относится позиция. |
| Товарная группа | связь | Группа товара; ключ группировки отчёта по продажам. |
| Количество | число | Число проданных единиц из группы. |
| Себестоимости единиц | список чисел | Себестоимость каждой проданной единицы товара; сумма списка используется для расчёта прибыли и рентабельности. |
| Цена со скидкой | число (2 знака) | Выручка по позиции; суммируется в отчёте по товарным группам. |

### Сводка по продажам (итоги)

*Составной отчёт, не модель; профильтрован по продажам с непустым количеством или суммой.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Всего продаж | число | — |
| Общая выручка | число (2 знака) | Сумма продаж с учётом скидки. |
| Общая себестоимость | число (2 знака) | Сумма себестоимостей всех проданных единиц. |
| Прибыль | число (2 знака) | Общая выручка минус общая себестоимость. |

### Сводка по продажам (по товарным группам)

*Составной отчёт, не модель; учитывает только проданные (статус «Продано») позиции.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название товарной группы | текст | — |
| Продано штук | число | Сумма количества по группе. |
| Выручка группы | число (2 знака) | Сумма цены со скидкой по группе. |
| Себестоимость группы | число (2 знака) | Сумма себестоимостей проданных единиц группы. |
| Рентабельность товара | число (2 знака), % | Прибыль группы делённая на её себестоимость, в процентах; пусто, если прибыль не положительна. |
| Рентабельность продаж | число (2 знака), % | Прибыль группы делённая на выручку группы, в процентах; пусто, если выручка не положительна. |

### Инвентаризация

*Основа отчёта по переходам состояний инвентаря; отчёт считает, сколько раз состояние менялось с одного значения на другое, по сотрудникам.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Аренда (заявка) | связь | Аренда, в рамках которой произошла инвентаризация. |
| Инвентарь | связь | Единица инвентаря, чьё состояние фиксируется. |
| Новое состояние | связь | Состояние инвентаря после инвентаризации; ключ группировки в отчёте. |
| Создал | связь | Сотрудник, выполнивший инвентаризацию; ключ группировки в отчёте. |
| Источник | список (перечисление «Источник инвентаризации») | Откуда создана запись: аренда, мастерская или вручную. |
| Дата создания | дата/время | Используется для фильтра периода и для нахождения предыдущего состояния. |

### Переход состояния инвентаря

*Вычисляется в памяти (не хранится): для каждой инвентаризации ищется предыдущее состояние той же единицы инвентаря и считается количество одинаковых переходов.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Сотрудник | связь | — |
| Новое состояние | связь | — |
| Предыдущее состояние | связь | Состояние инвентаря до текущей инвентаризации (может отсутствовать, если это первая запись). |
| Количество переходов | число | Сколько раз встретился такой переход у этого сотрудника. |

### Фильтр периода отчёта

*Используется отчётами по воронке и по продажам; по умолчанию период — текущий календарный месяц.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Начало периода | дата/время | По умолчанию — первое число текущего месяца. |
| Конец периода | дата/время | По умолчанию — первое число следующего месяца. |

## Статусы и справочники

### Тип доставки

Способ передачи инвентаря клиенту.

- Доставка
- Самовывоз

### Статус доставки

Стадия выполнения задания на доставку; по этим статусам строятся счётчики и суммы в отчёте по доставкам.

- Ожидает
- В процессе
- Выполнена
- Отменена

### Тип задачи мастерской

Кто выполняет задачу — свои сотрудники или сторонний подрядчик.

- Внутренняя
- Внешняя

### Статус задачи мастерской

Стадия выполнения задачи мастерской; по этим статусам строятся счётчики и суммы в отчёте по мастерской.

- Новая
- В процессе
- Завершена
- В архиве

### Тип этапа воронки

Роль этапа в воронке — обычный рабочий этап или финальный (успех/отмена); финальные этапы исключаются при поиске «самого загруженного» этапа в отчёте.

- Обычный
- Успех
- Отмена

### Статус продажи

Стадия жизненного цикла документа продажи; отчёт по продажам учитывает только продажи в статусе «Продано».

- Черновик
- Продано
- Отменено

### Источник инвентаризации

Откуда была инициирована запись об изменении состояния инвентаря.

- Аренда
- Мастерская
- Вручную
