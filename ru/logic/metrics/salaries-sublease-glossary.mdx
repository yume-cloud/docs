Справочник к странице [«Зарплаты и субаренда сотрудников»](/ru/logic/metrics/salaries-sublease).

## Понятия

| Понятие | Значение |
| --- | --- |
| Оклад сотрудника | Фиксированный ежемесячный оклад сотрудника, не зависящий от выполненных действий. Связь один-к-одному с пользователем; итоговая сумма в отчёте умножается на количество месяцев в выбранном периоде. |
| Действие по заявке | Запись о конкретном действии сотрудника над заявкой аренды (создание, бронирование, сбор, выдача, приём, доставка, отмена, архивация) — основа для расчёта бонусов. |
| Индивидуальные проценты вознаграждения по заявке | Персональные (заданные на уровне конкретной заявки) проценты бонуса за каждое действие, переопределяющие общие настройки компании. |
| Сводка по зарплате сотрудника | Строка отчёта «Зарплаты сотрудников»: оклад + бонусы по типам действий за выбранный период по одному сотруднику. |
| Детализация зарплаты по типу действия | Строка отчёта, агрегирующая количество действий, оборот и заработанный бонус по одному типу действия для сотрудника. |
| Действие сотрудника с расчётом бонуса | Отдельная запись действия сотрудника (по конкретной заявке) вместе с рассчитанным процентом и суммой бонуса и списком затронутого инвентаря. |
| История действий сотрудника | Строка истории конкретного действия сотрудника с рассчитанным заработком и процентом. |
| Единица инвентаря | Единица инвентаря; в этом разделе важны только поля субаренды и базовая идентификация. |
| Доход сотрудника от субаренды | Строка отчёта по субаренде: сколько единиц инвентаря сотрудник передал в субаренду и сколько заработал он и компания за период. |
| Доход по единице инвентаря в субаренде | Строка отчёта по субаренде в разрезе конкретной единицы инвентаря одного сотрудника-субарендатора. |
| История начислений по субаренде | Построчная история ежедневных начислений прибыли по единице инвентаря, находящейся в субаренде у сотрудника. |

## Модели и поля

### Оклад сотрудника

*Связь один-к-одному с пользователем; итоговая сумма в отчёте умножается на количество месяцев в выбранном периоде.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Сотрудник | связь | Владелец оклада. |
| Сумма оклада | число (2 знака) | Оклад за один месяц. |

### Действие по заявке

*На действие может быть привязано несколько единиц инвентаря (многие-ко-многим) и, для доставок, связанная запись доставки.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сотрудник | связь | Кто выполнил действие. |
| Заявка | связь | Заявка аренды, к которой относится действие. |
| Единицы инвентаря по заявке | связь (многие-ко-многим) | Какие позиции инвентаря заявки затронуты этим действием; используется для расчёта суммы бонуса через прогноз прибыли. |
| Доставка | связь | Заполняется только для действий типа «доставка выдана»/«доставка принята». |

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип действия | список (перечисление «Тип действия по заявке») | — |
| Дата создания | дата/время | Момент выполнения действия, используется для фильтра по периоду. |

### Индивидуальные проценты вознаграждения по заявке

*Связь один-к-одному с заявкой; создаётся автоматически при создании заявки со значениями по умолчанию из настроек компании.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Заявка | связь | Заявка, к которой относятся индивидуальные проценты. |

**Проценты**

| Поле | Тип | Описание |
| --- | --- | --- |
| Процент за создание | число (2 знака), % | — |
| Процент за сбор | число (2 знака), % | — |
| Процент за бронирование | число (2 знака), % | — |
| Процент за выдачу | число (2 знака), % | — |
| Процент за приём | число (2 знака), % | — |

### Сводка по зарплате сотрудника

*Вычисляемая строка (формат), не хранится в БД; строится поверх модели пользователя с аннотациями; структурно совпадает со «Списком сотрудников с бонусами (по действиям)», кроме поля «Итого к начислению».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Сотрудник | связь | — |
| Имя | текст | — |
| Фамилия | текст | — |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Оклад за период | число (2 знака) | Оклад сотрудника, умноженный на количество месяцев в выбранном периоде. |

**Бонусы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Бонус за создание заявок | число (2 знака) | Сумма бонуса за действия «создание» за период. |
| Бонус за бронирование | число (2 знака) | Сумма бонуса за действия «бронирование» за период. |
| Бонус за сбор | число (2 знака) | Сумма бонуса за действия «сбор» за период. |
| Бонус за выдачу | число (2 знака) | Сумма бонуса за действия «выдача» за период. |
| Бонус за приём | число (2 знака) | Сумма бонуса за действия «приём» за период. |
| Бонус за доставку | число (2 знака) | Сумма за выполненные доставки (фиксированная цена доставки + доля от разницы «сумма к оплате минус стоимость доставки», пропорционально дням аренды). |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Итого бонусов | число (2 знака) | Сумма всех бонусов по типам действий и доставкам за период. |
| Итого к начислению | число (2 знака) | Оклад за период плюс итого бонусов. |

### Детализация зарплаты по типу действия

*Вычисляемая строка (формат), группировка по полю «тип»; сводка «Общая сводка зарплаты по типам действий» группирует несколько таких строк по всем типам действий для одного сотрудника.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип действия | список (перечисление «Тип действия по заявке») | — |
| Количество действий | число | Сколько раз сотрудник выполнил действия этого типа за период. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма оборота | число (2 знака) | Сумма прогноза прибыли по инвентарю, затронутому действиями этого типа (без применения процента). |
| Бонус | число (2 знака) | Сумма оборота, умноженная на процент вознаграждения за этот тип действия. |

### Единица инвентаря

*Полный набор бизнес-полей инвентаря документируется в разделе «Инвентарь»; здесь важны только поля субаренды и базовая идентификация.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | — |
| Инвентарный номер | текст | — |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена покупки | число (2 знака) | Используется как база для расчёта суммарной стоимости выкупленного сотрудниками инвентаря и амортизации. |

**Субаренда**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сотрудник-субарендатор | связь | Сотрудник, которому единица инвентаря передана в субаренду (владелец). |
| Процент субаренды | число (2 знака), % | Доля прибыли от аренды этой единицы, которая причитается сотруднику-владельцу; остаток — доход компании. |

### Доход сотрудника от субаренды

*Вычисляемая строка поверх модели пользователя с аннотациями по связанному инвентарю в субаренде; агрегируется в «Итоговую сводку по субаренде».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Сотрудник | связь | — |
| Имя | текст | — |
| Фамилия | текст | — |
| Количество единиц в субаренде | число | Сколько единиц инвентаря сотрудник передал в субаренду (с учётом фильтра по точке). |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Стоимость инвентаря в субаренде | число (2 знака) | Суммарная цена покупки инвентаря, переданного сотрудником в субаренду. |
| Общий доход (факт) | число (2 знака) | Фактическая прибыль по завершённым/просроченным заявкам за период. |
| Общий доход (ожидаемый) | число (2 знака) | Прогнозируемая прибыль по активным/забронированным/просроченным заявкам за период. |
| Доход сотрудника (факт) | число (2 знака) | Доля фактической прибыли, причитающаяся сотруднику по проценту субаренды. |
| Доход сотрудника (ожидаемый) | число (2 знака) | Доля прогнозируемой прибыли, причитающаяся сотруднику. |
| Доход компании (факт) | число (2 знака) | Доля фактической прибыли, остающаяся компании (100% минус процент субаренды). |
| Доход компании (ожидаемый) | число (2 знака) | Доля прогнозируемой прибыли, остающаяся компании. |

## Статусы и справочники

### Тип действия по заявке

- Бронирование
- Выдача
- Приём (возврат)
- Отмена
- Архивация
- Сбор (комплектация)
- Создание заявки
- Доставка: забор инвентаря
- Доставка: выдача инвентаря
