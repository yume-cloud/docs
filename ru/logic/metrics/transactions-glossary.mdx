## Модели и поля

### Финансовая операция

*Запись о поступлении или списании денег (оплата аренды, продажи, мастерской, депозита, штрафа, произвольная операция по счёту), лежит в основе списка операций и всех отчётов. Хранится в таблице операций; сумма автоматически становится отрицательной для списания и положительной для поступления.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Направление операции | список (перечисление) | Поступление или списание. |
| Вид оплаты | связь | Ссылка на справочник видов оплаты (наличные, карта и т.п.). |
| Статус операции | список (перечисление) | Ожидает / успешно / ошибка / истёк срок. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма | число (2 знака) | Положительная для поступления, отрицательная для списания. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата и время создания | дата/время | Используется как дата операции, если нет даты ведомости. |
| Создал | связь | Сотрудник, создавший операцию. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Продажа | связь | Операция привязана к продаже. |
| Аренда | связь | Операция привязана к заявке на аренду. |
| Задача мастерской | связь | Операция привязана к работе мастерской. |
| Обслуживание | связь | Операция привязана к обслуживанию инвентаря. |
| Депозит | связь | Операция привязана к депозиту по аренде. |

### Фильтр транзакций

*Набор параметров фильтрации списка транзакций в отчётах: по клиенту, точке проката, типу источника операции, признаку возврата и другим полям. Это набор параметров запроса, а не модель данных.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Клиент | число (ID) | Фильтр по клиенту через связанную аренду/продажу/заказ мастерской. |
| Точка проката | число (ID) | Фильтр по точке проката через связанную аренду/продажу/заказ мастерской. |
| Источник операции | список | Аренда / продажа / мастерская / обслуживание. |
| Признак возврата | флаг | Оставляет только операции, по которым оформлен возврат. |
| Дата создания (фильтр) | дата/время | Диапазон «с даты» / «по дату». |
| Направление операции (фильтр) | число/список | Поступление или списание. |
| Статус транзакции (фильтр) | текст/список | Успешно / ошибка / ожидает / истёк. |

### Сводка по видам оплаты

*Представление одной строки разбивки транзакций по виду оплаты и направлению операции — с количеством и суммой. Строится группировкой успешных транзакций по виду оплаты и направлению.*

| Поле | Тип | Описание |
| --- | --- | --- |
| ID вида оплаты | число | Может быть пустым. |
| Направление операции | число (перечисление) | Может быть пустым. |
| Название вида оплаты | текст | Название из справочника видов оплаты. |
| Количество операций | число | — |
| Сумма | число (2 знака) | Суммарная сумма операций данной группы. |

### Общая сводка транзакций по дням

*Представление одной строки общей сводки — суммы операций за день в разрезе источника (аренда, продажа, мастерская, обслуживание) и итоговая сумма. Строится группировкой успешных транзакций по дате создания.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата | дата/время | День, за который агрегированы суммы. |
| Сумма по аренде | число (2 знака) | Сумма операций, связанных с арендой, за день. |
| Сумма по продажам | число (2 знака) | Сумма операций, связанных с продажами, за день. |
| Сумма по мастерской | число (2 знака) | Сумма операций, связанных с заказами мастерской, за день. |
| Сумма по обслуживанию | число (2 знака) | Сумма операций, связанных с обслуживанием техники, за день. |
| Итоговая сумма | число (2 знака) | Сумма всех операций за день. |

### Строка списка транзакций

*Представление одной транзакции в постраничном списке операций — с данными о клиенте, аренде/продаже/мастерской и точке проката. Дополняет поля финансовой операции вычисляемыми полями клиента и точки проката.*

| Поле | Тип | Описание |
| --- | --- | --- |
| ID транзакции | число | — |
| Направление операции | число (перечисление) | — |
| Сумма | число (2 знака) | — |
| Вид оплаты | число (ID) | — |
| Дата и время создания | дата/время | — |
| Имя клиента | текст | Вычисляется из аренды/продажи/мастерской. |
| Статус аренды | число | Статус связанной заявки на аренду. |
| Статус транзакции | текст | — |

## Статусы и справочники

### Направление операции

- Поступление (приход)
- Списание (расход)

### Статус операции

- Ожидает оплаты
- Успешно
- Ошибка
- Истёк срок

### Источник операции

- Аренда
- Продажа
- Мастерская
- Обслуживание техники
