Полный перечень полей — в [глоссарии](/ru/logic/metrics/discounts-glossary).

## Что показывает эта страница

Отчёт — это журнал применённых скидок: записи о том, где и на сколько была уменьшена стоимость аренды, плюс сводная
группировка по каждой скидке из справочника. Это отдельный список с постраничной выдачей и сводкой (агрегатами) в
шапке ответа, которая считается по тем же фильтрам, что применены к списку.

## Модель данных

Каждая запись о скидке по аренде фиксирует факт применения одной конкретной скидки (или скидки, введённой вручную) к одному из четырёх объектов:

| Объект применения | Смысл |
| --- | --- |
| На аренду целиком | Скидка распределяется между всеми позициями аренды |
| На единицу инвентаря | Скидка привязана к конкретной единице инвентаря в составе аренды |
| На услугу | Скидка привязана к конкретной услуге в составе аренды |
| На доставку | Скидка применена к доставке |

Способ применения показывает, была ли скидка выбрана из справочника скидок (тогда запись ссылается на конкретную скидку-промокод или акцию) или введена сотрудником вручную как произвольная сумма без привязки к справочнику.

## Пересчёт суммарной скидки аренды

При каждом сохранении или удалении записи о скидке по аренде для связанной аренды пересчитывается суммарная дополнительная скидка. В этот пересчёт попадают только записи, которые:

- не привязаны ни к конкретной единице инвентаря, ни к конкретной услуге (то есть относятся к аренде в целом или к доставке), **и**
- при этом являются либо скидкой, введённой вручную, либо скидкой из справочника с фиксированной суммой (не процентной).

<Warning>
Процентные скидки из справочника, применённые на всю аренду, а также скидки, привязанные к конкретной единице инвентаря или услуге, в это суммарное поле аренды не включаются — оно отражает только часть скидок. Полную картину даёт только сам отчёт (список записей и сводная группировка), а не это поле на аренде.
</Warning>

## Распределение скидки по дням при расчёте прибыли

Когда пересчитывается прибыль по аренде, каждая скидка «раскладывается» по календарным дням аренды и по объектам, к которым она относится:

- скидка на конкретную единицу инвентаря или услугу целиком относится к дням аренды этой позиции;
- скидка на аренду целиком делится пропорционально между всеми единицами инвентаря и услугами по их доле в общей стоимости;
- дни, отмеченные как выходные по графику аренды, из расчёта суммы скидки на день исключаются.

Это не хранится как отдельное поле — это промежуточный расчёт, который влияет на итоговое распределение прибыли по дням (см. [«Прибыль и окупаемость»](/ru/logic/profit-payback)), но сама запись о скидке при этом не меняется.

## Список истории скидок

Список отдельных записей о скидках можно отфильтровать по способу расчёта скидки (процент/фиксированная сумма), по конкретной скидке из справочника (или списку скидок), по типу скидки из справочника (обычная/промокод/фиксированная сумма), по тому, введена ли запись вручную или взята из справочника, по статусу и статусу оплаты связанной аренды, по клиенту, по датам начала/окончания аренды и по дате создания записи. Поиск работает по имени и телефону клиента и по названию скидки. Помимо стандартных полей, сортировка доступна и по числовым дополнительным полям аренды, если они настроены у компании.

Сводка в шапке этого списка показывает две суммы, посчитанные по текущим фильтрам: суммарную стоимость аренд (за вычетом скидки) и суммарную величину предоставленной скидки.

## Сводка по справочнику скидок (группировка)

Отдельный режим того же журнала строит не список отдельных применений, а сводную таблицу: одна строка на каждую скидку из справочника, которая хотя бы раз была применена (с учётом тех же фильтров, что и у списка). Для каждой скидки показываются:

| Поле | Тип | Назначение |
| --- | --- | --- |
| Скидка | Связь | Скидка из справочника, к которой относится строка |
| Тип скидки | Список | Обычная скидка / промокод / фиксированная сумма — из справочника |
| Количество применений | Число | Сколько раз скидка была применена в рамках текущих фильтров |
| Сумма аренд со скидкой | Число (2 знака) | Суммарная стоимость аренд, к которым применялась эта скидка |
| Сумма скидки | Число (2 знака) | Суммарная величина предоставленной скидки по этой скидке из справочника |

Если у компании настроены собственные числовые дополнительные поля аренды (целочисленные или дробные), сводка дополнительно возвращает по каждой скидке сумму значений этих полей по всем арендам, где скидка применялась — они попадают в отдельный блок дополнительных показателей в ответе. Дополнительное поле учитывается в сумме, только если его значение у конкретной аренды выглядит как число; нечисловые или пустые значения считаются нулём.

<Note>
Эта сводная группировка строится без привязки к конкретной аренде один-к-одному — если скидка применялась к нескольким арендам, все они схлопываются в одну строку с суммарными показателями.
</Note>

## Права доступа

Отчёт требует, чтобы у пользователя было право на просмотр данных метрик — доступ проверяется по стандартной модели прав компании и настраивается для ролей сотрудников отдельно от права на применение скидки.

## Особенности поведения

- Сортировка и суммирование по дополнительным (кастомным) числовым полям аренды в сводке по справочнику скидок доступны только для полей, настроенных у компании как целочисленный или дробный тип; нечисловые или пустые значения считаются нулём.
- В списке истории скидок нет отдельного фильтра по объекту применения скидки (аренда/инвентарь/услуга/доставка) — это поле есть только в данных, но не среди фильтров.
