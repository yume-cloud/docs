Справочник к странице [«Амортизация и окупаемость инвентаря»](/ru/logic/metrics/depreciation-payback).

## Понятия

| Понятие | Значение |
| --- | --- |
| Окупаемость инвентаря | Денормализованная сводка по единице инвентаря: сколько она уже принесла дохода и насколько окупила стоимость покупки; пересчитывается автоматически. |
| Прибыль (запись начисления) | Денормализованная построчная запись начисленной и спрогнозированной прибыли за один день по одному источнику дохода (аренда, услуга, доставка, штраф, продажа, работа мастерской); одна из ключевых таблиц раздела метрик. |
| Амортизация единицы инвентаря | Отчётное представление одной единицы инвентаря с расчётом амортизации и остаточной стоимости. |
| Окупаемость инвентаря — краткая карточка | Компактное представление записи окупаемости, вложенное в карточку единицы инвентаря. |
| Доходность группы инвентаря | Список групп инвентаря с показателями дохода, расходов и окупаемости за выбранный период. |
| Доходность единицы инвентаря | Список единиц инвентаря с показателями дохода, расходов и окупаемости за выбранный период. |
| Детализация дохода по единице инвентаря | Постатейный список начислений дохода (по дням/арендам) для конкретной единицы инвентаря. |
| Доходность инвентаря — общая сводка | Агрегированные показатели дохода, окупаемости и операций по всему отфильтрованному инвентарю. |
| Период доходности | Параметры `start_at` / `end_at` отчётов о доходности (группы, единицы, детализация, общая сводка): обе границы включаются и необязательны, не переданная граница не ограничивает выборку, без обеих — всё время. Период ограничивает начисления (по дате начисления), операции (по дате ведомости) и — только в общей сводке — записи окупаемости (по дате окупаемости). На состав списков, цену покупки, количество единиц и показатели окупаемости в списках групп и единиц он не влияет. |

## Модели и поля

### Окупаемость инвентаря

*Денормализованная сводка: сколько единица инвентаря уже принесла дохода и насколько окупила стоимость покупки; пересчитывается автоматически.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь | Единица инвентаря, к которой относится запись окупаемости (один к одному). |
| Дата окупаемости | дата/время | День, когда накопленный фактический доход впервые покрыл цену покупки; пусто, пока единица не окупилась или если цена покупки не задана. По этой дате общая сводка отбирает записи окупаемости за период. |
| Срок окупаемости | продолжительность | Сколько времени потребовалось единице инвентаря, чтобы окупить стоимость покупки. |
| Эффективность окупаемости | число (2 знака), % | Накопленный доход к стоимости покупки в процентах (профит / цена покупки × 100). |
| Ожидаемый доход (накопленный) | число (2 знака) | Суммарный ожидаемый доход по единице с учётом истории до подключения к учёту метрик. |
| Фактический доход (накопленный) | число (2 знака) | Суммарный фактически полученный доход по единице инвентаря (используется для расчёта окупаемости и остатка стоимости). |

### Прибыль (запись начисления)

*Одна из ключевых таблиц раздела метрик; сводка и детализация «Обзора» строятся поверх неё.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата | дата | День, за который начислена сумма. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь | — |
| Заявка (аренда) | связь | Аренда, к которой относится начисление. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Прогноз (начислено) | число (2 знака) | Сумма, причитающаяся за день по графику, независимо от факта оплаты. |
| Прибыль (получено) | число (2 знака) | Фактически зачтённая сумма за день с учётом оплаты. |

### Амортизация единицы инвентаря

*Поля срок амортизации / месяцев в эксплуатации / амортизация в месяц / накопленная амортизация / остаточная стоимость вычисляются в queryset аннотациями, не хранятся в БД; агрегируется в «Амортизация инвентаря — сводку».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Срок амортизации | число (месяцы) | Фактический срок полезного использования в месяцах: собственный срок инвентаря либо срок категории; 12 месяцев подставляются, только если срок не заполнен нигде. |
| Месяцев в эксплуатации | число (месяцы) | Сколько полных месяцев прошло с даты покупки; ноль, если дата покупки не заполнена или указана в будущем. |
| Амортизация в месяц | число (2 знака) | Сумма амортизации за один месяц = цена покупки / срок амортизации; равна 0, если срок эксплуатации превысил срок амортизации. |
| Накопленная амортизация | число (2 знака) | Цена покупки × отработанные месяцы (не больше срока амортизации) / срок амортизации; к концу срока равна полной цене покупки. |
| Остаточная стоимость | число (2 знака) | Цена покупки минус накопленная амортизация, но не ниже нуля; у изношенной позиции — ноль, у позиции без даты покупки — полная цена покупки. |
| Цена покупки | число (2 знака) | Закупочная стоимость единицы инвентаря. |
| Дата покупки | дата/время | Дата приобретения единицы инвентаря, от которой считается срок эксплуатации. |

| Фактический доход (накопленный) | число (2 знака) | Считается только по зачётным строкам дохода — тем же, что и доход за период в отчётах. |

### Доходность группы инвентаря

*Числовые поля вычисляются аннотациями в queryset (подзапросы к «Прибыль», «Окупаемость инвентаря» и операциям по счетам); агрегируется в «Доходность инвентаря — общую сводку».*

| Поле | Тип | Описание |
| --- | --- | --- |
| ID группы | число | — |
| Название группы | текст | — |
| Категория | связь | Категория группы инвентаря. |

**Доход**

| Поле | Тип | Описание |
| --- | --- | --- |
| Количество начислений | число | Число строк дохода по группе за период. |
| Доход за период | число (2 знака) | Сумма фактического дохода по всем единицам группы за выбранный период. |
| Расход по операциям | число (2 знака) | Сумма дебетовых (расходных) операций по группе за период. |
| Доход по операциям | число (2 знака) | Сумма кредитовых (доходных) операций по группе за период. |

**Окупаемость**

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена покупки (сумма по группе) | число (2 знака) | Суммарная закупочная стоимость единиц инвентаря в группе с учётом фильтров; от периода не зависит. |
| Срок окупаемости (средний) | продолжительность | Средний срок окупаемости по единицам группы; за всё время, период не влияет. |
| Эффективность окупаемости (средняя) | число (2 знака), % | Средняя эффективность окупаемости по единицам группы; за всё время, период не влияет. |
| Накопленный доход окупаемости | число (2 знака) | Суммарный накопленный доход окупаемости по единицам группы; за всё время, период не влияет. |

### Доходность инвентаря — общая сводка

*Используется на общей сводной карточке над списком групп/единиц инвентаря.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена покупки (сумма) | число (2 знака) | Суммарная закупочная стоимость по отфильтрованному инвентарю; от периода не зависит. |
| Цена покупки (среднее) | число (2 знака) | Средняя закупочная стоимость по отфильтрованному инвентарю; от периода не зависит. |
| Ожидаемый доход (сумма) | число (2 знака) | Суммарный ожидаемый доход по начислениям с датой в периоде — без фильтра учитываемой прибыли, то есть по арендам и продажам в любом статусе. |
| Ожидаемый доход (среднее) | число (2 знака) | Средний ожидаемый доход на одну строку начисления по тем же начислениям. |
| Фактический доход (сумма) | число (2 знака) | Суммарный фактический доход по тем же начислениям. |
| Фактический доход (среднее) | число (2 знака) | Средний фактический доход на одну строку начисления по тем же начислениям. |
| Расход по операциям (сумма) | число (2 знака) | Сумма дебетовых операций по ведомостям с датой в периоде. |
| Доход по операциям (сумма) | число (2 знака) | Сумма кредитовых операций по ведомостям с датой в периоде. |
| Превышение окупаемости (сумма) | число (2 знака) | Суммарный накопленный доход окупаемости минус суммарная цена покупки (не ниже нуля) — по единицам, чья дата окупаемости попадает в период; без границ периода — по всем записям окупаемости отфильтрованных единиц, в том числе ещё не окупившихся. Сами суммы накоплены за всё время. |
| Превышение окупаемости (среднее) | число (2 знака) | Средний накопленный доход окупаемости минус средняя цена покупки (не ниже нуля) по тем же записям окупаемости. |
| Срок окупаемости (средний) | продолжительность | Средний срок окупаемости по единицам, чья дата окупаемости попадает в период; без границ периода — по всем записям окупаемости отфильтрованных единиц. |
| Количество единиц инвентаря | число | Число единиц инвентаря, попавших под фильтр; от периода не зависит. |
