## Понятия

| Понятие | Значение |
| --- | --- |
| Сигнал пересчёта порядка | Обработчик, срабатывающий при сохранении лида: сдвигает порядок всех остальных лидов того же этапа со значением не меньше нового, освобождая позицию для перемещённого лида. Реализует ручное упорядочивание внутри этапа воронки. |
| Сигнал обновления сделки | Обработчик сохранения лида: запускает синхронизацию сделки с Wazzup в фоновом потоке. Захватывает текущего арендатора и передаёт его в асинхронную задачу. |
| Сигнал удаления сделки | Обработчик удаления лида: запускает удаление сделки в Wazzup в фоновом потоке. Захватывает текущего арендатора и передаёт его в асинхронную задачу. |
| Синхронизация сделки в Wazzup | Асинхронно подтягивает сделку из Wazzup и пересоздаёт её с флагом закрытия по токену интеграции арендатора. Вызывается сигналом сохранения через демон-поток; при отсутствии токена интеграции ничего не делает. |
| Удаление сделки в Wazzup | Асинхронно удаляет сделку в Wazzup по идентификатору лида, используя токен интеграции арендатора. Вызывается сигналом удаления через демон-поток; при отсутствии токена интеграции ничего не делает. |
| Публичный адрес приёма заявок | Неаутентифицированный адрес: принимает заявку с сайта и создаёт лид в стартовом этапе воронки. По идентификатору формы находит или создаёт источник привлечения, ищет или создаёт клиента по телефону, создаёт лид в первом обычном этапе; на тестовый запрос отвечает без создания записей. |
| JSON-кодировщик Decimal | Вспомогательный JSON-энкодер, сериализующий числа с фиксированной точностью (Decimal) в строку. |

## Модели и поля

### Лид

*Карточка потенциальной сделки в воронке продаж: клиент на конкретном этапе воронки с назначенным менеджером, источником, ценой и ручным порядком в колонке.*

*Наследует даты создания и изменения, а также мультиарендную изоляцию; при сохранении срабатывают сигналы пересчёта порядка и синхронизации сделки с Wazzup.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Клиент | связь | Клиент, к которому относится лид; при удалении клиента обнуляется. |
| Этап воронки | связь | Текущий этап воронки, на котором стоит лид; удаляется вместе с этапом. |
| Воронка | связь | Воронка продаж, которой принадлежит лид; удаляется вместе с воронкой. |
| Менеджер | связь | Ответственный сотрудник; может быть не назначен. |
| Источник привлечения | связь | Канал или метод привлечения клиента; при удалении обнуляется. |
| Заявка | связь | Связанная заявка на аренду, созданная из лида; при удалении обнуляется. |
| Продажа | связь | Связанная продажа; при удалении обнуляется. |

**Данные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма лида | число (2 знака) | Ожидаемая сумма сделки; суммируется в агрегате списка. |
| Порядок в колонке | число | Ручной порядок лида внутри этапа; при сохранении сдвигает остальные лиды вниз. |
| Причина отмены | текст | Комментарий при отмене лида; участвует в поиске. |
| Доп. данные | JSON | Произвольные дополнительные поля лида. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Проставляется автоматически; доступна для сортировки и фильтрации. |
| Дата изменения | дата/время | Обновляется автоматически при каждом сохранении. |

## Статусы и справочники

### Тип этапа воронки

Определяет роль этапа: обычный или системный (успех/отказ). Этапы «Успешно завершён» и «Нереализован (отказ)» создаются автоматически и защищены от ручного создания и удаления.

- Обычный
- Успешно завершён
- Нереализован (отказ)
