Справочник к странице [«Логи этапов и массовые операции над лидами»](/ru/logic/sales/logs-bulk).

## Понятия

| Понятие | Значение |
| --- | --- |
| Лог смены этапа лида | Запись истории перемещения лида между этапами воронки, создаётся сигналом при фактической смене этапа авторизованным пользователем. |
| Массовая операция над лидами | Обрабатывает массовое действие над всеми лидами исходного этапа: перенос, удаление или рассылка сообщений. |
| API массовых операций над лидами | Адрес, принимающий запрос на массовую операцию над лидами этапа. |
| Действие массовой операции | Тип массового действия над всеми лидами выбранного этапа. |

## Модели и поля

### Лог смены этапа лида

*Пишется при фактической смене этапа лида только тогда, когда этап изменился и действие выполнил неанонимный пользователь.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Лид | связь | Лид, у которого сменился этап. |
| Пользователь | связь | Кто выполнил смену этапа (может быть пустым). |
| Прежний этап | связь | Этап до перехода (пустой при первом попадании). |
| Новый этап | связь | Этап после перехода. |
| Дата события | дата/время | Момент смены этапа (индексируется). |

### Массовая операция над лидами

*Массовый перенос идёт в обход сигналов с ручной записью логов; удаление и рассылка логи не пишут.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Исходный этап | связь | Этап, все лиды которого попадают под операцию. |
| Действие | выбор | Тип операции: перенос, удаление или рассылка Wazzup. |
| Целевой этап | связь | Этап назначения при переносе; требуется для действия «Перенос». |
| Текст сообщения | текст | Текст для массовой рассылки при действии «Wazzup». |

### API массовых операций над лидами

*Адрес создания массовой операции; доступен только авторизованным пользователям.*

## Статусы и справочники

### Действие массовой операции

- Перенос на другой этап
- Удаление
- Массовая рассылка Wazzup
