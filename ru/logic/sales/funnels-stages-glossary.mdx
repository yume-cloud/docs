## Модели и поля

### Воронка продаж

*Воронка лидов в CRM-модуле продаж: набор этапов, через которые проходит лид. При создании автоматически заполняется стартовым набором из 5 этапов; мягкое удаление через отдельную запись отключения (связь один-к-одному).*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название воронки. |
| Кем создана | связь | Пользователь-автор воронки (общая/глобальная модель пользователей). |
| Доп. данные | JSON | Произвольные дополнительные данные. |
| Ответственные пользователи | список чисел | Идентификаторы пользователей, привязанных к воронке. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Этапы | связь (обратная) | Набор этапов воронки. |
| Отключение | связь 1:1 | Запись мягкого удаления; воронка активна, когда связь пуста. |
| Компания | связь | Владелец записи. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Заполняется автоматически при создании. |
| Дата обновления | дата/время | Обновляется автоматически при изменении. |

### Этап воронки

*Отдельный этап воронки продаж, по которому перемещаются лиды. Этапы успеха и отказа — системные: их нельзя создавать и удалять вручную; сортировка выполняется по полю порядка и обработчику пересортировки; мягкое удаление через отдельную запись отключения, и только для этапа без лидов — непустой этап удалить нельзя.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название этапа. |
| Тип этапа | перечисление | Обычный / успешно завершён / нереализован; успех и отказ — системные. |
| Цвет | текст (HEX) | Цвет этапа в интерфейсе, по умолчанию #ffffff. |
| Доп. данные | JSON | Произвольные дополнительные данные. |
| Порядок | число | Позиция этапа при сортировке внутри воронки. |
| Ответственные пользователи | список чисел | Идентификаторы пользователей, привязанных к этапу. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Воронка | связь | Воронка, которой принадлежит этап. |
| Отключение | связь 1:1 | Запись мягкого удаления; этап активен, когда связь пуста. Отключённый этап не отдаётся ни в списках, ни по идентификатору. |
| Лиды | связь (обратная) | Лиды, находящиеся на этом этапе. |
| Компания | связь | Владелец записи. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Заполняется автоматически при создании. |
| Дата обновления | дата/время | Обновляется автоматически при изменении. |

### Пересортировка этапов (сигнал сохранения)

*Обработчик, срабатывающий при сохранении этапа: сдвигает порядок остальных активных этапов той же воронки, освобождая позицию для сохранённого этапа. Затрагивает только этапы без записи отключения и исключает сам сохраняемый этап.*

## Статусы и справочники

### Тип этапа воронки

Определяет роль этапа: обычный или системный. Успех и отказ создаются автоматически и защищены от ручного создания и удаления.

- Обычный
- Успешно завершён
- Нереализован (отказ)
