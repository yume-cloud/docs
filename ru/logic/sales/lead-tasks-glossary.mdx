## Понятия

| Понятие | Значение |
| --- | --- |
| Метод задачи по лиду | Справочник типов (методов) задач по лиду, привязанный к конкретной воронке. Метод может быть привязан к воронке и используется как категория задачи. |
| Задача по лиду | Задача менеджера, связанная с лидом или клиентом, с методом, сроком и результатом выполнения. При сохранении создаётся или обновляется уведомление ответственному менеджеру. |
| Сигнал уведомления менеджера | Обработчик сохранения задачи по лиду: асинхронно создаёт или обновляет уведомление ответственному менеджеру. |

## Модели и поля

### Метод задачи по лиду

*Справочник типов (методов) задач по лиду, привязанный к конкретной воронке. Метод может быть привязан к воронке; используется как категория задачи.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название метода (типа) задачи. |
| Воронка | связь | Воронка, к которой относится метод (может быть пустой). |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент создания записи, проставляется автоматически. |
| Дата изменения | дата/время | Момент последнего изменения, проставляется автоматически. |
| Компания (тенант) | связь | Компания-владелец записи в мультитенантной модели. |

### Задача по лиду

*Задача менеджера, связанная с лидом или клиентом, с методом, сроком и результатом выполнения. При сохранении сигнал уведомления создаёт или обновляет уведомление менеджеру.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Лид | связь | Лид, к которому относится задача (только для чтения при создании через API). |
| Клиент | связь | Клиент, к которому относится задача. |
| Метод | связь | Тип (метод) задачи; при создании через API обязателен. |
| Менеджер | связь | Ответственный менеджер; при создании через API обязателен. |

**Содержание**

| Поле | Тип | Описание |
| --- | --- | --- |
| Описание | текст | Текст задачи; попадает в тело уведомления менеджеру. |
| Результат | текст | Результат выполнения задачи. |
| Доп. данные | JSON | Произвольные дополнительные данные задачи. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата задачи | дата/время | Плановая дата/время задачи (срок). |
| Дата завершения | дата/время | Момент завершения задачи; пусто пока задача не выполнена. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент создания записи, проставляется автоматически. |
| Дата изменения | дата/время | Момент последнего изменения, проставляется автоматически. |
| Компания (тенант) | связь | Компания-владелец записи в мультитенантной модели. |

### Сигнал уведомления менеджера

*Обработчик сохранения задачи по лиду: асинхронно создаёт или обновляет уведомление ответственному менеджеру. Уведомление формируется с типом задачи по лиду и получателем-менеджером.*
