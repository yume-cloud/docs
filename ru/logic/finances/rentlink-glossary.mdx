Справочник к странице [«Публичная страница оплаты аренды»](/ru/logic/finances/rentlink).

## Ссылка на аренду

*Публичный код доступа к одной заявке аренды — используется в SMS/WhatsApp-ссылке и в поиске по номеру телефона на
публичной странице оплаты. Общий для всех компаний, не привязан напрямую к данным конкретной компании.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Код | строка (8 симв.), уникальный | Публичный идентификатор ссылки; генерируется случайно, при совпадении с уже существующим — перегенерируется. |
| Компания | связь | Компания-владелец заявки; вместе с заявкой образует уникальную пару. |
| Заявка | число | Номер заявки аренды внутри компании; хранится как обычное число, а не связь. |
| Телефон | строка | Телефон клиента, каким он был на момент последнего создания/обновления ссылки. |
| Телефон (нормализованный) | строка (индекс) | Только цифры телефона, последние 10 знаков; по этому полю ищутся аренды на публичной странице по номеру телефона. |

<Note>
Пара «Компания + Заявка» уникальна: у каждой заявки только один код ссылки, который переиспользуется и при автоматическом
создании, и при повторной ручной отправке клиенту.
</Note>

Оплата, которую клиент создаёт по ссылке, — это обычная денежная операция (см. [«Оплата: модель, знак и проверки»](/ru/logic/finances/payments-glossary))
с карточкой Kaspi-оплаты (см. [«Оплата через Kaspi»](/ru/logic/finances/kaspi-glossary)); отдельной модели для оплаты по
ссылке нет. Если оплата разложена по дням графика, части суммы сопоставляются днями через ту же запись, что и обычные
оплаты (см. [«Сопоставление операции с днём графика»](/ru/logic/finances/schedule-glossary)).
