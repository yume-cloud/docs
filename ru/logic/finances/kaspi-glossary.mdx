## Оплата через Kaspi

*Дополнительная карточка к обычной оплате, хранящая детали платежа, проведённого через платёжный сервис Kaspi (QR-код или
счёт на телефон).*

| Поле | Тип | Описание |
| --- | --- | --- |
| Связанная оплата | связь один-к-одному | Обычная финансовая оплата компании, к которой относится этот платёж Kaspi; удаляется вместе с ней. |
| Способ Kaspi | выбор из списка | По QR-коду или по счёту на телефон. |
| Телефон плательщика | текст | Номер плательщика (10 цифр); заполняется при оплате по счёту, может уточняться из данных плательщика при подтверждении. |
| Идентификатор операции Kaspi | текст (с индексом) | Номер операции на стороне Kaspi; по нему входящее уведомление находит нужную карточку оплаты. |
| Статус платежа Kaspi | выбор из списка | Текстовое состояние платежа на стороне Kaspi (успешно совершён, отклонён, недостаточно средств, клиент не отсканировал QR и т.п.). |
| Код QR для оплаты | текст | Ссылка/токен для отображения QR-кода клиенту; заполняется только при оплате по QR. |
| Ссылка на чек | текст | Ссылка на электронный чек; приходит вместе с уведомлением об успешной оплате. |
| Данные ответа Kaspi | структурированные данные | Полный набор данных из последнего входящего уведомления Kaspi. |
