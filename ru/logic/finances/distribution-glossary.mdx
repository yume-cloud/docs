## Распределение оплаты

*Разбивка суммы одной оплаты по конкретным позициям аренды — сколько ушло на инвентарь, услугу, доставку, штраф или депозит.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Оплата | связь | Оплата, которую распределяют; при её удалении все части распределения удаляются автоматически. |
| Сумма части | число (2 знака) | Денежная величина этой части распределения; сумма всех частей должна совпадать с суммой оплаты. По умолчанию ноль. |
| Позиция инвентаря (проката) | связь | Часть суммы, отнесённая к конкретному предмету проката в аренде; может быть пустым. |
| Услуга | связь | Часть суммы, отнесённая к конкретной услуге в аренде; может быть пустым. |
| Доставка | связь | Часть суммы, отнесённая к доставке аренды; может быть пустым. |
| Штраф | связь | Часть суммы, отнесённая к штрафу по аренде; может быть пустым. |
| Депозит | связь | Часть суммы, отнесённая к депозиту (залогу) по аренде; может быть пустым. |

## Назначение платежа

*Дополнительные сведения о назначении платежа — привязанный инвентарь, контрагент, направление движения денег и дата
операции — для отображения и отчётности.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Оплата | связь один-к-одному | Денежная операция, к которой относится назначение платежа; удаляется вместе с ним. |
| Направление (приход/расход) | выбор из списка | Дублирует признак прихода или расхода привязанной оплаты для быстрой фильтрации. |
| Единица учёта (инвентарь) | связь | К какому объекту/машине относится операция; при удалении объекта связь обнуляется. |
| Контрагент | связь | Внешняя или своя сторона операции (поставщик, партнёр и т.п.); при удалении контрагента связь обнуляется, запись сохраняется. |
| Ресурс обслуживания | связь | Привязка к строке расхода на обслуживание; если задана, сумму операции менять запрещено. |
| Дата операции | дата и время | Дата для отображения и сортировки; если не заполнена, используется дата создания оплаты. |

## Контрагент

*Справочник сторон расчётов и товарных операций: поставщиков, партнёров и собственных юрлиц компании с их реквизитами и
признаками роли.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Наименование | строка | Название контрагента, обязательное поле. |
| Сторона | выбор из списка | Признак «свой» (собственное юрлицо компании) или «чужой» (внешняя сторона); по умолчанию чужой. |
| Область применения | выбор из списка | Где используется контрагент: в продажах/магазине или в расходах; по умолчанию продажи. |
| Форма собственности | выбор из списка | Юридический тип: индивидуальный предприниматель, ТОО, акционерное общество, публичная компания; по умолчанию ИП. |
| Характер расчётов | выбор из списка | Направление денег по контрагенту — приход или расход; по умолчанию приход. |
| ИИН | строка (12 знаков) | Индивидуальный идентификационный номер физлица/ИП, необязательный. |
| БИН | строка (12 знаков) | Бизнес-идентификационный номер организации, необязательный. |
| Номер счёта | строка | Банковский счёт (IBAN), необязательный. |
| Банк | строка | Наименование банка, необязательное. |
| Телефон | строка | Контактный телефон, необязательный. |
| Владелец | строка | ФИО владельца/ответственного лица, необязательное. |
| Адрес | строка | Адрес контрагента, необязательный. |
| Электронная почта | строка | Адрес эл. почты, необязательный. |
| Доступ | список чисел | Список идентификаторов для разграничения доступа к контрагенту; по умолчанию пустой. |
| Порядок сортировки | число | Позиция в списке для ручной сортировки; при сохранении сдвигает остальные записи вниз. |
| Дополнительные данные | произвольные данные | Служебное хранилище дополнительных сведений в свободной форме. |
