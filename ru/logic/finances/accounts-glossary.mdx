## Вид оплаты

*Справочник способов оплаты (наличные, карта, перевод и т.п.), выбираемых при создании денежной операции.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | строка | Наименование вида оплаты. |
| Порядок сортировки | число | Позиция в списке при ручной сортировке; по умолчанию 0. |
| Дата создания | дата и время | Проставляется автоматически при создании. |
| Дата изменения | дата и время | Обновляется автоматически при каждом сохранении. |

## Денежный счёт (касса)

*Касса или расчётный счёт компании с начальным и текущим остатком, на который зачисляются денежные операции определённых
видов оплаты.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | строка | Наименование счёта. |
| Счёт по умолчанию | флаг | Отмечает основной счёт, предлагаемый первым при выборе. |
| Начальный остаток | число (2 знака) | Стартовая сумма счёта; при её изменении баланс корректируется на разницу между новым и старым значением. |
| Текущий баланс | число (2 знака) | Начальный остаток плюс сумма успешных операций по счёту, дата которых наступила; операция с будущей датой учитывается с этой даты. Список и карточка счёта считают его в момент запроса; хранимое значение пересобирается при каждой записи или удалении оплаты по счёту. Вручную не задаётся, в API только для чтения. |
| Привязанные виды оплаты | список чисел | Перечень видов оплаты, которые зачисляются на этот счёт; служит для автоподстановки счёта по виду оплаты. Это массив идентификаторов без внешнего ключа, поэтому подбор счёта дополнительно сверяет компанию оплаты. При сохранении счёта на него переносятся оплаты этих видов, пришедшие без счёта с момента его открытия. |
| Порядок сортировки | число | Позиция в списке при ручной сортировке; по умолчанию 0. Если один вид оплаты привязан к нескольким счетам, оплаты получает первый по этому порядку. |
| Дата создания | дата и время | Проставляется автоматически при создании; это момент открытия счёта. Оплаты без счёта, сделанные раньше, при привязке вида оплаты не переносятся — считается, что они уже в начальном остатке. |
| Дата изменения | дата и время | Обновляется автоматически при каждом сохранении. |

## Строка «Без счёта»

*Виртуальная строка в конце списка счетов, без идентификатора и без записи в базе: показывает деньги, не привязанные ни к одному
счёту.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | строка | Всегда `Без счета` — буквальное значение из API. |
| Текущий баланс | число (2 знака) | Сумма успешных операций без счёта, дата которых наступила. Включает оплаты бонусами — у них нет ни вида оплаты, ни счёта. |

## Категория оплаты

*Статья доходов или расходов в виде двухуровневого дерева (категория и подкатегории), которой помечаются денежные операции.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | строка | Наименование категории. |
| Родительская категория | связь на себя | Ссылка на вышестоящую категорию; пусто у категорий верхнего уровня. При удалении родителя у дочерних очищается. |
| Направление | выбор (приход/расход) | Приход или расход для этой статьи; по умолчанию приход. |
| Активна | флаг | Признак того, что категорию можно выбирать; по умолчанию включена. |
| Порядок сортировки | число | Позиция в списке при ручной сортировке; по умолчанию 0. |
| Дата создания | дата и время | Проставляется автоматически при создании. |
| Дата изменения | дата и время | Обновляется автоматически при каждом сохранении. |
