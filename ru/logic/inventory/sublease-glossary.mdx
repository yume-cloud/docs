Справочник-словарь всех сущностей и полей, связанных с субарендой инвентаря. Повествовательное описание логики — на странице [Субаренда](/ru/logic/inventory/sublease).

## Понятия

| Понятие | Значение |
| --- | --- |
| Период субаренды | Запись о том, что единица инвентаря в указанный промежуток времени сдавалась в субаренду указанным владельцем под указанный процент. Единственный источник условий субаренды: отдельного «текущего среза» в карточке единицы нет. |
| Лента периодов | Все периоды одной единицы, упорядоченные от свежих к старым. Периоды не пересекаются, разрывы между ними допустимы. |
| Полуоткрытые границы | Начало периода включается, конец — нет. Любая из дат может быть пустой: пустое начало — «с самого начала», пустой конец — «до сих пор». |
| Текущий период | Период, покрывающий настоящий момент: начало не позже сейчас (или пусто) и конец строго позже сейчас (или пуст). Отвечает на вопрос «чей это инвентарь сейчас». |
| Покрытие начисления | Правило атрибуции дохода: начисление достаётся периоду, который покрывает дату начала этого начисления. Процент берётся из того же периода. |
| Пересечение периодов | Запрещённое состояние: два периода одной единицы, у которых есть общее время (с учётом открытых границ). Проверяется при сохранении. |
| Сводка дохода по субаренде | Агрегированные итоги по всем субарендодателям за период (суммы и средние). |

## Модели и поля

### Период субаренды

*Единственный источник условий субаренды единицы. Границы полуоткрытые, любая из дат может быть пустой. Проверочное ограничение базы данных требует, чтобы начало было строго раньше конца, если заданы обе даты; непересечение периодов одной единицы проверяется при сохранении.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Владелец (субарендодатель) | связь | Пользователь, которому принадлежит инвентарь и который получает долю дохода. Обязателен; выбирается только из сотрудников текущей компании. При удалении пользователя его периоды удаляются. |
| Единица инвентаря | связь | Инвентарь, к которому относится период. При удалении единицы её периоды удаляются. |
| Компания | связь | Компания-владелец записи; проставляется автоматически. |

**Условия**

| Поле | Тип | Описание |
| --- | --- | --- |
| Процент субаренды | число (2 знака) | Доля владельца в доходе, от 0 до 100 процентов. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Начало периода | дата/время | Начало действия условий; включается в период. Пусто — открытая граница слева. |
| Конец периода | дата/время | Конец действия условий; в период не включается. Пусто — открытая граница справа, период действует до сих пор. |
| Действует сейчас | признак | Вычисляется: покрывает ли период текущий момент. Только для чтения. |
| Создано | дата/время | Заполняется автоматически при создании. |
| Изменено | дата/время | Заполняется автоматически при каждом сохранении. |

**Фильтры списка**

| Параметр | Описание |
| --- | --- |
| Действует сейчас | Истина — только текущие периоды, ложь — все остальные. |
| Действовал в момент | Периоды, покрывавшие указанный момент времени. |
| Начало, конец: не раньше / не позже | Границы по датам начала и конца периода. |
| Начало не задано, конец не задан | Периоды с открытой левой или правой границей. |
| Единица, продукт, категория, пункт проката, состояние единицы | Отбор по самой единице инвентаря. |
| Владелец | Один или несколько субарендодателей. |
| Процент | Точное значение, не меньше, не больше. |
| Дата создания | Не раньше / не позже. |

*Агрегированные итоги по всем субарендодателям за период (суммы и средние).*

| Поле | Тип | Описание |
| --- | --- | --- |
| Всего единиц | число | Суммарное количество единиц в субаренде. |
| Число субарендодателей | число | Количество пользователей-владельцев. |

**Доход**

| Поле | Тип | Описание |
| --- | --- | --- |

| Доход, среднее | число (2 знака) | — |
| Доход владельцев, сумма | число (2 знака) | — |
| Доход владельцев, среднее | число (2 знака) | — |
