## Понятия

| Понятие | Значение |
| --- | --- |
| Инвентаризация | Запись о фиксации состояния единицы инвентаря в определённый момент, обычно в привязке к заказу и позиции заказа. При создании записи и при изменении состояния в ней текущее состояние единицы синхронизируется с записью; ведётся цепочка через ссылку на предыдущую запись. |
| Источник инвентаризации | Способ создания записи инвентаризации. |

## Модели и поля

### Инвентаризация

*Запись о фиксации состояния единицы инвентаря в определённый момент, обычно в привязке к заказу и позиции заказа. Текущее состояние единицы синхронизируется с записью при её создании и при фактическом изменении состояния в ней (вместе с состоянием обновляется отметка времени изменения единицы); ведётся цепочка через поле предыдущей инвентаризации.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Заказ | связь | Аренда, в рамках которой сделана фиксация; может отсутствовать. |
| Позиция заказа | связь | Конкретная позиция инвентаря в заказе; может отсутствовать. |
| Единица инвентаря | связь | Единица оборудования, состояние которой фиксируется. |
| Кто зафиксировал | связь | Пользователь, создавший запись инвентаризации. |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Состояние | связь | Зафиксированное состояние единицы; доступно на изменение — исправление состояния в существующей записи переносится в карточку единицы. |
| Предыдущая инвентаризация | связь | Ссылка на предыдущую запись той же единицы (цепочка истории). |
| Источник | перечисление | Как создана запись: вручную, из заказа и т. д. |
| Комментарий | текст | Текстовое описание или заметка при фиксации состояния. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент фиксации; проиндексирован. |
| Дата обновления | дата/время | Момент последнего изменения записи. |

## Статусы и справочники

### Источник инвентаризации

- Вручную
- Из заказа
- Из мастерской
