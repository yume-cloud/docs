## Модели и поля

### Тариф продукта

*Правило ценообразования продукта: цена на определённый период времени с ограничением по дням недели и времени суток. Одна и та же модель обслуживает тарифы продукта, отдельной единицы и комплекта; для продукта заполняется связь с продуктом.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Продукт | связь | Продукт, к которому относится тариф |
| Период времени | связь | Тарифицируемый период (час/сутки и т. п.) |

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название тарифа | текст |  |
| Цена | число (2 знака) | Стоимость за период |
| Порядок | число | Порядок сортировки тарифов |

**Расписание**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дни недели | список чисел | Дни недели действия тарифа (0–6) |
| Начало действия | время | Время начала действия тарифа в сутках |
| Конец действия | время | Время окончания действия тарифа в сутках |

**Объект тарификации**

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь | Тариф для конкретной единицы оборудования |
| Позиция комплекта | связь | Тариф для позиции внутри комплекта |
| Вариант цены комплекта | связь | Привязка к конкретному варианту цены комплекта |

**Отображение**

| Поле | Тип | Описание |
| --- | --- | --- |
| Опубликован | флаг | Виден ли тариф клиентам |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец записи |
| История изменений | журнал | Аудит-лог |
| Дата создания | дата/время |  |
| Дата обновления | дата/время |  |

### Менеджер тарифов

*Менеджер модели, скрывающий тарифы с отключённым временным периодом. Возвращает тарифы без периода или с активным (не отключённым) периодом.*

### Сериализатор тарифа единицы

*Чтение и запись тарифа для единицы инвентаря; создаёт тариф для единицы из URL и запрещает изменение тарифов комплекта. Поля идентификатора комплекта и продукта — только для чтения; единица инвентаря и позиция комплекта неизменяемы.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор комплекта | число | Только для чтения |
| Идентификатор продукта | число | Только для чтения |

### Сериализатор тарифа продукта

*Чтение и запись тарифа для продукта; создаёт тариф для продукта из URL.*

### Сериализатор тарифа варианта цены комплекта

*Компактное представление тарифа, привязанного к варианту цены комплекта.*

### Элемент массового создания тарифа комплекта

*Одна строка запроса на массовое создание тарифов комплекта.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена | число (2 знака) | Стоимость по тарифу |
| Позиция комплекта | связь | Позиция комплекта, к которой относится тариф |
| Вариант цены комплекта | связь | Вариант цены, к которому относится тариф |

### Элемент массового обновления тарифа комплекта

*Одна строка запроса на массовое обновление тарифов комплекта (наследует поля создания и добавляет идентификатор).*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор тарифа | число | Обязателен для обновления |

### Массовое создание тарифов комплекта

*Пакетно создаёт тарифы для позиций комплекта и пересчитывает итоговую цену вариантов цены комплекта. После вставки пересчитывает итоговую цену варианта как сумму цен тарифов, умноженных на количество позиций.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Тарифы | список | Список создаваемых тарифов |

### Массовое обновление тарифов комплекта

*Пакетно обновляет цену, название и период тарифов комплекта и пересчитывает итоговую цену вариантов цены комплекта. Пересчёт итоговой цены аналогичен массовому созданию.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Тарифы | список | Список обновляемых тарифов |

### Сериализатор варианта цены комплекта (V2)

*Чтение и запись варианта цены комплекта; создаёт вариант для комплекта из URL. Итоговая цена сюда не входит — она вычисляется при пересчёте тарифов.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название варианта цены |
| Временной период | связь | Период, к которому относится вариант цены |
| Порядок сортировки | число | Позиция в списке |
