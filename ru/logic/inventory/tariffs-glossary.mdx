## Понятия

| Понятие | Значение |
| --- | --- |
| Тариф | Правило ценообразования: цена за один тарифицируемый период с необязательным ограничением по дням недели и времени суток. Одна модель обслуживает тарифы единицы, продукта, позиции комплекта и услуги. |
| Объект тарификации (владелец) | То, к чему привязан тариф: единица инвентаря, продукт, позиция комплекта или услуга. У тарифа он ровно один. |
| Правило одного владельца | Проверка при сохранении: привязка обязана быть, и она может быть только одна. Вариант цены комплекта допустим только вместе с позицией состава. |
| Разовая оплата | Признак тарифа услуги: услуга стоит фиксированную сумму за аренду, а не за каждый период. |
| Менеджер тарифов | Менеджер модели, скрывающий тарифы с отключённым временным периодом: возвращает тарифы без периода или с активным (не отключённым) периодом. |
| Пересчёт цен комплекта | Автоматическое обновление итоговой цены вариантов цены комплекта после любой операции с тарифами его позиций: цена варианта равна сумме цен тарифов, умноженных на количество позиций. |
| Массовая операция | Один запрос, который одновременно добавляет, изменяет и удаляет тарифы и пересчитывает цены затронутых комплектов один раз. |

## Модели и поля

### Тариф

*Правило ценообразования: цена на определённый период времени с ограничением по дням недели и времени суток. Одна модель обслуживает тарифы единицы, продукта, позиции комплекта и услуги — роль определяется тем, какая связь объекта тарификации заполнена.*

**Объект тарификации**

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь | Тариф для конкретной единицы оборудования |
| Продукт | связь | Тариф для продукта; действует на все его единицы без собственного тарифа |
| Позиция комплекта | связь | Тариф для позиции внутри комплекта |
| Вариант цены комплекта | связь | Привязка к конкретному варианту цены комплекта; указывается только вместе с позицией состава |
| Услуга | связь | Тариф дополнительной услуги |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Период времени | связь | Тарифицируемый период (час/сутки и т. п.); может быть пустым. Период защищён от удаления, пока на него ссылается тариф |

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название тарифа | текст | Если не задано, подставляется имя объекта тарификации; у позиции комплекта — «Комплект \| Вариант цены» |
| Цена | число (2 знака) | Стоимость за период |
| Порядок | число | Порядок сортировки тарифов |

**Расписание**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дни недели | список чисел | Дни недели действия тарифа (0–6) |
| Начало действия | время | Время начала действия тарифа в сутках |
| Конец действия | время | Время окончания действия тарифа в сутках |

**Отображение и расчёт**

| Поле | Тип | Описание |
| --- | --- | --- |
| Опубликован | флаг | Виден ли тариф клиентам |
| Разовая оплата | флаг | Тариф берётся один раз за аренду, а не за каждый период; применяется к услугам |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец записи |
| История изменений | журнал | Аудит-лог |
| Дата создания | дата/время |  |
| Дата обновления | дата/время |  |

### Менеджер тарифов

*Менеджер модели, скрывающий тарифы с отключённым временным периодом. Возвращает тарифы без периода или с активным (не отключённым) периодом.*

### Фильтры списка тарифов

| Параметр | Описание |
| --- | --- |
| Единица инвентаря | Точное значение или признак «не задано» |
| Продукт | Точное значение или признак «не задано» |
| Позиция комплекта | Точное значение или признак «не задано» |
| Комплект | Все тарифы позиций указанного комплекта |
| Вариант цены комплекта | Точное значение или признак «не задано» |
| Услуга | Точное значение или признак «не задано» |
| Период времени | Точное значение или «без периода» |
| Опубликован | Только опубликованные или только скрытые |
| Прайс единицы | Тарифы, по которым считается цена указанной единицы |
| Область прайса | Уточнение к предыдущему параметру: «единица», «продукт», «комплект» либо без значения — собственные тарифы единицы вместе с тарифами её продукта |

### Формат тарифа

*Чтение и запись одиночного тарифа. Компания — только для чтения. При сохранении проверяется правило одного владельца, подставляется название и пересчитываются цены затронутых комплектов; при правке пересчитываются комплекты и до, и после изменения.*

### Элемент массового создания тарифа

*Одна строка запроса на массовое создание.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена | число (2 знака) | Стоимость по тарифу |
| Название, порядок, дни недели, время начала и конца, публикация, разовая оплата | — | Необязательные поля тарифа |
| Единица, продукт, позиция комплекта, вариант цены, услуга | связь | Объект тарификации; должен быть ровно один |
| Период времени | связь | Если не задан, а указан вариант цены комплекта, подставляется период этого варианта |

### Элемент массового обновления тарифа

*Одна строка запроса на массовое обновление: те же поля, что и при создании, плюс обязательный идентификатор; все поля необязательны.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор тарифа | число | Обязателен для обновления |

<Note>
Применяются только цена, название, порядок, дни недели, время начала и конца, публикация, период времени и разовая оплата. Переданные в строке связи объекта тарификации не меняют владельца тарифа.
</Note>

### Массовое создание тарифов

*Создаёт тарифы одной пакетной вставкой и пересчитывает итоговую цену вариантов цены затронутых комплектов. Выполняется в одной транзакции.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Тарифы | список | Список создаваемых тарифов |

### Массовое обновление тарифов

*Пакетно обновляет тарифы и пересчитывает итоговую цену вариантов цены затронутых комплектов. Выполняется в одной транзакции.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Тарифы | список | Список обновляемых тарифов |

### Массовая операция с тарифами

*Один запрос на добавление, изменение и удаление. Выполняется в одной транзакции, цены вариантов комплекта пересчитываются один раз.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Добавить | список | Строки массового создания |
| Изменить | список | Строки массового обновления |
| Удалить | список чисел | Идентификаторы удаляемых тарифов |
| Добавлено, изменено, удалено | число | Ответ: сколько записей затронуто каждой частью операции |

### Формат варианта цены комплекта (V2)

*Чтение и запись варианта цены комплекта; создаёт вариант для комплекта из URL. Итоговая цена сюда не входит — она вычисляется при пересчёте тарифов.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название варианта цены |
| Временной период | связь | Период, к которому относится вариант цены |
| Порядок сортировки | число | Позиция в списке |
