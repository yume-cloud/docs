## Понятия

| Понятие | Значение |
| --- | --- |
| Услуга (сервис) | Дополнительная платная услуга, которую можно добавить к аренде и опубликовать в витрине. При сохранении генерирует ссылочное имя и миниатюру изображения, после сохранения или удаления пересобирает витрину; уникальна в паре «компания + ссылочное имя». |
| Тариф услуги | Ценовой тариф услуги для определённого временного периода. Привязан к услуге и удаляется вместе с ней. |
| Способ вывода из оборота | Как единица была скрыта или выведена: удаление, архив или списание; хранится в связанной записи и влияет на вычисляемый статус. |
| Архивирование услуги | Отдельное действие, ставящее услуге отметку вывода из оборота со способом «архив». Повторное архивирование ничего не меняет (услуга остаётся в архиве), возврат из архива выполняется отдельным изменением услуги. Если услуга выведена из оборота другим способом, и архивирование, и возврат отклоняются с ошибкой. |
| Тип услуги | Классификатор типа дополнительной услуги; по умолчанию «не выбран». |

## Модели и поля

### Услуга (сервис)

*Дополнительная платная услуга, которую можно добавить к аренде и опубликовать в витрине.*

*При сохранении генерирует ссылочное имя и миниатюру изображения; после сохранения или удаления пересобирает витрину; уникальность по паре «компания + ссылочное имя».*

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название услуги. |
| Тип услуги | перечисление (тип услуги) | Категория или тип услуги; по умолчанию «не выбран». |
| Внутренний код | текст | Артикул или уникальный идентификатор для поиска. |
| Категория | связь | Связь с категорией. |
| Доп. данные | структура (JSON) | Произвольные дополнительные атрибуты. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Скидка | связь | Связь со скидкой. |
| Бонус | число (2 знака) | Начисляемый бонус. |
| Цена | число (2 знака) | Базовая цена услуги. |

**Витрина**

| Поле | Тип | Описание |
| --- | --- | --- |
| Ссылочное имя (slug) | текст | Генерируется из названия; используется в витрине; уникально в паре с компанией. |
| Опубликовано в витрине | флаг | Показывать ли услугу в витрине. |
| Изображение | изображение | Картинка услуги (хранится в облачном хранилище, создаётся миниатюра). |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец записи. |
| Создано | дата/время | Дата создания. |
| Обновлено | дата/время | Дата изменения. |

### Тариф услуги

*Ценовой тариф услуги для определённого временного периода.*

*Привязан к услуге (при удалении услуги удаляется каскадно).*

| Поле | Тип | Описание |
| --- | --- | --- |
| Услуга | связь | Услуга, к которой относится тариф. |
| Название тарифа | текст | Название тарифа. |
| Цена | число (2 знака) | Цена тарифа для клиента. |
| Себестоимость | число (2 знака) | Внутренняя цена или себестоимость для компании. |
| Период (единица времени) | связь | Временной период тарификации. |
| Разовая оплата | флаг | Оплачивается один раз, а не за период. |
| Опубликован | флаг | Активен ли тариф; по умолчанию да. |
| Компания | связь | Владелец записи. |
| Создано | дата/время | Дата создания. |
| Обновлено | дата/время | Дата изменения. |

### Формат услуги

*Основной набор полей услуги для списка и карточки.*

*Добавляет виртуальные поля отключения/удаления и вложенные тарифы.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Способ отключения | перечисление (способ вывода из оборота) | Входное поле: пометить услугу удалённой или архивной. |
| Удалена | флаг | Вычисляемое: есть ли запись о выводе услуги из оборота. |
| Тарифы | список | Вложенные тарифы услуги (только чтение). |

### Сводка по услугам

*Агрегированная статистика по услугам (сводные показатели).*

*Только для чтения, данные считаются в представлении сводки.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Количество | число | Число услуг в выборке. |
| Сумма | число (2 знака) | Суммарная выручка по услугам (со скидкой). |
| Средняя сумма | число (2 знака) | Средняя выручка по услуге. |

## Статусы и справочники

### Способ вывода из оборота

Как единица была скрыта или выведена; хранится в связанной записи, а не на самой единице.

- Удаление
- Архив
- Списание

### Тип услуги

Классификатор типа дополнительной услуги; по умолчанию «не выбран».
