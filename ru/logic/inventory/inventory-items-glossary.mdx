## Модели и поля

### Единица инвентаря

*Индивидуальная единица оборудования/транспорта, которую сдают в аренду или продают; несёт цену, состояние, точку хранения, субаренду и вычисляемый статус. Статус (свободна/в аренде/сломана и т.д.) не хранится, а вычисляется менеджером на лету; поля субаренды — живой кэш.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Наименование единицы. |
| Уникальный идентификатор | текст | Внутренний артикул/инвентарный номер; при включённой проверке уникален среди неудалённых. |
| Идентификатор устройства | текст | Технический ID устройства/метки; только для чтения. |
| Тип учёта | перечисление (аренда/продажа) | Аренда или продажа. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Категория | связь | Категория товара. |
| Продукт | связь | Продукт (учёт по количеству), к которому относится единица. |
| Точка проката | связь | Точка хранения/выдачи; меняется операцией перемещения. |
| Состояние | связь | Ссылка на состояние; блокирующее состояние делает единицу сломанной/недоступной. |

**Деньги**

| Поле | Тип | Описание |
| --- | --- | --- |
| Цена покупки | число (2 знака) | Закупочная стоимость. |
| Дата покупки | дата | Дата приобретения. |
| Цена продажи | число (2 знака) | Стоимость продажи; заполняется при продаже. |
| Дата продажи | дата/время | Проставляется при продаже; непустая дата = единица продана. |
| Складская цена | число (2 знака) | Учётная/складская стоимость. |
| Срок службы | число | Срок эксплуатации (для амортизации). |
| Предыдущая выручка | число (2 знака) | Накопленный/перенесённый доход по единице (кэш для метрик). |

**Субаренда**

| Поле | Тип | Описание |
| --- | --- | --- |
| Владелец субаренды | связь | Пользователь-субарендодатель; заполнено = единица в субаренде (живой кэш поверх истории субаренды). |
| Процент субаренды | число (2 знака, 0–100) | Доля выплаты субарендодателю. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Комментарий | текст | Произвольное описание. |
| Изображение | файл | Фото единицы; при сохранении создаётся превью. |
| Доп. данные | JSON | Произвольные атрибуты; сюда пишется общий пробег при добавлении пробега. |
| История изменений | журнал аудита | Лог изменений полей. |
| Дата создания | дата/время | Из базовой модели. |
| Дата обновления | дата/время | Из базовой модели. |
| Компания | связь | Ограничение по компании. |

### Авто-карточка единицы

*Авто-специфичные атрибуты единицы (номер, техпаспорт, VIN, марка/модель) для транспортного проката. Связь один-к-одному с единицей инвентаря; активна при включённой опции авто-инвентаря.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь один-к-одному | Единица, к которой относится авто-карточка. |
| Тип транспорта | перечисление | Машина / электросамокат / мотоцикл. |
| Гос. номер | текст | Для машин проверяется формат; вместе с техпаспортом должен быть уникален. |
| Техпаспорт | текст | Номер техпаспорта; для машин проверяется формат. |
| Серийный номер | текст | Серийный номер (для самокатов/мото). |
| VIN | текст | VIN-код. |
| Марка | текст | Марка транспорта. |
| Модель | текст | Модель транспорта. |
| Доп. данные | JSON | Произвольные атрибуты. |

### Состояние инвентаря

*Справочник пользовательских состояний единицы (например «Исправна», «На ремонте»); влияет на доступность. Флаг блокировки выводит единицу из проката; связь с мастерской привязывает состояние к ремонту.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Наименование состояния. |
| Блокирует прокат | флаг | Если включено — единица считается сломанной/недоступной. |
| Отправляет в мастерскую | флаг | Состояние связано с ремонтом/мастерской. |
| Воронка мастерской | связь | Пайплайн задач мастерской. |
| Цвет | текст (HEX) | Цвет метки состояния. |
| Комментарий | текст | Описание состояния. |

### Страховка единицы

*Полис страхования единицы (КАСКО/ОГПО) с компанией, номером, суммой и сроком действия. Связь один-к-одному с единицей инвентаря.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь один-к-одному | Застрахованная единица. |
| Тип полиса | перечисление (КАСКО/ОГПО) | Вид страхования. |
| Страховая компания | текст | Наименование страховщика. |
| Номер полиса | текст | Номер страхового полиса. |
| Сумма | число (2 знака) | Страховая сумма/стоимость. |
| Начало действия | дата/время | Дата начала полиса. |
| Окончание действия | дата/время | Дата окончания полиса. |

### Пробег единицы

*Запись показания пробега/дистанции единицы на определённый момент; используется для планового ТО по пробегу. При сохранении обновляет общий пробег единицы и может инициировать уведомление о ТО.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь | Единица, по которой зафиксирован пробег. |
| Инвентаризация | связь | Инвентаризация, в рамках которой снят пробег (опционально). |
| Пробег | число | Показание пробега/дистанции. |
| Дата снятия | дата/время | Когда зафиксировано показание. |

### Менеджер единиц (расчёт доступности)

*Расчётный слой единицы: вычисляет статус и доступность единиц по расписанию, состоянию, складу, задачам мастерской и продаже. Аннотирует статус на лету; учитывает буфер между бронями.*

| Поле | Тип | Описание |
| --- | --- | --- |
| С доступностью | метод | Аннотирует статус единицы с учётом брони, ремонта, склада, списания и продажи. Из задач мастерской учитываются только открытые задачи на этапах с признаком «Занимать инвентарь» и задачи без этапа. |
| По расписанию | метод | Исключает единицы, занятые в интервале, проданные, на складе или отключённые. Задачи мастерской не учитывает. |
| Со статусом | метод | Аннотирует статус без учёта арендного расписания; задачи мастерской отбираются по тому же признаку «Занимать инвентарь». |

## Статусы и справочники

### Статус единицы (вычисляемый)

Оперативный статус единицы, вычисляемый на лету из расписания, состояния, склада, ремонта и продажи. Не хранится в базе, а аннотируется менеджером.

- Свободна
- Забронирована
- В аренде
- Сломана
- Просрочена
- Отключена/удалена
- Продана
- На ремонте
- Списана
- На складе
- На доставке
- Возврат с доставки

### Тип учёта единицы

Определяет, предназначена ли единица для аренды или для продажи.

- Аренда
- Продажа

### Тип транспорта

Вид транспортной единицы в авто-карточке; влияет на проверки формата и лимиты.

- Машина
- Электросамокат
- Мотоцикл/Мопед

### Тип страхового полиса

Вид страхования единицы.

- КАСКО
- ОГПО (ОСАГО)

### Способ вывода из оборота

Как единица была скрыта/выведена: удаление, архив или списание; влияет на вычисляемый статус.

- Удаление
- Архив
- Списание
