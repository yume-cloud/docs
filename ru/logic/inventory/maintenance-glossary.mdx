## Модели и поля

### Обслуживание инвентаря

*Разовое или периодическое техническое обслуживание/ремонт единицы инвентаря по интервалу времени или по пробегу. После сохранения переносит выбранное состояние на саму единицу инвентаря; периодическое ТО при завершении автоматически создаёт следующую запись.*

**Основное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Наименование обслуживания. |
| Тип обслуживания | перечисление | Разовое или периодическое. |
| Тип периодичности | перечисление | По интервалу времени или по пробегу. |
| Описание | текст | Подробное описание работ; используется в тексте уведомления. |
| Комментарий | текст | Заметка; заполняется при завершении ТО (только чтение в API). |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Единица инвентаря | связь | Обслуживаемая единица инвентаря. |
| Ответственный | связь | Пользователь, ответственный за обслуживание. |
| Состояние инвентаря | связь | Состояние, присваиваемое единице инвентаря при этом ТО. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Плановая дата ТО | дата/время | Дата/время планового обслуживания. |

**Периодичность**

| Поле | Тип | Описание |
| --- | --- | --- |
| Интервал повторения | интервал | Период между повторами для периодического ТО по времени. |
| Интервал по пробегу | число | Пробег между обслуживаниями (для типа по пробегу). |

**Пороги уведомлений**

| Поле | Тип | Описание |
| --- | --- | --- |
| Порог уведомления по времени | интервал | За сколько до даты ТО уведомить. |
| Порог уведомления по пробегу | число | За сколько километров до достижения пробега уведомить. |

**Пробег**

| Поле | Тип | Описание |
| --- | --- | --- |
| Начальный пробег | число | Пробег на момент назначения ТО (база отсчёта). |

**Завершение**

| --- | --- | --- |
| Фактическая дата ТО | дата/время | Дата завершения; пустая — ТО ещё не выполнено (только чтение в API). |
| Пробег при завершении | число | Пробег на момент фактического завершения (только чтение в API). |

### Ресурс обслуживания

*Позиция расхода из склада мастерской (запчасть/материал), использованная при обслуживании. При создании списывает ресурс со склада и создаёт расходную транзакцию; при удалении возвращает остаток и удаляет транзакцию.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Обслуживание | связь | Обслуживание, к которому относится ресурс. |
| Ресурс мастерской | связь | Ресурс из склада мастерской. |
| Цена | число (2 знака) | Цена за единицу ресурса. |
| Количество | число (2 знака) | Списываемое количество ресурса. |
| Дата создания | дата/время | |
| Дата изменения | дата/время | |

### Задача уведомления о ТО

*Фоновая задача: формирует уведомление о необходимости ТО и при включённой интеграции отправляет клиенту сообщение в WhatsApp. Запускается по расписанию (разовому или периодическому), создаваемому при сохранении обслуживания; шлёт только при активной интеграции.*
