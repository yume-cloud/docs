Справочник к странице [«Сообщения»](/ru/logic/chat).

## Понятия

| Понятие | Значение |
| --- | --- |
| Переписка (чат) | Беседа внутри одной компании: чат с поддержкой, личный или групповой чат |
| Чат с поддержкой | Закреплённая переписка сотрудника с поддержкой Yume; одна на сотрудника в каждой компании. Отвечает ассистент поддержки или специалист Yume |
| Личный чат | Переписка двух сотрудников одной компании; на пару сотрудников — одна |
| Групповой чат | Переписка нескольких сотрудников с необязательным названием и создателем |
| Участник | Сотрудник, который видит переписку и получает о ней сигналы |
| Сообщение | Текст, фото, файлы и упоминания записей внутри переписки; хранится как комментарий к переписке, но в общем разделе комментариев не виден |
| Ответ ассистента | Сообщение без автора с пометкой «ответ ассистента» — то, что ассистент поддержки положил в чат |
| Отметка о прочтении | Момент, до которого участник прочитал переписку; всё более позднее от других — непрочитанное |
| Общая отметка поддержки | Одна отметка о прочтении чата с поддержкой на всех специалистов Yume |
| Кто отвечает | Признак чата с поддержкой: ассистент или человек |
| Передача человеку | Переключение чата с поддержкой с ассистента на специалиста; после неё ассистент больше не отвечает |
| Возврат ассистенту | Обратное переключение; делает только специалист поддержки |
| Резервная фраза | «Ассистент не смог ответить — здесь ответит специалист поддержки.» — публикуется при сбое, отмене запуска или исчерпанном лимите |
| Карточка подтверждения | Сообщение ассистента с действием, которое он предлагает выполнить и которое ждёт решения сотрудника |
| Входящие поддержки | Общий список чатов с поддержкой по всем компаниям, доступный специалистам Yume |
| Специалист поддержки | Сотрудник Yume с правами поддержки на всей платформе |
| Сигнал | Сообщение по каналу реального времени: только номера чата и получателей, без текста |

## Модели и поля

### Переписка

*Одна беседа внутри компании. Для чата с поддержкой сочетание «компания + сотрудник» уникально.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания, которой принадлежит переписка; при удалении компании переписка удаляется |
| Тип | справочник | Чат с поддержкой, личный или групповой — см. [виды переписки](#вид-переписки) |
| Название | текст | Название группы; у других видов пустое. При переименовании пробелы по краям обрезаются |
| Сотрудник | связь (пользователь) | Только у чата с поддержкой: чей это чат. При удалении пользователя чат удаляется |
| Создатель | связь (пользователь) | Только у группы: кто её создал; вместе с администратором компании может переименовать, удалить группу и исключать участников. При удалении пользователя обнуляется |
| Последнее сообщение | дата/время | Время последнего сообщения; по нему сортируется список чатов. Пусто, пока сообщений нет |
| Прочитано поддержкой | дата/время | Общая отметка о прочтении для всех специалистов поддержки; используется только у чата с поддержкой |
| Кто отвечает | справочник | Только для чата с поддержкой: ассистент или человек — см. [кто отвечает](#кто-отвечает). Новый чат начинается с ассистента, чат, открытый специалистом, — с человека |
| Сессия ассистента | связь | Сессия ассистента поддержки, которая ведёт историю этого чата; создаётся при первом обращении к ассистенту, одна на чат |
| Дата создания | дата/время | Момент создания переписки |
| Дата изменения | дата/время | Момент последнего изменения |

**Что отдаётся в списке чатов дополнительно**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | объект | Номер и название компании |
| Участники | список | Имя, фамилия, аватар и телефон каждого участника |
| Непрочитанное | число | Для участника — сообщения других после его отметки; во входящих поддержки — сообщения сотрудника после общей отметки поддержки |
| Последнее сообщение | объект | Автор и начало текста последнего сообщения (разметка убрана, упоминания заменены именами) |

### Участник переписки

*Связь сотрудника с перепиской. Сотрудник может быть участником одной переписки только один раз.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Переписка | связь | Переписка; при её удалении участие удаляется |
| Сотрудник | связь (пользователь) | Участник; при удалении пользователя участие удаляется |
| Прочитано | дата/время | Отметка о прочтении этого участника; ставится при открытии чата и при отправке своего сообщения |

### Сообщение

*Комментарий, прикреплённый к переписке. Поля те же, что у [комментария](/ru/logic/attachments/comments-glossary); ниже — то, что в переписке работает иначе.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Текст | текст | Может быть пустым, если в сообщении только вложения. Упоминания сотрудников в тексте уведомлений не рассылают |
| Автор | связь (пользователь) | Текущий пользователь; у ответа ассистента — пусто |
| Контекст | произвольные данные | У ответа ассистента — пометка «ответ ассистента»; у карточки подтверждения — ожидающие действия и, после решения, принятые решения |
| Фото, файлы | список | Загружаются после создания сообщения; сигнал собеседникам подаётся после загрузки |
| Упоминания записей | список | Связи с записями из общего реестра, как у комментариев |

### Карточка подтверждения

*Пометка в контексте ответа ассистента, когда ассистент ждёт решения сотрудника.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Запуск | идентификатор | Запуск ассистента, который остановился в ожидании решения |
| Действия | список | Что ассистент предлагает сделать: инструмент, параметры и человекочитаемое описание действия |
| Решение | объект | Появляется после решения: для каждого действия — подтверждено или отклонено. Пустое решение означает, что сотрудник прошёл мимо карточки и все действия отклонены |

## Статусы и справочники

### Вид переписки

| Значение | Подпись | Описание |
| --- | --- | --- |
| Поддержка | Поддержка Yume | Чат сотрудника с поддержкой; один на сотрудника в компании, создаётся сам |
| Личный | Личный чат | Два сотрудника одной компании; повторно не создаётся |
| Группа | Групповой чат | Несколько сотрудников, с названием и создателем |

### Кто отвечает

| Значение | Подпись | Когда устанавливается |
| --- | --- | --- |
| Ассистент | Агент | Новый чат с поддержкой; возврат ассистенту специалистом |
| Человек | Человек | Ассистент передал вопрос в поддержку; запуск завершился сбоем или отменой; исчерпан лимит ассистента; написал специалист поддержки; чат открыл сам специалист |

### Входящие поддержки: фильтр «кто отвечает»

| Значение | Что показывает |
| --- | --- |
| Человек (по умолчанию) | Чаты, переданные специалистам |
| Ассистент | Чаты, которые ведёт ассистент |
| Все | Все чаты с поддержкой, где есть хотя бы одно сообщение |

### Сигналы реального времени

| Сигнал | Кому | Когда |
| --- | --- | --- |
| Новое сообщение | Участникам переписки, кроме автора | Отправлено сообщение или пришёл ответ ассистента |
| Новое сообщение (поддержка) | Всем специалистам поддержки | Сотрудник написал в чат с поддержкой; чат передан человеку |
| Обновить список | Участникам | Изменён состав или название группы, группа удалена, чат с поддержкой передан человеку или возвращён ассистенту |
