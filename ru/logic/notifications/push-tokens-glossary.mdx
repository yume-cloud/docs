Плоский справочник всех сущностей, полей и справочников, участвующих в хранении push-токенов устройств. Повествовательное описание логики — на странице [Push-токены устройств](/ru/logic/notifications/push-tokens).

## Понятия

| Понятие | Значение |
| --- | --- |
| Push-токен устройства | Хранит Expo push-токен конкретного устройства сотрудника для мобильных пуш-уведомлений. Уникальность по связке компании, пользователя, токена, идентификатора и типа устройства; у одного идентификатора устройства и у одного токена — не больше одной активной записи. |
| Тип устройства push | Платформа устройства, для которого зарегистрирован push-токен. Значение по умолчанию — iOS. |
| Одна активная запись на устройство и на токен | Два частичных уникальных индекса в базе (`push_token_one_active_per_device`, `push_token_one_active_per_token`) действуют только на активные записи. Записи без идентификатора устройства сравниваются только по токену. |
| Освобождение устройства | Первый шаг регистрации: деактивирует все активные записи с тем же токеном или тем же идентификатором устройства — независимо от сотрудника и компании. Выполняется в одной транзакции с созданием записи, под блокировкой по токену и идентификатору устройства. |
| Регистрация токена (API) | `POST /v1/notifications/mobile/` — регистрирует или обновляет токен текущего сотрудника в текущей компании; принимает только токены Expo (`ExponentPushToken[…]`), иначе 400. `GET` по тому же адресу — токены сотрудника в текущей компании, от новых к старым. |
| Отписка устройства (API) | `POST /v1/notifications/mobile/unsubscribe/` — деактивирует записи текущего сотрудника с переданным идентификатором устройства во всех его компаниях. Записи не удаляются. |
| Очистка неактивных токенов | Периодическая задача, ежедневно в 05:15: удаляет неактивные записи, не менявшиеся дольше 30 дней. |
| Повторная регистрация из приложения | Мобильное приложение регистрирует устройство при запуске и при каждом возвращении из фона; при неизменных токене, устройстве и компании — не чаще раза в 12 часов. При выходе из аккаунта отписывает устройство. |

## Модели и поля

### Push-токен устройства

*Хранит Expo push-токен конкретного устройства сотрудника для мобильных пуш-уведомлений. Уникальность по связке компании, пользователя, токена, идентификатора и типа устройства; у одного идентификатора устройства и у одного токена — не больше одной активной записи.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | компания, из которой зарегистрирован токен; может быть пустым |
| Пользователь | связь | владелец устройства; обратная связь — список push-токенов пользователя |

**Устройство**

| Поле | Тип | Описание |
| --- | --- | --- |
| Токен | текст | Expo push-токен устройства |
| Идентификатор устройства | текст | необязательный идентификатор устройства |
| Тип устройства | перечисление | iOS / Android / Web; по умолчанию iOS |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Активен | флаг | снимается при новой регистрации того же устройства или токена, при отписке и при недоставке (недействительный токен или незарегистрированное устройство) |
| Последнее использование | дата/время | обновляется автоматически при сохранении |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создан | дата/время | из базовой модели |
| Обновлён | дата/время | из базовой модели; любая деактивация проставляет его заново, по нему чистятся неактивные токены старше 30 дней |
