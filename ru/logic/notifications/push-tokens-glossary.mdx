Плоский справочник всех сущностей, полей и справочников, участвующих в хранении push-токенов устройств. Повествовательное описание логики — на странице [Push-токены устройств](/ru/logic/notifications/push-tokens).

## Понятия

| Понятие | Значение |
| --- | --- |
| Push-токен устройства | Хранит Expo push-токен конкретного устройства сотрудника для мобильных пуш-уведомлений. Уникальность по связке компании, пользователя, токена, идентификатора и типа устройства. |
| Тип устройства push | Платформа устройства, для которого зарегистрирован push-токен. Значение по умолчанию — iOS. |

## Модели и поля

### Push-токен устройства

*Хранит Expo push-токен конкретного устройства сотрудника для мобильных пуш-уведомлений. Уникальность по связке компании, пользователя, токена, идентификатора и типа устройства.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | арендатор, которому принадлежит токен; может быть пустым |
| Пользователь | связь | владелец устройства; обратная связь — список push-токенов пользователя |

**Устройство**

| Поле | Тип | Описание |
| --- | --- | --- |
| Токен | текст | Expo push-токен устройства |
| Идентификатор устройства | текст | необязательный идентификатор устройства |
| Тип устройства | перечисление | iOS / Android / Web; по умолчанию iOS |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Активен | флаг | деактивируется при недоставке (недействительный токен или незарегистрированное устройство) |
| Последнее использование | дата/время | обновляется автоматически при сохранении |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создан | дата/время | из базовой модели |
| Обновлён | дата/время | из базовой модели; по нему чистятся неактивные токены старше 30 дней |
