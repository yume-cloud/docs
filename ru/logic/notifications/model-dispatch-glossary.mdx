## Понятия

| Понятие | Значение |
| --- | --- |
| Веер доставки | Обработчик после сохранения: подбирает подходящих сотрудников и рассылает уведомление по каналам. Срабатывает только при создании; кэширует список сотрудников и фильтрует их по теме и включённому источнику. |
| Доставка в веб | Публикует уведомление веб-клиентам в реальном времени через канал реального времени. |
| Отзыв одноразового уведомления из веба | Сообщает веб-клиентам убрать одноразовое уведомление из списка после его захвата; у захватившего оно остаётся помеченным. |
| Доставка в мобильный push | Отправляет push-уведомление на мобильные устройства. |
| Доставка в Telegram | Формирует текст со ссылкой в зависимости от типа связанного объекта и рассылает его в Telegram-чаты сотрудников. |

## Модели и поля

### Уведомление

*Одно событие-уведомление компании, адресованное объекту системы и разосланное по каналам. Веер доставки запускается при создании записи.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания-владелец уведомления. |
| Автор/источник | связь | Пользователь, породивший уведомление; при удалении обнуляется. |

**Содержимое**

| Поле | Тип | Описание |
| --- | --- | --- |
| Текст | текст | Основное содержимое сообщения. |
| Тип | перечисление | Уровень важности (информация/предупреждение/тревога), по умолчанию информация. |
| Доп. данные | JSON | Произвольные полезные данные (например, для задачи). |

**Адресация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип объекта | текст | Строковый код связанной сущности (аренда, задача, документ и т.д.). |
| ID объекта | число | Идентификатор связанной сущности; используется для построения ссылок. |
| Целевые получатели | список (числа) | Явный список получателей; если задан, доставка сужается только до них. |

**Маршрутизация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тема | перечисление | Тема уведомления для фильтрации доступа, по умолчанию — тема по умолчанию. |
| Каналы доставки | список (перечисление) | Разрешённые каналы (Telegram/push/веб); по умолчанию все три. |

**Захват**

| Поле | Тип | Описание |
| --- | --- | --- |
| Одноразовый захват | флаг | Уведомление, которое «прочитывает» только один пользователь. |
| Кем захвачено | связь | Пользователь, забравший одноразовое уведомление; при удалении обнуляется. |
| Время захвата | дата/время | Момент, когда уведомление было захвачено. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создано | дата/время | Из базовой модели. |
| Обновлено | дата/время | Из базовой модели; ключевое для окна группировки. |

### Уведомление пользователя

*Персональное состояние уведомления для конкретного получателя (прочтение/архив). Уникально по сочетанию компании, пользователя и уведомления.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания-владелец записи. |
| Уведомление | связь | Родительское уведомление. |
| Получатель | связь | Пользователь, для которого хранится состояние; при удалении обнуляется. |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| В архиве | флаг | Признак того, что пользователь заархивировал уведомление. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создано | дата/время | Из базовой модели; трактуется как отметка прочтения. |
| Обновлено | дата/время | Из базовой модели. |
