## Модели и поля

### Telegram-пользователь

*Хранит привязку личного Telegram-чата пользователя к его аккаунту в конкретной компании, включая процесс подтверждения кодом.
Таблица общая для всех компаний.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Может быть пустой до момента привязки. |
| ID пользователя | число | Пользователь, привязанный к чату. |

**Telegram-данные**

| Поле | Тип | Описание |
| --- | --- | --- |
| ID чата Telegram | число | Уникальный идентификатор личного чата с ботом. |
| Имя пользователя в Telegram | текст | |
| Имя | текст | |
| Фамилия | текст | |

**Подтверждение**

| Поле | Тип | Описание |
| --- | --- | --- |
| Подтверждена | флаг | Привязка подтверждена вводом верного кода. |
| Код подтверждения | текст | Обнуляется после подтверждения. |

### Сериализатор привязки Telegram-бота

*По введённому коду находит неподтверждённую запись Telegram-пользователя и связывает её с текущим пользователем и компанией.
При успешной привязке отправляет сообщение в Telegram о том, что профиль привязан.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Имя пользователя в Telegram | текст | Только для чтения. |
| Код подтверждения | текст | Только для записи. |

### Сериализатор отвязки Telegram-бота

*Удаляет привязку Telegram-аккаунта текущего пользователя в текущей компании.*

Отдельных полей нет — сериализатор работает без входных данных.

### Отправка Telegram-уведомления

*Фоновая задача, отправляющая текстовое сообщение через Telegram Bot API в указанный чат или канал.
По умолчанию отправляет от имени основного бота компании в общий канал уведомлений.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Текст сообщения | текст | Поддерживает HTML-разметку Telegram. |
| Токен бота | текст | По умолчанию — основной бот Yume. |
| ID получателя | число | По умолчанию — общий канал компании. |
