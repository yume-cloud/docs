Справочник к странице [«Push-уведомления»](/ru/logic/notifications/push).

## Понятия

| Понятие | Значение |
| --- | --- |
| Сервис отправки push-уведомлений | Формирует и отправляет push-сообщения на один или несколько токенов и разбирает ответы на успешные и ошибочные. Ошибки вида «невалидный токен»/«устройство снято с регистрации» используются задачей отправки, чтобы деактивировать соответствующий токен. |

## Модели и поля

### Push-токен устройства

*Хранит push-токен конкретного устройства пользователя для отправки мобильных или web push-уведомлений в рамках
компании. При регистрации нового устройства старые активные токены с тем же токеном/устройством у других пользователей
автоматически деактивируются.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Может быть не заполнена. |
| ID пользователя | число | Владелец токена. |

**Устройство**

| Поле | Тип | Описание |
| --- | --- | --- |
| Push-токен | текст | Токен устройства, выданный сервисом push-уведомлений. |
| ID устройства | текст | Отличает одно физическое устройство от другого. |
| Тип устройства | список (enum) | Платформа устройства — iOS, Android или Web. |

**Статус**

| Поле | Тип | Описание |
| --- | --- | --- |
| Активен | флаг | Выключается вручную, при регистрации того же устройства другим пользователем, или автоматически при ошибке отправки. |
| Последнее использование | дата/время | Обновляется автоматически при каждом сохранении. |

**Даты**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | |
| Дата обновления | дата/время | |
