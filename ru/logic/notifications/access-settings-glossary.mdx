## Модели и поля

### Доступ к уведомлениям

*Матрица подписки сотрудника на тему по конкретному каналу — определяет, кому и куда доставлять. При веерной рассылке используется для отбора web-получателей по теме.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Ссылка на компанию. |
| Сотрудник | связь | Ссылка на сотрудника-получателя. |

**Ключ**

| Поле | Тип | Описание |
| --- | --- | --- |
| Канал | перечисление | Канал доставки; по умолчанию мобильный push. |
| Тема | перечисление | Тема события; по умолчанию «По умолчанию». |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Включено | флаг | Подписка активна; в рассылке учитываются только включённые доступы. |

### Список и обновление доступов

*адрес API: отдаёт матрицу доступов текущего сотрудника и лениво досоздаёт недостающие строки по умолчанию.*

Чтение возвращает список доступов; массовое обновление применяет переданные настройки. При неполной матрице все недостающие пары канал×тема досоздаются со значением «включено».

### Формат доступа (чтение)

*Отдаёт запись доступа без служебных полей компании и пользователя.*

Из ответа исключаются поля компании и сотрудника.

### Элемент массового обновления

*Одна строка входных данных массового обновления: канал, тема и флаг включения.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Канал | перечисление | Канал доставки. |
| Тема | перечисление | Тема события. |
| Включено | флаг | Новое значение флага. |

### Массовое обновление доступов

*Принимает список настроек и upsert-ит их: создаёт отсутствующие и обновляет флаг у существующих в одной транзакции.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Список доступов | список | Набор настроек канал×тема×флаг для upsert: недостающие пары создаются, существующие обновляются по значению флага. |
