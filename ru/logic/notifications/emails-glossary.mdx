Справочник к странице [«Транзакционные письма»](/ru/logic/notifications/emails).

## Понятия

| Понятие | Значение |
| --- | --- |
| Транзакционное письмо | Письмо на конкретный адрес в ответ на событие: регистрация, создание компании, счёт, оплата, окончание подписки, сброс пароля, приглашение. Не связано с системой уведомлений и её настройками. |
| Отправка по шаблону | Общая функция `send_template_email` (`common/emails.py`): отбрасывает пустые адреса, добавляет общий контекст, рендерит пару шаблонов и ставит задачу отправки. Возвращает «отправлено / не отправлено»; ошибки рендера и постановки пишет в журнал и не пробрасывает. |
| Задача отправки письма | Фоновая задача `send_email_message` (`tenant/tasks/send_email.py`), очередь «default»: текстовая часть и HTML-альтернатива, отправитель `DEFAULT_FROM_EMAIL`, заголовок `Auto-Submitted: auto-generated`. Ошибки SMTP не подавляются, автоповтора нет. Зарегистрирована в пакете задач модуля компаний. |
| Общий контекст письма | Значения, которые получает каждый шаблон: `app_url` — адрес веб-приложения, `logo_url` и `logo_url_dark` — логотипы для светлой и тёмной темы. |
| Каркас письма | Шаблоны `base.html` и `base.txt`: логотип, заголовок, вводный абзац, содержимое, примечание, подпись и строка о том, что ответы не читаются. |
| Фрагменты шаблонов | `_button.html` — кнопка действия, `_fallback.html` — ссылка текстом, `_rows.html` — таблица «параметр — значение», `_code.html` — блок одноразового кода. |
| Постановка после фиксации | Письмо, вызванное внутри транзакции, ставится в очередь только после её фиксации; при откате не уходит. Так отправляются приветствие при регистрации, «Компания создана», «Счёт на оплату» и «Оплата получена». |
| Владелец компании | Пользователь, записанный владельцем в карточке компании; получатель писем компании и счетов. Без владельца или без его адреса такие письма не уходят. |
| Срок окончания подписки | Вычисляется функцией `annotate_expiry` (`tenant/services/subscription.py`): более поздняя из двух дат — самой ранней даты окончания подключённых интеграций с тарифом и самой ранней даты окончания платных лимитов. Та же функция отбирает компании для автоматического удаления. |
| Напоминание об окончании подписки | Периодическая задача `remind_expiring_subscriptions`, ежедневно в 09:30, по всем компаниям: письмо владельцу ровно за 7 и за 1 день до срока окончания. |
| Маркер напоминания | Отметка в доп. данных компании, защищающая от повторного напоминания; ставится при постановке письма в очередь. |

## Письма

| Письмо | Шаблон | Тема | Кому | Данные шаблона |
| --- | --- | --- | --- | --- |
| Приветствие | `welcome` | «Добро пожаловать в Yume» | адрес нового аккаунта | имя, адрес |
| Компания создана | `company_created` | «Компания «‹название›» создана — Yume» | владелец компании | название, строки «Компания» и «Доступ до» |
| Счёт на оплату | `invoice_created` | «Счёт №‹номер› на оплату — Yume» | владелец компании | название, номер, сумма, строки счёта, ссылка на оплату |
| Оплата получена | `invoice_paid` | «Оплата счёта №‹номер› получена — Yume» | владелец компании | название, номер, строки счёта |
| Подписка заканчивается | `subscription_expiring` | «Подписка Yume заканчивается ‹ДД.ММ.ГГГГ›» | владелец компании | название, дата окончания, дней до неё, ссылка на раздел подписки |
| Код подтверждения почты | `register_otp` | «Код подтверждения Yume» | адрес из запроса | код, адрес |
| Код сброса пароля | `password_reset_otp` | «Сброс пароля Yume!» | адрес из запроса | код, адрес |
| Пароль изменён | `password_changed` | «Пароль изменён — Yume» | адрес аккаунта | адрес, момент смены |
| Приглашение в компанию | `staff_invite` | «Приглашение в компанию ‹название› — Yume» | адрес из приглашения | название, роль, ссылка, срок действия |

Строки счёта: «Счёт» (номер), «Сумма» (разряды через пробел, со знаком валюты) и «Подписка до» — окончание периода счёта, если оно задано.

## Служебные поля

| Поле | Где | Описание |
| --- | --- | --- |
| Маркер напоминания | доп. данные компании, ключ `subscription_reminder` | текст «‹дата окончания›:‹дней›», например `2026-10-01:7`; хранится только последний |
| Время отправки | приглашение сотрудника | проставляется, когда письмо с приглашением поставлено в очередь |
| Ссылка на оплату | счёт | её появление или смена у счёта в ожидании запускает письмо «Счёт на оплату» |
| Статус | счёт | переход в «Подтверждён» запускает письмо «Оплата получена» |

## Настройки

| Настройка | Значение |
| --- | --- |
| `DEFAULT_FROM_EMAIL` | Отправитель; из окружения, иначе `Yume <адрес почтового ящика>` или `Yume <noreply@yume.cloud>` |
| Почтовый сервер | SMTP `smtp.gmail.com`, порт 587, TLS; логин и пароль ящика — из окружения |
| `APP_BASE_URL` | Адрес веб-приложения для кнопок и ссылок; по умолчанию `https://account.<окружение>`, локально `http://localhost:3000` |
| Хост логотипов | API-хост платформы; картинки лежат по пути `/static/email/` |
| Расписание напоминания | Ежедневно в 09:30 |
