## Модели и поля

### Уведомление

*Единая запись о событии в компании, которая после сохранения запускает рассылку по каналам. При создании
уведомления система берёт сотрудников компании, при необходимости сужает список полем «Явные получатели», сверяет
получателей с их персональными настройками по теме и рассылает только по тем каналам, что указаны в поле «Каналы
рассылки» (веб, мобильный push и Telegram — если канал доступен и разрешён). Лента в API сортируется по дате
обновления, поэтому при повторном обновлении уже существующего уведомления оно поднимается в начало списка.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| ID | число | Первичный ключ; используется в ссылках и как идентификатор уведомления в пуш-пейлоаде. |
| Компания | связь | Компания, к которой относится уведомление. |

**Источник события**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип объекта-источника | текст | Строковый код модели-источника события; управляет текстом/ссылкой и служит ключом дедупликации. |
| ID объекта-источника | число | ID записи-источника события; вместе с типом объекта-источника образует пару для поиска/обновления. |

**Содержание**

| Поле | Тип | Описание |
| --- | --- | --- |
| Текст | текст | Текст уведомления, отображается в ленте и рассылается во все выбранные каналы. |
| Тип | список (enum NotificationType) | Влияет на визуальное оформление; передаётся только внутрь пуш-пейлоада. |
| Тема | список (enum NotificationTopic) | Категория события; сверяется с персональными настройками пользователя. |
| Каналы рассылки | список (enum NotificationSource) | Через какие каналы разрешено отправлять это уведомление; фактическая отправка дополнительно фильтруется правами доступа. |
| Явные получатели | список чисел | Если задан — сужает рассылку до этих людей; если пуст — адресуется всем сотрудникам с включённой темой. |
| Доп. данные | JSON | Произвольные данные события, используются для построения диплинка и передаются в пуш/веб-пейлоад. |

**Даты**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создано | дата/время | Момент создания. |
| Обновлено | дата/время | По этому полю фактически сортируется лента в API. |

### Отметка пользователя об уведомлении

*Персональная пометка «прочитано»/«в архиве» по конкретному уведомлению для конкретного пользователя. Отсутствие
записи означает, что уведомление не прочитано; запись без отметки «В архиве» означает, что уведомление прочитано, но
не заархивировано; запись с отметкой «В архиве» означает, что уведомление отправлено в архив.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | |
| Уведомление | связь | Ссылка на запись из общей ленты. |
| Пользователь | число | ID пользователя, которому принадлежит пометка. |
| В архиве | флаг | Включено — уведомление отправлено в архив. |
| Создано | дата/время | |
| Обновлено | дата/время | |
