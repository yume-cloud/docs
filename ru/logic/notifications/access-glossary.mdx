## Модели и поля

### Доступ к уведомлениям

*Персональная настройка пользователя: включена ли у него конкретная тема по конкретному каналу. Используется сигналом
fan-out при отборе получателей push/web/Telegram.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | — |
| Канал | список (см. «Канал уведомлений») | Канал, к которому относится настройка. |
| Пользователь | число | — |
| Тема | список (см. «Тема уведомления») | — |
| Включено | флаг | Если включено, пользователь получает уведомления по этой теме через этот канал. |

### Эндпоинт списка и сохранения доступа к уведомлениям

*API для чтения текущих предпочтений пользователя по уведомлениям и массового сохранения; при первом обращении
автоматически создаёт полный набор настроек «канал × тема».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Автодополнение матрицы доступа | логика | Недостающие комбинации канал/тема создаются со значением включено. |
| Выбор поведения по методу | логика | Чтение и массовое сохранение обрабатываются разными сериализаторами. |

### Сериализатор доступа к уведомлениям (чтение)

*Отдаёт клиенту одну запись предпочтения (канал, тема, включено).*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор записи | число | — |
| Канал уведомления | список | — |
| Тема уведомления | список | — |
| Включено | флаг | — |

### Элемент массового обновления доступа

*Описывает одну пару «канал/тема» и желаемое состояние включённости внутри запроса на массовое обновление.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Канал уведомления | список | — |
| Тема уведомления | список | — |
| Включено | флаг | Новое значение флага для этой пары. |

### Сериализатор массового обновления доступа к уведомлениям

*Атомарно сохраняет присланный пользователем набор предпочтений: создаёт отсутствующие записи и обновляет флаг
включено у существующих.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Список настроек | список | Массив пар канал/тема с флагом включено. |
