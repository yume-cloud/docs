## День графика платежей

*Одна запись на каждый день аренды: сколько по этому дню нужно заплатить и сколько уже оплачено фактически и по плану.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Клиент | связь | Клиент, к которому относится день графика (может быть не заполнен, если запись привязана к заявке). |
| Заявка на аренду | связь | Аренда, к которой относится этот день графика. |
| Штраф по заявке | связь | Если день графика создан под конкретный штраф с рассрочкой — ссылка на этот штраф. |
| Позиция аренды | связь | Необязательная привязка дня графика к конкретной арендуемой позиции. |
| Услуга по заявке | связь | Необязательная привязка дня графика к конкретной услуге. |
| Сумма к оплате за день | число (2 знака) | Плановая стоимость этого дня аренды с учётом скидок и штрафов; для выходного дня равна нулю. |
| Оплачено по плану за день | число (2 знака) | Часть внесённой предоплаты, распределённая на этот день при построении графика. |
| Покрыто фактическими операциями | число (2 знака) | Сколько из суммы дня закрыто реальными успешными денежными операциями после распределения поступлений по датам. |
| Фактические операции по дню | связь многие-ко-многим | Реальные денежные операции, сопоставленные этому дню графика, через промежуточную запись с суммой сопоставления. |
| Дата дня графика | дата и время | Календарный день аренды, за который начисляется плата. |
| Выходной (нерабочий) день | флаг | Признак дня без начисления платы; сумма к оплате обнуляется. |
| Ручная правка дня | флаг | Признак того, что рабочий/выходной статус дня задан вручную и не должен перезаписываться автоматическим расчётом. |

## Сопоставление операции с днём графика

*Промежуточная запись, связывающая конкретную фактическую денежную операцию с конкретным днём графика и указывающая, какая
сумма операции отнесена на этот день.*

| Поле | Тип | Описание |
| --- | --- | --- |
| День графика | связь | День графика, к которому отнесена операция. |
| Денежная операция | связь | Фактическая операция оплаты. |
| Отнесённая сумма | число (2 знака) | Часть суммы операции, засчитанная в этот день графика. |
