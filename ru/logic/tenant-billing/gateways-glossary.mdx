## Модели и поля

### Клиент FreedomPay

*Клиент платёжного шлюза FreedomPay: формирует подпись, инициирует платежи и рекуррентные списания по сохранённым картам, управляет картами и статусами платежей. Инициализируется как синглтон из настроек платёжных вариантов; обмен ведётся XML-ответами.*

**Настройки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Адрес шлюза | текст | базовый URL API FreedomPay |
| Идентификатор мерчанта | текст | ID магазина в FreedomPay |
| Секретный ключ мерчанта | текст | используется для создания MD5-подписи запросов |
| Секретный ключ выплат | текст | отдельный секрет для операций выплат |
| Тестовый режим | флаг | 1 включает тестовый режим, иначе не задан |
| Базовый URL сайта | текст | префикс, добавляемый к URL проверки и результата |

**Методы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Отправка запроса | метод | POST на шлюз с JSON, разбор XML-ответа в словарь |
| Создание подписи | метод | MD5-подпись из имени скрипта, отсортированных полей и секрета |
| Инициация платежа | метод | создаёт обычный платёж (оплата подписки) с чеком и шаблоном формы |
| Инициация платежа по сохранённой карте | метод | рекуррентное списание по токену карты |
| Подтверждение оплаты по карте | метод | вызов оплаты по идентификатору платежа |
| Прямое списание по карте | метод | вызов прямого списания по идентификатору платежа |
| Привязка карты | метод | добавление карты в хранилище (с откатом на упрощённый способ) |
| Список карт | метод | получение сохранённых карт пользователя |
| Удаление карты | метод | удаление карты из хранилища по токену |
| Статус платежа | метод | запрос статуса платежа |
| Отмена платежа | метод | отмена незавершённого платежа |
| Возврат платежа | метод | полный или частичный возврат средств |
| Списание заблокированной суммы | метод | клиринг ранее авторизованного платежа |
