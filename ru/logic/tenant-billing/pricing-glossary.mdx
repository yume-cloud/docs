## Понятия

| Понятие | Значение |
| --- | --- |
| Ядро расчёта | Единая функция расчёта цены корзины: используется оплатой из кабинета, автопродлением и страницей регистрации оплаты. Возвращает итог и оценённые позиции. |
| Корзина | Список желаемых изменений подписки: позиции интеграций/модулей (с тарифом) и лимитные позиции (с желаемым итоговым количеством). |
| Режим «по периодам» | Тарификация по длительности выбранного тарифа для интеграций и по циклу компании для лимитов; применяется, когда целевая дата не указана. |
| Цикл компании | Длительность тарифа основной подписки «аренда» (30 / 180 / 365 дней): задаёт для лимитов ценовой период, делитель пропорции и длину нового окна. Месяц — когда тарифа аренды прочитать негде. |
| Режим «продление до даты» | Тарификация пропорционально дням до указанной целевой даты для всех позиций корзины; включает автоподбор тарифного периода и защиту от подорожания. |
| Целевая дата | Дата, до которой продлеваются все позиции корзины. Её наличие переключает режим тарификации. |
| Периодный тариф | Тариф интеграции, дающий доступ на срок в днях; ограничен датой окончания и участвует в пропорциональном расчёте. |
| Количественный тариф | Тариф интеграции, дающий пакет единиц (например, SMS); без даты окончания, цена всегда фиксированная, целевой датой не затрагивается. |
| Бесплатный объём | Количество единиц ресурса, доступное компании без оплаты; единицы внутри него не тарифицируются и не требуют настроенной цены. |
| Оплачиваемый прирост | Разница между желаемым и уже оплаченным количеством выше бесплатного объёма — единственное, за что берётся доплата. |
| Пропорциональная доплата | Доплата за увеличение лимита в середине действующего срока: цена месяца, умноженная на долю оставшихся дней. Окно лимита при этом не сдвигается. |
| Автоподбор тарифного периода | Выбор прайса (месячный / полугодовой / годовой) по фактическому числу оплачиваемых дней, а не по изначально выбранному тарифу. Для лимитов подобранный период не короче цикла компании. |
| Защита от подорожания | Правило, по которому пропорциональная цена короткого срока не может превышать фиксированную цену более длинного пакета, покрывающего этот срок. |
| Округление до десятков | Приведение итоговой цены каждой позиции к десяткам тенге обычным арифметическим округлением. |
| Строка детализации | Готовая к отображению строка расчёта: название, количество, цена за период, длительность периода, оплачиваемые дни, сумма и дата окончания. |
| Бесплатная связанная интеграция | Интеграция, подключаемая автоматически в комплекте к оплаченной; показывается в детализации пометкой «бесплатно» и в сумму не входит. |
| Регистрация оплаты | Создание в админке уже подтверждённого счёта по оплате, пришедшей мимо шлюза (перевод, наличные), с отметкой «вручную». |
| Способ оплаты | Описание того, чем оплачен счёт: платёжная система и маскированная карта для оплаты через шлюз либо пометка ручной регистрации с комментарием. |

## Состав позиции после расчёта

*Каждая позиция корзины после расчёта получает набор полей, которые затем переносятся в позицию счёта.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Количество | число | Итоговое количество: желаемый лимит для лимитных позиций, единица для интеграций и модулей. |
| Цена | число (2 знака) | Стоимость позиции после округления до десятков. |
| Начало периода | дата/время | Начало оплаченного срока: конец действующего срока при пристыковке либо «сейчас». Записывается в позицию счёта; на подключение и лимит не переносится — им важна только дата окончания. |
| Конец периода | дата/время (может быть пустым) | Конец оплаченного срока; пусто для количественных тарифов, которые не истекают. |
| Оплачиваемых единиц | число | Количество единиц, за которые фактически взята плата (прирост либо все платные единицы в режиме продления). |
| Оплачиваемых дней | число | Число дней, за которые начислена плата. |
| Цена за период | число | Цена, взятая из прайса или тарифа, до пропорционального пересчёта. |
| Длительность периода | число (дни) | Длительность прайса или тарифа, применённого к позиции; ноль для количественных тарифов. |

## Строка детализации расчёта

*Отображаемая построчная расшифровка расчёта; одинакова для кабинета клиента и админки.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название лимита либо интеграции с указанием тарифа (дни или количество единиц). |
| Тип позиции | выбор | Тип оплачиваемой сущности из перечня типов позиций счёта. |
| Тарифный период | связь (может быть пустым) | Идентификатор тарифа интеграции; пусто для лимитных и бесплатных строк. |
| Количество | число | Итоговое количество по позиции. |
| Оплачиваемых единиц | число | Сколько единиц тарифицировано. |
| Оплачиваемых дней | число | За сколько дней начислена плата. |
| Цена за период | число | Цена прайса или тарифа. |
| Длительность периода | число (дни) | Длительность применённого периода; ноль — цена не зависит от времени. |
| Лимитная строка | признак | Отличает лимитную позицию от интеграции или модуля. |
| Бесплатно | признак | Строка показана справочно (связанная интеграция) и в сумму не входит. |
| Сумма | число (2 знака) | Стоимость строки. |
| Действует до | дата | Дата окончания результата по этой строке. |

## Данные оплаты, зарегистрированной вручную

*Сохраняются в данных платежа счёта вместо данных карты и отличают ручную оплату от оплаты через шлюз.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Признак ручной оплаты | признак | Помечает счёт как зарегистрированный вручную, а не оплаченный через шлюз. |
| Источник | текст | Откуда зарегистрирована оплата (админка). |
| Кто зарегистрировал | связь | Сотрудник, оформивший оплату. |
| Комментарий | текст | Пояснение оператора (например, номер платёжного поручения). |

## Данные оплаты через шлюз

*Заполняются из вебхука результата платежа и служат для показа способа оплаты.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Телефон плательщика | текст | Телефон, переданный шлюзом. |
| Номер карты | текст | Маскированный номер карты; для отображения приводится к последним четырём цифрам. |
| Срок действия | текст | Срок действия карты. |
| Держатель | текст | Имя держателя карты, введённое плательщиком. |
| Платёжная система | текст | Бренд карты; приводится к отображаемому названию по справочнику. |
| Способ оплаты | текст | Карта, Apple Pay, Google Pay, электронный кошелёк или баланс; приводится к русскому названию по справочнику. |
