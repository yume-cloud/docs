## Понятия

Сквозные процессы и вспомогательные обработчики вокруг компании-арендатора.

| Понятие | Значение |
| --- | --- |
| Менеджер компаний | Аннотирует каждую компанию вычисляемыми полями «Ссылка (домен)» (основной домен .yume.cloud либо account.yume.cloud) и «Код типа» и сортирует по дате окончания периода. |
| Провижининг компании | Транзакционно создаёт запись компании в публичной схеме, стартовый 7-дневный период, домен *.yume.cloud, членство владельца, лимиты и набор дефолтных справочников и настроек тенанта; автоматическое создание схемы отключено. |
| Генерация лимитов плана | Создаёт недостающие лимиты тенанта (персонал, пункты проката, инвентарь по типам ТС) и сбрасывает кэш лимитов; вызывается при создании компании и при нехватке лимитов. |
| Регистрация кастомного домена | Фоновая задача: проверяет DNS кастомного домена (сверка IP), вызывает внешний API регистрации и при успехе помечает домен верифицированным; при неудаче повторяет с задержкой — до 30 повторов с интервалом 15 минут. |
| Сериализатор аккаунта компании | Чтение и создание компании через API: валидирует поддомен (чёрный список и занятость), отдаёт вычисляемые ссылку-домен, код типа и лимиты, при создании запускает провижининг компании. |
| Проверка занятости поддомена | Проверяет, свободен ли запрошенный поддомен; занятые и зарезервированные (из чёрного списка) считаются существующими. |
| Заявка на демо | Принимает заявку на демо (телефон, ФИО, сфера) и отправляет уведомление в Telegram-канал администраторов. |
| Регистрация арендатора | Создаёт нового пользователя (телефон, почта, пароль с проверкой уникальности), уведомляет администратора, провижионит для него компанию и добавляет членство; используется в публичной схеме. |
| Вход арендатора | Устаревший вход арендатора, возвращающий токены без идентификатора тенанта; помечен на удаление после обновления iOS/Android. |

## Модели и поля

### Компания (тенант)

*Основная запись компании-арендатора: наследует механизм тенантов django-tenants и связывает её со схемой БД и владельцем.*

Автоматическое создание и удаление схемы отключены — схема не создаётся и не дропается автоматически; менеджер добавляет вычисляемые поля «Ссылка (домен)» и «Код типа».

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ компании. |
| Имя схемы БД | текст | Имя PostgreSQL-схемы тенанта; по умолчанию public, уникально среди непубличных. |
| Название | текст | Название компании. |
| Адрес | текст | Адрес компании. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Начало периода | дата/время | Начало текущего оплаченного/пробного периода. |
| Окончание периода | дата/время | Дата окончания подписки; для нового тенанта +7 дней. |

**Оформление**

| Поле | Тип | Описание |
| --- | --- | --- |
| Логотип | изображение | Логотип компании в S3. |
| Фон | изображение | Фоновое изображение в S3. |
| Фирменный цвет | текст (HEX) | Цвет бренда, по умолчанию #f25a29. |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Владелец | связь | Пользователь-владелец компании (в публичной схеме, удаление запрещено при наличии связей). |
| Тип компании | связь | Категория/сфера деятельности (тип компании). |

**Локализация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Страна | список | Страна из справочника стран, по умолчанию Казахстан. |
| Валюта | список | Валюта из справочника валют, по умолчанию тенге. |
| Часовой пояс | текст | Часовой пояс компании, по умолчанию UTC. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Доп. данные | JSON | Произвольные дополнительные данные. |
| Теги | связь (M2M) | Теги компании. |
| Дата создания | дата/время | Из базовой модели. |
| Дата обновления | дата/время | Из базовой модели. |

**Вычисляемые**

| Поле | Тип | Описание |
| --- | --- | --- |
| Ссылка (домен) | текст | Вычисляется менеджером: основной домен .yume.cloud либо account.yume.cloud; в самой модели значение отсутствует. |
| Код типа | текст | Вычисляется менеджером на основе типа компании. |

### Домен компании

*Домен, привязанный к компании (наследует механизм доменов django-tenants); хранит признак кастомного домена и статус его верификации.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Домен | текст | Полное доменное имя (из механизма доменов). |
| Компания | связь | Компания-владелец домена (из механизма доменов). |
| Основной домен | флаг | Признак основного домена (из механизма доменов). |
| Кастомный домен | флаг | Домен добавлен клиентом, требует внешней регистрации. |
| Верифицирован | флаг | Домен подтверждён (по умолчанию да). |
| Дата верификации | дата/время | Момент успешной проверки/регистрации. |

| Ссылка на карте | текст (URL) | Ссылка на карту/2GIS. |

**Оформление**

### Привязка периодической задачи к компании

*Связывает периодическую задачу (django-celery-beat) с компанией, делая задачу тенант-зависимой: прописывает идентификатор компании в заголовки задачи и, при необходимости, часовой пояс компании в расписание.*

Связь один-к-одному с периодической задачей; синхронизация выполняется при сохранении и через сигнал выравнивания.

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Компания | связь | Компания, к которой привязана задача. |
| Периодическая задача | связь (1:1) | Задача django-celery-beat. |
| Использовать часовой пояс компании | флаг | Если включено, расписание пересчитывается в часовой пояс компании, иначе используется UTC. |

## Статусы и справочники

### Тип компании

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Название | текст | Отображаемое название типа. |
| Код | текст | Машинный код типа. |
| Иконка | файл | Иконка типа компании. |
