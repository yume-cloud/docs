Справочник к странице [«Онбординг, новости и статистика»](/ru/logic/tenant-billing/onboarding-news-stats).

## Понятия

| Понятие | Значение |
| --- | --- |
| Задача архивации просроченных заявок | Фоновая задача: по всем компаниям помечает удалёнными забронированные заявки с приближающимся стартом аренды. Управляется настройками автоархивации и буфера; работает в RLS-контексте каждой компании. |
| Задача отправки email | Фоновая задача для отправки письма (текст и опциональный HTML) списку получателей. Ошибки не подавляются. |
| Список новостей (API) | Публичный список новостей, отсортированный от новых к старым, с подгруженными изображениями. |
| Детали новости (API) | Получение одной новости по идентификатору с подгруженными изображениями. |
| Сериализатор новости | Формирует ответ по новости: идентификатор, заголовок, содержимое, изображения, дата создания. Изображения только для чтения. |

## Модели и поля

### Шаг онбординга компании

*Отметка о пройденном шаге онбординга для компании. Уникальная пара «компания — шаг».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ. |
| Компания | связь | Компания. |
| Шаг | текст | Код пройденного шага онбординга. |
| Дата прохождения | дата/время | Когда шаг был отмечен. |

### Новость

*Системная новость/анонс с форматированным содержимым и вложенными изображениями. Наследует стандартную пару «дата создания / дата обновления».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Заголовок | текст | Заголовок новости. |
| Содержимое | форматированный текст | HTML-контент, редактируется через визуальный редактор. |
| Изображения | связь (список) | Прикреплённые изображения (обобщённая связь с изображениями-вложениями). |
| Дата создания | дата/время | Момент создания (индексируется). |
| Дата обновления | дата/время | Момент последнего изменения. |

### Снимок статистики компании

*Периодический снимок ключевых метрик и размера БД по одной компании. Каждая запись — срез показателей на момент даты снимка.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания, по которой собран снимок. |

**Пользователи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Число сотрудников | число | Количество сотрудников компании. |
| Число пользователей | число | Общее количество пользователей. |

**Тариф**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип тарифа | текст | Название/тип действующего тарифа. |
| Период тарифа | число | Длительность периода подписки (в месяцах). |
| Категория компании | текст | Категория/сфера деятельности компании. |

**Заявки**

| Всего заявок | число | Общее количество заявок на аренду. |
| Заявок в аренде | число | Количество заявок в статусе «в аренде». |
| Забронированных заявок | число | Количество заявок в статусе «забронирована». |
| Завершённых заявок | число | Количество завершённых заявок. |
| Отменённых заявок | число | Количество отменённых заявок. |
| Просроченных заявок | число | Количество просроченных заявок. |

**Продажи**

| Поле | Тип | Описание |

**Справочники**

| Поле | Тип | Описание |
| --- | --- | --- |

### Планировщик пени по заявке

*Запись для периодического начисления пени по конкретной заявке на аренду. Пара «компания — индекс — заявка» уникальна; идентификатор заявки — «сырой» ID из данных компании.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания, к которой относится начисление. |
| Индекс | число | Порядковый индекс правила пени в рамках заявки. |
| ID заявки | число | Идентификатор заявки на аренду (в данных компании). |
| Время начисления | дата/время | Момент, с которого начинается начисление пени. |
| Последний запуск | дата/время | Момент последнего срабатывания начисления. |
| Интервал | интервал | Период повтора начисления (по умолчанию 1 час). |
| Включено | флаг | Активно ли начисление пени. |
