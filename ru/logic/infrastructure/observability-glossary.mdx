## Модели и поля

### Middleware корреляции запросов

*Middleware, который присваивает каждому запросу идентификатор, кладёт его в contextvar и возвращает в заголовке ответа. Стоит одним из первых в цепочке middleware.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Ключ входящего заголовка | текст | Откуда берётся внешний идентификатор запроса. |
| Имя заголовка ответа | текст | Заголовок, который возвращается клиенту. |
| Идентификатор запроса | текст | Входящий идентификатор из заголовка либо сгенерированный uuid4. |

### Контекстная переменная идентификатора запроса

*ContextVar, хранящий идентификатор запроса в рамках одного запроса или задачи, с помощниками для чтения, установки и сброса значения.*

### Middleware аудита действий

*Расширение журнала аудита: фиксирует автора и IP-адрес для записей и хранит текущего пользователя в thread-local. Все модели в аудит не включаются по умолчанию.*

| Поле | Тип | Описание |
| --- | --- | --- |
| IP-адрес клиента | текст | Источник действия для журнала аудита. |
| Автор действия | связь | Текущий пользователь, привязывается к записям аудита. |
| Пользователь (thread-local) | связь | Хранится для доступа вне запроса. |

### Middleware мониторинга Prometheus

*Пара middleware, оборачивающих цепочку обработки для сбора метрик запросов. «Начало» стоит первым в цепочке, «конец» — последним; кэш и БД обёрнуты отдельно.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Метрики: начало запроса | связь | Первый компонент в цепочке middleware. |
| Метрики: конец запроса | связь | Последний компонент в цепочке middleware. |

### Конфигурация логирования

*Django-конфигурация логирования: JSON в stdout через console-хендлер с фильтром корреляции, плюс отдельный файловый SQL-лог. SQL-лог создаётся только в режиме отладки.*

**Общее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Уровень логирования | текст | Задаётся переменной окружения, по умолчанию INFO. |
| Каталог логов | текст (путь) | Папка логов, создаётся в режиме отладки. |

**Хендлеры**

| Поле | Тип | Описание |
| --- | --- | --- |
| Хендлер stdout | связь | JSON-формат и фильтр корреляции, пишет в стандартный вывод. |
| Фильтр корреляции | связь | Добавляет идентификатор запроса и схему тенанта. |
| Форматтер json | связь | JSON-форматтер с ограничениями размера. |

**Только в режиме отладки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Файловый SQL-хендлер | связь | Ротируемый файл 10 МБ × 3, только в режиме отладки. |
| Логгер SQL | связь | Пишет SQL в файловый хендлер, только в режиме отладки. |

### JSON-форматтер логов

*Форматтер, который рендерит каждую запись лога в одну JSON-строку с жёстким ограничением размера. Настраивается в конфигурации логирования; лимиты берутся из переменных окружения.*

**Настройки размера**

| Поле | Тип | Описание |
| --- | --- | --- |
| Максимальный размер записи | число (байты) | Предел на всю JSON-строку; при превышении запись урезается до ядра полей. |
| Максимальный размер поля | число (байты) | Предел на одно строковое поле, лишнее обрезается. |
| Размер записи по умолчанию | число (байты) | 32 КБ по умолчанию. |
| Размер поля по умолчанию | число (байты) | 8 КБ по умолчанию. |
| Маркер обрезки | текст | Приписывается к урезанному значению. |
| Ядро полей записи | список | Поля, сохраняемые при аварийном сжатии слишком большой записи. |
| Служебные поля записи лога | список | Стандартные атрибуты записи, которые не выносятся в дополнительные поля. |

**Выходная запись**

| Поле | Тип | Описание |
| --- | --- | --- |
| Отметка времени | текст (ISO, UTC) | Время события в формате с миллисекундами и суффиксом Z. |
| Уровень | текст | Уровень логирования (INFO, ERROR и т. д.). |
| Имя логгера | текст | Имя логгера, породившего запись. |
| Сообщение | текст | Текст записи, обрезается по лимиту поля. |
| Идентификатор запроса | текст | Берётся из записи, проставляется фильтром корреляции. |
| Схема тенанта | текст | Имя PostgreSQL-схемы компании на момент лога. |
| Трассировка исключения | текст | Форматированный traceback, если есть. |
| Стек вызовов | текст | Стек, если запрошен. |
| Флаг усечения | флаг | Проставляется, когда запись пришлось сжать до лимита. |
| Отброшенные поля | список | Имена дополнительных полей, выброшенных при сжатии. |

### Форматтер расширенных полей

*Вспомогательный форматтер, собирающий дополнительные поля записи в текст и умеющий форматировать время и исключения. Используется JSON-форматтером для форматирования времени; как самостоятельный хендлер не подключён.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Пропускаемые атрибуты | список | Стандартные поля записи лога, не попадающие в текст доп. полей. |
| Простые типы | список | Типы, которые пишутся как есть; остальные — через repr. |
| Текст доп. полей | текст | Собранная строка вида [ключ: значение]. |

### Фильтр корреляции логов

*Фильтр логирования, добавляющий в каждую запись идентификатор запроса и текущую схему тенанта. Подключён к console-хендлеру.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор запроса | текст | Читается из контекстной переменной идентификатора запроса. |
| Схема тенанта | текст | Берётся из текущего соединения, None при ошибке. |

### Декоратор захвата локальных переменных

*Декоратор, который при исключении сохраняет значения локальных переменных из строки, где произошла ошибка.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Захваченные локальные переменные | словарь | Прикрепляются к исключению для диагностики. |

### Интеграция Sentry

*Инициализация Sentry SDK с интеграциями Django и Celery; включается только при заданных адресе проекта и версии релиза. Фильтр перед отправкой и сэмплер трассировок задают фильтрацию и сэмплинг.*

**Инициализация**

| Поле | Тип | Описание |
| --- | --- | --- |
| DSN Sentry | текст | Адрес проекта Sentry; без него интеграция не включается. |
| Релиз | текст | Версия сборки; обязательна для включения. |
| Окружение | текст | Среда; по умолчанию выводится из релиза. |

**Сэмплинг**

| Поле | Тип | Описание |
| --- | --- | --- |
| Базовая доля трассировок | число (доля) | По умолчанию 0.05. |
| Сэмплер трассировок | связь (функция) | Отбрасывает шумные пути и задачи, иначе применяет базовую долю. |
| Шумные пути | список | Служебные пути (проверки здоровья, наличия, метрик, документации) не трассируются. |
| Шумные задачи Celery | список | Автоштрафы по заявкам исключены из трассировки. |

**Фильтрация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Фильтр перед отправкой | связь (функция) | Отбрасывает ошибки 404 и 403 и дубликаты, добавляет теги тенанта. |
