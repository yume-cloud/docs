## Понятия

| Понятие | Значение |
| --- | --- |
| Базовая модель с привязкой к компании | Абстрактная база для компанийных приложений: обязательная связь с компанией и стандартные вложения (фото, файлы, комментарии, ссылки). |
| Менеджер по умолчанию | Менеджер модели, полагающийся на RLS-политику таблицы: собственного фильтра по компании в коде не добавляет. |
| Конфигурация мультитенантности | Набор настроек проекта, задающих модель изоляции компаний через RLS. |
| Дефолт компании для поля «Компания» | Значение по умолчанию для связи с компанией: текущая компания из соединения (или её id в режиме миграций). |
| Получение id текущей компании | Хелпер, возвращающий id текущей компании из соединения либо ничего. |
| Установка компании при миграции | Миграционный хелпер: устанавливает переданную компанию в RLS-контекст соединения. |
| Middleware разрешения компании | Определяет компанию по заголовку или хосту и выставляет её как активную для соединения. |
| Middleware добора компании по JWT | Дорезолвит компанию из токена, если её не удалось определить по хосту или заголовку. |

## Модели и поля

### Базовая модель с привязкой к компании

*Абстрактная базовая модель для компанийных приложений: даёт обязательную связь с компанией и стандартные вложения (фото, файлы, комментарии, ссылки).*

Абстрактная модель; наследуется моделями crm, sales, workshop и fleet.

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Связь с компанией; по умолчанию подставляется через дефолт компании. |

**Вложения**

| Поле | Тип | Описание |
| --- | --- | --- |
| Изображения | обратная связь (generic) | Обобщённая связь с изображениями-вложениями. |
| Файлы | обратная связь (generic) | Обобщённая связь с файлами-вложениями. |
| Комментарии | обратная связь (generic) | Обобщённая связь с комментариями-вложениями. |
| Ссылки | обратная связь (generic) | Обобщённая связь со ссылками-вложениями. |

**Менеджеры**

| Поле | Тип | Описание |
| --- | --- | --- |
| Менеджер по умолчанию | менеджер | Полагается на RLS-политику таблицы, собственного фильтра по компании не добавляет. |
| Менеджер с обходом RLS | менеджер | Обычный менеджер без фильтрации по компании (для админки). |

### Менеджер по умолчанию

*Менеджер модели, который полагается на RLS-политику таблицы и не добавляет собственный фильтр по компании поверх неё.*

Фактическая изоляция обеспечивается RLS-политикой на самой таблице, а не кодом менеджера.

| Поле | Тип | Описание |
| --- | --- | --- |
| Формирование выборки | метод | Возвращает обычный queryset; ограничение по компании накладывает RLS-политика в базе, а не менеджер. |

### Конфигурация мультитенантности

*Набор настроек проекта, задающих модель изоляции компаний через RLS.*

Это не класс, а константы в настройках проекта.

**Приложения**

| Поле | Тип | Описание |
| --- | --- | --- |
| Общие приложения (без RLS) | список | Приложения, чьи таблицы не имеют RLS-политики (пользователи, компании, интеграции и др.). |
| Приложения компании (таблицы под RLS) | список | Приложения crm, shared, workshop, sales, fleet — таблицы имеют колонку компании и RLS-политику. |
| Итоговый список приложений | список | Общие приложения плюс непересекающиеся приложения компании. |

**Модели компании**

| Поле | Тип | Описание |
| --- | --- | --- |
| Модель компании | строка (ссылка на модель) | Указывает модель компании. |
| Модель домена компании | строка (ссылка на модель) | Указывает модель домена компании. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Ограничение переключений компании | флаг | Лимитирует число смен активной компании за запрос. |

### Дефолт компании для поля «Компания»

*Функция-значение по умолчанию для связи с компанией: возвращает текущую компанию из соединения (или её id в режиме миграций).*

В обычном режиме возвращает объект компании, в режиме миграций — id.

### Получение id текущей компании

*Хелпер, возвращающий id текущей компании из соединения либо ничего.*

### Установка компании при миграции

*Миграционный хелпер: устанавливает переданную компанию в RLS-контекст соединения и включает режим миграций.*

Используется в data-миграциях компанийных приложений.

### Middleware разрешения компании

*Определяет компанию по заголовку идентификатора компании или хосту и выставляет её как активную для соединения.*

Первый шаг резолвинга компании в цепочке middleware.

**Кэширование**

| Поле | Тип | Описание |
| --- | --- | --- |
| Время жизни кэша компании | число (секунды) | 24 часа для кэша по хосту и по идентификатору. |
| Маркер «нет в кэше» | объект-сигнал | Позволяет отличить закэшированное «компания не найдена» от отсутствия ключа. |

**Резолвинг**

| Поле | Тип | Описание |
| --- | --- | --- |
| Извлечение хоста | метод | Снимает служебные префиксы (www., api., manager., stage., dev.); localhost переписывает в основной домен. |
| Компания по идентификатору | метод | Поиск компании по заголовку идентификатора; результат кэшируется на 24 часа. |
| Компания по домену | метод | Служебные хосты не дают компании; иначе поиск домена, результат (в том числе «не найдено») кэшируется на 24 часа. |
| Обработка запроса | метод | Сначала сброс активной компании на соединении, затем при найденной компании — установка её как активной. |

**Middleware добора компании по JWT** — см. [канонический глоссарий](/ru/logic/user/tenant-middleware-glossary).
