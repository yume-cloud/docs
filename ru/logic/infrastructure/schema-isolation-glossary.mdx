| Понятие | Значение |
| --- | --- |

| Менеджер с фильтром по компании | Менеджер модели, на public-схеме автоматически дофильтровывающий выборку по текущей компании. |

## Модели и поля

### Базовая модель с привязкой к компании

*Абстрактная базовая модель для tenant-приложений: даёт обязательную связь с компанией и стандартные вложения (фото, файлы, комментарии, ссылки).*

Абстрактная модель; наследуется моделями crm, sales, workshop и fleet.

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Связь с компанией (public-схема); по умолчанию подставляется через дефолт компании. |

**Вложения**

| Поле | Тип | Описание |
| --- | --- | --- |
| Изображения | обратная связь (generic) | Обобщённая связь с изображениями-вложениями. |
| Файлы | обратная связь (generic) | Обобщённая связь с файлами-вложениями. |
| Комментарии | обратная связь (generic) | Обобщённая связь с комментариями-вложениями. |
| Ссылки | обратная связь (generic) | Обобщённая связь со ссылками-вложениями. |

**Менеджеры**

| Поле | Тип | Описание |
| --- | --- | --- |
| Менеджер по умолчанию | менеджер | Менеджер с авто-фильтром по компании на public-схеме. |
| Менеджер без фильтра | менеджер | Обычный менеджер без фильтрации по компании (для админки). |

### Менеджер с фильтром по компании

*Менеджер модели, который на public-схеме автоматически дофильтровывает выборку по текущей компании из соединения.*

На tenant-схеме фильтр отключён — есть пометка про 100% CPU и долгие запросы, менять нельзя.

| Поле | Тип | Описание |
| --- | --- | --- |
| Формирование выборки | метод | Если контекст компании есть и схема не public — возвращает выборку без фильтра; на public добавляет фильтр по компании; без контекста компании — обычная выборка. |

### Конфигурация мультитенантности

*Набор настроек проекта, задающих модель изоляции компаний через django-tenants.*

Это не класс, а константы в настройках проекта.

**Приложения**

| Поле | Тип | Описание |
| --- | --- | --- |
| Общие приложения (public-схема) | список | Приложения, чьи таблицы живут в общей схеме public (пользователи, компании, интеграции и др.). |
| Приложения компании (схема на компанию) | список | Приложения crm, shared, workshop, sales, fleet — таблицы создаются в схеме каждой компании. |
| Итоговый список приложений | список | Общие приложения плюс непересекающиеся приложения компании. |

**Маршрутизация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Роутер синхронизации схем | список | Направляет таблицы в нужную схему. |

**Модели тенанта**

| Поле | Тип | Описание |
| --- | --- | --- |
| Модель компании | строка (ссылка на модель) | Указывает модель компании. |
| Модель домена компании | строка (ссылка на модель) | Указывает модель домена компании. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Ограничение переключений схемы | флаг | Лимитирует число переключений схемы за запрос. |

### Дефолт компании для поля tenant

*Функция-значение по умолчанию для связи с компанией: возвращает текущую компанию из соединения (или её id в режиме миграций).*

В обычном режиме возвращает объект компании, в режиме миграций — id.

### Получение id текущей компании

*Хелпер, возвращающий id текущей компании из соединения либо ничего.*

### Установка компании при миграции

*Миграционный хелпер: по имени схемы находит компанию и проставляет её в соединение, включая режим миграций.*

Используется в data-миграциях tenant-приложений.

### Middleware разрешения компании

*Определяет компанию по заголовку идентификатора компании или хосту и переключает схему.*

Первый шаг резолвинга компании в цепочке middleware.

**Кэширование**

| Поле | Тип | Описание |
| --- | --- | --- |
| Время жизни кэша компании | число (секунды) | 24 часа для кэша по хосту и по идентификатору. |
| Маркер «нет в кэше» | объект-сигнал | Позволяет отличить закэшированное «компания не найдена» от отсутствия ключа. |

**Резолвинг**

| Поле | Тип | Описание |
| --- | --- | --- |
| Извлечение хоста | метод | Снимает служебные префиксы (www., api., manager., stage., dev.); localhost переписывает в основной домен. |
| Компания по идентификатору | метод | Поиск компании по заголовку идентификатора; результат кэшируется на 24 часа. |
| Компания по домену | метод | Служебные хосты не дают компании; иначе поиск домена, результат (в том числе «не найдено») кэшируется на 24 часа. |
| Обработка запроса | метод | Сначала сброс схемы на public, затем при найденной компании переключение схемы на неё. |

**Middleware добора компании по JWT** — см. [канонический глоссарий](/ru/logic/user/tenant-middleware-glossary).
