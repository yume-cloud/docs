## Модели и поля

### Таблица маршрутов (ROOT_URLCONF)

*Единый список URL-маршрутов проекта: монтирует каждое приложение под версионированным префиксом и подключает служебные вью, админку, метрики Prometheus и статику.*

Единственный корневой файл маршрутизации; используются версии `/v1/` и `/v2/`; в конце цикл достраивает Swagger-маршруты по каждой группе.

### Реестр групп Swagger

*Словарь, сопоставляющий ключ логической группы набору URL-паттернов; по нему в цикле генерируются OpenAPI-схема и Swagger UI каждой группы.*

Ключи совпадают с ключами реестра разделов; группа «Wallet» указывает на маршруты Kaspi.

**Генерируемые маршруты**

| Поле | Тип | Описание |
| --- | --- | --- |
| OpenAPI JSON группы | генерируемый маршрут | OpenAPI-схема группы в формате JSON. |
| Схема группы | генерируемый маршрут | OpenAPI-схема группы. |
| Swagger UI группы | генерируемый маршрут | Интерфейс Swagger UI группы. |

### Вью индекса документации

*Отдаёт JSON со списком разделов из метаданных разделов, добавляя к каждому абсолютный URL его OpenAPI-схемы.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Ключ раздела | текст | Ключ из реестра разделов. |
| Название | текст | — |
| Описание | текст | — |
| Иконка | текст | — |
| URL OpenAPI-схемы | текст (URL) | Абсолютная ссылка на схему раздела. |

### Вью проверки здоровья

*Возвращает JSON `{status: ok}` для проверки доступности сервиса.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Статус | текст | Всегда «ok». |

### Вью проверки существования компании

*По заголовку Origin или хосту определяет домен и сообщает, обслуживается ли такая компания.*

Нормализует хост: срезает `www.`, `manager.`, `stage.`, `dev.`, `api.`, `localhost` → `yume.cloud`; для `taxi.yume.cloud` возвращает «не существует».

| Поле | Тип | Описание |
| --- | --- | --- |
| Существует | флаг | Истина, кроме исключённых доменов. |

### Колбэк дашборда Unfold

*Наполняет контекст главной страницы админки Unfold: фильтр дат, KPI-карточки, графики и таблицы по счетам, интеграциям и компаниям.*

Период по умолчанию 30 дней; данные по счетам, интеграциям, компаниям и сотрудникам.

**Контекст**

| Поле | Тип | Описание |
| --- | --- | --- |
| Форма фильтра дат | форма | Форма фильтра дашборда. |
| KPI-карточки | список | Выручка, активные интеграции, компании, сотрудники. |
| График выручки по неделям | JSON | Подтверждённая выручка по неделям. |
| График счетов по статусам | JSON | Количество счетов по статусам оплаты. |
| Таблица последних счетов | таблица | Постранично. |
| Таблица топ-интеграций | таблица | По числу подключений, демо/платные. |
| Строка параметров пагинации | текст | Хранит выбранный диапазон дат. |

**Константы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Диапазон по умолчанию (дней) | число | = 30 |
| Счетов на страницу | число | = 10 |
| Интеграций на страницу | число | = 10 |
| Параметр страницы счетов | текст | Имя GET-параметра. |
| Параметр страницы интеграций | текст | Имя GET-параметра. |
