## Модели и поля

### Кастомный движок БД (rental_tenant_back.postgresql)

*Движок основной базы: класс, склеивающий обёртки мультитенантности и мониторинга поверх PostgreSQL. Наследует обе обёртки одновременно; тело пустое — вся логика в родителях. Порядок наследования важен, менять нельзя.*

**Родители**

| Поле | Тип | Описание |
| --- | --- | --- |
| Обёртка мониторинга | базовый класс | Снимает метрики запросов к базе для системы мониторинга. |
| Обёртка мультитенантности | базовый класс | Устанавливает RLS-контекст (активную компанию) на соединении. |

### Основная база данных (default)

*Главная PostgreSQL-база на кастомном движке; хранит общие таблицы и таблицы компаний в одной общей схеме, разграниченные RLS-политикой. Движок указывает на кастомную обёртку, а не на стандартный PostgreSQL; параметры подключения читаются из переменных окружения.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Движок | текст | Tenant-aware движок с метриками. |
| Имя базы | текст | Имя базы из переменной окружения. |
| Пользователь | текст | Пользователь базы из переменной окружения. |
| Пароль | текст | Пароль подключения из переменной окружения. |
| Хост | текст | Адрес сервера базы из переменной окружения. |
| Порт | текст | Порт подключения из переменной окружения. |

### База GPS-данных (geo)

*Отдельная обычная PostgreSQL-база для данных геолокации, без мультитенантности. Использует стандартный движок; кросс-базовые внешние ключи с основной базой запрещены. Порт зафиксирован.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Движок | текст | Стандартный движок PostgreSQL без tenant-логики. |
| Имя базы | текст | Имя базы GPS из переменной окружения. |
| Пользователь | текст | Пользователь базы GPS из переменной окружения. |
| Пароль | текст | Пароль подключения из переменной окружения. |
| Хост | текст | Адрес сервера базы GPS из переменной окружения. |
| Порт | число | Фиксированный порт 5432. |

### Роутер баз данных (TenantSyncRouter)

*Определяет, в какую базу уходит каждая операция — основную или GPS. Изоляцию данных компаний внутри основной базы обеспечивает RLS-политика на таблицах, а не роутер. Единственный роутер; действует правило «без кросс-базовых внешних ключей» между основной базой и базой GPS.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Роутер приложений | класс-роутер | Направляет общие приложения и приложения компаний в одну и ту же схему основной базы; разделение данных компаний между собой обеспечивает RLS-политика на их таблицах. |

### Срок жизни кэша (CACHE_TTL)

*Константа времени жизни кэша, используемая кодом при явном указании срока (15 минут). Не равна тайм-ауту самого кэша (15 секунд) — применяется точечно в местах кэширования.*

| Поле | Тип | Описание |
| --- | --- | --- |
| TTL кэша | число (сек) | 900 секунд (15 минут). |
