## Модели и поля

### Настройки подключения к S3

*Параметры доступа к S3-совместимому объектному хранилищу. Значения берутся из переменных окружения.*

**Доступ**

| Поле | Тип | Описание |
| --- | --- | --- |
| Адрес S3-эндпоинта | текст | URL S3-совместимого сервиса. |
| Ключ доступа | текст | |
| Секретный ключ | текст | |
| Имя бакета | текст | |
| Регион | текст | |
| Подпись в query-строке | флаг | Включена — ссылки на файлы содержат временную подпись доступа. |

### Конфигурация хранилищ

*Настройка бэкендов хранения Django: по умолчанию — S3, для статики — WhiteNoise.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Хранилище по умолчанию | настройка | Хранилище S3 для загружаемых медиафайлов. |
| Хранилище статики | настройка | WhiteNoise со сжатием и версионированием статики. |

### S3-хранилище компании

*Основной бэкенд хранения загружаемых файлов в S3-совместимом бакете media, изолирующий файлы каждой компании по префиксу идентификатора компании. Является хранилищем проекта по умолчанию; имя файла всегда префиксуется идентификатором компании.*

**Настройки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Имя бакета | текст | Фиксировано как «media». |
| Перезапись файлов | флаг | Включена — файл с тем же именем перезаписывается, не добавляется суффикс. |

**Логика**

| Поле | Тип | Описание |
| --- | --- | --- |
| Формирование имени файла | метод | Добавляет префикс идентификатора компании, нормализует слэши и блокирует выход за каталог (path traversal, «..»). |

### Общее публичное хранилище

*Бэкенд хранения файлов в общем бакете public без привязки к компании. Без префикса идентификатора компании — файлы общие для всех компаний; используется явно, не как хранилище по умолчанию.*

**Настройки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Имя бакета | текст | Фиксировано как «public». |
| Перезапись файлов | флаг | Включена. |

**Логика**

| Поле | Тип | Описание |
| --- | --- | --- |
| Формирование имени файла | метод | Нормализует слэши и блокирует path traversal, но без префикса компании. |

### Хелпер URL медиафайла

*Возвращает публичный URL файла по его ключу через хранилище по умолчанию. Возвращает пустое значение для пустого ключа.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Ключ файла | текст | Путь/ключ объекта в хранилище. |

### Пути статики и медиа

*Базовые URL и локальные пути для статических и медиафайлов, а также префикс WhiteNoise.*

**URL**

| Поле | Тип | Описание |
| --- | --- | --- |
| URL статики | текст | «/static/». |
| URL медиа | текст | «/media/». |
| Префикс WhiteNoise | текст | «/static/» — префикс раздачи статики через WhiteNoise. |

**Пути**

| Поле | Тип | Описание |
| --- | --- | --- |
| Каталог статики | путь | Куда собираются файлы статики. |
| Каталог медиа | путь | Локальный каталог медиафайлов. |
