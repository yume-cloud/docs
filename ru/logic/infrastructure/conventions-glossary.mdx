## Понятия

Сквозные вспомогательные сущности механизма прав доступа — модульные справочники, функции и модели-заглушки.

| Понятие | Значение |
| --- | --- |
| Справочник метод → право (модульный) | Модульный словарь сопоставления HTTP-методов и шаблонов прав; дублирует карту прав внутри класса проверки и используется вспомогательной функцией получения ключей прав. |
| Ключи права на создание | Вспомогательная функция: возвращает коды прав на добавление (POST) для указанной модели. |
| Модели с кастомными правами | Список моделей, для которых права берутся не из стандартной карты, а из объявленных в самой модели; содержит модель прав на метрики. |
| Модель прав на метрики | Неуправляемая модель-заглушка, существующая только ради набора кастомных прав доступа к разделам аналитики; своей таблицы не создаёт, права проверяются через проверку прав по модели. |
| Проверка наличия точек аренды (заглушка) | Класс прав, задуманный для допуска только пользователей с точками аренды, но сейчас всегда разрешающий доступ: реальная логика закомментирована. |

## Модели и поля

### Базовая модель (метки времени)

*Абстрактный базовый класс моделей, добавляющий стандартную пару временных меток создания и изменения записи. Своей таблицы не создаёт (abstract=True); наследуется большинством моделей проекта.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Проставляется автоматически при создании записи, проиндексировано. |
| Дата изменения | дата/время | Обновляется автоматически при каждом сохранении. |

### Проверка прав по модели (для ViewSet)

*Класс прав, сопоставляющий HTTP-метод запроса с правом на модель и проверяющий, что пользователь — сотрудник компании. Во всём проекте доступ по умолчанию открыт всем, поэтому каждый эндпоинт подключает этот класс явно, а во вью нужно задать список моделей.*

**Маппинг**

| Поле | Тип | Описание |
| --- | --- | --- |
| Карта метод → право | словарь | Сопоставление: просмотр для GET, добавление для POST, изменение для PUT/PATCH, удаление для DELETE; служебные методы (OPTIONS/HEAD) прав не требуют. |

**Логика**

| Поле | Тип | Описание |
| --- | --- | --- |
| Разрешить GET без права | метод | Если у вью включён признак свободного чтения, GET-запросы пропускаются без проверки права на просмотр. |
| Модели вью | метод | Берёт список моделей из атрибута вью; при его отсутствии — ошибка. |
| Требуемые права | метод | Вычисляет коды прав для метода и модели; для моделей с кастомными правами возвращает все кастомные права модели. |
| Проверка доступа | метод | Пропускает при отключённой проверке прав; требует аутентификации и статуса сотрудника компании; учитывает свободное чтение, иначе проверяет наличие всех прав по всем моделям вью. |
