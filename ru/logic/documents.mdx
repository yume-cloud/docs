Document V2 — сервис документооборота Yume, общий для всех компаний платформы: любая карточка договора, акта или счёта, привязанная к заявке на аренду, клиенту или другому бизнес-объекту компании, живёт здесь. Документ либо генерируется автоматически из шаблона компании с подстановкой данных заявки, клиента и инвентаря, либо загружается вручную готовым файлом; итоговый результат в обоих случаях приводится к PDF с QR-штампом и, при необходимости, отдельной страницей-подтверждением подписания.

Подписать документ может несколько сторон — компания и один или несколько клиентов — тремя способами: вручную сотрудником, по одноразовому SMS-коду или через мобильное приложение ЕГОВ либо загрузку файла с электронной цифровой подписью. Клиент подписывает по публичной ссылке, без входа в личный кабинет. Отдельно ведётся учёт лимита подписей: компания покупает пакеты подписей, привязанные к тарифу, и лимит расходуется по мере подписания документов.

## Как всё устроено

Три сущности связывают все разделы модуля между собой:

- **Шаблон документа** описывает, как выглядит документ и откуда берутся данные для подстановки.
- **Документ** — конкретная карточка, созданная из шаблона (или загруженная файлом), с привязкой к заявке на аренду.
- **Подписант** и **Подпись документа** описывают, кто и как подписывает уже созданный документ.
