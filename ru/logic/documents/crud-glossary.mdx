## Документ

*Основная сущность документооборота: одна карточка документа (договор, акт и т.п.), сгенерированного из шаблона или загруженного вручную. Связывается с произвольным бизнес-объектом (например, заявкой на аренду) через тип и идентификатор связанного объекта.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| UUID документа | текст | Публичный идентификатор, используется во внешних/подписных ссылках |
| Компания-арендодатель | связь | Компания, которой принадлежит документ |
| Порядковый номер | число | Сквозной номер в рамках компании и шаблона, выдаётся автосчётчиком |
| Название документа | текст | — |
| Ссылка на документ-основание | связь | На другой документ (например, прежнюю версию); в реальной логике не заполняется |

**Содержимое**

| Поле | Тип | Описание |
| --- | --- | --- |
| Источник | список | Сгенерирован / Загружен |
| Формат документа | список | HTML / PDF / DOCX / DOC |
| Содержимое | текст (HTML) | Только для сгенерированных документов; у загруженных — пусто, файл лежит в «Файле документа». В списке не отдаётся: поле принимается только на запись, читается в карточке документа |
| Шаблон | связь | Пусто для загруженных документов |
| Создатель | число | ID пользователя, без прямой связи |
| Доп. данные | JSON | Произвольные служебные данные |

**Связь с объектом и подписание**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип связанного объекта | текст | Копируется из шаблона |
| ID связанного объекта | число | Например, ID заявки на аренду |
| Подписан | флаг (вычисляемый) | Включается, когда все подписи документа получили статус «Подписан» и подписантов не меньше двух |
| Дата создания / Дата обновления | дата/время | — |

## Файл документа

*Физический файл, прикреплённый к документу: оригинал, служебный слой для подписи или итоговый подписанный файл. У одного документа не может быть двух файлов одного типа.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Документ | связь | Документ, которому принадлежит файл |
| Тип файла | список | См. «Тип файла документа» ниже |
| Файл | файл | Хранится в облачном хранилище |
| Доп. данные | JSON | Произвольные служебные данные |
| Дата создания / Дата обновления | дата/время | — |

## Связь документа

*Запись о том, что конкретный объект попал в текст документа при его сборке. Набор производный: пересчитывается при каждой генерации, адреса для ручной записи нет.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Документ | связь | Документ, которому принадлежит связь |
| Компания | связь | Владелец записи |
| Вид объекта | связь | Вид связанной записи (клиент, аренда, инвентарь и т. д.) |
| Идентификатор объекта | число | Номер конкретной записи |
| Роль | список | «Основная» (предмет документа — аренда) или «второстепенная» |
| Дата создания | дата/время | — |
| Подпись вида, ссылка | вычисляемые | Человекочитаемое название вида объекта и адрес записи в интерфейсе; берутся из общего реестра связей |

<Note>
Пара «документ + вид объекта + объект» уникальна, а основная связь у документа может быть только одна — оба правила обеспечены ограничениями базы данных.
</Note>

## Фильтр списка документов

*Набор параметров фильтрации в списке документов. Часть фильтров работает через существование связанной подписи или связи документа, а не через поля самого документа.*

ID документа, тип и ID связанного объекта, шаблон, формат документа, источник, создатель, дата создания (диапазон), «Подписан», статус подписи, «Активные» (есть хотя бы одна подпись, ложное значение — документы без подписей) — а также способ подписания, подписант (по первичному ключу), подписант по внешнему ID и тип подписанта, которые фильтруют документы через связанные подписи.

**Фильтр по связанным записям**

| Параметр | Описание |
| --- | --- |
| Вид связанного объекта | Одно имя вида; есть множественный вариант «любой из видов» |
| Идентификатор связанного объекта | Одно число; есть множественный вариант «любой из объектов» |
| Роль связи | «Основная» или «второстепенная» |

<Warning>
Параметры этой группы проверяются на одной строке связи, а не по отдельности. Незнакомое имя вида отбрасывается; если не осталось ни одного известного — ответ пустой. Имена параметров этой группы имеют собственный префикс, потому что короткие «тип объекта» и «идентификатор объекта» заняты собственными полями документа.
</Warning>

## Статусы и справочники

### Источник документа

*Каким образом появился документ; влияет на то, какие поля документа разрешено редактировать.*

- Сгенерирован
- Загружен

### Тип (формат) документа

*Формат содержимого документа.*

- HTML
- PDF
- DOCX
- DOC

### Тип файла документа

*Роль конкретного физического файла, прикреплённого к документу.*

- Оригинал — исходный файл (сгенерированный или загруженный)
- Слой для подписи — служебный слой с местами для подписи/печатей поверх оригинала
- Файл с ЭЦП — итоговый файл, подписанный через ЭЦП/ЕГОВ
- Подписанный файл — итоговый файл после ручного/визуального подписания
