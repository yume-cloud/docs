## Режим биллинга подписания

*Настройка компании, определяющая, за что компания платит при подписании документов. Назначается платформой; в настройках компании доступна только для чтения.*

| Значение | Описание |
| --- | --- |
| За SMS | Значение по умолчанию. Компания платит за сообщения подписания (ссылка и код) со своего SMS-баланса; пакеты подписей не расходуются и не ограничивают подписание |
| За документ | Компания платит фиксированную цену за подписываемый документ — один слот из пакета; сообщения подписания бесплатны, а при нулевом остатке слотов отправка ссылки и кода отклоняется |

Незаполненное или незнакомое значение трактуется как «За SMS». Режим определяется по настройкам компании, которой принадлежит документ.

## Пакет документов

*Пакет лимита подписей, привязанный к тарифу компании и, опционально, к счёту на оплату. Остаток и активность вычисляются как свойства и не хранятся в базе.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец пакета |
| Тариф | связь | Период тарифа, к которому привязан пакет; может быть пустым |
| Счёт | связь | Позиция счёта, по которой начислен пакет; может быть пустой |
| Документы | связь (М:М) | Через промежуточную сущность «Расход пакета документов» |

**Квота**

| Поле | Тип | Описание |
| --- | --- | --- |
| Всего подписей | число | Изначальный лимит, выданный в пакете |
| Использовано подписей | число | Сколько уже списано |
| Остаток подписей | число (вычисляемое) | «Всего» минус «Использовано», не меньше нуля |
| Активен | флаг (вычисляемое) | Остаток больше нуля |

## Расход пакета документов

*Связующая (промежуточная) запись, фиксирующая факт списания одного документа из конкретного пакета. Уникальна пара «пакет + документ», но проверка «уже списано» ведётся по документу, поэтому на один документ приходится ровно одна такая запись.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Пакет | связь | Пакет, из которого списан документ |
| Документ | связь | Документ, подпись по которому списана |

## Баланс документов

*Баланс (счётчик) документов компании за период. Не подключён ни к одному бизнес-процессу — см. предупреждение на странице логики.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец баланса |
| Сумма баланса | число | Величина, накопленная/доступная за период |
| Начало периода / Конец периода | дата | Границы периода |

## Разрешение на подписание по квоте документов

*Отдельное разрешение доступа, которое должно ограничивать подписание при исчерпании квоты пакетов. Проверка отключена — запрос всегда пропускается.*

Ошибку «Количество подписей исчерпано» возвращает не это разрешение, а проверка остатка внутри сценариев подписания (см. «Проверка остатка пакета подписей» в [глоссарии подписания](/ru/logic/documents/signing-glossary)) — и только в режиме «за документ».

<Info>
Компания видит пакеты и остаток через два тонких адреса API только для чтения: список пакетов (без пагинации, отсортирован от старого к новому) и суммарный остаток по всем активным пакетам. Их сериализация не добавляет новых полей сверх перечисленных выше — тариф в списке отображается сокращённо (сумма, срок, цена, валюта).
</Info>
