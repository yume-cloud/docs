## Подписант

*Сторона (клиент или компания), которая подписывает документ. Один подписант закрепляется за парой «компания + клиент» (или самой компанией) и переиспользуется на разных документах.*

| Поле | Тип | Описание |
| --- | --- | --- |
| ID | число | Первичный ключ |
| Компания-арендодатель | связь | Компания, в рамках которой существует подписант |
| Тип подписанта | список | См. «Тип подписанта» ниже |
| Имя/название | текст | ФИО клиента или название компании на момент подписания |
| Телефон | текст | Используется для отправки SMS-кода подписания |
| Email | текст | — |
| Внешний ID | число | ID связанной сущности вне модуля документов (например, клиента компании) |
| Доп. данные | JSON | Произвольные атрибуты подписанта |
| Дата создания / Дата обновления | дата/время | — |

## Подпись документа

*Запрос на подписание документа конкретным подписантом. На один документ не может быть двух подписей от одного подписанта. Документ считается подписанным, когда все его подписи получили статус «Подписан».*

| Поле | Тип | Описание |
| --- | --- | --- |
| ID | число | Первичный ключ |
| UUID подписи | текст (UUID) | Публичный идентификатор, используется в ссылке для подписания |
| Документ | связь | Документ, который подписывается |
| Подписант | связь | Сторона, которая должна подписать |
| Способ подписания | список | См. «Способ подписания» ниже |
| Разрешённые способы подписания | список | Информационное поле — не проверяется сервером |
| Статус | список | См. «Статус документа/подписи» ниже |
| Дата создания / Дата обновления | дата/время | — |

## Этап подписания

*Запись истории смены статуса подписи (журнал переходов для аудита, не редактируется напрямую).*

| Поле | Тип | Описание |
| --- | --- | --- |
| ID | число | Первичный ключ |
| Подпись | связь | Подпись, к которой относится этап |
| Статус до | список | Проставляется автоматически реальным предыдущим статусом |
| Статус после | список | Новый статус подписи |
| Доп. данные | JSON | Метаданные перехода — IP, ОС, браузер, устройство (см. ниже) |
| Дата создания | дата/время | — |

**Метаданные, сохраняемые в «Доп. данные»:** IP-адрес клиента, операционная система (детали и семейство), браузер (с версией и семейством), тип устройства (мобильное/планшет/десктоп) — определяются по данным запроса. Исключение — подтверждение через мобильное приложение ЕГОВ: там сохраняются только данные сертификата.

## Проверка лимита подписей

*Общая проверка для всех способов подписания, которая должна блокировать подписание при исчерпании лимита пакетов компании. Проверка временно отключена — метод всегда пропускает подписание; аналогично отключена проверка в «Разрешении на подписание по квоте документов».*

## Статусы и справочники

### Тип подписанта

*Определяет, кем является подписант.*

- Компания
- Клиент

### Способ подписания

*Каким способом подписант подтверждает документ.*

- Вручную
- По SMS-коду
- Через ЕГОВ/ЭЦП

### Статус документа/подписи

*Стадия жизненного цикла одной подписи. Хранится в подписи (не в самом документе); история переходов — в этапах подписания.*

- Черновик
- Готов к подписанию
- Просматривается
- На подтверждении
- Отклонён — определён в системе, но ни один способ подписания фактически в него не переводит
- Подписан
