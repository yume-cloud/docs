## Шаблон документа

*HTML-шаблон документа компании с плейсхолдерами для подстановки данных заявки, клиента и инвентаря, настройками формата страницы и фильтрами содержимого таблиц. Общая таблица, но каждая запись привязана к конкретной компании; из шаблона создаются документы.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ |
| Название шаблона | текст | Отображается в списке шаблонов компании |
| Дата создания / Дата обновления | дата/время | — |

**Содержимое и подстановка**

| Поле | Тип | Описание |
| --- | --- | --- |
| Содержимое шаблона | текст (HTML) | Разметка с плейсхолдерами; возвращается только в подробном ответе |
| Тип источника данных | текст | «Клиент» или «Заявка на аренду» — чьи данные подставляются; ограничение только на уровне API |
| Фильтр содержимого | JSON | Условия отбора инвентаря/услуг для таблиц документа |
| Точки проката | список чисел | Ограничивает применимость шаблона конкретными точками проката |

**Формат печатной страницы** — применяется при конвертации документа в PDF (см. [«Генерация документа и PDF»](/ru/logic/documents/generation))

| Поле | Тип | Описание |
| --- | --- | --- |
| Формат страницы | список | Стандартный размер (A4, Letter и т.д.) или «Другой размер» — см. «Формат страницы шаблона» ниже; только подпись, реальный размер берётся из ширины/высоты |
| Ширина / Высота страницы | число (мм) | По умолчанию 210×297 мм (A4) |
| Масштаб | число (%) | По умолчанию 100%; при конвертации в PDF делится на 100 |
| Отступы слева/справа | число (мм) | По умолчанию 7,62 мм |
| Отступы сверху/снизу | число (мм) | По умолчанию 25,4 мм |

**Служебные поля**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Проставляется автоматически, не принимается через API |
| Шаблон-первоисточник | связь (самоссылка) | Зарезервировано для группировки версий/копий; фактически не используется |
| Создан пользователем | число (ID) | Необязательно, без проверки; сервер не подставляет его автоматически |
| Статус | список | Признак обязательности документа, см. «Статус шаблона» ниже. На доступность самого шаблона не влияет |
| Порядок сортировки | число | Позиция в списке; при изменении номера шаблоны своей компании с таким же или большим значением сдвигаются на +1. Пустое значение допустимо — пересчёт просто пропускается |

## Статусы и справочники

### Статус шаблона

*Признак обязательности документа — нужно ли заполнять и подписывать его в аренде. Обязательные шаблоны попадают в блок «Документы» карточки аренды (быстрая генерация), необязательные из него убраны. На доступность шаблона статус не влияет: необязательный шаблон виден в списке, открывается, редактируется и может быть выбран при создании документа. Удаление шаблона статуса не касается — оно удаляет запись, обнуляя ссылку на шаблон у ранее созданных документов.*

- Обязательный
- Необязательно

### Формат страницы шаблона

*Набор стандартных форматов бумаги плюс произвольный размер. При «Другом размере» ширина и высота берутся из полей шаблона.*

- Letter (21,6 × 27,9 см)
- Tabloid (27,9 × 43,2 см)
- Legal (21,6 × 35,6 см)
- Statement (14,0 × 21,6 см)
- Executive (18,4 × 26,7 см)
- Folio (21,6 × 33,0 см)
- A3 (29,7 × 42,0 см)
- A4 (21,0 × 29,7 см)
- A5 (14,8 × 21,0 см)
- B4 (25,0 × 35,3 см)
- B5 (17,6 × 25,0 см)
- Другой размер
