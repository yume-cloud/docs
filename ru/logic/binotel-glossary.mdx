## Понятия

| Понятие | Значение |
| --- | --- |
| Подключение Binotel | Состояние интеграции у компании: ключ вебхука, курсоры синхронизации, ход импорта истории, кэш сотрудников. Одно на компанию. |
| Звонок Binotel | Один звонок компании; уникален по паре «компания + идентификатор звонка в Binotel». |
| Идентификатор звонка | Сквозной идентификатор звонка в Binotel; по нему звонок узнаётся при повторном получении из любого источника. |
| Источник звонка | Откуда звонок попал в систему: периодическая синхронизация, импорт истории или вебхук. |
| Курсор синхронизации | Момент самого свежего известного звонка; следующая синхронизация начинается с него минус нахлёст. |
| Импорт истории | Одноразовая загрузка звонков за глубину истории порциями по окну; одна фоновая задача на окно. |
| Отвеченный звонок | Разговор состоялся: статусы «Отвечен», «Переведён», «Голосовое сообщение». |
| Пропущенный звонок | Входящий, не отвеченный, не SMS/факс и не «в разговоре». |
| Сопоставление с клиентом | Подстановка клиента компании к звонку при чтении — по номеру целиком или по последним девяти цифрам. |

## Модели и поля

### Подключение Binotel

*Состояние интеграции у одной компании. Создаётся при первом обращении (подключение, синхронизация, статус) и живёт отдельно от записи подключения интеграции.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь (один к одному) | Компания, которой принадлежит подключение. |
| Ключ вебхука | текст (уникальный) | Случайная строка в адресе вебхука; перевыпускается действием в админке. |
| Курсор синхронизации | дата/время | Момент самого свежего известного звонка. |
| Последняя удачная синхронизация | дата/время | Когда синхронизация последний раз завершилась без ошибки. |
| Последняя ошибка синхронизации | текст | Текст последней ошибки; очищается удачной синхронизацией. |
| Ключ отклонён | дата/время | Когда Binotel отверг ключ или секрет; сбрасывается удачной синхронизацией, а синхронизация не запускается, пока подключение не отредактировано позже этого момента. |
| Последний вебхук | дата/время | Когда последний раз пришёл звонок по вебхуку. |
| Статус импорта истории | перечисление | Ожидает / идёт / завершён / сбой. |
| Начало импорта, прогресс импорта, окончание импорта | дата/время | Начало окна импорта, до какого момента история уже загружена, когда импорт завершён. |
| Сотрудники | JSON | Кэш списка сотрудников Binotel по адресу почты: идентификатор, имя, отдел, внутренний номер. |
| Сотрудники обновлены | дата/время | Момент обновления кэша. |

### Звонок Binotel

*Один звонок компании. Все поля, кроме компании, источника и служебных отметок, приходят из данных звонка Binotel.*

**Идентификация и время**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания-владелец звонка. |
| Идентификатор звонка | текст (до 32) | Идентификатор звонка в Binotel; уникален внутри компании. |
| Идентификатор компании в Binotel | текст | Как компания названа у Binotel. |
| Начало | дата/время | Момент начала звонка (из отметки времени Binotel). |
| Направление | перечисление | Входящий (0) или исходящий (1). |

**Номера**

| Поле | Тип | Описание |
| --- | --- | --- |
| Внутренний номер | текст | Внутренний номер сотрудника. |
| Номер группы | текст | Дополнительные данные внутреннего номера (группа). |
| Номер клиента | текст | Внешний номер как пришёл. |
| Цифры номера | текст | Только цифры внешнего номера — ключ точного сопоставления и поиска. |
| Суффикс номера | текст (9) | Последние девять цифр — ключ сопоставления при разных кодах страны; пусто, если цифр меньше девяти. |
| Номер АТС, название номера АТС | текст | Номер АТС, на который пришёл звонок, и его название. |

**Ход звонка**

| Поле | Тип | Описание |
| --- | --- | --- |
| Ожидание | число (сек) | Сколько звонок ждал ответа. |
| Разговор | число (сек) | Длительность разговора. |
| Статус | перечисление | Код состояния Binotel (см. «Статусы звонка»). |
| Первый звонок | флаг (может быть пустым) | Признак Binotel «первый звонок с этого номера». |
| Есть запись | флаг | Выводится из статуса: «Отвечен», «Голосовое сообщение», «Факс принят». |

**Клиент и сотрудник по данным Binotel**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор клиента, имя клиента | текст | Клиент в базе Binotel (не клиент Yume). |
| Имя сотрудника, почта сотрудника | текст | Сотрудник, обработавший звонок; почта — ключ фильтра и отчёта по сотрудникам. |

**Служебное**

| Поле | Тип | Описание |
| --- | --- | --- |
| Источник | перечисление | Периодическая синхронизация / импорт истории / вебхук. |
| Исходные данные | JSON | Ответ Binotel по звонку целиком. |

Индексы: по компании и времени, по компании и направлению, по компании и почте сотрудника, по компании и суффиксу номера, по компании и статусу.

## Адреса API компании

Все адреса, кроме вебхука, требуют авторизации и активного подключения интеграции Binotel.

| Адрес | Метод | Что делает |
| --- | --- | --- |
| Список звонков | чтение | Постраничная история за период с фильтрами; к каждому звонку подставляется клиент Yume. |
| Сводка звонков | чтение | Всего, входящие, исходящие, отвечено, пропущено, среднее ожидание, средний и суммарный разговор, уникальных номеров. |
| Звонки по дням | чтение | На каждый день периода: входящие, исходящие, отвечено, пропущено; дни без звонков — нули. |
| Звонки по сотрудникам | чтение | По почте сотрудника: всего, отвечено, пропущено, средний и суммарный разговор; сортировка по числу звонков. |
| Сотрудники | чтение | Варианты для фильтра: кэш Binotel плюс сотрудники из сохранённых звонков; сортировка по имени. |
| Статус | чтение | Адрес вебхука, курсоры, последняя ошибка, последний вебхук, ход импорта, число сохранённых звонков. |
| Синхронизировать | запись | Ставит синхронизацию компании в очередь; повтор раньше окна — отказ с указанием ожидания. |
| Ссылка на запись | запись | По идентификатору звонка возвращает ссылку на запись и срок её жизни (900 секунд). |
| Позвонить | запись | Соединяет внутренний номер сотрудника с внешним номером клиента. |
| Вебхук | запись, без авторизации | Принимает завершённый звонок по ключу компании в адресе; отправитель проверяется по адресам Binotel. |

**Параметры периода и фильтры списка**

| Параметр | Описание |
| --- | --- |
| Начало, конец периода | Границы по времени начала звонка; приводятся к часовому поясу компании. Без начала — первое число текущего месяца, без конца — месяц от начала. |
| Направление | Входящие или исходящие. |
| Статусы | Один или несколько кодов статуса. |
| Сотрудник | Почта сотрудника. |
| Пропущенные | Только пропущенные / только не пропущенные. |
| Номер | Цифры номера: девять и больше — по суффиксу, меньше — по окончанию номера. |
| Поиск | Цифры — по номеру; текст — по имени сотрудника, имени клиента Binotel и клиентам Yume с таким именем (первые 200). |
| Сортировка | По времени, ожиданию или разговору; пустые значения в конце. |

**Ответы на запуск и записи**

| Ответ | Когда |
| --- | --- |
| Синхронизация запущена | Окно ручной синхронизации свободно. |
| Слишком часто | С прошлого ручного запуска не прошло окно (60 секунд). |
| Записи нет | У звонка нет записи по статусу, либо Binotel не нашёл запись. |
| Binotel отклонил запрос | Неверный ключ или отключённая компания. |
| API Binotel недоступен | Нет связи с Binotel. |
| Интеграция не настроена | Нет активного подключения или ключей. |

## Статусы и справочники

### Статусы звонка

| Код Binotel | Подпись в интерфейсе | Группа |
| --- | --- | --- |
| ANSWER | Отвечен | отвеченный, есть запись |
| TRANSFER | Переведён | отвеченный |
| VM-SUCCESS | Голосовое сообщение | отвеченный, есть запись |
| ONLINE | В разговоре | в процессе |
| BUSY | Занято | пропущенный (для входящего) |
| NOANSWER | Нет ответа | пропущенный (для входящего) |
| CANCEL | Отменён | пропущенный (для входящего) |
| CONGESTION | Сбой сети | пропущенный (для входящего) |
| CHANUNAVAIL | Канал недоступен | пропущенный (для входящего) |
| VM | Голосовая почта | пропущенный (для входящего) |
| SMS-SENDING, SMS-SUCCESS, SMS-FAILED | SMS отправляется / доставлено / не доставлено | не разговор |
| SUCCESS | Факс принят | не разговор, есть запись |
| FAILED | Факс не принят | не разговор |

### Источник звонка

- Периодическая синхронизация
- Импорт истории
- Вебхук

### Статус импорта истории

- Ожидает
- Идёт
- Завершён
- Сбой

### Коды ошибок Binotel, которые система различает

| Код | Значение | Реакция |
| --- | --- | --- |
| 106 | Слишком частые запросы | Пауза и один повтор; задача повторяется через 15 секунд |
| 120 | Компания отключена | Плашка «отключено», синхронизация прекращается |
| 121 | Неверные ключ или секрет | Плашка «ключ отклонён», синхронизация прекращается до редактирования подключения |

### Периодические задачи

| Задача | Периодичность | Что делает |
| --- | --- | --- |
| Синхронизация звонков | Каждые 5 минут | Одна задача на каждую подключённую компанию |
| Обновление сотрудников | Ежедневно 04:20 | Обновляет кэш сотрудников у всех подключённых компаний |

Команда управления позволяет запустить синхронизацию, импорт истории (с указанием глубины) или обновление сотрудников по одной компании вручную.

## Настройки окружения

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| Адрес API Binotel | База адресов REST API | версия 4.0 API Binotel |
| Внешний адрес для вебхука | Из него собирается адрес вебхука компании | адрес API Yume |
| Разрешённые адреса вебхука | Список через запятую: адрес, сеть или диапазон «от-до»; пусто — проверка отключена | три диапазона серверов Binotel |
| Нахлёст синхронизации, минуты | На сколько назад от курсора запрашивать | 15 |
| Глубина истории, дни | Сколько дней импортировать при подключении | 90 |
| Порция истории, дни | Длина одного окна импорта | 7 |
| Пауза между тяжёлыми запросами, секунды | Между порциями импорта | 13 |
| Пауза при ограничении частоты, секунды | Перед единственным повтором запроса | 10 |
| Окно ручной синхронизации, секунды | Как часто можно нажимать «Обновить» | 60 |
