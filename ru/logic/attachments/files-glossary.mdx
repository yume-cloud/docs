## Прикреплённый файл

*Произвольный файл (документ), прикреплённый к любому объекту системы и хранящийся в облачном хранилище. Привязка к объекту, к которому относится вложение.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ записи |
| Арендатор | связь | Компания-владелец файла |
| Тип объекта | связь | Тип родительского объекта, к которому прикреплён файл |
| Идентификатор объекта | число | Идентификатор родительского объекта |
| Родительский объект | связь | Сам объект, к которому прикреплён файл (вычисляется из типа и идентификатора) |

**Файл**

| Поле | Тип | Описание |
| --- | --- | --- |
| Файл | файл | Сам документ, хранится в облачном хранилище под случайным именем с сохранением расширения; в ответе приходит адрес, при открытии которого файл отображается в окне браузера и сохраняется под исходным названием |
| Название | текст | Исходное имя файла; при загрузке файла заполняется автоматически (при массовой загрузке — общим названием, если оно передано) |
| Тип | текст | Произвольная метка/категория файла |
| Расширение | текст | Расширение файла из его имени в нижнем регистре, с ведущей точкой («.pdf»), определяется автоматически; при прямой загрузке — без точки; по умолчанию pdf |
| Хэш | текст | SHA-256 содержимого файла; только для чтения |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент загрузки файла |
| Кем создан | связь (пользователь) | Пользователь, загрузивший файл; при удалении пользователя обнуляется |
