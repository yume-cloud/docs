## Прикреплённый файл

*Произвольный файл (документ), прикреплённый к любому объекту системы и хранящийся в облачном хранилище. Привязка к объекту, к которому относится вложение.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ записи |
| Арендатор | связь | Компания-владелец файла |
| Тип объекта | связь | Тип родительского объекта, к которому прикреплён файл |
| Идентификатор объекта | число | Идентификатор родительского объекта |
| Родительский объект | связь | Сам объект, к которому прикреплён файл (вычисляется из типа и идентификатора) |

**Файл**

| Поле | Тип | Описание |
| --- | --- | --- |
| Файл | файл | Сам документ, хранится в облачном хранилище |
| Название | текст | Необязательное имя файла |
| Тип | текст | Произвольная метка/категория файла |
| Расширение | текст | Расширение файла, определяется автоматически; по умолчанию pdf |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент загрузки файла |
| Кем создан | число | Идентификатор пользователя, загрузившего файл |
