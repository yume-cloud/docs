Справочник к странице [логики комментариев](/ru/logic/attachments/comments).

## Комментарий

*Текстовый комментарий с автором и произвольным контекстом, прикрепляемый к любому объекту системы через привязку к объекту. Привязан к компании; родительский объект задаётся парой «тип объекта + идентификатор». Удаление разрешено только автору или суперпользователю компании.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ комментария |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания-владелец комментария; при удалении компании комментарии удаляются |

**Содержимое**

| Поле | Тип | Описание |
| --- | --- | --- |
| Текст комментария | текст | Содержимое комментария, обязательное поле |
| Автор | связь (пользователь) | Пользователь-автор; заполняется автоматически из текущего пользователя, только для чтения, в API отдаётся идентификатором. При удалении пользователя обнуляется, комментарий остаётся |
| Контекст | произвольные данные | Дополнительные данные в свободной структуре, привязанные к комментарию |

**Родительский объект**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип объекта | связь | Тип родительского объекта, к которому прикреплён комментарий (в API — по имени модели) |
| Идентификатор объекта | число | Идентификатор конкретного родительского объекта |
| Родительский объект | привязка к объекту | Сам объект, к которому прикреплён комментарий; вычисляется по паре «тип объекта + идентификатор», в базе не хранится |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент создания комментария |
| Дата изменения | дата/время | Момент последнего изменения комментария |

## Связь комментария

*Запись, которой комментарий ссылается на объект системы. Роли у связи нет: сам комментарий уже прикреплён к своему объекту, а связи называют то, о чём в нём говорится.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Комментарий | связь | Комментарий, которому принадлежит связь |
| Компания | связь | Владелец записи |
| Вид объекта | связь | Вид упомянутой записи |
| Идентификатор объекта | число | Номер конкретной записи |
| Дата создания | дата/время | — |
| Подпись вида, название, ссылка | вычисляемые | Название вида объекта (с учётом переименований в компании), человекочитаемое представление самой записи и адрес её страницы; вычисляются на чтении, а не хранятся |

<Note>
Пара «комментарий + вид объекта + объект» уникальна — повторное упоминание того же объекта в одном комментарии невозможно ни через запрос, ни на уровне базы данных. Порядок связей — тот, в котором их назвал автор.
</Note>

**Что принимается на запись**

| Поле | Тип | Описание |
| --- | --- | --- |
| Вид объекта | текст | Имя вида из общего реестра связей; незнакомое отклоняется |
| Идентификатор объекта | число | Объект обязан существовать внутри текущей компании |

<Info>
Список упоминаний передаётся целиком и заменяет прежний, но применяется разницей: неизменившиеся связи сохраняют свои идентификаторы. Если поле не передано при изменении комментария, прежние связи остаются нетронутыми.
</Info>

**Виды объектов, доступные для упоминания**

Клиент, аренда, лид, инвентарь, продукт, комплект, услуга, пункт проката, задача мастерской, техобслуживание, доставка, документ.
