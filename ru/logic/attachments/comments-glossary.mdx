## Комментарий

*Текстовый комментарий с автором и произвольным контекстом, прикрепляемый к любому объекту системы через полиморфную связь. Привязан к арендатору; родительский объект задаётся парой «тип объекта + идентификатор». Удаление разрешено только автору или суперпользователю арендатора.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ комментария |

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Арендатор | связь | Компания-владелец комментария; при удалении арендатора комментарии удаляются |

**Содержимое**

| Поле | Тип | Описание |
| --- | --- | --- |
| Текст комментария | текст | Содержимое комментария, обязательное поле |
| Автор | число | Идентификатор пользователя-автора; заполняется автоматически из текущего пользователя, только для чтения |
| Контекст | произвольные данные | Дополнительные данные в свободной структуре, привязанные к комментарию |

**Родительский объект**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип объекта | связь | Тип родительского объекта, к которому прикреплён комментарий (в API — по имени модели) |
| Идентификатор объекта | число | Идентификатор конкретного родительского объекта |
| Родительский объект | полиморфная связь | Сам объект, к которому прикреплён комментарий; вычисляется по паре «тип объекта + идентификатор», в базе не хранится |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Дата создания | дата/время | Момент создания комментария |
| Дата изменения | дата/время | Момент последнего изменения комментария |
