Механизм «Ссылка-вложение» позволяет прикрепить внешний веб-адрес к любому объекту — например, к заказу, клиенту или
единице оборудования. Привязка устроена так же полиморфно, как у прочих [вложений](/ru/logic/attachments).

Полный перечень полей — в [глоссарии ссылок](/ru/logic/attachments/links-glossary).

## Логика

**Поля записи:**

| Поле | Тип | Назначение |
| --- | --- | --- |
| Название | текст | Необязательная подпись ссылки |
| Веб-адрес | ссылка | Обязательный внешний адрес |
| Тип объекта | связь | Вид родительского объекта (в API — по имени вида объекта) |
| Идентификатор объекта | число | Номер конкретного родительского объекта |
| Дата создания | дата/время | Заполняется автоматически в момент создания |
| Кем создано | число | Идентификатор пользователя, добавившего ссылку |

При создании клиент передаёт обязательный веб-адрес, вид родительского объекта и его идентификатор; название можно не
указывать. Компания, автор («Кем создано») и дата создания проставляются автоматически. Поля с собственным
идентификатором записи, датой создания и автором доступны только для чтения; идентификатор родительского объекта клиент
указывает сам.

<Warning>
Поле «Компания» заполняется автоматически из контекста запроса при создании — клиент не может задать его вручную и не
может создать ссылку от имени другой компании.
</Warning>

Список ссылок возвращается без постраничной разбивки (в пределах компании и применённых фильтров), от новых к старым.
Доступна фильтрация по автору, по идентификатору объекта и по типу объекта (по имени вида объекта, можно несколько).

<Tip>
Чтобы получить все ссылки конкретного объекта, комбинируйте фильтр по виду объекта и фильтр по идентификатору объекта —
вместе они однозначно указывают на нужную запись-родителя.
</Tip>

При удалении компании все её ссылки удаляются автоматически; ссылка также удаляется при удалении соответствующего типа
объекта. При этом удаление самого родительского объекта не обязательно удаляет прикреплённую к нему ссылку — связь с
объектом вычисляемая, поэтому осиротевшие ссылки просто перестают указывать на существующий объект.

## Подводные камни

<Warning>
**Ссылки не защищены проверкой авторства.** Любой пользователь компании может изменить или удалить чужую ссылку —
ограничение действует только на уровне принадлежности компании. Более того, на операциях со ссылками не заданы отдельные
правила доступа, поэтому доступ регулируется лишь общей политикой проекта и фильтрацией по компании; отдельного требования
авторизации на модуль ссылок нет (в отличие от комментариев, где требуется авторизованный пользователь).
</Warning>

<Warning>
**Поле «Кем создано» хранится как обычное числовое поле**, а не как связь с пользователем, поэтому целостность этой связи
на уровне базы не гарантируется.
</Warning>
