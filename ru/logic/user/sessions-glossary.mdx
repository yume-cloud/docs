Справочник к странице [«Сессии и срок действия входа»](/ru/logic/user/sessions).

## Понятия

| Понятие | Значение |
| --- | --- |
| Сессия | Подтверждение того, что вы вошли в систему. Предъявляется автоматически при каждом обращении, повторно вводить пароль не нужно. |
| Срок сессии | Как долго действует вход без продления — 1 день. |
| Продление сессии | Автоматическое продолжение работы без ввода пароля. Происходит незаметно, пока вы пользуетесь системой. |
| Окно продления | Сколько времени можно продлевать вход без пароля — 30 дней с последнего входа. По истечении потребуется войти заново. |
| Выход | Прекращение сессии по вашей команде. После выхода нужен новый вход. |
| Отключённый аккаунт | Сотрудник, которому закрыли доступ в настройках. Войти не может; уже открытая сессия получает отказ со следующего обращения. |
| Запомненные сведения | Сведения об аккаунте и роль в компании запоминаются на 5 минут, набор прав роли — на сутки. Всё это сбрасывается в момент изменения, поэтому смена роли, прав или отключение аккаунта действуют со следующего обращения. Повторный вход для этого не нужен и ничего не сбрасывает. |
| Один аккаунт в нескольких компаниях | Одна учётная запись может участвовать в нескольких компаниях; при изменении аккаунта запомненные сведения сбрасываются во всех них и вне компаний. |

## Частые вопросы

**Почему меня разлогинило?** Скорее всего, вы не заходили дольше 30 дней, либо вышли вручную, либо аккаунт отключили в настройках сотрудников.

**Я изменил права сотруднику, а он их не видит.** Смена роли и изменение прав роли действуют со следующего обращения, повторный вход не нужен. Проверьте, что роль назначена в нужной компании и права сохранены именно у этой роли — см. [«Вход в систему»](/ru/logic/user/login).

**Я отключил сотрудника, а он ещё работает.** Отключение аккаунта действует со следующего обращения: запомненные сведения сбрасываются в момент отключения. Смена пароля открытую сессию не завершает, поэтому для закрытия доступа нужно именно отключение.
