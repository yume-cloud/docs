## Понятия

| Понятие | Значение |
| --- | --- |
| Сессия | Подтверждение того, что вы вошли в систему. Предъявляется автоматически при каждом обращении, повторно вводить пароль не нужно. |
| Срок сессии | Как долго действует вход без продления — 1 день. |
| Продление сессии | Автоматическое продолжение работы без ввода пароля. Происходит незаметно, пока вы пользуетесь системой. |
| Окно продления | Сколько времени можно продлевать вход без пароля — 30 дней с последнего входа. По истечении потребуется войти заново. |
| Выход | Прекращение сессии по вашей команде. После выхода нужен новый вход. |
| Отключённый аккаунт | Сотрудник, которому закрыли доступ в настройках. Войти не может; уже открытая сессия прекращается в течение нескольких минут. |
| Задержка применения изменений | Сведения об аккаунте хранятся около 5 минут, поэтому смена роли, прав или отключение аккаунта могут подействовать не мгновенно. Ускорить можно повторным входом. |
| Один аккаунт в нескольких компаниях | Одна учётная запись может участвовать в нескольких компаниях; при изменении профиля сведения обновляются во всех них. |

## Частые вопросы

**Почему меня разлогинило?** Скорее всего, вы не заходили дольше 30 дней, либо вышли вручную, либо аккаунт отключили в настройках сотрудников.

**Я изменил права сотруднику, а он их не видит.** Изменение применяется в пределах нескольких минут; права роли могут держаться дольше. Попросите сотрудника выйти и войти заново — см. [«Вход в систему»](/ru/logic/user/login).

**Я отключил сотрудника, а он ещё работает.** Проверка выполняется по недавно сохранённым сведениям, поэтому доступ прекращается не мгновенно. Если нужно немедленно — отключите аккаунт и смените пароль.
