## Понятия

| Понятие | Значение |
| --- | --- |
| Задача пересчёта лояльности | задача: пересчитывает уровень лояльности пользователя по сумме завершённых заказов клиента и выбирает подходящий уровень. Выбирает максимальный уровень, чей порог не превышает сумму завершённых заказов; обновляет только изменившиеся строки. |
| Валидатор минимальных размеров изображения | Валидатор, отклоняющий изображения меньше эталонного @3x-размера. Используется для минимальных размеров иконок, логотипов и полос Apple, а также логотипов и баннеров Google. |
| Валидатор hex-цвета | Проверяет, что строка цвета задана в формате #RRGGBB. |
| Валидатор hex-цвета (необязательный) | Пропускает пустое значение, иначе проверяет формат #RRGGBB. |
| Валидатор расширения изображения | Допускает только файлы PNG или JPEG. |
| Рендер квадратного варианта | Вписывает изображение по центру в прозрачный PNG-квадрат заданного размера; используется для квадратных ассетов (иконки Apple). |
| Рендер варианта с сохранением пропорций | Масштабирует изображение с сохранением пропорций и возвращает PNG; используется для логотипов и полос. |

## Модели и поля

### Уровень лояльности

*Уровень программы лояльности: процент кэшбэка и лимиты, привязанные к порогу суммы завершённых заказов. Порог активации определяется полем порога; уровень пользователя пересчитывается задачей пересчёта лояльности.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Название уровня лояльности (необязательное). |
| Процент | число | Процент начисления/кэшбэка на уровне (по умолчанию 3). |
| Порог (цена) | число (2 знака) | Порог суммы завершённых заказов, с которого действует уровень. |
| Лимит начисления | число (2 знака) | Максимальная сумма начисления (по умолчанию 200000). |
| Лимит по времени | интервал времени | Ограничение по длительности события (по умолчанию 3 дня). |
| Лимит на доставку | число (2 знака) | Максимальная сумма по доставке (по умолчанию 15000). |
