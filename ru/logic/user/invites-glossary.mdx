## Понятия

| Понятие | Значение |
| --- | --- |
| Приглашение сотрудника | Одноразовое приглашение в компанию по ссылке с заранее выбранными ролью, признаками, пунктами проката и зарплатой. Принадлежит компании; живёт 7 дней. |
| Ссылка приглашения | Адрес вида `<адрес веб-приложения>/invite/<токен>/`. Токен не меняется, поэтому повторная отправка присылает ту же ссылку. |
| Открытое приглашение | Приглашение в статусе «ожидает»: его можно принять и отправить повторно. На одну почту в компании может быть только одно открытое приглашение. |
| Приглашение без почты | Ссылка, которую отправляют вручную. Письмо не уходит, а почту указывает сам человек при принятии. |
| Отзыв приглашения | Пометка временем отзыва вместо удаления: ссылка перестаёт работать, запись остаётся. |
| Принятие приглашения | Обмен ссылки на членство в компании и вход в систему: новый аккаунт задаёт пароль, существующий подтверждает свой. |
| Выдача доступа в компании | Общая функция принятия приглашения и добавления по почте: создаёт членство, если его нет, привязывает пункты, пишет зарплату и пересчитывает лимит сотрудников. |
| Добавление существующего аккаунта | Прямое включение в компанию аккаунта, который уже есть в Yume, по его почте — без ссылки и без подтверждения со стороны человека. |
| Ответ «аккаунт уже есть» | Отказ `409` с кодом `user_exists` на заведение сотрудника с почтой аккаунта из другой компании; несёт карточку найденного аккаунта. |

## Модели и поля

### Приглашение сотрудника

*Одноразовое приглашение в компанию. Принадлежит компании: строка несёт компанию, выборки ограничены активной компанией, а публичные адреса ищут приглашение по токену среди всех компаний. Список — новые сверху.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ |
| Компания | связь | Компания, в которую приглашают |
| Токен | UUID | Уникальный, выдаётся при создании, не редактируется |
| Почта | текст | Необязательна; при сохранении обрезаются пробелы по краям и приводится к нижнему регистру, пустая — к отсутствию значения |
| Роль | связь | Группа прав компании; при удалении роли обнуляется |
| Сотрудник | флаг | По умолчанию «да» |
| Субарендатор | флаг | По умолчанию «нет» |
| Пункты проката | JSON (список чисел) | По умолчанию пусто |
| Сумма зарплаты | число (2 знака) | Необязательна |
| Истекает | дата/время | По умолчанию — момент создания плюс 7 дней |
| Отозвано | дата/время | Время отзыва |
| Принято | дата/время | Время принятия |
| Кем принято | связь | Аккаунт, принявший приглашение; при удалении аккаунта обнуляется |
| Кем создано | связь | Пригласивший; при удалении аккаунта обнуляется |
| Создано | дата/время | Проставляется автоматически |
| Отправлено | дата/время | Когда письмо в последний раз поставлено в очередь |

**Вычисляемые**

| Поле | Тип | Описание |
| --- | --- | --- |
| Статус | перечисление | Вычисляется при чтении: принято → отозвано → истекло → ожидает, см. ниже |
| Открыто | флаг | Статус — «ожидает» |

### Формат приглашения

*Чтение приглашения в списке и карточке компании (`GET /v1/crm/invites/`, `GET /v1/crm/invites/<id>/`). Ответ на создание дополнительно несёт признак `sent`.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор (`id`) | число | |
| Токен (`token`) | UUID | |
| Ссылка (`url`) | текст | Готовая ссылка приглашения |
| Почта (`email`) | текст | Может быть пустой |
| Статус (`status`) | перечисление | `pending`, `accepted`, `expired`, `revoked` |
| Роль (`group`), название роли (`group_name`) | число, текст | Название — отображаемое имя роли в компании |
| Сотрудник (`is_staff`), субарендатор (`is_sublease`) | флаги | |
| Пункты проката (`points`) | список | |
| Сумма зарплаты (`salary_amount`) | число (2 знака) | |
| Истекает, отправлено, принято, отозвано, создано (`expires_at`, `sent_at`, `accepted_at`, `revoked_at`, `created_at`) | дата/время | |
| Кем создано (`created_by`, `created_by_name`) | число, текст | Имя — «имя фамилия» пригласившего |
| Письмо ушло (`sent`) | флаг | Только в ответе на создание: письмо поставлено в очередь. «Нет» — почты нет или очередь недоступна |

### Формат создания приглашения

*Проверяет данные `POST /v1/crm/invites/`. Создатель и компания проставляются из запроса.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Почта (`email`) | текст (email) | Необязательна. Отказ, если человек с этой почтой уже в компании или на неё есть открытое приглашение компании |
| Роль (`group`) | число | Только роль этой компании, иначе «Роль не найдена.» |
| Сотрудник (`is_staff`), субарендатор (`is_sublease`) | флаги | Необязательны |
| Пункты проката (`points`) | список чисел | Только пункты этой компании, иначе «Пункт проката не найден: …» |
| Сумма зарплаты (`salary_amount`) | число (2 знака) | Необязательна |

### Публичный формат приглашения

*То, что видит приглашённый без входа (`GET /v1/auth/invite/<токен>/`). Без внутренних данных компании. Ограничение — 30 запросов в минуту с одного адреса.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Токен (`token`) | UUID | |
| Почта (`email`) | текст | Может быть пустой |
| Статус (`status`) | перечисление | Отдаётся для любого статуса — страница показывает, почему ссылка не работает |
| Компания (`company`) | текст | Название компании |
| Роль (`role`) | текст | Отображаемое название роли |
| Аккаунт существует (`user_exists`) | флаг | Есть ли аккаунт с почтой приглашения; у приглашения без почты — всегда «нет» |
| Истекает (`expires_at`) | дата/время | |

### Формат принятия приглашения

*Проверяет данные `POST /v1/auth/invite/<токен>/accept/`. Ограничение — 10 запросов в минуту с одного адреса.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Почта (`email`) | текст (email) | Нужна только у приглашения без почты; иначе не учитывается |
| Имя (`first_name`), фамилия (`last_name`) | текст (до 150) | Обязательны, только если аккаунт создаётся |
| Пароль (`password`) | текст (мин. 8) | Новый аккаунт — проверяется стандартными правилами; существующий — должен совпасть с его паролем |

**Ответ**

| Поле | Тип | Описание |
| --- | --- | --- |
| Access-токен (`access`), refresh-токен (`refresh`) | текст | Вход сразу после принятия |
| Компания (`tenant_id`, `company`) | число, текст | Идентификатор и название компании приглашения |

### Выдача доступа в компании

*Общая функция принятия приглашения и добавления существующего аккаунта; выполняется в одной транзакции.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Аккаунт, компания | связи | Кому и где выдаётся доступ |
| Роль, признаки сотрудника и субарендатора | число, флаги | Пишутся в новое членство; «суперпользователь компании» — «нет» |
| Пункты проката | список | Привязываются неактивными; первый становится активным, если активного пункта в компании нет |
| Сумма зарплаты | число (2 знака) | Пишется, если не нулевая, в единственную запись о зарплате аккаунта — общую для всех компаний |
| Результат | членство, флаг | Членство и признак «создано». Уже существующее членство не меняется, остальное тогда не выполняется |

### Формат добавления существующего аккаунта

*Проверяет данные `POST /v1/crm/users/attach/`. В ответе — карточка человека в формате списка сотрудников.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Почта (`email`) | текст (email) | Обязательна. Отказ, если аккаунта нет или человек уже в компании |
| Роль (`group`) | число | Необязательна |
| Сотрудник (`is_staff`) | флаг | По умолчанию «да» |
| Субарендатор (`is_sublease`) | флаг | По умолчанию «нет» |
| Пункты проката (`points`) | список чисел | Необязательны |
| Сумма зарплаты (`salary_amount`) | число (2 знака) | Необязательна |

### Ответ «аккаунт уже есть»

*Отказ `409` при заведении сотрудника (`POST /v1/crm/users/`) с почтой аккаунта, который есть в Yume, но не в этой компании. При правке сотрудника вместо него — обычная ошибка поля.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Код (`code`) | текст | `user_exists` |
| Сообщение (`detail`) | текст | «Пользователь с такой почтой уже зарегистрирован в Yume.» |
| Аккаунт (`user`) | объект | Идентификатор, имя, фамилия, почта и ссылка на аватар (пусто, если аватара нет) |

## Статусы и справочники

### Статус приглашения

*Вычисляется при каждом чтении в указанном порядке; первое совпавшее условие побеждает.*

- Принято (`accepted`) — проставлено время принятия.
- Отозвано (`revoked`) — проставлено время отзыва.
- Истекло (`expired`) — наступил срок действия.
- Ожидает (`pending`) — всё остальное; единственный статус, в котором приглашение можно принять или отправить повторно.
