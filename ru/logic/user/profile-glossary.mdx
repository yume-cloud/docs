## Модели и поля

### Сервисы пользователей

*Вспомогательные функции поиска пользователя, привязки к компании и проверки уникальности.*

Общая логика для входа, регистрации и профиля: поиск пользователя, привязка к компании и проверка уникальности.

**Функции**

| Поле | Тип | Описание |
| --- | --- | --- |
| Поиск пользователя | функция | Ищет по телефону/почте/логину, возвращает первого по идентификатору. |
| Привязка к компании | функция | Создаёт членство в компании с ролями; игнорирует отсутствие компании. |
| Проверка уникальности | функция | Реальная защита уникальности по телефону/почте/логину с исключением текущей записи. |

**Константы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Уникальные поля пользователя | список | Телефон, почта, логин. |
| Сообщения о дубликатах | словарь | Тексты ошибок уникальности по полям. |

### Профиль пользователя (представление)

*Эндпоинт чтения и обновления собственного профиля авторизованного пользователя.*

Доступен только авторизованному пользователю. Объект берётся по идентификатору текущего пользователя; на чтение отдаётся детальный профиль, на запись — сериализатор ограниченного редактирования. Список пользователей дополнительно аннотируется зарплатой, списком точек и основной точкой.

**Аннотации**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма зарплаты | число (2 знака) | Аннотация из связи с зарплатой менеджера. |
| Список точек аренды | список | Агрегированный набор точек текущей компании. |
| Основная точка аренды | число | Первый элемент списка точек. |

### Вход по кросс-токену (представление)

*Эндпоинт обмена одноразового кросс-токена на пару JWT (refresh/access).*

Доступен без авторизации; при ошибке токена возвращает ошибку недействительного токена.

### Сериализатор создания/редактирования пользователя

*Создаёт и обновляет пользователя вместе с членством в компании, ролями, зарплатой и точками.*

Роли пишутся в членство в компании; точки синхронизируются с точками аренды пользователя, зарплата — с зарплатой менеджера. При создании увеличивается лимит сотрудников, пароль хешируется при сохранении.

| Поле | Тип | Описание |
| --- | --- | --- |

| Имя | текст | |
| Фамилия | текст | |
| Электронная почта | текст | Обязательное. |
| Пароль | текст | Только запись, обязательное; сохраняется в хешированном виде. |

**Роли**

| Поле | Тип | Описание |
| --- | --- | --- |
| Группа прав | число | Пишется в членство в компании. |
| Сотрудник | флаг | Пишется в членство в компании. |
| Суперпользователь компании | флаг | Пишется в членство в компании. |
| Субарендатор | флаг | Пишется в членство в компании. |

**Ресурсы**

| Поле | Тип | Описание |
| --- | --- | --- |

| Сумма зарплаты | число (2 знака) | Необязательное; пишется в зарплату менеджера. |

### Сериализатор входа по кросс-токену

*Проверяет одноразовый кросс-токен и выдаёт пару JWT для соответствующего пользователя.*

Обновляет время последнего входа.

<Warning>
Логическое замечание (безопасность): инвалидация использованного кросс-токена отключена, поэтому задуманный как одноразовый токен переиспользуется без ограничений.
</Warning>

| Поле | Тип | Описание |
| --- | --- | --- |
| Кросс-токен | UUID | Обязательное; ищется среди неистёкших токенов. |
| Refresh-токен | текст | Выдаётся при успешной проверке. |
| Access-токен | текст | Выдаётся при успешной проверке. |
