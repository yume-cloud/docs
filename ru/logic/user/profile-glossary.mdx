## Модели и поля

### Сервисы пользователей

*Вспомогательные функции поиска пользователя, привязки к компании и проверки уникальности.*

Общая логика для входа, регистрации и профиля: поиск пользователя, привязка к компании и проверка уникальности.

**Функции**

| Поле | Тип | Описание |
| --- | --- | --- |
| Поиск пользователя | функция | Ищет по телефону/почте/логину, возвращает первого по идентификатору. |
| Привязка к компании | функция | Создаёт членство в компании с ролями; игнорирует отсутствие компании. |
| Проверка уникальности | функция | Реальная защита уникальности по телефону/почте/логину с исключением текущей записи. |
| Проверка почты сотрудника | функция | Используется карточкой сотрудника. Почта занята человеком из текущей компании — ошибка поля; занята аккаунтом Yume вне компании — при создании отказ `409` `user_exists` с карточкой аккаунта, при правке — ошибка поля. |

**Константы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Уникальные поля пользователя | список | Телефон, почта, логин. |
| Сообщения о дубликатах | словарь | Тексты ошибок уникальности по полям. |

### Профиль пользователя (представление)

*Адрес чтения и обновления собственного профиля авторизованного пользователя.*

Доступен только авторизованному пользователю. Объект берётся по идентификатору текущего пользователя; на чтение отдаётся детальный профиль, на запись — формат ограниченного редактирования. Список пользователей дополнительно аннотируется зарплатой, списком точек и основной точкой.

**Аннотации**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сумма зарплаты | число (2 знака) | Аннотация из связи с зарплатой менеджера. |
| Список точек аренды | список | Агрегированный набор точек текущей компании. |
| Основная точка аренды | число | Первый элемент списка точек. |
| Настройки интерфейса | словарь | Личные настройки сотрудника (закреплённая страница, язык). До 20 ключей, ключ и значение — до 200 символов, значение только строка, число, логическое или пусто. При записи ключи дописываются поверх сохранённых. Отдаются и в собственном профиле, и в карточке сотрудника. |

### Формат создания/редактирования пользователя

*Создаёт и обновляет пользователя вместе с членством в компании, ролями, зарплатой и точками.*

Роли пишутся в членство в компании; точки синхронизируются с точками аренды пользователя, зарплата — с зарплатой менеджера. При создании увеличивается лимит сотрудников, пароль хешируется при сохранении. При обновлении роли, которых нет в запросе, берутся из текущего членства; явное пустое значение снимает Группу прав.

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | |
| Аватар | файл/изображение | Необязательное. |
| Имя | текст | |
| Фамилия | текст | |
| Электронная почта | текст | Обязательное; до записи сверяется с другими аккаунтами — см. «Проверка почты сотрудника». |
| Пароль | текст | Только запись, обязательное; сохраняется в хешированном виде. |

**Роли**

| Поле | Тип | Описание |
| --- | --- | --- |
| Группа прав | число | Пишется в членство в компании. |
| Сотрудник | флаг | Пишется в членство в компании. |
| Суперпользователь компании | флаг | Пишется в членство в компании. |
| Субарендатор | флаг | Пишется в членство в компании. |

**Ресурсы**

| Поле | Тип | Описание |
| --- | --- | --- |
| Точки аренды | список | Синхронизируется с точками аренды пользователя (лишние удаляются при обновлении). |
| Сумма зарплаты | число (2 знака) | Необязательное; пишется в зарплату менеджера. |
