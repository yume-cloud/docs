## Модели и поля

### Артефакт миграции

*Немигрируемая таблица, хранящая соответствие старых и новых идентификаторов записей, перенесённых между схемами (используется для remap идентификаторов пользователей). Таблица неуправляемая; для JWT фильтруется по таблице-источнику пользователей.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Исходная схема | текст | Имя схемы-источника записи. |
| Исходная таблица | текст | Имя таблицы-источника; для пользователей — таблица учётных записей. |
| Исходный столбец | текст | Имя столбца-источника идентификатора. |
| Старый идентификатор | число | Прежний идентификатор записи до миграции. |
| Новый идентификатор | число | Текущий идентификатор записи после миграции. |

### Кастомная JWT-аутентификация

*DRF-класс аутентификации по умолчанию: извлекает пользователя из access-токена, применяет remap старого идентификатора в новый и кэширует объект пользователя на 5 минут. Ключ кэша namespaced по схеме.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Получение пользователя по токену | метод | Читает идентификатор пользователя из клейма токена, при непубличной схеме применяет remap через артефакт миграции, берёт пользователя из кэша или базы данных, проверяет активность и кэширует. |
| Флаг remap артефактов | флаг (константа модуля) | Включает поиск remap старого идентификатора в новый для непубличных схем. |

### Схема JWT для документации

*Класс drf-spectacular, указывающий кастомную JWT-аутентификацию в качестве целевого класса для генерации OpenAPI-схемы безопасности.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Целевой класс аутентификации | текст (путь к классу) | Указывает на кастомную JWT-аутентификацию. |

### Сериализатор обновления токена

*Сериализатор для эндпоинта обновления: применяет remap старого идентификатора в новый, проверяет пользователя и ротирует refresh-токен. Ветка обработки отсутствующего пользователя недостижима — при отсутствии пользователя валидация не срабатывает и access-токен всё равно выдаётся.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Валидация и обновление | метод | Разбирает refresh-токен, при непубличной схеме применяет remap и обновляет идентификатор пользователя в payload, проверяет правило аутентификации пользователя, ротирует refresh-токен при включённой ротации. |

### Кэш аутентификации

*Модуль-помощник для формирования ключа кэша пользователя и инвалидации кэша по всем схемам, где пользователь состоит. Время жизни кэша — 5 минут.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Время жизни кэша пользователя | число (секунды) | 5 минут (300 секунд). |
| Ключ кэша пользователя | функция | Возвращает ключ по идентификатору пользователя; кэш namespaced по схеме автоматически. |
| Схемы пользователя | функция | Собирает набор схем (публичная плюс схемы тенантов, где пользователь является администратором), где закэширован пользователь. |
| Инвалидация кэша пользователя | функция | Удаляет ключ пользователя во всех его схемах, переключаясь между схемами. |
