## Модели и поля

### Кастомный бэкенд аутентификации

*Бэкенд аутентификации (в списке бэкендов): ищет пользователя по телефону, логину или email, при заданном тенанте фильтрует по членству и выдаёт права через группу тенанта. В инструкции проекта он назван иначе, но реальный класс — кастомный бэкенд аутентификации.*

**Вход**

| Поле | Тип | Описание |
| --- | --- | --- |
| Проверка учётных данных | метод | Ищет по совпадению телефона, логина или email с сортировкой по убыванию идентификатора; при заданном тенанте (не фейковом) фильтрует по членству в компании; проверяет пароль и возможность аутентификации пользователя. |

**Права**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сбор прав пользователя | метод | Возвращает набор строковых прав из группы тенанта с кэшированием. Замечание: проверка наличия группы тенанта всегда истинна (это вычисляемое свойство), то есть фактически мёртвая. |
| Проверка права | метод | Ложь для неактивного пользователя; истина для суперпользователя тенанта; иначе проверяет наличие права в правах группы. |
| Время жизни кэша прав | число (секунды) | 24 часа; время жизни ключа кэша прав по группе. |

### Маршруты входа/выхода/refresh

*URL-маршруты приложения пользователей; вход, выход и обновление токена смонтированы на стандартные вьюхи SimpleJWT. Смонтированы стандартные классы SimpleJWT, кастомной логики входа в самих маршрутах нет.*

**JWT**

| Поле | Тип | Описание |
| --- | --- | --- |
| Вход | маршрут | Выдача пары токенов доступа и обновления по логину и паролю. |
| Выход | маршрут | Помещение токена обновления в чёрный список. |
| Обновление токена | маршрут | Обновление токена доступа по токену обновления. |

**Прочее**

| Поле | Тип | Описание |
| --- | --- | --- |
| Вход по токену | маршрут | Вход без пары логин и пароль. |
