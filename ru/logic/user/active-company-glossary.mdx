Справочник к странице [«Как система определяет вашу компанию»](/ru/logic/user/active-company).

## Понятия

| Понятие | Значение |
| --- | --- |
| Аккаунт | Учётная запись человека. Одна и та же учётная запись может участвовать сразу в нескольких компаниях. |
| Компания | Организация, которой принадлежат данные: аренды, клиенты, инвентарь, оплаты. Все данные в системе привязаны к одной компании. |
| Участие в компании | Связь аккаунта с компанией. Задаёт роль человека и его права внутри этой компании. |
| Адрес компании (поддомен) | Собственный адрес компании. Если вы заходите по нему, компания определяется сразу из адреса. |
| Активная компания | Компания, в контексте которой выполняется текущее обращение. От неё зависит, какие данные вы видите. |
| Аккаунт без компании | Нормальное состояние сразу после регистрации: аккаунт создан, компании ещё нет. Обычные разделы в этом состоянии недоступны. |
| «Нужно создать компанию» | Признак в ответе системы, по которому приложение понимает, что человека надо направить на форму создания компании, а не показать обычную ошибку доступа. |
| Сессия | Подтверждение того, что вы вошли в систему. Предъявляется при каждом обращении; см. [«Сессии и срок действия входа»](/ru/logic/user/sessions). |

## Как это связано

Компания определяется одним из двух способов — по адресу сайта или по аккаунту. Первый работает для входа через браузер по адресу компании, второй — для мобильного приложения и внешних интеграций, которые обращаются к общему адресу.

Если аккаунт участвует в нескольких компаниях, выбирается одна из них; правила выбора описаны в разделе [«Аккаунт и участие в компании»](/ru/logic/user/model).

Если у аккаунта нет ни одной компании и запрошен обычный раздел, система отвечает отказом с признаком «нужно создать компанию». Разделы, которые обязаны работать до её появления — вход, регистрация, создание компании, проверка занятости адреса, справочник сфер деятельности и заявка на демо — остаются доступны.
