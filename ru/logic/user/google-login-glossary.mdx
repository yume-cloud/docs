## Понятия

| Понятие | Значение |
| --- | --- |
| Вход через Google | Способ войти без пароля: личность подтверждает Google, а система находит или создаёт учётную запись. |
| Согласие Google | Страница Google, на которой человек разрешает передать системе свои имя, фото и адрес почты. |
| Подтверждённая почта | Признак того, что человек действительно владеет указанным адресом. Система на него опирается при входе. |
| Связывание по почте | Правило сопоставления: если аккаунт с такой почтой уже есть, вход выполняется в него; если нет — создаётся новый. |
| Заполнение пустых полей | При входе имя, фамилия и фото подставляются только туда, где у профиля пусто. Существующие значения не затираются. |
| Первый вход | Вход, при котором аккаунт создаётся. Компания при этом не создаётся — её нужно завести отдельно. |
| Аккаунт без компании | Состояние после первого входа: учётная запись есть, компании нет, обычные разделы недоступны. |

## Частые ситуации

**Вошёл через Google, но данных компании не вижу.** Аккаунт не добавлен в компанию либо создан на другой адрес почты. Проверьте адрес и попросите администратора добавить сотрудника.

**Создался второй аккаунт.** Адрес почты в Google отличается от указанного в системе — связывание идёт строго по совпадению адреса.

**Google отказывает во входе.** Чаще всего адрес почты в Google не подтверждён.
