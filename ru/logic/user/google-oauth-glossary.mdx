## Понятия

Ключевые адаптеры, endpoint-ы и хелперы, участвующие в социальном входе.

| Понятие | Значение |
| --- | --- |
| Адаптер локальных аккаунтов | Кастомный allauth-адаптер обычных (не соц-) аккаунтов: открыт для регистрации и сохраняет пользователя. Регистрация всегда разрешена; сохранение пользователя откладывается до фиксации транзакции. |
| Адаптер социального входа | Кастомный allauth-адаптер соцвхода: заполняет и сохраняет пользователя из данных Google, связывает по email. Соц-логин привязывается к существующему пользователю по email; имя и фамилия переносятся из профиля, имя пользователя подставляется из email. |
| Создание/обновление Google-пользователя | Ядро соцвхода: по данным Google создаёт или обновляет пользователя, привязывает социальный аккаунт и при отсутствии компании создаёт компанию и членство. Принимает как данные userinfo, так и ID-token; если у пользователя ещё нет компании, генерирует её и создаёт членство с правами администратора. |
| Callback веб-OAuth | Endpoint обмена authorization code на access-токен и получения userinfo, затем создание/обновление пользователя и выдача JWT. Метод POST, доступен всем; адрес возврата по умолчанию ведёт на локальный callback. |
| Вход по ID-token (мобильный) | Endpoint для нативных клиентов: проверяет Google ID-token и выдаёт JWT приложения. Проверяет получателя токена (по списку web/iOS/Android), издателя и подтверждённость email. |
| Генерация OAuth-ссылки | Endpoint, собирающий URL авторизации Google из идентификатора клиента и адреса возврата. Метод GET, доступен всем; запрашиваются области «openid email profile», код авторизации и офлайн-доступ. |
| Загрузка аватара из Google | Хелпер: скачивает картинку профиля по ссылке и возвращает файл для поля аватара. Работает с ограничением по времени; при ошибке или пустой ссылке возвращает пустое значение. |
| Список допустимых audience | Хелпер: собирает разрешённые идентификаторы Google-клиентов (web/iOS/Android) для проверки получателя ID-token. Берёт значения из настроек, отбрасывая пустые. |

## Модели и поля

### Социальный аккаунт

*Модель allauth, связывающая пользователя с его учётной записью во внешнем провайдере (Google). Хранится в общих (глобальных) таблицах, не привязанных к компании; для Google идентификатор у провайдера совпадает с идентификатором аккаунта Google.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Пользователь | связь | Владелец социального аккаунта. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Провайдер | текст | Идентификатор провайдера, здесь всегда «google». |
| UID у провайдера | текст | Уникальный идентификатор пользователя на стороне Google. |

**Данные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Сырые данные профиля | структура (JSON) | Полный payload userinfo или ID-token; перезаписывается при повторном входе. |

**Служебные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Последний вход | дата/время | Время последнего входа через провайдера. |
| Дата привязки | дата/время | Когда социальный аккаунт был привязан. |

### Приложение провайдера

*Модель allauth с настройками OAuth-приложения (идентификатор и секрет клиента) для провайдера.*

<Warning>
Логическое замечание: в блоке создания приложения при входе через Google допущена ошибка — выборка «первого» результата не бросает исключение и возвращает пустое значение, из-за чего ветка обработки отсутствия оказывается недостижимой, и приложение этим кодом фактически никогда не создаётся.
</Warning>

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Человекочитаемое имя приложения («Google»). |
| Провайдер | текст | Идентификатор провайдера («google»). |
| Client ID | текст | Публичный идентификатор OAuth-клиента. |
| Client Secret | текст | Секрет OAuth-клиента. |
