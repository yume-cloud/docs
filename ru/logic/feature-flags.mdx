**Флаги функций** — это настройки уровня компании, которые включают/выключают части логики или задают значения по умолчанию. Они хранятся отдельно для каждой компании и читаются логикой аренды при расчётах и создании записей. Ниже — справочник флагов с их эффектом и значением по умолчанию.

<Note>
В таблицах указан технический ключ настройки (как она называется в конфигурации) и её понятное название. Это единственная страница раздела, где ключи настроек приводятся намеренно — здесь они и есть предмет справочника.
</Note>

## Расчёт и график платежей

Самый влиятельный флаг для ценообразования — «Посуточный график платежей». Как именно он меняет расчёт, подробно разобрано в разделе [Пересчёт сумм и цен](/ru/logic/rent/pricing).

| Ключ | Название | Что делает | По умолчанию |
| --- | --- | --- | --- |
| `feature_transaction_schedule` | Посуточный график платежей | Переключает расчёт с непрерывного времени на посуточный: длительность считается календарными сутками за вычетом нерабочих дней, создаётся план платежей по дням, появляются посуточные списания. | выкл. |
| `feature_transaction_schedule_initial_fee` | Плата за первый день | При посуточном графике делает первый день аренды платным (по умолчанию он бесплатный). | выкл. |
| `order_autoweekday` | Авто-выходной день | Автоматически выводит один недельный выходной день (по дню начала аренды), цикл 6 рабочих / 1 выходной. Влияет на оплачиваемые дни в посуточном графике. | выкл. |
| `feature_transaction_overpay` | Разрешить переплату | Снимает проверку переплаты — позволяет вносить сумму больше остатка/залога. | выкл. |
| `feature_transaction_date` | Ручная дата операции | Разрешает вручную указывать дату платежа/операции. | выкл. |

## Аренды (заказы)

| Ключ | Название | Что делает | По умолчанию |
| --- | --- | --- | --- |
| `order_draft` | Новые аренды как черновик | Новые аренды создаются в статусе «Заявка» (иначе сразу «Забронирована»/«В аренде»). | вкл. |
| `reservation` | Этап бронирования | Включает статус «Забронирована» в жизненном цикле. | вкл. |
| `collection` | Этап сборки | Включает стадию комплектации/сборки. | выкл. |
| `order_autorenewal` | Автопродление по умолчанию | Новые аренды по умолчанию с автопродлением; активная аренда автоматически продлевается. | выкл. |
| `order_duration` | Длительность аренды по умолчанию | Срок новой аренды по умолчанию; также ограничивает шаг автопродления. | 1 день |
| `order_deposit` | Залоги | Включает работу с залогами в аренде. | вкл. |
| `order_service` | Услуги в аренде | Разрешает добавлять услуги к аренде. | выкл. |
| `order_agent` | Агент/реферер в аренде | Включает поле агента (реферера) в аренде. | выкл. |
| `order_agent_percent` | Комиссия агента, % | Комиссия агента по умолчанию. | 10 |
| `single_issue` | Выдача одним действием | Переход «В аренде» выдаёт весь инвентарь сразу. | выкл. |
| `single_recievement` | Приём одним действием | Переход «Завершена» принимает весь инвентарь сразу. | выкл. |
| `order_rental_point_return` | Смена точки при возврате | При приёме единица переносится в точку возврата, если она отличается от точки выдачи. | выкл. |
| `order_merge_inrent_exceed` | Объединять «В аренде» и «Просрочена» | В счётчиках списка объединяет просроченные с арендуемыми. | выкл. |
| `order_archive_auto` | Автоархивация завершённых | Автоматически архивирует завершённые аренды после задержки. | выкл. |
| `order_archive_buffer_duration` | Задержка автоархивации | Пауза после завершения перед автоархивацией. | 3 часа |
| `order_filter_type` | Стратегия фильтра списка | Пресет фильтрации списка аренд. | default |
| `order_single_inventory` | Одна единица на аренду | Режим такси: ограничивает аренду одной единицей. | выкл. |
| `feature_order_recipe` | Генерация квитанции | Включает генерацию чека/квитанции по аренде. | выкл. |

## Штрафы

| Ключ | Название | Что делает | По умолчанию |
| --- | --- | --- | --- |
| `penalty` | Штрафы включены по умолчанию | Новые аренды по умолчанию начисляют автоштраф (при выкл. — авто-штраф отключён). | выкл. |
| `penalty_after` | Округлять шаги просрочки вверх | Направление округления шагов просрочки: вкл. — вверх, выкл. — вниз. Меняет сумму штрафа. | выкл. |
| `penalty_default` | Шаг штрафа по умолчанию | Шаг начисления штрафа для новых аренд. | 1 час |
| `order_penalty_rounding` | Квант округления штрафа | Кратность, до которой округляется итоговый штраф. | 1 |
| `order_penalty_buffer_duration` | Буфер перед штрафом | Льготный интервал после срока возврата, в течение которого штраф не начисляется. | 1 час |
| `penalty_type` | Способ расчёта штрафа | Модель начисления штрафа (по времени / по длительности). | по времени |
| `penalty_manager_access` | Доступ менеджеров к штрафам | Разрешает менеджерам управлять штрафами. | вкл. |
| `penalty_options` | Пресеты штрафов | Список готовых вариантов шага штрафа (посменный/почасовой). | посменный, почасовой |

| `recievement_percent` | Комиссия за приём, % | 3 |
| `delivery_order_percent` | Комиссия за доставку, % | 10 |
