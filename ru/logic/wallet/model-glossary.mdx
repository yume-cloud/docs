## Модели и поля

### Пропуск (карта Wallet)

*Выпущенная карта Apple/Google Wallet, привязанная к клиенту или заказу арендатора; живёт в публичной схеме, один пропуск на объект.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания (арендатор) | связь | Владелец пропуска; ссылка на компанию-арендатора в публичной схеме. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип пропуска | перечисление | Бонусная карта или заказ; индексируется. |
| ID связанного объекта | число | ID бонусной карты или заказа, к которому привязан пропуск; может быть пустым. |
| Серийный номер | текст | Уникальный серийный номер пропуска в системе Wallet. |
| Идентификатор типа пропуска | текст | Идентификатор типа пропуска Apple PassKit; индексируется. |
| Токен авторизации | текст | Секрет для проверки запросов к пропуску; генерируется автоматически (16 байт в hex). |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Аннулирован | флаг | Признак отозванного/недействительного пропуска. |
| Обновлён | дата/время | Время последнего изменения; используется для push-обновлений. |
| Создан | дата/время | Время создания пропуска. |

### Регистрация устройства

*Регистрация устройства для push-обновлений конкретного пропуска через APNs; одно устройство на пропуск.*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Пропуск | связь | Пропуск, к которому привязана регистрация. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор устройства | текст | Идентификатор устройства Apple Wallet; индексируется. |
| Push-токен | текст | Токен устройства для отправки push через APNs. |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создана | дата/время | Время регистрации устройства. |

### Генератор токена авторизации

*Функция генерации случайного токена авторизации (16 байт в hex) по умолчанию для нового пропуска; используется как значение по умолчанию для поля «Токен авторизации».*
