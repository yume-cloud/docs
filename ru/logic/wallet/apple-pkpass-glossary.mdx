## Модели и поля

### Сборка .pkpass (диспетчер)

*Точка входа: генерирует серийный номер и выбирает сборщик карты по типу пропуска. По типу вызывает сборщик бонусной карты или сборщик карты заказа.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Арендатор | связь | Компания-владелец карты. |
| Тип карты | перечисление | Бонусная или заказ. |
| Объект-источник | связь | Бонус или заказ, из которого берутся данные. |
| Серийный номер | текст | Уникальный номер пропуска; генерируется, если не задан. |
| Токен авторизации | текст | Токен веб-сервиса Apple PassKit. |

### Конверт пропуска

*Формирует общие поля pass.json: идентификаторы Pass Type/Team, серийный номер, URL веб-сервиса и токен.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Версия формата | число | Всегда 1. |
| Идентификатор Pass Type | текст | Из настроек Apple. |
| Идентификатор команды | текст | Apple Team ID. |
| Серийный номер | текст | Уникальный номер пропуска. |
| Название организации | текст | Из настроек. |
| URL веб-сервиса | текст | Адрес PassKit для обновлений. |
| Токен авторизации | текст | Токен для запросов к веб-сервису. |
| Запрет шаринга | флаг | Всегда true. |
| Аннулирован | флаг | Всегда false при сборке. |

### Сборщик бонусной карты

*Формирует pass.json типа storeCard: баланс, владелец, цвета из дизайна лояльности и QR с ID клиента. Цвета и тексты берутся из дизайна лояльности, иначе значения по умолчанию.*

**Поля**

| Поле | Тип | Описание |
| --- | --- | --- |
| Поля storeCard | структура | Поле баланса и поле владельца карты. |

**Оформление**

| Поле | Тип | Описание |
| --- | --- | --- |
| Текст логотипа | текст | Из дизайна или имени организации. |
| Цвет фона | текст (rgb) | Из дизайна или #141828. |
| Цвет текста | текст (rgb) | Из дизайна или #FFFFFF. |
| Цвет подписей | текст (rgb) | Из дизайна или #AAAFC8. |
| Цвет полосы | текст (rgb) | Добавляется только если задан в дизайне. |
| Убрать блик полосы | флаг | Из дизайна. |

**Баркод**

| Поле | Тип | Описание |
| --- | --- | --- |
| QR-баркод | список | QR с ID клиента; дублируется в legacy-поле баркода. |

### Дизайн карты Apple Wallet

**Дизайн карты Apple Wallet** — см. [канонический глоссарий](/ru/logic/user/loyalty-glossary).

### Сборщик карты заказа

*Формирует pass.json типа generic: статус, сроки, точки, оплата заказа и QR с ID заказа. Срок действия и актуальная дата вычисляются из даты окончания аренды; цвета фиксированы.*

**Поля**

| Поле | Тип | Описание |
| --- | --- | --- |
| Поля generic | структура | Заголовочные, основные, второстепенные, вспомогательные и обратные поля заказа. |
| Номер заказа | текст | Плотный или обычный номер заказа. |
| Статус заказа | текст | Подпись из справочника статусов заказа. |
| Статус оплаты | текст | Подпись из справочника статусов оплаты. |
| Точка получения | текст | Название точки выдачи. |
| Точка возврата | текст | Точка возврата или та же, что получения. |

**Сроки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Срок действия | дата/время | Год от текущей даты либо окончание аренды + 30 дней. |
| Актуальная дата | дата/время | Дата окончания аренды, если задана. |

**Баркод**

| Поле | Тип | Описание |
| --- | --- | --- |
| QR-баркод | список | QR с ID заказа; дублируется в legacy-поле баркода. |

### Рендер иконок/логотипа

*Готовит PNG-файлы иконки, логотипа и полосы для пропуска из дизайна лояльности либо из логотипа арендатора. Иконка обязательна: при отсутствии дизайна логотип арендатора обрезается в квадрат; полоса необязательна.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Варианты изображений | список | Перечень изображений: базовое имя, поле-источник, режим вписывания. |
| Варианты из дизайна | функция | Собирает изображения @3x/@2x/@1x из полей дизайна. |
| Квадратный рендер | функция | Вписывает изображение в прозрачный квадрат заданного размера. |

### Упаковка и подпись пропуска

*Считает SHA1-манифест файлов, подписывает его и упаковывает всё в zip-архив .pkpass. Манифест и подпись добавляются в архив вместе с ресурсами.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Манифест | структура | SHA1-хэши всех файлов пропуска. |
| Подпись | двоичные данные | PKCS7-подпись манифеста. |

### PKCS7-подпись манифеста

*Создаёт отделённую DER-подпись PKCS7 сертификатами Apple и WWDR с приватным ключом.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Материал подписи | функция | Загружает и кэширует сертификат, WWDR и приватный ключ из настроек. |

### Конвертер цвета HEX→RGB

*Преобразует HEX-цвет в строку rgb(...), которую ожидает формат Apple pkpass.*

Отдельных полей нет.

## Статусы и справочники

### Тип пропуска

Определяет, к чему привязан пропуск: к бонусной карте или к заказу аренды.

- Бонусная карта
- Заказ

### Подписи статусов заказа

Сопоставление числовых статусов заказа с русскими подписями для карты.

- Заявка
- Резерв
- В аренде
- Отменён
- Завершён
- Должник

### Подписи статусов оплаты

Сопоставление числовых статусов оплаты заказа с русскими подписями для карты.

- Не оплачен
- Оплачен
- Частично
