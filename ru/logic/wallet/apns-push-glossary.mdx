## Модели и поля

### Пропуск (карта Wallet)

*Выпущенная карта Apple/Google Wallet, привязанная к клиенту или заказу арендатора. Живёт в публичной схеме; один пропуск на объект (уникальная тройка «компания + тип + связанный объект»).*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания (арендатор) | связь | FK на арендатора в public-схеме; владелец пропуска. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип пропуска | перечисление | Бонусная карта или заказ; индексируется. |
| ID связанного объекта | число | ID бонусной карты или заказа, к которому привязан пропуск; может быть пустым. |
| Серийный номер | текст | Уникальный серийный номер пропуска в системе Wallet. |
| Идентификатор типа пропуска | текст | Идентификатор типа пропуска Apple PassKit; индексируется. |
| Токен авторизации | текст | Секрет для проверки запросов пропуска; генерируется автоматически (16 байт hex). |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Аннулирован | флаг | Признак отозванного/недействительного пропуска. |
| Обновлён | дата/время | Время последнего изменения (auto_now); используется для push-обновлений. |
| Создан | дата/время | Время создания пропуска. |

### Регистрация устройства

*Регистрация устройства для push-обновлений конкретного пропуска через APNs. Одно устройство на пропуск (уникальная пара «пропуск + устройство»).*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Пропуск | связь | FK на пропуск, к которому привязана регистрация. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор устройства | текст | Идентификатор устройства Apple Wallet; индексируется. |
| Push-токен | текст | Токен устройства для отправки push через APNs. |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создана | дата/время | Время регистрации устройства. |

### Отправка push-обновления пропуска

*Функция, которая по серийному номеру пропуска собирает все регистрации устройств и рассылает им фоновые APNs-уведомления об обновлении. На ответ 400/410 удаляет неактуальную регистрацию; возвращает число успешно уведомлённых устройств.*

**Вход/выход**

| Поле | Тип | Описание |
| --- | --- | --- |
| Серийный номер пропуска | текст | Вход: по нему ищется объект пропуска. |
| Количество отправленных пушей | число | Сколько устройств вернули статус 200; 0 если пропуск не найден или регистраций нет. |

**Логика**

| Поле | Тип | Описание |
| --- | --- | --- |
| Список регистраций устройств | список | Все регистрации данного пропуска. |
| Заголовки APNs-запроса | структура | authorization (bearer JWT), apns-topic = идентификатор типа пропуска, apns-push-type = background, apns-priority = 5. |
| Хост APNs | текст | sandbox или production в зависимости от настроек. |

### Celery-задача push-обновления пропуска

*Фоновая обёртка над отправкой push-обновления с автоповтором при ошибках. Автоповтор для любых исключений, максимум 3 попытки, задержка повтора 10 с.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Серийный номер пропуска | текст | Аргумент задачи. |
| Количество отправленных пушей | число | Проброс результата отправки push-обновления. |

### Провайдер JWT-токена APNs

*Формирует и кэширует JWT-токен авторизации APNs, подписанный ключом ES256. Токен кэшируется в памяти на ~50 минут; при отсутствии ключа авторизации возникает ошибка.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Кэш JWT-токена | структура | Словарь `{токен, срок действия}` в памяти процесса. |
| Срок жизни токена | число (секунды) | 50 минут. |

### Выбор хоста APNs

*Возвращает адрес APNs: sandbox при включённом песочном режиме, иначе production.*

Функция без собственных полей — переключает адрес между песочным и боевым хостами APNs.
