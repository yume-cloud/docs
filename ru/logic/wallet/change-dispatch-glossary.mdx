## Понятия

Сквозные механизмы, которые связывают изменения данных с рассылкой обновлений на устройства.

| Понятие | Значение |
| --- | --- |
| Celery-задача push-обновления пропуска | Фоновая задача-обёртка: принимает серийный номер пропуска, отправляет push-обновление и возвращает количество отправленных пушей. При ошибке повторяется до трёх раз с задержкой 10 секунд. |
| Обработчик изменения заказа | Приёмник сигнала сохранения заказа: при изменении значимых полей запускает обновление пропуска типа «Заказ». Создание нового заказа пропускается; при точечном сохранении срабатывает только если затронуты значимые поля. |
| Значимые поля заказа | Набор полей заказа, изменение которых требует обновления пропуска: статус, статус оплаты, плановые и фактические даты аренды, точки выдачи и возврата, скидка и оплаченная сумма. |
| Пометка пропуска обновлённым | Находит непогашенные пропуска арендатора по типу и связанному объекту, поднимает время последнего изменения и после фиксации транзакции ставит задачи push на каждый серийный номер. Требует установленного контекста арендатора; при отсутствии пропусков ничего не делает. |
| Конфигурация приложения Wallet | Конфигурация модуля; при инициализации подключает обработчики сигналов сохранения заказа. |

## Модели и поля

### Пропуск (карта Wallet)

*Выпущенная карта Apple/Google Wallet, привязанная к клиенту или заказу арендатора. Живёт в публичной схеме; один пропуск на объект (уникальная тройка компания-тип-объект).*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания (арендатор) | связь | Владелец пропуска (компания-арендатор в публичной схеме). |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип пропуска | перечисление | Бонусная карта или заказ; индексируется. |
| ID связанного объекта | число | ID бонусной карты или заказа, к которому привязан пропуск; может быть пустым. |
| Серийный номер | текст | Уникальный серийный номер пропуска в системе Wallet. |
| Идентификатор типа пропуска | текст | Идентификатор типа пропуска в Apple PassKit; индексируется. |
| Токен авторизации | текст | Секрет для проверки запросов от приложения Wallet; генерируется автоматически (16 байт в шестнадцатеричном виде). |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Аннулирован | флаг | Признак отозванного или недействительного пропуска. |
| Обновлён | дата и время | Время последнего изменения; используется для push-обновлений. |
| Создан | дата и время | Время создания пропуска. |

### Регистрация устройства

*Регистрация устройства для push-обновлений конкретного пропуска. Одно устройство на пропуск (уникальная пара пропуск-устройство).*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Пропуск | связь | Пропуск, к которому привязана регистрация. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор устройства | текст | Идентификатор устройства в Apple Wallet; индексируется. |
| Push-токен | текст | Токен устройства для отправки push-уведомлений. |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создана | дата и время | Время регистрации устройства. |
