## Понятия

| Понятие | Значение |
| --- | --- |
| Подписка телефона | Телефон сообщает системе, что готов получать обновления по этой карте. Происходит сразу после добавления карты в Wallet. |
| Отписка телефона | Телефон сообщает, что карту удалили из Wallet. После этого уведомления по ней не отправляются. |
| Проверка изменений | Телефон периодически спрашивает, появилась ли новая версия карты, и сравнивает её с той, что у него уже есть. |
| Скачивание карты | Телефон забирает обновлённую карту и заменяет её в Wallet. Клиент видит новые данные, ничего не нажимая. |
| Секретный признак карты | Индивидуальный признак, выданный карте при выпуске. Телефон предъявляет его при каждом обращении; без него карту нельзя получить или обновить. |
| Номер карты | Уникальный номер выпущенной карты, по которому система её находит. |

## Что важно помнить

Все эти действия телефон выполняет **сам** — по расписанию и в ответ на уведомления об изменении. Клиент и сотрудник ничего не делают.

Знание номера карты не даёт к ней доступа: без секретного признака посторонний карту не скачает.

Один телефон может держать карты нескольких компаний одновременно — они не пересекаются, каждая карта привязана к своей компании.
