Справочник к странице [«Оформление карты Apple»](/ru/logic/wallet/apple-card).

## Понятия

| Понятие | Значение |
| --- | --- |
| Бонусная карта | Компактная карта клиента с балансом бонусов, именем владельца и QR-кодом. |
| Карта аренды | Карта конкретного заказа: номер, статус, сроки, точка выдачи и оплата; часть данных — на обороте. |
| Оформление карты | Набор фирменных настроек: цвета фона, текста и подписей, подпись рядом с логотипом, описание карты. Привязано к программе лояльности клиента. |
| Значения по умолчанию | Оформление, которое применяется, если своё не задано: тёмно-синий фон, белый текст, серо-голубые подписи, название организации из настроек. |
| QR-код | Код на бонусной карте с идентификатором клиента — по нему сотрудник опознаёт человека. Тот же номер печатается под кодом. |
| Оборот карты | Вторая сторона карты аренды: точка возврата, сумма к оплате и внесённая сумма. |
| Сообщение об изменении | Текст, который Apple Wallet показывает клиенту при обновлении баланса — «Ваш баланс обновлён». |

## Что важно помнить

Оформление задаётся в разделе уровней лояльности — см. [«Уровни лояльности и карты»](/ru/logic/user/loyalty). Если оформление не задано, карта всё равно выпустится, но в стандартных цветах.

Карту нельзя передать другому человеку — она привязана к своему владельцу.

Статусы заказа и оплаты выводятся понятными подписями, а не кодами: «Заявка», «Резерв», «В аренде», «Отменён», «Завершён», «Должник»; «Не оплачен», «Оплачен», «Частично».
