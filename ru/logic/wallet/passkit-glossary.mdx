## Понятия

| Понятие | Значение |
| --- | --- |
| Базовый вид веб-сервиса PassKit | Базовый класс для эндпоинтов Apple PassKit: отключает стандартную аутентификацию/пермишены и находит пропуск с проверкой токена. Отдаёт либо пропуск, либо ответ 404/401. |
| Регистрация/отмена устройства | Эндпоинт PassKit: регистрирует или удаляет привязку устройства к пропуску. Регистрация требует push-токен в теле, удаление снимает привязку. |
| Список обновлённых пропусков | Эндпоинт PassKit: возвращает серийные номера пропусков устройства, обновлённых после заданного момента. При отсутствии обновлений — пустой ответ. |
| Скачивание пропуска | Эндпоинт PassKit: отдаёт актуальный файл пропуска с учётом времени последнего изменения, подгружая исходный объект из схемы тенанта. Если объект удалён — ответ «более недоступен». |
| Лог PassKit | Эндпоинт PassKit: принимает лог-сообщения устройств Apple и пишет их в лог сервера; всегда отвечает успехом. |
| Проверка токена ApplePass | Вспомогательная функция: сверяет заголовок авторизации с ожидаемым токеном пропуска с защитой от timing-атак. |

## Модели и поля

### Пропуск (карта Wallet)

*Выпущенная карта Apple/Google Wallet, привязанная к клиенту или заказу арендатора. Живёт в публичной схеме; действует правило «один пропуск на объект» (компания, тип, объект).*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания (арендатор) | связь | Владелец пропуска; ссылка на компанию-арендатора в публичной схеме. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип пропуска | перечисление | Бонусная карта или заказ; индексируется. |
| ID связанного объекта | число | ID бонусной карты или заказа, к которому привязан пропуск; может быть пустым. |
| Серийный номер | текст | Уникальный серийный номер пропуска в системе Wallet. |
| Идентификатор типа пропуска | текст | Идентификатор типа пропуска Apple PassKit; индексируется. |
| Токен авторизации | текст | Секрет для проверки запросов ApplePass; генерируется автоматически (16 байт hex). |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Аннулирован | флаг | Признак отозванного/недействительного пропуска. |
| Обновлён | дата/время | Время последнего изменения; используется для push-обновлений. |
| Создан | дата/время | Время создания пропуска. |

### Регистрация устройства

*Регистрация устройства для push-обновлений конкретного пропуска через APNs. Действует правило «одно устройство на пропуск».*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Пропуск | связь | Пропуск, к которому привязана регистрация. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор устройства | текст | Идентификатор устройства Apple Wallet; индексируется. |
| Push-токен | текст | Токен устройства для отправки push через APNs. |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Создана | дата/время | Время регистрации устройства. |
