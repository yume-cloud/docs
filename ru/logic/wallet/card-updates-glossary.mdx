## Понятия

| Понятие | Значение |
| --- | --- |
| Бесшумное уведомление | Сигнал на телефон клиента о том, что карта устарела. Клиент его не видит и не слышит; телефон по этому сигналу забирает новую версию карты. |
| Подписка телефона | Запись о том, что на конкретном телефоне установлена конкретная карта. Появляется, когда клиент добавляет карту в Wallet, и определяет, куда отправлять уведомления. |
| Отметка изменения | Признак того, что карта изменилась. Именно по нему телефон понимает, что версия устарела и её нужно перекачать. |
| Самоочистка получателей | Автоматическое удаление подписки телефона, если он больше не принимает уведомления по этой карте: карту удалили или сменили устройство. |
| Номер карты | Уникальный номер выпущенной карты. По нему система находит, каким телефонам отправлять уведомление. |

## Что важно помнить

Автоматическое обновление есть только у **Apple Wallet**. Карты Google Wallet после выдачи не обновляются — клиенту нужно открыть ссылку выдачи заново.

Рассылку запускают значимые изменения **заказа**. Изменение баланса бонусов карту в Wallet не обновляет.

Если карта не установлена ни на одном телефоне, уведомления не отправляются — рассылать некому.

Телефон без сети получит обновление позже, когда снова окажется на связи.
