## Понятия

| Понятие | Значение |
| --- | --- |
| Пропуск (карта Wallet) | Выпущенная карта Apple/Google Wallet, привязанная к клиенту или заказу компании. Живёт в общих (глобальных) таблицах; один пропуск на объект в рамках компании. |
| Получение или создание пропуска | Хелпер: находит существующий пропуск по (компания, тип, объект) или создаёт новый с новым серийным номером. Гарантирует один пропуск на объект внутри компании. |
| Формирование ответа .pkpass | Хелпер: собирает файл .pkpass и оборачивает его в HTTP-ответ с заголовками скачивания (Content-Disposition, Last-Modified). |
| Выдача бонусной карты в Apple Wallet | Публичный обработчик: генерирует .pkpass для бонусной карты клиента и отдаёт файл на скачивание; создаёт или переиспользует пропуск. |
| Выдача заказа в Apple Wallet | Публичный обработчик: генерирует .pkpass для заказа аренды и отдаёт файл на скачивание; требует наличия клиента у заказа. |
| Выдача бонусной карты в Google Wallet | Публичный обработчик: возвращает ссылку сохранения бонусной карты в Google Wallet; клиент должен существовать. |
| Выдача заказа в Google Wallet | Публичный обработчик: возвращает ссылку сохранения заказа аренды в Google Wallet; клиент должен существовать. |

## Модели и поля

### Пропуск (карта Wallet)

*Выпущенная карта Apple/Google Wallet, привязанная к клиенту или заказу компании. Живёт в общих (глобальных) таблицах; один пропуск на объект в рамках компании (уникальность по паре компания + тип + объект).*

**Связи**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец пропуска; ссылка на компанию. |

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип пропуска | перечисление | Бонусная карта или заказ; индексируется. |
| ID связанного объекта | число | ID бонусной карты или заказа, к которому привязан пропуск; может быть пустым. |
| Серийный номер | текст | Уникальный серийный номер пропуска в системе Wallet. |
| Идентификатор типа пропуска | текст | Идентификатор типа пропуска Apple PassKit; индексируется. |
| Токен авторизации | текст | Секрет для проверки запросов к пропуску; генерируется автоматически. |

**Состояние**

| Поле | Тип | Описание |
| --- | --- | --- |
| Аннулирован | флаг | Признак отозванного/недействительного пропуска. |
| Обновлён | дата/время | Время последнего изменения; используется для push-обновлений. |
| Создан | дата/время | Время создания пропуска. |

## Статусы и справочники

### Тип пропуска

Определяет, к чему привязан пропуск: к бонусной карте или к заказу аренды.

- Бонусная карта
- Заказ
