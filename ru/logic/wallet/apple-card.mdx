Для Apple Wallet система собирает готовую карту с вашим оформлением. Этот раздел показывает, какие данные попадают на карту и чем можно управлять.

## Бонусная карта клиента

Компактная карта с балансом и логотипом.

| Место на карте | Подпись | Что показывает |
|---|---|---|
| Верхнее поле | «БАЛАНС» | текущий баланс бонусов клиента |
| Второе поле | «владелец карты» | имя клиента |

При обновлении баланса Apple Wallet показывает клиенту сообщение «Ваш баланс обновлён».

На карту помещается **QR-код** с идентификатором клиента — по нему сотрудник опознаёт человека. Тот же номер печатается под кодом, чтобы его можно было прочитать глазами.

## Карта аренды

Более подробная карта с несколькими рядами полей и оборотной стороной.

| Место на карте | Подпись | Что показывает |
|---|---|---|
| Верхнее поле | «ЗАКАЗ» | номер заказа |
| Главное поле | «СТАТУС» | статус заказа |
| Второе поле | «НАЧАЛО» | дата и время начала аренды |
| Второе поле | «ОКОНЧАНИЕ» | дата и время окончания аренды |
| Дополнительное | «ПОЛУЧЕНИЕ» | точка выдачи |
| Дополнительное | «ОПЛАТА» | статус оплаты |
| Оборот карты | «Возврат» | точка возврата |
| Оборот карты | «К оплате» | сумма к оплате с учётом скидки |
| Оборот карты | «Оплачено» | внесённая сумма |

Статусы выводятся понятными подписями: «Заявка», «Резерв», «В аренде», «Отменён», «Завершён», «Должник» — и «Не оплачен», «Оплачен», «Частично» для оплаты.

## Фирменное оформление

Цвета, подпись рядом с логотипом и описание карты берутся из **оформления карты**, привязанного к программе лояльности клиента. Так карта выглядит в ваших фирменных цветах.

Если оформление не задано, применяются значения по умолчанию:

| Параметр | По умолчанию |
|---|---|
| Цвет фона | тёмно-синий |
| Цвет текста | белый |
| Цвет подписей | серо-голубой |
| Подпись у логотипа | название вашей организации из настроек |
| Описание карты | описание из настроек |

<Note>
Цвет полосы и отключение блика на ней применяются только если заданы в оформлении явно. Задать оформление можно в разделе уровней лояльности — см. [«Уровни лояльности и карты»](/ru/logic/user/loyalty).
</Note>

<Info>
Карту нельзя передать другому человеку — она привязана к своему владельцу.
</Info>
