## Модели и поля

### Наименование сущности

*Переименование системной сущности (инвентарь, комплект, продукт, точка, услуга, клиент, депозит, мастерская, статусы аренды) на нужный язык со всеми падежными формами. Одна запись = ключ + язык. Если компания не указана — это глобальный набор, привязанный к типам компаний; если указана — переопределение компании. Уникальность (компания, язык, ключ) действует только для записей компании, глобальные записи не ограничены.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ записи, используется в адресе конкретного наименования |
| Ключ переименования | выбор из списка | Какую именно сущность или статус аренды переименовывает запись (см. «Ключ переименования») |
| Язык | выбор из списка | Язык, для которого заданы формы; выбирается из языков, поддерживаемых системой |

**Область действия**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец набора. Пусто — глобальный набор по умолчанию; заполнено — собственное наименование компании, которое перекрывает глобальное |
| Типы компаний | связь (много) | Типы бизнеса, которым выдаётся глобальный набор (прокат авто, самокаты и т. д.). Заполняется только у глобальных наборов |

**Единственное число**

| Поле | Тип | Описание |
| --- | --- | --- |
| Именительный падеж (ед. ч.) | текст | Базовая форма: кто? что? — например «Инвентарь» |
| Родительный падеж (ед. ч.) | текст | Кого? чего? — например «инвентаря» |
| Дательный падеж (ед. ч.) | текст | Кому? чему? — например «инвентарю» |
| Винительный падеж (ед. ч.) | текст | Кого? что? — например «инвентарь» |
| Творительный падеж (ед. ч.) | текст | Кем? чем? — например «инвентарём» |
| Предложный падеж (ед. ч.) | текст | О ком? о чём? — например «об инвентаре» |

### Глобальные наименования

*Наборы наименований по умолчанию, которые платформа заводит для типов компаний. Не отдельная таблица, а отдельное представление наименований в админке: показываются только записи без компании. Поле «Компания» у них недоступно, набор полей во всём остальном совпадает с наименованием сущности.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Типы компаний | связь (много) | Кому достаётся набор по умолчанию: компания получает глобальные наименования своего типа |
| Ключ переименования | выбор из списка | Переименовываемая сущность или статус аренды |
| Язык | выбор из списка | Язык набора по умолчанию |

### Наименования компании

*Собственные наименования конкретной компании, перекрывающие глобальные значения. Не отдельная таблица, а отдельное представление наименований в админке: показываются только записи с заполненной компанией. Набор полей совпадает с наименованием сущности.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Компания-владелец переопределения; обязательна для этого представления |
| Ключ переименования | выбор из списка | Переименовываемая сущность или статус аренды |
| Язык | выбор из списка | Язык, для которого компания задала свои формы |

*Определяет, какие поля наименования компания видит и может задать через интерфейс. Компания и типы компаний через API не передаются: принадлежность подставляется автоматически по текущей компании, а привязка к типам остаётся за платформой.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Возвращается для последующего изменения или удаления наименования |
| Ключ переименования | выбор из списка | Вместе с языком образует пару, по которой запись создаётся или обновляется |
| Язык | выбор из списка | Вторая половина пары «ключ + язык» |

### Список и сохранение наименований

*Отдаёт компании итоговый список наименований и принимает новые значения. В выдаче склеиваются глобальные наборы типа компании и собственные записи: по каждому ключу побеждает наименование компании. Сохранение работает как «создать или обновить» по паре ключ + язык, поэтому повторная отправка не плодит дубликаты. Изменять может только владелец компании, остальным доступно чтение.*

### Наименования по умолчанию

*Отдельная выдача глобальных наборов — значения, к которым можно вернуться. Возвращает только записи без компании, без учёта типа компании; доступна любому авторизованному пользователю.*

### Отдельное наименование

*Просмотр, изменение и удаление одного наименования компании. Работает только с записями текущей компании: глобальные наборы через него не редактируются и не удаляются. Удаление возвращает компанию к глобальному значению.*

## Статусы и справочники

### Ключ переименования

*Перечень сущностей и статусов аренды, названия которых компания может изменить под себя. Первые восемь значений — справочные сущности, остальные — статусы аренды.*

- Инвентарь
- Комплект
- Продукт
- Точка проката
- Услуга
- Клиент
- Депозит
- Мастерская
- Запрос
- Забронировано
- В прокате
- Отменено
- Завершено
- Должник
- Просрочено
- Удалено

### Падеж

*Справочник падежей, по которым заполняются формы наименования в единственном и множественном числе. Служит справочником: сами формы хранятся в отдельных полях наименования, а не выбором из этого списка.*

- Именительный (кто? что?)
- Родительный (кого? чего?)
- Дательный (кому? чему?)
- Винительный (кого? что?)
- Творительный (кем? чем?)
- Предложный (о ком? о чём?)
