## Модели и поля

### Значение настройки компании

*Сохранённое значение одной настройки конкретной компании. Пара «компания + ключ» уникальна; ключи без записи работают
на значении по умолчанию из реестра.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ строки |
| Компания | связь | Владелец значения настройки |
| Ключ настройки | текст | Имя параметра из реестра настроек |
| Значение | произвольное значение | Хранится в сериализованном виде, поэтому поддерживает списки, словари и длительности |

### Ленивый объект настроек

*Глобальная точка доступа к настройкам, которая инициализируется при первом обращении. Позволяет импортировать настройки
на старте приложения без обращения к базе.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Первичная инициализация | метод | Создаёт объект доступа к настройкам при первом обращении |

### Подключение модуля настроек

*Конфигурация приложения: при запуске регистрирует поисковые правила и обработчики изменений. Благодаря этим
обработчикам сохранение значения обновляет кэш; сброс параметра удаляет строку напрямую и кэш не трогает.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Имя приложения | текст | Идентификатор приложения настроек |
| Тип первичного ключа | текст | Тип автонумерации моделей приложения |
| Запуск приложения | метод | Подключает пользовательские поисковые правила и обработчики изменения настроек |

### Админ-раздел «Настройки»

*Раздел админ-панели со списком сохранённых значений и отдельной страницей редактирования всех параметров одной
компании. Доступ ограничен суперпользователем платформы, добавление вручную запрещено.*

**Список**

| Поле | Тип | Описание |
| --- | --- | --- |
| Колонки списка | список полей | Компания, ключ, значение и ссылка на страницу редактирования компании |
| Фильтры списка | список фильтров | Фильтр по компании через автодополнение и фильтр по ключу параметра |
| Поля поиска | список полей | Поиск по названию компании и по ключу параметра |
| Поля с автодополнением | список полей | Компания подставляется поиском, а не длинным выпадающим списком |
| Поля только для чтения | список полей | Компанию и ключ менять нельзя, редактируется только значение |
| Форма записи | класс формы | Форма одиночного значения, подбирающая тип поля по реестру параметров |
| Ссылка «Редактировать» | вычисляемая колонка | Ведёт на страницу всех настроек компании из строки списка |

**Доступ**

| Поле | Тип | Описание |
| --- | --- | --- |
| Право на добавление | правило доступа | Всегда запрещено: значения создаются только через страницу редактирования компании |
| Право на изменение | правило доступа | При включённом режиме «только суперпользователь» доступно лишь суперпользователю платформы |
| Право на удаление | правило доступа | Разрешено только суперпользователю, иначе запрещено полностью |

**Страница компании**

| Поле | Тип | Описание |
| --- | --- | --- |
| Регистрация адресов | метод | Добавляет адрес страницы настроек одной компании перед стандартными адресами раздела |
| Страница настроек компании | метод-страница | Показывает все параметры компании, обрабатывает сохранение и сброс, затем возвращает на ту же страницу |
| Сборка секций параметров | метод | Раскладывает параметры по секциям, подмешивая сохранённые значения компании поверх значений по умолчанию |

### Форма одиночной настройки

*Форма стандартной карточки значения: подставляет поле ввода, соответствующее типу параметра. Если ключ отсутствует
в реестре параметров, форма не открывается; для неизвестного типа берётся текстовое поле.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Состав формы | список полей | Идентификатор, компания, ключ и значение |
| Поле значения | поле ввода | Класс поля и виджет подбираются по типу параметра из карты типов |

### Карта типов и полей ввода

*Соответствие типа параметра классу поля формы и виджету ввода. Используется карточкой одиночного значения;
на странице компании применяется отдельный подбор виджета.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Флаг | поле-флажок | Необязательное поле, отсутствие отметки означает «выключено» |
| Целое число | числовое поле | Короткое текстовое поле ввода |
| Дробное число (точное) | десятичное поле | Используется для процентов и денежных лимитов |
| Дробное число | числовое поле | Обычное число с плавающей точкой |
| Строка | текстовая область | Необязательное поле в три строки |
| Структура (JSON) | текстовая область | Редактируется как текст, разбирается как JSON при сохранении |
| Дата и время | раздельные поля даты и времени | Стандартный виджет админки |
| Дата | поле даты | Стандартный календарь админки |
| Время | поле времени | Поддерживается картой типов, но в текущем реестре параметров не используется |
| Длительность | поле длительности | Вводится текстом в формате часы:минуты:секунды |

### Разбор описания параметра

*Возвращает значение по умолчанию, код и тип параметра, вычисляя тип по умолчанию, если он не указан явно. Описание
из двух элементов допустимо: тип определяется по значению по умолчанию.*

### Приведение введённого значения к типу

*Превращает текст из формы в значение нужного типа перед сохранением. Пустое значение сохраняется как «не задано»
(для флагов — как значение по умолчанию); при ошибке разбора текст сохраняется как есть.*

### Отображение значения в поле

*Обратное преобразование: готовит хранимое значение к показу в поле формы. Флаги показываются как ДА/НЕТ,
длительность — как часы:минуты:секунды, структуры — как JSON.*

### Строка параметра

*Описание одного параметра для таблицы на странице компании. Собирается заново при каждом открытии страницы,
в базу не сохраняется.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Ключ | текст | Имя параметра без префикса хранения; из него строится имя поля формы |
| Код | текст | Технический код параметра, показывается отдельной меткой |
| Название | текст | Подпись параметра: код, а при его отсутствии — сам ключ |
| Значение по умолчанию | текст | Подготовленное к показу значение из реестра параметров, выводится меткой в колонке «По умолчанию» |
| Текущее значение | текст | Сохранённое значение компании либо значение по умолчанию |
| Текущее значение (исходное) | произвольный тип | Непреобразованное значение, по нему определяется состояние переключателя |
| Вид поля | перечисление | Какой элемент управления рисовать |
| Изменено | флаг | Есть сохранённое значение компании; только для таких строк видна кнопка сброса |

### Секции параметров

*Разбивка таблицы параметров на именованные блоки. Состав секций берётся из настройки проекта; сейчас она не задана,
поэтому все параметры попадают в одну общую секцию.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название секции | текст | Заголовок блока; остаток параметров собирается в секцию «Все настройки» |
| Строки секции | список | Параметры, попавшие в блок, в порядке реестра |

### Страница настроек компании (шаблон)

*Таблица всех параметров компании с полями ввода, значением по умолчанию, кодом и кнопкой сброса. Сохранение одной
кнопкой внизу страницы; отправляются только изменённые значения.*

**Форма**

| Поле | Тип | Описание |
| --- | --- | --- |
| Форма страницы | форма | Единая форма для всех секций, отправляется кнопкой «Сохранить» в нижней панели |
| Поле параметра | поле ввода | Имя поля собирается из ключа параметра; невыставленный флажок трактуется как «выключено» |
| Действие | скрытое значение кнопки | Сохранение или сброс |
| Ключ для сброса | скрытое поле | Заполняется при нажатии кнопки сброса в строке параметра |

**Управление**

| Поле | Тип | Описание |
| --- | --- | --- |
| Кнопка сброса | кнопка | Видна только у изменённых параметров, отправляет форму без проверки полей |
| Связка палитры и текста | поведение | Выбор цвета и текстовое поле с кодом цвета синхронизируются в обе стороны |
| Панель сохранения | блок | Закреплена внизу экрана |

### Наименование сущности

*Переименование системной сущности (инвентарь, комплект, продукт, точка, услуга, клиент, депозит, мастерская, статусы
аренды) на нужный язык со всеми падежными формами. Одна запись = ключ + язык. Если компания не указана — это глобальный
набор, привязанный к типам компаний; если указана — переопределение компании. Уникальность (компания, язык, ключ)
действует только для записей компании, глобальные записи не ограничены.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ записи, используется в адресе конкретного наименования |
| Ключ переименования | выбор из списка | Какую именно сущность или статус аренды переименовывает запись (см. «Ключ переименования») |
| Язык | выбор из списка | Язык, для которого заданы формы; выбирается из языков, поддерживаемых системой |

**Область действия**

| Поле | Тип | Описание |
| --- | --- | --- |
| Компания | связь | Владелец набора. Пусто — глобальный набор по умолчанию; заполнено — собственное наименование компании, которое перекрывает глобальное |
| Типы компаний | связь (много) | Типы бизнеса, которым выдаётся глобальный набор (прокат авто, самокаты и т. д.). Заполняется только у глобальных наборов |

**Единственное число**

| Поле | Тип | Описание |
| --- | --- | --- |
| Именительный падеж (ед. ч.) | текст | Базовая форма: кто? что? — например «Инвентарь» |
| Родительный падеж (ед. ч.) | текст | Кого? чего? — например «инвентаря» |
| Дательный падеж (ед. ч.) | текст | Кому? чему? — например «инвентарю» |
| Винительный падеж (ед. ч.) | текст | Кого? что? — например «инвентарь» |
| Творительный падеж (ед. ч.) | текст | Кем? чем? — например «инвентарём» |
| Предложный падеж (ед. ч.) | текст | О ком? о чём? — например «об инвентаре» |

**Множественное число**

| Поле | Тип | Описание |
| --- | --- | --- |
| Именительный падеж (мн. ч.) | текст | Базовая форма множественного числа — например «Инвентари» |
| Родительный падеж (мн. ч.) | текст | Кого? чего? — например «инвентарей» |
| Дательный падеж (мн. ч.) | текст | Кому? чему? — например «инвентарям» |
| Винительный падеж (мн. ч.) | текст | Кого? что? — например «инвентари» |
| Творительный падеж (мн. ч.) | текст | Кем? чем? — например «инвентарями» |
| Предложный падеж (мн. ч.) | текст | О ком? о чём? — например «об инвентарях» |

### Глобальные наименования

*Наборы наименований по умолчанию, которые платформа заводит для типов компаний. Не отдельная таблица, а отдельное

| Поле | Тип | Описание |
| --- | --- | --- |

### Настройка таблицы

*Сохранённая раскладка колонок одной таблицы интерфейса для конкретной компании. Название уникально в рамках компании:
пара «компания + название» задана ограничением, поэтому повторное создание с занятым названием возвращает ошибку
«Настройка с таким названием уже существует».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Внутренний номер записи, отдаётся в ответе API |
| Название таблицы | текст | Ключ таблицы, к которой относится раскладка; по нему же идёт обращение к отдельной настройке (чтение, изменение, удаление выполняются по названию, а не по идентификатору) |
| Описания колонок | список | Массив описаний колонок таблицы: каждый элемент задаёт ключ колонки, её ширину и включённость |
| Компания | связь | Компания-владелец настройки; выборка и создание всегда ограничены текущей компанией |

### Промо-баннер

*Рекламный баннер платформы, который показывается сотрудникам компаний в интерфейсе. Баннеры общие для всей платформы
(создаются в админке), а ограничения и журнал показов ведутся по компаниям и пользователям внутри одной записи.*

**Идентификация**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Числовой номер баннера, по нему баннер отмечается прочитанным |

**Содержимое**

| Поле | Тип | Описание |
| --- | --- | --- |
| Заголовок | текст | Обязательный заголовок баннера |
| Описание | длинный текст | Обязательный текст баннера |
| Промокод | текст | Код, который предлагается пользователю; может быть пустым |
| Иконка | текст | Название иконки для оформления баннера; может быть пустым |
| Ссылка | текст | Адрес перехода по клику на баннер; может быть пустым |
| Изображение | изображение | Картинка баннера, загружается в папку promo/ |
| Анимация | файл | Анимированный файл баннера, загружается в папку promo/ |

**Показ**

| Поле | Тип | Описание |
| --- | --- | --- |
| Периодичность показа | число (часы) | Через сколько часов после последнего показа баннер можно показать тому же пользователю снова; по умолчанию 24 |
| Журнал показов | структура (объект) | Отметки о показах в разрезе компания → пользователь → время последнего показа |

**Доступность**

| Поле | Тип | Описание |
| --- | --- | --- |
| Чёрный список компаний | список чисел | Компании, которым баннер не показывается вовсе |
| Активен | флаг | Выключенный баннер не участвует в подборе; по умолчанию включён |

### Баннеры в админке

*Страница платформенной админки, где создаются и отключаются баннеры. Список показывает заголовок и флаг активности,
поиск идёт по заголовку, описанию, промокоду и ссылке.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Колонки списка | список полей | Заголовок и признак активности |
| Поля поиска | список полей | Заголовок, описание, код и ссылка |
| Фильтр | список фильтров | По признаку активности |

### Сквозной счётчик

*Хранит текущее значение автонумерации для пары «компания + ключ счётчика». Номер выдаётся с блокировкой строки,
поэтому одновременные запросы не получают одинаковых номеров; пара «компания + ключ» уникальна, счётчики разных
компаний независимы.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Внутренний номер записи счётчика |
| Компания | связь | Владелец счётчика; у каждой компании свой набор счётчиков |
| Ключ счётчика | текст (до 40 символов) | Что именно нумеруется: клиенты, единицы конкретного продукта, документы конкретного шаблона |
| Текущее значение | целое число (неотрицательное) | Номер, который будет выдан следующим; после выдачи увеличивается |
