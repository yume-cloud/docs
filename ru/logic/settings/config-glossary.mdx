## Модели и поля

### Значение настройки компании

*Сохранённое значение одной настройки конкретной компании. Пара «компания + ключ» уникальна; ключи без записи работают на значении по умолчанию из реестра.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ строки. |
| Компания | связь | Владелец значения настройки. |
| Ключ настройки | текст | Имя параметра из реестра настроек. |
| Значение | произвольное значение | Хранится в сериализованном виде, поэтому поддерживает списки, словари и длительности. |

### Ленивый объект настроек

*Глобальная точка доступа к настройкам, которая инициализируется при первом обращении. Позволяет импортировать настройки на старте приложения без обращения к базе.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Первичная инициализация | метод | Создаёт объект доступа к настройкам при первом обращении. |

### Хранилище настроек

*Читает и записывает значения настроек, поддерживая кэш по каждой компании. Кэш прогревается целиком на сутки; массовое сохранение и сохранение из админки сбрасывают кэш компании.*

| Поле | Тип | Описание |
| --- | --- | --- |
| **Операции** | | |
| Прочитать значение | операция | Берёт из кэша, при промахе прогревает кэш и обращается к базе. |
| Прочитать набор значений | операция | Одним запросом достаёт сохранённые значения по списку ключей. |
| Сохранить значение | операция | Пишет в базу и сразу обновляет кэш. |
| Сохранить набор значений | операция | Пишет пачку значений, затем сбрасывает и заново прогревает кэш. |
| **Кэш** | | |
| Прогрев кэша | операция | Загружает все настройки компании в кэш на сутки. |
| Сброс кэша | операция | Чистит кэш всех ключей компании и прогревает его заново. |
| Сброс по изменению | операция | Срабатывает при сохранении значения настройки вне массового обновления. |

### Настройки компании (API)

*Единая точка чтения и обновления всего набора настроек компании. Читают сотрудники и субарендодатели, изменяет только владелец компании; ответ — значения по умолчанию, перекрытые сохранёнными значениями компании.*

### Схема настроек компании

*Описывает состав и типы настроек, доступных через API. Повторяет реестр настроек за вычетом служебных ключей (буфер между арендами, периодичность инвентаризации, первоначальный взнос, тип фильтрации, автоучёт дней недели, процент за сбор, секрет разбора выписок); дополнительные поля и режим тарификации документов доступны только для чтения; пустые значения при сохранении записываются как пустая строка.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Дополнительные поля справочников | словарь | Отдаётся только на чтение, меняется отдельной точкой API. |
| Режим тарификации документов | текст | Только чтение: назначается платформой, компания изменить не может. |
| Проверка срока аренды | проверка | Запрещает отрицательную продолжительность. |
| Проверка штрафного интервала | проверка | Запрещает отрицательную продолжительность. |

### Вариант штрафа

*Описывает один пресет штрафа в настройках. Из таких элементов состоит настройка «Варианты штрафов».*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Подпись варианта штрафа, например посменный или почасовой. |
| Интервал | длительность | Шаг, за который начисляется штраф. |

### Поле длительности настройки

*Отдаёт длительность настройки, подставляя ноль вместо пустого значения. Строковые значения разбираются в длительность.*

### Дробное поле настройки

*Отдаёт дробное значение настройки, подставляя ноль вместо пустого значения. Применяется к процентам, ставкам и денежным лимитам.*

### Целочисленное поле настройки

*Отдаёт целое значение настройки, подставляя ноль вместо пустого значения. Применяется к числовым параметрам вроде длины ИИН или округления.*

## Статусы и справочники

### Тип штрафа

*Способ начисления штрафа за просрочку аренды. Хранится в настройке «Тип штрафа».*

- От момента просрочки
- За интервал просрочки

### Приоритет подбора инвентаря

*Какой инвентарь предлагать в аренду в первую очередь. Хранится в настройке «Приоритет подбора инвентаря».*

- Свой инвентарь компании
- Субарендный инвентарь
- Весь инвентарь
