## Модели и поля

### Значение настройки компании

*Сохранённое значение одной настройки конкретной компании. Пара «компания + ключ» уникальна; ключи без записи работают на значении по умолчанию из реестра.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Первичный ключ строки |
| Компания | связь | Владелец значения настройки |
| Ключ настройки | текст | Имя параметра из реестра настроек |
| Значение | произвольное значение | Хранится в сериализованном виде, поэтому поддерживает списки, словари и длительности |

### Реестр настроек компании

*Словарь всех настроек системы: ключ → значение по умолчанию, служебная подпись и тип значения; через него же идёт чтение и запись значений компании. Задаётся в конфигурации модуля и может быть переопределён на уровне проекта; значение по умолчанию действует, пока компания не сохранила своё.*

### Хранилище настроек

*Читает и записывает значения настроек, поддерживая кэш по каждой компании. Кэш прогревается целиком на сутки; массовое сохранение и сохранение из админки сбрасывают кэш компании.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Прочитать значение | операция | Берёт из кэша, при промахе прогревает кэш и обращается к базе |
| Прочитать набор значений | операция | Одним запросом достаёт сохранённые значения по списку ключей |
| Сохранить значение | операция | Пишет в базу и сразу обновляет кэш |
| Сохранить набор значений | операция | Пишет пачку значений, затем сбрасывает и заново прогревает кэш |

### Параметры модуля настроек

*Набор общих параметров самого модуля: реестр ключей, механизм хранения, префикс, время жизни кэша, секции и правила доступа. Каждый параметр можно переопределить в общей конфигурации проекта.*

**Параметры**

| Поле | Тип | Описание |
| --- | --- | --- |
| Реестр параметров | упорядоченный справочник | Перечень всех ключей с значением по умолчанию, кодом и типом — источник состава страницы настроек |
| Секции параметров | справочник | Группировка ключей по блокам страницы настроек; по умолчанию пусто |

**Хранение**

| Поле | Тип | Описание |
| --- | --- | --- |
| Механизм хранения | текст | Путь к слою хранения, читающему и пишущему значения; по умолчанию хранение в базе с кэшем |
| Префикс ключа хранения | текст | Добавляется к ключу при чтении и записи значения; по умолчанию пустой |

**Кэш**

| Поле | Тип | Описание |
| --- | --- | --- |
| Срок предзаполнения кэша | число (секунды) | Сутки по умолчанию: на это время весь набор значений компании прогревается в кэше; ноль отключает предзаполнение |

**Доступ**

| Поле | Тип | Описание |
| --- | --- | --- |
| Только для суперпользователя | флаг | Включён по умолчанию: правка и удаление настроек в админке доступны лишь суперпользователю платформы |

Ранее модуль имел собственные параметры подключения к кэш-серверу (класс подключения, адрес, префикс, срок жизни, версия формата хранения), список дополнительных полей и отключение проверки версии админки — сейчас эти параметры не используются.

### Поле сериализованного значения

*Тип поля, позволяющий положить в одну колонку значение любого вида. Надстройка над стандартным полем сериализации: без сжатия, фиксированная версия формата.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Сжатие | флаг | По умолчанию выключено |
| Версия формата | число | Версия сериализации, по умолчанию 2 |
| Копирование значения | флаг | Значение копируется перед сохранением, чтобы исходный объект не менялся |
| Редактируемость | флаг | Поле доступно для правки в админке |

### Безопасная работа с кэшем

*Обёртки над кэшем: при сбое кэша пишут предупреждение в журнал и не роняют запрос. Все обращения модуля настроек к кэшу идут только через эти функции.*

**Обычные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Чтение значения | метод | При ошибке возвращает значение по умолчанию |
| Запись значения | метод | Возвращает признак успеха |
| Запись, если ключа ещё нет | метод | Не перетирает существующее значение; при ошибке считается успешной |
| Удаление ключа | метод | Убирает одно значение из кэша |
| Пакетная запись | метод | Кладёт сразу набор пар «ключ — значение» |
| Пакетное удаление | метод | Используется при полном сбросе кэша компании |

**Асинхронные**

| Поле | Тип | Описание |
| --- | --- | --- |
| Асинхронное чтение | метод | Асинхронный вариант чтения значения |
| Асинхронная запись | метод | Асинхронный вариант записи значения |
| Асинхронная запись, если ключа нет | метод | Асинхронный вариант записи без перезаписи |
| Асинхронное удаление | метод | Асинхронный вариант удаления ключа |

### Подавление реакций на сохранение

*Временное отключение обработчиков сохранения настроек на время массовой записи. Нужно, чтобы кэш не сбрасывался на каждой строке; после записи кэш сбрасывается один раз целиком.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Признак подавления | флаг | Переменная контекста, по умолчанию выключена; действует только внутри текущего запроса или фоновой задачи |
| Проверка подавления | метод | Обработчики спрашивают её перед тем, как что-то делать |

### Обработчик сохранения настройки

*Реакция на сохранение настройки: кладёт новое значение в кэш в схеме своей компании.*

Не срабатывает при подавлении сигналов; пишет ключ без номера компании, поэтому основную инвалидацию делает сброс кэша в бэкенде.

### Заглушка компании

*Объект, который подставляется вместо компании, когда работа идёт вне контекста конкретной компании.*

При заглушке чтение настройки возвращает пусто, запись и прогрев кэша молча пропускаются.
