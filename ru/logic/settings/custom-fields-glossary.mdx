## Модели и поля

### Дополнительное поле

*Описание пользовательского поля, которое компания добавляет к карточке справочника или аренды. Пустая привязка к компании = глобальное
поле платформы; имя уникально в рамках пары «компания + раздел»; список полей упорядочен по разделу и позиции, кэшируется на сутки
и сбрасывается при сохранении или удалении записи. С 2 октября 2026 года — единственное хранилище дополнительных полей.*

**Привязка**

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Номер записи; по нему работают чтение, правка и удаление одного поля. При сохранении целыми разделами поля сопоставляются по имени. |
| Компания | связь | Владелец поля. Если не заполнено — поле глобальное и попадает в список всех компаний. |
| Раздел | список | К какой сущности относится поле: клиент, документ клиента, инвентарь, авто, комплект, продукт, точка, категория, аренда, позиция аренды, услуга, лид, мастерская, документ, шаблон. |

**Название и подсказки**

| Поле | Тип | Описание |
| --- | --- | --- |
| Имя поля | текст | Техническое имя, по которому значение сохраняется в карточке; не может повторяться внутри одного раздела компании. |
| Подпись | текст | Название поля, которое видит пользователь в интерфейсе. |
| Подсказка | текст | Текст-заполнитель внутри пустого поля. |

**Поведение в интерфейсе**

| Поле | Тип | Описание |
| --- | --- | --- |
| Обязательное | флаг | Поле нужно заполнить, чтобы сохранить карточку. |
| Показывать в таблице | флаг | Поле выводится отдельной колонкой в списке раздела. |
| Доступно в фильтрах | флаг | По полю можно отбирать записи в фильтрах раздела. |

**Тип значения**

| Поле | Тип | Описание |
| --- | --- | --- |
| Тип значения | список | Как заполняется поле: текст, число, дата, флажок, цвет или ссылка на другую сущность. |
| Варианты значений | список | Заранее заданный набор вариантов для выбора; по умолчанию пустой список. Значение обязано быть именно списком. |
| Позиция | число | Порядок поля внутри раздела, начиная с 0. Задаётся порядком в списке при сохранении раздела; у отдельной записи только для чтения. |

### Кэш списка дополнительных полей

*Механизм выдачи и кэширования списка дополнительных полей компании. В список попадают поля компании вместе с глобальными полями
платформы; вне контекста компании возвращается пустой список.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Ключ кэша | текст | Отдельный ключ кэша на каждую компанию. |
| Срок жизни кэша | число (секунды) | Сутки: список полей перечитывается из базы не чаще раза в день. |
| Сброс кэша | обработчик | Кэш компании очищается при сохранении и удалении дополнительного поля; изменение глобального поля кэш компаний не сбрасывает. |

### Описание поля в разделе

*Одно дополнительное поле как элемент списка раздела при сохранении целыми разделами. У поля нет идентификатора: оно сопоставляется
с записью справочника по имени, а свойства, которые не переданы, получают значения по умолчанию. Набор типов здесь короче общего:
ссылок на услугу, ремонт, документ и шаблон нет.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Имя поля | текст | Обязательное техническое имя поля. |
| Подпись | текст | Название поля в интерфейсе; по умолчанию пустое. |
| Подсказка | текст | Текст-заполнитель; допускается пустое значение. |
| Обязательное | флаг | По умолчанию выключено. |
| Показывать в таблице | флаг | По умолчанию выключено. |
| Доступно в фильтрах | флаг | По умолчанию выключено. |
| Тип значения | список | По умолчанию строка. |
| Варианты значений | список | Список текстовых вариантов; по умолчанию пустой. |

### Набор дополнительных полей по разделам

*Способ записи целыми разделами: поля передаются одним объектом, сгруппированным по разделам. Каждый переданный раздел заменяет поля
компании в этом разделе — по имени, в порядке списка, с удалением непереданных полей. При частичном сохранении непереданные разделы
не меняются, при полном — очищаются. Тот же объект отдаётся в общем ответе настроек. Разделов мастерской, документа, шаблона и
транспорта в нём нет. До 2 октября 2026 года объект хранился в настройке компании отдельно от справочника.*
