## Модели и поля

### Сквозной счётчик

*Хранит текущее значение автонумерации для пары «компания + ключ счётчика». Номер выдаётся с блокировкой строки, поэтому одновременные запросы не получают одинаковых номеров; пара «компания + ключ» уникальна, счётчики разных компаний независимы.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Идентификатор | число | Внутренний номер записи счётчика |
| Компания | связь | Владелец счётчика; у каждой компании свой набор счётчиков |
| Ключ счётчика | текст (до 40 символов) | Что именно нумеруется: клиенты, единицы конкретного продукта, документы конкретного шаблона |
| Текущее значение | целое число (неотрицательное) | Номер, который будет выдан следующим; после выдачи увеличивается |

**Клиент** — см. [канонический глоссарий](/ru/logic/metrics/referrals-clients-glossary#клиент).

**Продукт** — см. [канонический глоссарий](/ru/logic/inventory/inventory-groups-glossary#продукт).

**Единица инвентаря** — см. [канонический глоссарий](/ru/logic/inventory/inventory-items-glossary#единица-инвентаря).

**Форма массового создания единиц** — см. [канонический глоссарий](/ru/logic/inventory/inventory-groups-glossary#форма-создания-единиц-из-продукта).

### Форма документа

*Правила создания и изменения документа, в том числе выдачи ему сквозного номера. Перевыпуск создаёт новый документ и получает новый номер, а перегенерация обновляет содержимое и номер сохраняет; загруженные файлы номер не получают.*

| Поле | Тип | Описание |
| --- | --- | --- |
| Название | текст | Если не задано, собирается из названия шаблона и номера аренды |
| Источник | список | Сформирован по шаблону или загружен файлом |
| Файл | файл | Для загруженных документов; не-PDF конвертируется в PDF |
| Шаблон | связь | Доступны только активные шаблоны компании |
| Объект | число | Номер аренды, по которой заполняется документ |
| Тип объекта | текст | Берётся из шаблона |
| Перегенерировать | флаг | Пересобрать содержимое по шаблону, номер не меняется |
| Перевыпустить | флаг | Создать новый документ вместо подписанного; получает следующий номер |
| Файлы | список | Прикреплённые файлы документа |
| Подписи | список | Подписи и их статусы |
| Содержимое | текст | Итоговый текст документа |

**Документ** — см. [канонический глоссарий](/ru/logic/documents/crud-glossary#документ).

## Статусы и справочники

### Ключи счётчиков

*Набор ключей, под которыми компания ведёт независимые сквозные нумерации. Это не фиксированный перечень: ключи складываются в местах использования, поэтому у продуктов и шаблонов документов каждый свой счётчик.*

- Номера клиентов
- Порядковые номера единиц продукта
- Номера документов по шаблону
- Номера документов без шаблона
